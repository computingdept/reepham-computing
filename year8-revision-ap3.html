COMPUTER SYSTEMS

Recall → Check → Fix → Challenge

RecallTry from memory first.
CheckChoose the best answer.
FixUse the small knowledge card if needed.
ChallengeExplain it in your own words.
Recall: Which process turns input data into useful output?
Fix: The revision material describes computer systems using input, processing, output and storage.
Check: A self-checkout scans a barcode, looks up the item and shows the price. Which is the output?
Fix: An output device presents data from the computer.
Challenge: Explain the difference between an input device and a computer system.
An input device puts data into a computer system, whereas a computer system includes the parts needed to input, process, output and store data.

INPUT & OUTPUT

Recall → Check → Fix → Challenge

Recall: Which group contains only input devices from the revision guide?
Fix: Input devices put data into a computer system. Examples include keyboard, mouse, scanner, camera and microphone.
Check: Which device can be both input and output?
Fix: The revision guide notes that touchscreens, headsets and some games controllers can be both input and output.
Challenge: Give one input and one output you might find in a supermarket self-checkout.
Example: barcode scanner = input; screen or receipt printer = output.

COMPUTER COMPONENTS

Recall → Check → Fix → Challenge

Recall: Which component connects the other computer parts together?
Fix: The motherboard is the main circuit board that connects computer parts together.
Check: Which component stores programs and files long term?
Fix: The revision booklet describes the hard drive as storage for programs and files.
Challenge: What is the job of the PSU?
The power supply unit gives power to the computer.

CPU

Recall → Check → Fix → Challenge

Recall: Put the CPU cycle in the correct order.
Fix: The CPU fetches instructions from memory, decodes them and then executes them.
Check: What does the Control Unit do?
Fix: CU = Control Unit. ALU = calculations and logic. Cache = small fast memory close to the CPU.
Challenge: Explain one way a CPU can be made faster.
Example: A faster clock speed allows the CPU to complete more fetch-decode-execute cycles every second.

RAM, ROM & STORAGE

Recall → Check → Fix → Challenge

Recall: Which memory stores data and programs currently being used?
Fix: RAM stores current data/programs, is read/write and is volatile.
Check: Which statement describes ROM in the lesson?
Fix: ROM stores a start-up program and its data is not lost when power is removed.
Challenge: Compare RAM and ROM. Use “whereas” or “however”.
RAM stores data and programs currently being used and is volatile, whereas ROM stores a start-up program and is non-volatile.

BINARY

Recall → Check → Fix → Challenge

Recall: What is a binary digit called?
Fix: 0 or 1 = one bit. Four bits = one nibble. Eight bits = one byte.
Check: What is 10000011 in denary?
Fix: Use the place values 128, 64, 32, 16, 8, 4, 2, 1. Here 128 + 2 + 1 = 131.
Challenge: Convert denary 75 into 8-bit binary.
75 = 64 + 8 + 2 + 1, so the 8-bit binary value is 01001011.
