Binary search reminder
low = 0
high = size - 1
mid = (low + high) DIV 2

The data must be sorted.

Bubble sort reminder

Compare adjacent values and swap them when they are in the wrong order. After each pass, the largest remaining value has bubbled right.

Insertion sort reminder

Treat the left side as sorted. Take the next value and insert it into the correct position in that sorted section.

Merge sort reminder

Repeatedly split the list into smaller lists, then merge the lists back together in order.
