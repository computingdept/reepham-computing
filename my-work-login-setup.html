My Work · Staff setup

Private preparation for anonymous student usernames. This page does not upload anything until you select Activate logins.

1 · Prepare login details

Paste two columns from your private school spreadsheet: Username then Practice code. One student per line. You can paste directly from Excel.

No names or school email addresses. The passwords will be generated on this device. Keep the downloaded file in restricted school OneDrive storage.

2 · Save the credentials privately

Download the generated file before activating anything. It contains anonymous usernames, their existing practice codes and individual passwords.

If you need to retry later, paste the saved three-column file back into the box above. It will reuse the same passwords.

3 · Activate the logins

Enter your private Cloudflare teacher token. It is used only for this request and is not stored by this page.

The teacher token is required for every batch. On interruption, use the same downloaded file to continue; already imported entries can safely be retried.
