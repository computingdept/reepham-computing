# H446 original teaching visuals

Use [the shared Computing Visual Standard](../VISUAL-STANDARD.md). H446 uses exactly the same black-and-white artwork and **shape-following, blurred school-colour glows** as J277. Only the school's approved glow colour varies at the build stage.

Candidate diagram references are recorded in `data/exam-questions/h446-visual-assets.csv` and remain **planned** until the original H446 question paper and its marking scheme are independently checked. Do not recreate OCR drawings or disclose worked answers in a student-facing question diagram.

All approved SVGs will have separate desktop and mobile layouts and will be linked to the H446 question bank. As with J277, **no live lessons change during the asset audit**.
