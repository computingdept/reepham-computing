DEMO 2 OF 2 · QUESTION SCREEN · LESSON 020

Implement push/pop in C#

Create an integer stack array and write code that pushes 5, 8 and 3, then pops and prints one item.

DEMO 2 OF 2 · MODEL ANSWER · LESSON 020

Model code: implement push/pop

int[] stack = new int[5];
int top = -1;
top++; stack[top] = 5;
top++; stack[top] = 8;
top++; stack[top] = 3;
Console.WriteLine(stack[top]); // 3
top--;
Console.WriteLine(stack[top]); // 8

Check your method

The top pointer becomes 1, pointing to 8.
