Lesson 089 · The Processor City: Architecture Overview

By the end you can…
  • Inside CPU City Hall, the Control Unit organises operations, the ALU carries out arithmetic and logic, and registers hold immediate working state.
  • The Memory Warehouse stores program instructions and data. Address, data and control buses connect processor and memory; they carry different kinds of information.
  • Von Neumann architecture stores instructions and data in a shared memory/address space, whereas Harvard uses separate instruction and data memories/pathways.

Explore the model

CPU 'CITY HALL' = ALU + CONTROL UNIT + REGISTERS
MEMORY 'WAREHOUSE' = stored instructions and data
BUSES 'HIGHWAYS' = address, data, control links
PC = address of next instruction
CIR = current instruction being decoded/executed
