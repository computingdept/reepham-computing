CODING CHALLENGE 1

Student names

using System;

public class Program
{
    public static void Main()
    {
        string[] studentNames =
        {
            "Amelia", "Ben", "Charlie", "Daisy", "Ethan"
        };

        Console.WriteLine(studentNames[0]);
        Console.WriteLine(studentNames[studentNames.Length - 1]);

        for (int i = 0; i < studentNames.Length; i++)
        {
            Console.WriteLine(studentNames[i]);
        }
    }
}

Key idea: a one-dimensional array needs one index. The final valid index is one less than its length.

First = AmeliaLast = Ethan5 names displayed

    {
        string[,] studentResults =
        {
            { "Amelia", "72" },
            { "Ben", "65" },
            { "Charlie", "81" },
            { "Daisy", "59" },
            { "Ethan", "90" }

        Console.WriteLine(studentResults[0,0]);
        Console.WriteLine(studentResults[0,1]);

Why strings? one rectangular array has one element type. In this teaching example, both the name and the score are stored as strings.

CODING CHALLENGE 3

Traverse every result

using System;

public class Program
{
    public static void Main()
    {
        string[,] studentResults =
        {
            { "Amelia", "72" },
            { "Ben", "65" },
            { "Charlie", "81" },
            { "Daisy", "59" },
            { "Ethan", "90" }
        };

        for (int row = 0;
             row < studentResults.GetLength(0);
             row++)
        {
            Console.WriteLine(
                studentResults[row,0] + " " +
                studentResults[row,1]);
        }
    }
}

Why GetLength(0)? dimension 0 is the row count, so the loop automatically follows however many students are stored.

No hard-coded 5 in loop conditionAll rows displayed
CODING CHALLENGE 4

Room readings

using System;

public class Program
{
    public static void Main()
    {
        int[,,] readings = new int[2,3,4];

        readings[1,2,3] = 21;

        Console.WriteLine(readings[1,2,3]);
        Console.WriteLine(readings.GetLength(0));
        Console.WriteLine(readings.GetLength(1));
        Console.WriteLine(readings.GetLength(2));
    }
}

Three dimensions: the array needs three indexes, and each dimension can be queried separately with GetLength().

Value = 21Lengths = 2, 3, 424 elements in total
