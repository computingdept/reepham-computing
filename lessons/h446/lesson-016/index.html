OCR H446 · 1.4.2(a)

Arrays up to 3 dimensions

string[] names;
string[,] results;
int[,,] readings;
Core rule: one array has one element type. More dimensions mean more indexes are needed to locate one element.
STEP 1 OF 4

1D · one index

string[] students =
{
    "Amelia", "Ben", "Charlie", "Daisy"
};

Console.WriteLine(students[2]);

Indexes start at 0, so students[2] is Charlie.

1 of 4
STEP 2 OF 4

2D · row and column

string[,] studentResults =
{
    { "Amelia", "72" },
    { "Ben", "65" },
    { "Charlie", "81" }
};

Console.WriteLine(studentResults[0,0]);

[0,0] means row 0, column 0. It outputs Amelia.

The scores are strings here because every element in this array must have the same type.
2 of 4
STEP 3 OF 4

GetLength() names the dimension

studentResults.GetLength(0)  // rows
studentResults.GetLength(1)  // columns

For the array above, the answers are 3 and 2.

Use nested loops when you need to visit every row and every column.
3 of 4
STEP 4 OF 4

3D · three indexes

int[,,] readings = new int[2,3,4];

readings[1,2,3] = 21;

A 3D array needs three indexes. This structure contains 2 × 3 × 4 = 24 elements.

OCR expects arrays of up to three dimensions.

ONE COMPLETE WORKED EXAMPLE

Build studentResults

Store each student's name and score in a 2D array, then display every row.

Amelia 72
Ben 65
Charlie 81
Worked example
STEP 1 · PLAN

Rows are students · columns are fields

row 0 → Amelia | 72
row 1 → Ben    | 65
row 2 → Charlie| 81

We need 3 rows and 2 columns.

STEP 2 · DECLARE

Create the 2D array

string[,] studentResults =
{
    { "Amelia", "72" },
    { "Ben", "65" },
    { "Charlie", "81" }
};

Both columns use strings in this teaching example.

STEP 3 · ACCESS

Use row, then column

Console.WriteLine(studentResults[0,0]);
Console.WriteLine(studentResults[0,1]);

The outputs are Amelia and 72.

STEP 4 · TRAVERSE

Visit every row

for (int row = 0;
     row < studentResults.GetLength(0);
     row++)
{
    Console.WriteLine(
        studentResults[row,0] + " " +
        studentResults[row,1]);
}
Use GetLength(0) so the loop follows the number of rows.
