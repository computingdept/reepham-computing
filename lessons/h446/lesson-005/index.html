LESSON 005 · OCR H446 1.4.1(g)1 minute

Floating point → denary

By the end, you can…
  • evaluate the signed mantissa and exponent separately;
  • decode positive and negative values with positive or negative exponents;
  • recognise normalisation and explain precision versus range.

Use an eight-bit mantissa and four-bit exponent unless a question states otherwise. Both fields are two’s complement; the mantissa’s point follows the sign bit.

NEW LEARNING6 minutes

Split → evaluate → scale

8-bit mantissa: −1 | ½  ¼  ⅛  ¹⁄₁₆  ¹⁄₃₂  ¹⁄₆₄  ¹⁄₁₂₈
4-bit exponent: −8   4   2   1
Value = mantissa × 2ᴱ
  1. Split the pattern at the stated field boundary.
  2. Add the mantissa weights whose bits are 1. Include −1 if the sign bit is 1.
  3. Decode the exponent as a signed integer.
  4. Multiply by 2ᴱ. For a negative exponent, divide by the corresponding power of two.

Two signs with different jobs

The mantissa determines the sign of the number. The exponent determines its scale. A negative exponent does not make the value negative: 2⁻² = ¼.

Normalisation, precision and range

Nonzero normalised mantissas begin 01 (positive) or 10 (negative). More mantissa bits improve precision; more exponent bits increase range.

I DO · WATCH THE METHOD12 minutes
EXAMPLE 1 · POSITIVE MANTISSA + POSITIVE EXPONENT

Decode this value

01011000 0011

Keep the question visible. Watch how each field is decoded before the scale is applied.

Worked example 1 of 5

Worked method

Mantissa 01011000 = 0.6875
Exponent 0011 = 3
Value = 0.6875 × 2³ = 5.5

½ + ⅛ + ¹⁄₁₆ = 0.6875. The exponent is 3, so multiply by 8.

EXAMPLE 2 · NEGATIVE MANTISSA

Decode this value

10110000 0010

The leading 1 in the mantissa has a negative place value.

Worked example 2 of 5

Worked method

Mantissa 10110000 = −0.625
Exponent 0010 = 2
Value = −0.625 × 2² = −2.5

−1 + ¼ + ⅛ = −0.625. The leading 1 is not a separate minus sign.

EXAMPLE 3 · NEGATIVE EXPONENT

Decode this value

01100000 1110

A negative exponent changes the scale. It does not decide the sign of the number.

Worked example 3 of 5

Worked method

Mantissa 01100000 = 0.75
Exponent 1110 = −2
Value = 0.75 × 2⁻² = 0.1875

1110 = −8 + 4 + 2 = −2. Divide 0.75 by 4.

EXAMPLE 4 · BOTH FIELDS NEGATIVE

Decode this value

10100000 1111

Decode the mantissa and exponent separately before combining them.

Worked example 4 of 5

Worked method

Mantissa 10100000 = −0.75
Exponent 1111 = −1
Value = −0.75 × 2⁻¹ = −0.375

The exponent −1 means halve the mantissa.

EXAMPLE 5 · CHECK NORMALISATION

Decode this value

00011010 0101

Decode first. Then decide whether the mantissa is normalised.

Worked example 5 of 5

Worked method

Mantissa 00011010 = 0.203125
Exponent 0101 = 5
Value = 0.203125 × 2⁵ = 6.5

The mantissa begins 00, so it is not normalised. 01101000 0011 represents the same value in normalised form.
