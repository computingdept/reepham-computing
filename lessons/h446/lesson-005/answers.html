QUESTION 5 · OCR IDEA + CLASSROOM EXTENSION

Precision and range

More mantissa bits:
→ greater precision / more significant binary digits.

More exponent bits:
→ greater range / larger and smaller magnitudes can be represented.

If the total number of bits is fixed:
allocating more bits to the mantissa improves precision but leaves fewer bits for the exponent and reduces range;
allocating more bits to the exponent increases range but leaves fewer bits for the mantissa and reduces precision.
