Original question · 3 of 5 QUESTION 3 · OCR JUNE 2022 Q3(c) · [4]

Which representations are normalised?

Each representation uses a six-bit two’s-complement mantissa followed by a three-bit two’s-complement exponent. State which representations are normalised by checking the mantissa’s leading bits.

a) 010101 100
b) 110101 111
c) 011010 010
d) 101010 110

Paraphrased OCR June 2022 Q3(c); original marks retained. Source.

Completed answer
FINAL ANSWER
a, c and d are normalised; b is not
Working and marking guidance 
a) 010101 100 → normalised
b) 110101 111 → not normalised
c) 011010 010 → normalised
d) 101010 110 → normalised

Rule:
positive normalised mantissa begins 01
negative normalised mantissa begins 10

Convert both floating-point representations to denary

(a) 01110000 0010
(b) 10010000 1111

Each representation uses an eight-bit two’s-complement mantissa and a four-bit two’s-complement exponent. Convert both to denary and show the mantissa value, exponent value and final denary result.

Completed answer
FINAL ANSWER
(a) 3.5 · (b) −0.4375
Working and marking guidance 
(a) 01110000 0010

mantissa = 0.1110000₂ = 0.875
exponent = 2

0.875 × 2^2 = 3.5

(b) 10010000 1111

mantissa = -1 + 1/8 = -0.875
exponent = -1

-0.875 × 2^-1 = -0.4375
Original question · 5 of 5 QUESTION 5 · OCR IDEA + CLASSROOM EXTENSION

Precision and range

What improves if more bits are allocated to (a) the mantissa and (b) the exponent?

Then explain the trade-off if the total number of bits is fixed.

Starting point

Think about what mantissa bits control and what exponent bits control.

The first two prompts paraphrase OCR June 2023 Q3(e). The trade-off prompt is an original classroom extension. Source.

Completed answer
FINAL ANSWER
Mantissa → precision · exponent → range
Working and marking guidance 
More mantissa bits:
→ greater precision / more significant binary digits.

More exponent bits:
→ greater range / larger and smaller magnitudes can be represented.

If the total number of bits is fixed:
allocating more bits to the mantissa improves precision but leaves fewer bits for the exponent and reduces range;
allocating more bits to the exponent increases range but leaves fewer bits for the mantissa and reduces precision.
