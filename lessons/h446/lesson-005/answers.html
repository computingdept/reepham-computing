Which are normalised?

ANSWER
a) 010101 100 → normalised
b) 110101 111 → not normalised
c) 011010 010 → normalised
d) 101010 110 → normalised
Rule:
  • positive normalised mantissas begin 01;
  • negative normalised mantissas begin 10.

QUESTION 5 · OCR IDEA + CLASSROOM EXTENSION Suggested classroom marks: 3

What improves with more mantissa bits and more exponent bits? Explain the trade-off if the total number of bits is fixed.

QUESTION 5 · OCR IDEA + CLASSROOM EXTENSION Suggested classroom marks: 3

Precision and range

ANSWER
Mantissa → precision
Exponent → range

If the total number of bits is fixed, giving more bits to one field leaves fewer bits for the other. Increasing precision therefore reduces the available exponent range, and increasing range reduces the available mantissa precision.

Suggested marking:
  • 1 mark: more mantissa bits improve precision;
  • 1 mark: more exponent bits increase range;
  • 1 mark: explains the fixed-width trade-off.
