Questions and marking guidance

OCR source marks are retained only where the source question has them. Original classroom extensions are left unscored.

Question 1 · OCR June 2023 Q3(d) · [3]

Question: Decode 0100 1110 using a four-bit mantissa and four-bit exponent.

Mantissa 0100 = 0.5
Exponent 1110 = −2
Value = 0.5 × 2⁻² = 0.125

Check for the correct mantissa, exponent/scale and final denary value.

Question 2 · OCR June 2022 Q3(b) · [4]

Question: Decode 1010 1110 using a four-bit mantissa and four-bit exponent.

Mantissa 1010 = −0.75
Exponent 1110 = −2
Value = −0.75 × 2⁻² = −0.1875

Check the signed mantissa, signed exponent, scaling operation and final value.

Question 3 · OCR June 2022 Q3(c) · [4]

Question: State whether each representation is normalised.

a) 010101 100 → normalised
b) 110101 111 → not normalised
c) 011010 010 → normalised
d) 101010 110 → normalised

Use the leading mantissa bits: normalised nonzero values begin 01 or 10.

Question 4 · Original exam-style extension

Question: Decode 01110000 0010 and 10010000 1111 in 8+4 format.

01110000 0010
Mantissa = 0.875
Exponent = 2
Value = 3.5

10010000 1111
Mantissa = −0.875
Exponent = −1
Value = −0.4375

No invented mark allocation is attached to this original classroom question.

Question 5 · OCR idea + classroom extension

Question: What improves with more mantissa bits and more exponent bits? Explain the trade-off at a fixed total width.

Mantissa: greater precision. Exponent: greater range. With a fixed total width, allocating more bits to one field leaves fewer for the other.

The trade-off explanation is an original classroom extension, so it is not given an invented OCR-style mark allocation.

Before correcting an answer, check the sign, binary point, exponent and normalisation.
