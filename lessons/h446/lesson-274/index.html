Compiler stages, linkers, loaders and libraries

By the end you can…
  • Lexical analysis identifies tokens, while syntax analysis checks grammar and generates a parse structure.
  • Semantic analysis checks rules beyond grammar such as type compatibility or declared identifiers; optimisations can transform intermediate code.
  • A linker combines object files and resolves symbols/libraries; a loader places the executable into memory for execution.

→ syntax analysis (structure)
→ semantic analysis (types/names)
→ intermediate representation/optimisation
→ code generation → object files
→ linking libraries → executable → loading.
