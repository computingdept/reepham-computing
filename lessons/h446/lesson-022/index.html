1.4.2(b)(c) · TREE + BST

Hierarchy plus ordering

        40
       /       20    60
    /     /    10 30  50 70
A tree is hierarchical. A binary search tree adds an ordering rule that supports efficient searching when the tree is reasonably balanced.
STEP 1 OF 4

Node needs two links

class TreeNode
{
    public int Data;
    public TreeNode Left;
    public TreeNode Right;
}

A binary tree node can refer to a left child and a right child.

1 of 4
STEP 2 OF 4

Search uses comparisons

if (value < current.Data)
    current = current.Left;
else
    current = current.Right;

Each comparison chooses one branch.

2 of 4
STEP 3 OF 4

Insert at null

if (current.Left == null)
    current.Left = new TreeNode(value);

A new node is attached where the required child reference is null.

3 of 4
STEP 4 OF 4

Remove by case

leaf        → disconnect
one child   → bypass node
two children→ replace using ordered successor/predecessor

Removal must preserve the BST ordering rule.
