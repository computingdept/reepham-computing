1.4.2(b)(c) · HASH TABLE

Hash chooses the row; collision uses another slot

table size = 5
hash(key) = key MOD 5

12 → row 2
17 → row 2
22 → row 2

bucket 2: [12, 17, 22]
A fixed 2D array lets us model separate chaining without introducing OO or library collection classes.
STEP 1 OF 4

Create fixed buckets

int[,] table = new int[5,3];
int[] count = new int[5];

Each row is a bucket with three available collision slots.

1 of 4
STEP 2 OF 4

Hash

int bucket = key % 5;

The same key maps to the same row.

2 of 4
STEP 3 OF 4

Add

table[bucket, count[bucket]] = key;
count[bucket]++;

A collision goes into the next free column in that bucket.

3 of 4
STEP 4 OF 4

Search/remove

for (int c = 0; c < count[bucket]; c++)
{
    if (table[bucket,c] == key)
    {
        // found
    }
}

Only the calculated bucket is searched. Removal can shift later bucket items left.

4 of 4

Add 12, 17 and 22

All three keys hash to bucket 2.
