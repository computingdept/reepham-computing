Retrieval

What index identifies the first element of a C# array?

ANSWER

0 — C# arrays are zero indexed.

QUESTION 2 OF 4

Retrieval

How does a linear search differ from a binary search?

ANSWER

Linear search checks sequentially; binary search repeatedly halves the remaining sorted range.

QUESTION 3 OF 4

Retrieval

Given int[] numbers = {3, 7, 12, 18, 24}; what is numbers[3]?

ANSWER

18 — the fourth item has index 3.

QUESTION 4 OF 4

Challenge

Why can binary search miss a target that exists in an unsorted array?

ANSWER

Because comparisons rely on sorted order to discard one half safely.

STEP 1 OF 4

Start with valid bounds

low = 0;
high = numbers.Length - 1;

The last index is 7, not 8. Array length is not a valid index.

1 of 4
STEP 2 OF 4

Find the midpoint

mid = low + (high - low) / 2;
numbers[3] = 18;

Integer division gives index 3. Compare its value (18) with target (31).

2 of 4
STEP 3 OF 4

Discard half

18 < 31  →  low = mid + 1;
low = 4; high = 7;

All positions through index 3 are too small. Keep only 4–7.

3 of 4
STEP 4 OF 4

Stop when found or exhausted

mid = 5; numbers[mid] = 31;
return 5;

If low becomes greater than high, return -1. Never assume the target exists.

Worked example · 1 complete method
STEP 1 · MODEL

Set the bounds

static int BinarySearch(int[] data, int target)
{
    int low = 0;
    int high = data.Length - 1;

Describe the valid array index range.

STEP 2 · MODEL

Repeat while a candidate remains

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

Model midpoint calculation and integer division.

STEP 3 · MODEL

Handle all three outcomes

        if (data[mid] == target)
            return mid;
        else if (data[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;

Explain equality first; otherwise shrink the correct half.

STEP 4 · MODEL

Stop cleanly

    }
    return -1;
}

After the loop, no candidates remain, so return -1.
