1.4.3(a)(d) · BOOLEAN LOGIC

Problem → expression → gates → truth table

Words:
alarm set AND sensor active AND NOT test

Expression:
C ∧ (A ∨ B) ∧ ¬D
OCR assesses the same logic in several representations. Move confidently between all of them.
STEP 1 OF 4

Core gates

AND: 1 only if both are 1
OR:  1 if either/both are 1
NOT: reverses
XOR: 1 if inputs differ

Know the behaviour before worrying about a diagram.

WORKED EXAMPLE

Define an alarm system

Door or motion must detect movement, the alarm must be set, and test mode must be off.

A door
B motion
C set
D test
Worked example
STEP 1 · SENSORS

Combine movement sensors

A ∨ B

Either sensor is enough.

STEP 2 · SET

Require alarm set

(A ∨ B) ∧ C

C must also be true.

STEP 3 · TEST

Disable during testing

¬D

Test mode must be false.

STEP 4 · FINAL

Combine requirements

Q = (A ∨ B) ∧ C ∧ ¬D

This is the logic behind the OCR June 2024 alarm context.
