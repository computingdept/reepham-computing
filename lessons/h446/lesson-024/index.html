What index identifies the first element of a C# array?

ANSWER

0 — C# arrays are zero indexed.

QUESTION 2 OF 4

Retrieval

How does a linear search differ from a binary search?

ANSWER

Linear search checks sequentially; binary search repeatedly halves the remaining sorted range.

QUESTION 3 OF 4

Retrieval

Given int[] numbers = {3, 7, 12, 18, 24}; what is numbers[3]?

ANSWER

18 — the fourth item has index 3.

QUESTION 4 OF 4

Challenge

Why can binary search miss a target that exists in an unsorted array?

ANSWER

Because comparisons rely on sorted order to discard one half safely.

Write a function that returns the target’s index

Your task: Create BinarySearch, a C# function that takes a sorted integer array and a target integer. It must return the array index (position) where the target is found, or -1 when the target is absent.

int[] numbers = {3, 7, 12, 18, 24, 31, 45, 60};

Syntax: int = integer · [] = array · numbers = name · { } = values.

Question: The array holds 8 values. Why is the final index 7?

Example: Search for 31 → return 5 (its index, not its value). Search for 13 → return -1 (not found).

Worked example · build one working method
STEP 1 OF 8

Declare an integer array

int[] numbers = {3, 7, 12, 18, 24, 31, 45, 60};

int = integer; [] = an array; numbers = its name; { } = the values; ; = end of the statement. The first index is 0.

STEP 2 OF 8

Choose a target

int target = 31;

int declares an integer variable. The value 31 is what we want to find. This is not its index.

STEP 3 OF 8

Declare a function that returns a position

static int BinarySearch(int[] data, int target)
{

The return type int means the function gives back a whole number: the position of the target or -1. int[] data receives the sorted array; int target receives the number to find.

STEP 4 OF 8

Set the search bounds

    int low = 0;
    int high = data.Length - 1;

low is the first valid index (0); high is the last valid index (7). Length is 8, but index 8 does not exist.

STEP 5 OF 8

Repeat and find the middle

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

while repeats while a candidate remains; <= also checks when low and high are equal. Integer division gives a whole-number index.

STEP 6 OF 8

Compare and move the bounds

        if (data[mid] == target)
            return mid;
        else if (data[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;

== checks equality; < means move right; otherwise move left. Each unsuccessful step removes half of the remaining candidates.

STEP 7 OF 8

Finish the method

    }
    return -1;
}

} closes the loop and the method. Returning -1 means the value was not found.

STEP 8 OF 8

Call the method and print the result

int position = BinarySearch(numbers, target);
Console.WriteLine(position); // 5

Call the function from Main after declaring the array and target. Its returned integer is stored in position and printed. Here 31 is at index 5; if the target is absent, position contains -1.
