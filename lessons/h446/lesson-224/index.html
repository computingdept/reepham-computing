NEW LEARNING · CODE FIRST

Study the code and predict the state

Node? root=null;
foreach(int x in new[] {40,20,60,10,30,25})
    root=Insert(root,x);
Node Insert(Node? node,int key) {
  if(node is null) return new Node(key);
  if(key < node.Key) node.Left=Insert(node.Left,key);
  else if(key > node.Key) node.Right=Insert(node.Right,key);
  // Equal keys are ignored in this implementation.
  return node;
}
class Node {
  public int Key;
  public Node? Left,Right;
  public Node(int key){Key=key;}
}
STEP 1 OF 3

Find the starting node

The root is 40, so compare 25 with 40 and move left.

STEP 2 OF 3

Repeat comparisons

25>20 goes right to 30; 25<30 goes left.

STEP 3 OF 3

Insert at a null child

Create node 25 at the empty left-child position of 30. This implementation ignores duplicate keys: when key equals node.Key, neither subtree changes.

WORKED ANSWER

Core · 6 marks · QUESTION 2 OF 3

Insert 50,30,70,20,40,35 into an empty BST. State parent and side of 35, and the in-order visit sequence.

WORKED ANSWER

[6] Parent of 35 is 40 [1], it is left child [1]; in-order sequence 20,30,35,40,50,70 [4].

Stretch · 6 marks · QUESTION 3 OF 3

In BST 40 with children 20 and 60, and 20 with children 10 and 30, delete leaf 10. Explain a second case in which deletion is more involved.

WORKED ANSWER

[6] Find node 10 by moving left twice [2]; it is a leaf [1], so set parent 20.Left=null [1]. For a node with two children, replace it using an in-order successor/predecessor and remove the replacement from its old location [2].

True or false?

In-order traversal of a BST with distinct keys visits values in ascending order.

Model answer

True. Left subtree, node and right subtree produce increasing keys.
