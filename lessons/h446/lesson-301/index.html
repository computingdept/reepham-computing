STEP 1 OF 3

Identify the dominant operation

Single full loop grows O(n); two full nested n loops grow O(n²). Repeated halving grows O(log n).

STEP 2 OF 3

Separate time and space

Counting two scalar variables uses O(1) auxiliary memory even if repeated n² times; copying n elements uses O(n) extra storage.

STEP 3 OF 3

Interpret asymptotics

Big O describes a bound on growth, not an exact runtime. Constants, cache effects and data size still matter.

I DO · WORKED MODEL

Find worst-case time and auxiliary space for summing n array elements into one accumulator.

int sum=0;
foreach(int x in a) sum+=x;
STEP 1 OF 2

Predict first

Each element is visited once: time O(n).

STEP 2 OF 2

Explain the method

The only additional state is a scalar sum (apart from iterator control): auxiliary space O(1).

WE DO · DIFFERENT PROBLEM

Find time and extra space for copying each element to a separate new n-element array.

int[] b=new int[a.Length];
for(int i=0;i<a.Length;i++) b[i]=a[i];
STEP 1 OF 2

Predict first

Copy performs a constant amount of work n times, so time grows O(n).

STEP 2 OF 2

Explain the method

New array b stores n values, giving O(n) auxiliary memory.

EXAM QUESTION 1 OF 4 · 2 MARKS · 2 MINUTES

A sorting routine has best-case time complexity O(n). Describe what the n means and how the best-case running time scales as the size of the input grows. [2]

OCR H446/02 · June 2024 · Q6(d)(i) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

n is the number of input items. In the best case the number of operations (and hence time) grows linearly, approximately in direct proportion to n.

Marking: One mark for identifying linear growth/O(n), one for time increasing proportionally with input size.

EXAM QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A different sorting routine has worst-case auxiliary-space complexity O(log n). Explain what this implies about the additional memory used as the input grows. [2]

OCR H446/02 · June 2024 · Q6(d)(ii) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

The extra memory increases logarithmically with the item count: it grows at a decreasing rate, so doubling the number of items adds only a roughly constant amount to the logarithmic space term.

Marking: One mark for logarithmic growth, one for describing progressively slower increase in extra memory requirements.

An algorithm allocates twice as much working memory every time the input length increases by one item. Name the associated space-complexity class. [1]
