STEP 1 OF 3

Identify the dominant operation

Single full loop grows O(n); two full nested n loops grow O(n²). Repeated halving grows O(log n).

STEP 2 OF 3

Separate time and space

Counting two scalar variables uses O(1) auxiliary memory even if repeated n² times; copying n elements uses O(n) extra storage.

STEP 3 OF 3

Interpret asymptotics

Big O describes a bound on growth, not an exact runtime. Constants, cache effects and data size still matter.

I DO · WORKED MODEL

Find worst-case time and auxiliary space for summing n array elements into one accumulator.

int sum=0;
foreach(int x in a) sum+=x;
STEP 1 OF 2

Predict first

Each element is visited once: time O(n).

STEP 2 OF 2

Explain the method

The only additional state is a scalar sum (apart from iterator control): auxiliary space O(1).

WE DO · DIFFERENT PROBLEM

Find time and extra space for copying each element to a separate new n-element array.

int[] b=new int[a.Length];
for(int i=0;i<a.Length;i++) b[i]=a[i];
STEP 1 OF 2

Predict first

Copy performs a constant amount of work n times, so time grows O(n).

STEP 2 OF 2

Explain the method

New array b stores n values, giving O(n) auxiliary memory.

MODEL ANSWER AND MARKING POINTS
