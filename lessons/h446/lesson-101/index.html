Lesson 101 · Multicore CPUs and Parallel Systems

By the end you can…
  • A multicore CPU integrates two or more processing cores, which can execute independent threads concurrently.
  • Parallel processing can reduce completion time when tasks can be divided; a serial dependency is a critical-path constraint.
  • Shared memory bandwidth, locking, thread scheduling and the serial proportion of a program limit speedup. More cores do not guarantee proportional gains.

I DO · MODEL

Eight equal independent jobs are shared across two identical cores. How many ideal waves?

WORKED REASONING

Explain the choice

8 ÷ 2 = 4 equal-duration waves, versus 8 on one core.

WE DO · DIFFERENT EXAMPLE

Twelve equal independent jobs run on four cores. Give ideal waves and one practical caveat.

WORKED REASONING

Explain the choice

12 ÷ 4 = 3 waves; shared-memory contention or scheduling overhead can extend time.

CHALLENGE · QUESTION 3 OF 3

Half a program must run serially; other half parallelised perfectly across four cores. Compute ideal speedup and interpret. [6]

MARK SCHEME / WORKED ANSWER

Normalised time 0.5+0.5/4=0.625 [3], speedup 1/0.625=1.6 [2], not fourfold due serial work [1].
