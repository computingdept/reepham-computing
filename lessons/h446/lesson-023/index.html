1.4.2(b)(c) · HASH TABLE

Key → hash → bucket

table size = 5
hash(key) = key % 5

12 → 2
7  → 2   collision
22 → 2   collision
This lesson uses separate chaining so collisions are explicit and add/remove/traverse operations remain clear.
STEP 1 OF 4

Create buckets

List<int>[] table = new List<int>[5];

for (int i = 0; i < table.Length; i++)
    table[i] = new List<int>();

Each array position is a bucket list.

1 of 4
STEP 2 OF 4

Hash the key

int index = key % table.Length;

The same key always maps to the same bucket for a fixed table size.

2 of 4
STEP 3 OF 4

Add and search

table[index].Add(key);
bool found = table[index].Contains(key);

Only the calculated bucket needs to be checked.

3 of 4
STEP 4 OF 4

Remove and traverse

table[index].Remove(key);

for (int b = 0; b < table.Length; b++)
    foreach (int item in table[b])
        Console.WriteLine(item);

Removal changes a bucket list; traversal visits every bucket and entry.

4 of 4
WORKED EXAMPLE

Store 12, 7 and 22

All three keys collide in table size 5.

12 % 5 = 2
 7 % 5 = 2
22 % 5 = 2
Worked example
STEP 1 · HASH

Calculate 12

12 % 5 = 2
STEP 2 · ADD

Bucket 2

table[2].Add(12);
STEP 3 · COLLIDE

Add 7

table[2].Add(7);

Chaining keeps both values.

STEP 4 · COLLIDE

Add 22

table[2].Add(22);

Bucket 2 now stores 12, 7, 22.
