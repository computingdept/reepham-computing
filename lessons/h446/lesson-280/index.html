Q1 CPU AND MEMORY • 15 marks: (a) Define PC,MAR,MDR,CIR,ACC. [5] (b) Explain fetch-decode-execute including one bus role. [6] (c) Compare Von Neumann and Harvard memory paths. [4]

WORKED ANSWER

/15 (a) Next instruction address, accessed address, transferred contents, current instruction, accumulator [1 each]. (b) PC→MAR [1], address bus [1], memory→MDR [1], MDR→CIR [1], CU decode [1], execute [1]. (c) Von Neumann shared path/memory [2]; Harvard separate instruction/data access paths [2].

QUESTION 2 OF 3

Q2 OS • 15 marks: (a) Trace FCFS for A (3 time units), B (2) and C (1), all arriving at t=0. When arrivals tie, use the given order A, then B, then C. Show the schedule, waiting time for each process and their mean waiting time. [7] (b) Page size 128, VA 390, page3→frame6: find page, offset, physical address. [6] (c) Define page fault. [2]

WORKED ANSWER

/15 (a) A 0–3 [1], B 3–5 [1], C 5–6 [1]; waits A=0 [1], B=3 [1], C=5 [1]; mean wait (0+3+5)/3=8/3≈2.67 time units [1]. (b) page3 [1], offset 6 [2], frame base 6×128=768 [2], physical774 [1]. (c) Attempt to access a virtual page not resident in RAM [2].

QUESTION 3 OF 3

Q3 DATABASES • 15 marks: Student(ID,Name)=(1,Ada),(2,Ben),(3,Cleo), Score(ID,Mark)=(1,70),(3,85). (a) Explain PK and FK. [4] (b) Give INNER JOIN result. [3] (c) Write SELECT showing Name where Mark>=80. [6] (d) Distinguish DELETE FROM and DROP TABLE. [2]

WORKED ANSWER

/15 (a) PK uniquely identifies row [2], FK references another table key [2]. (b) Ada70 [1], Cleo85 [1], Ben unmatched/excluded [1]. (c) SELECT Student.Name [1] FROM Student [1] INNER JOIN Score [1] ON Student.ID=Score.ID [2] WHERE Score.Mark>=80 [1]. (d) DELETE records [1], DROP removes table/schema [1].
