Lesson 071 · Pipelining and Computational Methods Review

By the end you can…
  • Pipelining overlaps separate stages of different tasks; it increases throughput after filling the pipeline, not necessarily single-task latency.
  • Four tasks on a three-stage pipeline complete in six ideal cycles, versus twelve when each task runs all stages in isolation.
  • Choose the computational method that fits: decomposition for parts; backtracking for reversible choices; heuristic for guided estimates; visualisation for patterns.

I DO · MODEL

Find ideal cycles for 3 tasks through 2 single-cycle stages.

Pipeline: 2+3−1=4 cycles; sequential 2×3=6.
WORKED METHOD

Explain

Start a new task each cycle while earlier tasks advance; last task finishes cycle4.

WE DO · DIFFERENT PROBLEM

For 5 tasks with 3 equal-length pipeline stages, predict ideal cycles.

3+5−1=7 cycles; sequential total=15 cycles.
WORKED METHOD

Explain

This is a throughput model assuming one task enters each cycle and no stall.

FOUNDATION · Q1/3

Draw ideal 2-stage pipeline schedule for 3 tasks and state completion cycle. [6]

WORKED ANSWER

T1 occupies stages at cycles1,2 [2]; T2 at cycles2,3 [1]; T3 at cycles3,4 [1]; finishes cycle4 [2].

APPLY · Q2/3

For 6 tasks and 4 one-cycle stages, compare pipelined and sequential ideal times. [6]

WORKED ANSWER

Pipeline 4+6−1=9 cycles [3]; sequential 4×6=24 [2]; assumes no stall [1].
