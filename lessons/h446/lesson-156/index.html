I DO · TEACHER MODEL

A pupil edits a teacher-assigned mark in browser developer tools before submitting a form. How is the system protected?

STEP 1 OF 3

Browser value is untrusted

Identify the input or diagram and predict the first result.

STEP 2 OF 3

Server checks permissions

Follow the second stage and explain its importance.

STEP 3 OF 3

Reject forbidden edit

The server must authenticate the user and enforce edit permissions, ignoring unauthorised mark values. It validates requests and writes to the authoritative database only after checking access.
