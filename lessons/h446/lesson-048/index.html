Lesson 048 · C# List<T>: Add, Insert and Remove

By the end you can…
  • List<T> is a resizable sequence. Add appends; Insert inserts at a specified index and shifts following items.
  • RemoveAt removes an item by index; Remove(value) removes the first matching value instead.
  • Unlike an array, List<T> changes Count as items are inserted/removed. An index must still be within the valid bounds.

Key vocabulary

List<T>InsertRemoveAtCount
NEW LEARNING · C# EXAMPLE FIRST

Trace the code

var nums=new List<int>{4,8,12};
nums.Insert(1,6);  // [4,6,8,12]
nums.RemoveAt(2);  // [4,6,12]
Console.WriteLine(nums.Count); // 3
STEP 1 OF 3

Observe

List<T> is a resizable sequence. Add appends; Insert inserts at a specified index and shifts following items.

STEP 2 OF 3

Explain

RemoveAt removes an item by index; Remove(value) removes the first matching value instead.

STEP 3 OF 3

Apply

Unlike an array, List<T> changes Count as items are inserted/removed. An index must still be within the valid bounds.

I DO · MODEL

Trace a list after inserting at the start, then removing the last element.

var n=new List<int>{2,5,7};
n.Insert(0,1);
n.RemoveAt(3);
MODEL EXPLANATION

Trace and justify

After Insert: [1,2,5,7]; RemoveAt(3) removes 7; final [1,2,5].

WE DO · DIFFERENT DATA

A different list starts [3,6,9]. Add 12, then remove the VALUE 6. What remains?

var n=new List<int>{3,6,9};
n.Add(12);
n.Remove(6);
MODEL EXPLANATION

Trace and justify

[3,9,12]. Add appends 12; Remove(6) removes matching value 6, unlike RemoveAt(6).

FOUNDATION · Q1 OF 3

Trace Insert(1,6) then RemoveAt(2) for [4,8,12]. [6]

WORKED ANSWER / MARKS

[4,6,8,12] after Insert [3]; [4,6,12] after RemoveAt [3].

CORE · Q2 OF 3

Explain the difference between Remove(5) and RemoveAt(1) for [2,5,5,9]. [6]

WORKED ANSWER / MARKS

Remove(5) finds first value5 [2] → [2,5,9] [1]; RemoveAt(1) removes item at index1 [2] → [2,5,9] [1]. Same final list here but different selection rule.
