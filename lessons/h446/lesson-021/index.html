QUESTION 1 OF 4

Retrieval

What is an array, and how do you access an individual element?

ANSWER

An array stores indexed elements. Access an element by its index, for example values[2].

QUESTION 2 OF 4

Retrieval

What is the purpose of a pointer in a linked list?

ANSWER

It stores a reference or index identifying another node, allowing nodes to be linked together.

QUESTION 3 OF 4

Retrieval

Explain the difference between LIFO and FIFO. Name one data structure using each.

ANSWER

LIFO: last in, first out (stack). FIFO: first in, first out (queue).

QUESTION 4 OF 4

Challenge

A graph has vertices A, B, C and D. Its undirected edges are A–B, A–C and C–D. Write its adjacency list.

ANSWER

A: B, C; B: A; C: A, D; D: C. Each undirected edge is represented at both ends.

1.4.2(b)(c) · TREE + BST

Store left/data/right using arrays

The numbers in brackets are array indexes, not values.

index  data  left  right
0      40    1     2
1      20    3     4
2      60   -1    -1
3      10   -1    -1
4      30   -1    -1
This is the same pointer-table idea used in OCR exam questions: the structure is defined by indexes, not by physical adjacency.
STEP 1 OF 4

BST ordering

smaller → left
larger  → right

Each comparison chooses the next branch.

1 of 4
STEP 2 OF 4

Search

current = root;

while (current != -1 && data[current] != target)
{
    if (target < data[current])
        current = left[current];
    else
        current = right[current];
}

Search follows only one branch at each comparison.

2 of 4
STEP 3 OF 4

Add

if (value < data[parent])
    left[parent] = newIndex;
else
    right[parent] = newIndex;

The new index is attached to the correct null pointer.

3 of 4
STEP 4 OF 4

Remove simple cases

leaf → parent pointer = -1

one child → parent pointer = child index

Two-child removal is more involved; first secure leaf and one-child cases.

4 of 4
WORKED EXAMPLE

Search for 30

Use the array pointers rather than scanning every row.

C# search example (paste into .NET Fiddle)

using System;

public class Program
{
    public static void Main()
    {
        int[] data = { 40, 20, 60, 10, 30 };
        int[] left = { 1, 3, -1, -1, -1 };
        int[] right = { 2, 4, -1, -1, -1 };
        int root = 0;
        int target = 30;
        int current = root;

        while (current != -1 && data[current] != target)
        {
            Console.WriteLine("Visit " + data[current]);
            if (target < data[current])
                current = left[current];
            else
                current = right[current];
        }
        Console.WriteLine(current == -1 ? "Not found" : "Found at index " + current);
    }
}
