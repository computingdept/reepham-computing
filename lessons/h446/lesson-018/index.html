OO BRIDGE · ONLY WHAT WE NEED

A Node is a useful building block

Node
├── Data
└── Next → another Node
This is not the full OOP unit. It introduces only the ideas needed to make linked structures readable.
STEP 1 OF 4

Class = template

class Node
{
    public int Data;
    public Node Next;
}

The class states what every Node object will contain.

1 of 4
STEP 2 OF 4

Constructor initialises

public Node(int data)
{
    Data = data;
    Next = null;
}

Each new Node receives its own Data value and starts with no next node.

2 of 4
STEP 3 OF 4

Objects are instances

Node first = new Node(10);
Node second = new Node(20);

first and second refer to two different objects.

3 of 4
STEP 4 OF 4

References connect objects

first.Next = second;

The first node now refers to the second. This idea underpins linked lists and trees.

4 of 4
WORKED EXAMPLE

Create two connected Node objects

We want 10 to point to 20.

10 → 20 → null
Worked example
STEP 1 · DEFINE

Use the Node class

class Node
{
    public int Data;
    public Node Next;

    public Node(int data)
    {
        Data = data;
        Next = null;
    }
}
STEP 2 · CREATE

Instantiate two objects

Node first = new Node(10);
Node second = new Node(20);
STEP 3 · LINK

Store a reference

first.Next = second;
STEP 4 · READ

Follow the reference

Console.WriteLine(first.Data);
Console.WriteLine(first.Next.Data);
