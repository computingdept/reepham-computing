1.4.2(b)(c) · PROCEDURAL LINKED LIST

The pointer chooses the next index

index:  0      1      2      3
data:   Ben    Daisy  Alex   Cara
next:   3      null   0      1

start = 2

Alex → Ben → Cara → Daisy → null
This matches the OCR style: data can sit anywhere in the array; pointer values define the logical order.
STEP 1 OF 4

Start pointer

int start = 2;

The first logical item is stored at index 2, not necessarily index 0.

1 of 4
STEP 2 OF 4

Follow next pointers

int current = start;

while (current != -1)
{
    Console.WriteLine(data[current]);
    current = next[current];
}

Use -1 as null in code. Each pointer decides the next index.

2 of 4
STEP 3 OF 4

Insert at the front

next[newIndex] = start;
start = newIndex;

The new item points to the old first item, then start changes.

3 of 4
STEP 4 OF 4

Remove after current

next[current] = next[next[current]];

The pointer bypasses one node. The array data itself does not need to shift.

4 of 4
WORKED EXAMPLE

Traverse Alex → Ben → Cara → Daisy

The array order is deliberately different from the linked-list order.

start = 2
next = [3, -1, 0, 1]
Worked example
STEP 1 · START

Use the start pointer

current = 2
data[2] = "Alex"
STEP 2 · FOLLOW

Read next[2]

next[2] = 0
current = 0
data[0] = "Ben"
STEP 3 · FOLLOW

Continue pointers

next[0] = 3
data[3] = "Cara"

next[3] = 1
data[1] = "Daisy"
STEP 4 · STOP

Reach null

next[1] = -1
stop
