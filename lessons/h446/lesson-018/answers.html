INDEPENDENT 1 · CREATE

Build a linked list in arrays

string[] data = { "Ben", "Daisy", "Alex" };
int[] next = { 1, -1, 0 };
int start = 2;

Check: Following pointers outputs the intended order, not array order.

INDEPENDENT 2 · TRAVERSE

Output every linked item

int current = start;
while (current != -1)
{
    Console.WriteLine(data[current]);
    current = next[current];
}

Check: Every logical item is output once.

INDEPENDENT 3 · ADD

Insert a new first item

data[3] = "Finn";
next[3] = start;
start = 3;

Check: The previous first item is still reachable.

INDEPENDENT 4 · REMOVE

Remove the second logical item

next[start] = next[next[start]];

int current = start;
while (current != -1)
{
    Console.WriteLine(data[current]);
    current = next[current];
}

Check: The list remains connected and the removed item is not visited.
