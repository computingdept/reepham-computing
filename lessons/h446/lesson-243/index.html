I DO · MODEL

Unmarked example: what earns method marks for a negative 8-bit value?

+5 = 00000101
invert = 11111010
add 1 = 11111011 (−5)
STEP 1 OF 2

Predict the method

Write +5 in exactly 8 bits.

STEP 2 OF 2

Check and explain

Invert each bit, then add one to obtain the two's complement result for −5.

WE DO · DIFFERENT PROBLEM

Unmarked different example: evaluate ¬(A ∧ B) for A=1, B=0.

A ∧ B = 1 AND 0 = 0
¬0 = 1
STEP 1 OF 2

Predict the method

First calculate A AND B = 0.

STEP 2 OF 2

Check and explain

Negate it: ¬0=1. Include intermediate reasoning when a question asks for it.

Q1 · 15 marks · QUESTION 1 OF 3

(a) Convert −18 to eight-bit two's complement, showing working. [4] (b) Perform arithmetic right shift by 1 on that representation, giving the binary result and signed decimal value. [3] (c) Add 1011₂ and 0110₂, showing carry and answer. [3] (d) Normalise positive 0.0011₂ × 2⁵, showing shifts and decimal value. [5]

FULL MODEL ANSWER

MARK SCHEME /15. (a) +18=00010010 [1], invert 11101101 [1], add 1=11101110 [2]. (b) Sign-preserving right shift gives 11110111 [2] = −9 [1]. (c) Correct binary addition yields 10001₂ [2], correct carry evidence [1]. (d) 0.0011×2⁵ →0.0110×2⁴ [2] →0.1100×2³ [2], decimal 6 [1].

Q2 · 15 marks · QUESTION 2 OF 3

(a) Complete four output rows of A XOR B in order 00,01,10,11. [4] (b) Simplify ¬(A ∧ B) using De Morgan's law. [3] (c) For a half adder with A=1, B=1, state Sum and Carry and explain the gates. [4] (d) Simplify A ∨ (B ∧ ¬B) using Boolean identities. [4]

FULL MODEL ANSWER

MARK SCHEME /15. (a) Outputs 0,1,1,0 [4]. (b) ¬A ∨ ¬B [2], De Morgan swaps AND to OR and negates components [1]. (c) Sum=0 [1], Carry=1 [1], XOR gives sum [1], AND gives carry [1]. (d) B∧¬B=0 [2]; A∨0=A [2].

Q3 · 15 marks · QUESTION 3 OF 3

(a) State the roles of PC, MAR, MDR, CIR and ACC. [5] (b) Describe a simplified fetch-decode-execute cycle using PC, MAR, MDR, CIR and the control unit. [6] (c) Explain one role of an interrupt and an interrupt service routine. [4]

FULL MODEL ANSWER

MARK SCHEME /15. (a) PC address of next instruction [1], MAR memory address accessed [1], MDR data/instruction transferred [1], CIR current instruction [1], ACC result/intermediate arithmetic [1]. (b) PC address into MAR [1]; instruction fetched from memory into MDR [1]; PC advanced [1]; instruction copied to CIR [1]; control unit decodes [1]; processor executes and updates registers as needed [1]. (c) Interrupt signals event requiring attention [1]; CPU checks/services it at a suitable point [1]; relevant ISR handles event [1]; execution state restored and normal processing resumes [1].
