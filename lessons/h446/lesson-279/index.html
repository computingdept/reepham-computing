SQL INSERT, DELETE, DROP and LIKE

By the end you can…
  • INSERT adds a row; DELETE removes records matching a WHERE predicate. Omitting WHERE can delete every row.
  • DROP TABLE removes the table itself, not just one record. It is a destructive schema operation.
  • LIKE uses % for any number of characters and _ for a single character in standard SQL. SELECT * means all columns, a different use of *.

Vocabulary

INSERTDELETEDROP TABLELIKE%
NEW LEARNING · CODE FIRST

Work through the process

-- Independent examples on a practice Student table:
INSERT INTO Student(ID,Name) VALUES (4,'Dana');
DELETE FROM Student WHERE ID=4;
SELECT Name FROM Student WHERE Name LIKE 'A%';
-- % matches zero or more characters.
SELECT * FROM Student; -- * means all columns.
-- Destructive example: do NOT execute on real school data.
-- Run only on a disposable practice table:
DROP TABLE Student; -- deletes the table and its data.

EXAM QUESTION 1 OF 4 · 3 MARKS · 3 MINUTES

The club now licenses a sound program with ProductID EDU07, Name EDUCast, Type Sound and Price 89.99. Write one complete SQL INSERT statement that adds this record. [3]

GIVEN INFORMATION
A school media club stores software products in TblSoftware(ProductID, Name, Type, Price), where Price is a number in pounds. The table currently contains:
ProductID | Name | Type | Price
EDU01 | EDUCanvas | Image | 129.99
EDU02 | EDUDraw | Image | 119.99
EDU03 | EDUAnimate | Image | 99.99
EDU04 | EDUMovie | Video | 189.99
EDU05 | EDUEffects | Video | 99.99
EDU06 | EDUAudio | Sound | 119.99

OCR H446/01 · June 2025 · Q6(c)(i) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

INSERT INTO TblSoftware (ProductID, Name, Type, Price) VALUES ('EDU07', 'EDUCast', 'Sound', 89.99);

Marking: Mark the correct INSERT INTO/table and fields; VALUES clause; and correctly ordered values, up to three. Full marks require correct working SQL. These RHS names differ from OCR identifiers.

EXAM QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A sailing club keeps activity logs in TblSessionLog(ID, UserType, DateAccessed). It wants to remove only records whose UserType is the string "Archived". Write a complete SQL DELETE command with the correct WHERE condition. [2]

OCR H446/01 · June 2023 · Q4(f)(i) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

DELETE FROM TblSessionLog WHERE UserType = "Archived";

Marking: One mark for DELETE FROM TblSessionLog, one for correctly quoted WHERE UserType = "Archived". Do not use DELETE * or ==.

RHS ADDITIONAL PRACTICE · QUESTION 3 OF 4 · 3 MARKS · 3 MINUTES

A library stores books in TblBook(BookID, Title, Author). Write an SQL statement to return BookID and Title for books whose Title begins with the word Computing. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

SELECT BookID, Title FROM TblBook WHERE Title LIKE 'Computing%';

Marking: One mark for SELECT BookID, Title FROM TblBook; one for WHERE Title LIKE; one for the correct quoted pattern with % after Computing.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

A technician wants to remove the entire temporary table TblImport, including its structure. Write the SQL command and explain why DELETE FROM TblImport would not achieve the same result. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

DROP TABLE TblImport; DELETE FROM TblImport removes the records but leaves the table structure.

Marking: One mark for the correct DROP TABLE statement; one for explaining that DELETE retains the table structure.
