SQL INSERT, DELETE, DROP and LIKE

By the end you can…
  • INSERT adds a row; DELETE removes records matching a WHERE predicate. Omitting WHERE can delete every row.
  • DROP TABLE removes the table itself, not just one record. It is a destructive schema operation.
  • LIKE uses % for any number of characters and _ for a single character in standard SQL. SELECT * means all columns, a different use of *.

Vocabulary

INSERTDELETEDROP TABLELIKE%
NEW LEARNING · CODE FIRST

Work through the process

-- Independent examples on a practice Student table:
INSERT INTO Student(ID,Name) VALUES (4,'Dana');
DELETE FROM Student WHERE ID=4;
SELECT Name FROM Student WHERE Name LIKE 'A%';
-- % matches zero or more characters.
SELECT * FROM Student; -- * means all columns.
-- Destructive example: do NOT execute on real school data.
-- Run only on a disposable practice table:
DROP TABLE Student; -- deletes the table and its data.
