Node

What is a vertex/node in a graph?

ANSWER

A point/entity represented in the graph.

QUESTION 2 OF 4

Edge

What does an edge represent?

ANSWER

A connection between two nodes.

QUESTION 3 OF 4

Priority queue

What is special about a priority queue?

ANSWER

Items are removed according to priority rather than simple arrival order.

QUESTION 4 OF 4

Shortest path

Does the shortest path always use the fewest edges?

ANSWER

No. It uses the smallest total weight/cost.

Dijkstra’s Shortest Path

By the end, you can…
  • apply Dijkstra’s method systematically to a weighted graph;
  • update tentative distances and choose the next lowest-cost node;
  • reconstruct the final shortest route from predecessor information.

TERM 1 OF 8

Dijkstra’s algorithm

DEFINITION

An algorithm for finding shortest paths through a weighted graph.

TERM 2 OF 8

weighted graph

DEFINITION

A graph whose edges have numerical costs or distances.

TERM 3 OF 8

edge weight

DEFINITION

The numerical cost associated with travelling along an edge.

TERM 4 OF 8

tentative distance

DEFINITION

The best currently known total cost from the start node to another node.

TERM 5 OF 8

priority queue

DEFINITION

A queue ordered so that the smallest current distance can be selected next.

TERM 6 OF 8

visited

DEFINITION

A node whose shortest current distance has been selected and processed.

TERM 7 OF 8

predecessor

DEFINITION

The previous node on the best currently known route.

TERM 8 OF 8

shortest path

DEFINITION

The route with the smallest total edge cost between two nodes.

STANDARD ALGORITHM · PATH FINDING

Start → smallest tentative distance → update neighbours → repeat

Source graph from A:
A-B = 7
A-C = 3
A-D = 6
B-C = 2
B-D = 3
B-E = 6
C-E = 10
D-E = 5
Key idea: Keep the best known distance to each node. When a newly found route is shorter, replace the old value.

Model the method clearly
STEP 1

Choose C

C = 3

It has the smallest current distance.

STEP 2

Relax C’s neighbours

B via C = 5
E via C = 13

Replace larger tentative values with smaller ones.

STEP 3

Process B then D

B = 5
D stays 6

B→D gives 8, so it does not improve D.

STEP 4

Reach E

E via D = 6 + 5 = 11
route = A-D-E

11 is the shortest source-example route cost.
