OOP · Constructors and Initialisation

Book b = new Book("Dune");
Console.WriteLine(b.Title);

class Book {
  public string Title;
  public Book(string title) {
    Title = title;
  }
}
THINK

Explain the design decision

The constructor Book receives an argument when new Book is executed and sets Title before the object is used.

CONNECT TO PRIOR KNOWLEDGE

Procedural programming was taught in Lessons 009–012. Now focus on how classes and objects organise related data and behaviour.

OOP · Constructors and Initialisation

Book b = new Book("Dune");
Console.WriteLine(b.Title);

class Book {
  public string Title;
  public Book(string title) {
    Title = title;
  }
}
One worked example
STEP 1

Recognise the constructor

Its name matches the class, and it has no return type.

STEP 2

Trace the argument

The string Dune is passed into the title parameter.

STEP 3

Read the state

Title stores Dune, so Dune is output.
