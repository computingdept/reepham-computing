QUESTION 1 OF 4

LAST LESSON · L039 · METHODS

A Counter starts with Value = 0. Its Increment() method is called twice. What is Value afterwards?

ANSWER

2. Each call increases the stored Value by one.

QUESTION 2 OF 4

EARLIER · L030 · ADDERS

A half adder receives A = 1 and B = 1. Calculate Sum and Carry.

ANSWER

Sum = 0 (XOR); Carry = 1 (AND). Binary 1 + 1 produces 10.

QUESTION 3 OF 4

EARLIER · L019 · STACKS

Push A then B onto an empty stack. Pop once, then push C. Which item is now on top?

ANSWER

C. B is popped, leaving A; C is then pushed on top.

QUESTION 4 OF 4

CHALLENGE · L038–039 · OBJECT STATE

Two separately created Counter objects both start at Value = 0. One receives two Increment() calls; the other receives one. State both final values and explain.

ANSWER

The values are 2 and 1. Each instance stores its own Value, so calls on one do not alter the other.

    Title = title;

THINK

Explain the design decision

The constructor Book receives an argument when new Book is executed and sets Title before the object is used.
