QUESTION 4 OF 4

Charizard has 1000 HP and Squirtle has 1800 HP. Charizard attacks Squirtle for 160 damage. Why does Charizard remain on 1000 HP?

The attack changes Squirtle’s HP only. Each Pokémon instance stores its own attributes, so Charizard stays on 1000 HP.

OCR H446 · 1.2.4(e) · 2.2.1(f)

How a Pokémon gets its starting state

class Pokemon {
  public int HP;
  public Pokemon(int hp) {
    HP = hp;
  }
}
Pokemon charizard = new Pokemon(1000);
Console.WriteLine(charizard.HP); // 1000
THINK

What does the constructor do?

The argument 1000 is passed into hp. The constructor then assigns it to the new object’s HP attribute.

CONNECT TO LAST LESSON

Lesson 039 traced a Pokémon’s changing state in OCR pseudocode. Today we use C# to explain how that state is first initialised when an object is created.

MODELLED EXAMPLE · C#

Build the Pokémon constructor

class Pokemon {
  public string Name;
  public string Type;
  public int HP;
  public int Attack;
  public Pokemon(string n, string t, int hp, int a) {
    Name = n;
    Type = t;
    HP = hp;
    Attack = a;
  }
}
Pokemon p1 = new Pokemon("Charizard", "fire", 1000, 160);
Pokemon p2 = new Pokemon("Squirtle", "water", 1800, 90);
Console.WriteLine(p1.Name + ": " + p1.HP);
Console.WriteLine(p2.Name + ": " + p2.HP);
One worked example · reveal each step
STEP 1

Find the constructor

It is named Pokemon, just like the class, and has no return type. It runs when new Pokemon(...) creates an object.

STEP 2

Trace arguments into parameters

For Charizard: n gets "Charizard", t gets "fire", hp gets 1000, and a gets 160.

STEP 3

Read both objects’ initial state

The constructor assigns each argument to an attribute. Output: Charizard: 1000 and Squirtle: 1800. Each object has its own starting values.
