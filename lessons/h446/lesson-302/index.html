NEW LEARNING · WORKED EXAMPLE FIRST

Trace and predict

// Count distinct values in a SORTED array.
static int DistinctCount(int[] a){
 if(a.Length==0) return 0;
 int count=1;
 for(int i=1;i<a.Length;i++)
  if(a[i]!=a[i-1]) count++;
 return count;
}
// [1,1,2,2,4] → 3 distinct values.
STEP 1 OF 3

State the precondition

The input must be sorted; equal values then appear consecutively.

STEP 2 OF 3

Trace the invariant

Start with one distinct value for a nonempty array. Each change from previous value adds one.

STEP 3 OF 3

Evaluate and test

The algorithm scans once O(n) time, O(1) extra space; test empty, all equal and all distinct inputs.

I DO · WORKED MODEL

Trace distinct count in [2,2,5,5,7,7,7].

Start count=1
Change 2→5: count2
Change 5→7: count3
STEP 1 OF 2

Predict first

Duplicates do not increment the counter because each equals the preceding element.

STEP 2 OF 2

Explain the method

Only changes to five and seven increment count; result is three distinct values.

WE DO · DIFFERENT PROBLEM

Trace the algorithm on [1,1,1,3,4,4] and state two edge tests.

STEP 2 OF 2

Test empty input and an all-equal array to confirm base conditions and comparisons.
