NEW LEARNING · WORKED EXAMPLE FIRST

Trace and predict

// Count distinct values in a SORTED array.
static int DistinctCount(int[] a){
 if(a.Length==0) return 0;
 int count=1;
 for(int i=1;i<a.Length;i++)
  if(a[i]!=a[i-1]) count++;
 return count;
}
// [1,1,2,2,4] → 3 distinct values.
STEP 1 OF 3

State the precondition

The input must be sorted; equal values then appear consecutively.

STEP 2 OF 3

Trace the invariant

Start with one distinct value for a nonempty array. Each change from previous value adds one.

STEP 3 OF 3

Evaluate and test

The algorithm scans once O(n) time, O(1) extra space; test empty, all equal and all distinct inputs.

EXAMPLE

Trace distinct count in [2,2,5,5,7,7,7].

STEP 1 OF 2

Predict first

Duplicates do not increment the counter because each equals the preceding element.

STEP 2 OF 2

Explain the method

Only changes to five and seven increment count; result is three distinct values.

number = int(input("Denary:")) if number == 0 then print("0") else digits = "" while number > 0 remainder = number MOD 8 digits = str(remainder) + digits number = number DIV 8 endwhile print(digits) endif

EXAM QUESTION 2 OF 4 · 4 MARKS · 4 MINUTES

For a test, numbers = [4, 2, 4, 4, 2, 7] should produce distinct = [4, 2, 7], counts = [3, 2, 1].

GIVEN INFORMATION

A wildlife centre has written an original algorithm to count occurrences of integers in a list. It uses two parallel output arrays: distinct contains each unique integer and counts stores its frequency. Four numbered lines contain a logical error. Identify each wrong line and give a corrected complete line. [4]

01 function countOccurrences(numbers)
02   distinct = []
03   counts = []
04   size = numbers.length
05   for i = 0 to size
06     target = numbers[i]
07     match = -1
08     for j = 0 to distinct.length - 1
09       if distinct[j] != target then
10         match = j
11       endif
12     next j
13     if match == -1 then
14       distinct.append(target)
15       counts.append(0)
16     else
17       counts[match] = counts[match] - 1
18     endif
19   next i
20   return distinct, counts
21 endfunction

OCR H446/02 · June 2025 · Q6(d) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

Line 05: for i = 0 to size - 1 Line 09: if distinct[j] == target then Line 15: counts.append(1) Line 17: counts[match] = counts[match] + 1

Marking: Four marks: one for each correct combination of the original line number and corrected line (05, 09, 15, 17). Other logically equivalent changes can be considered only if they correctly repair the stated algorithm; four separate fixes are required. RHS ADDITIONAL PRACTICE · QUESTION 3 OF 4 · 3 MARKS · 3 MINUTES

An algorithm must find the largest difference between consecutive values in a list containing at least two integers. Describe a method that examines the list only once. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

Set largest to the absolute difference between the first two values. Loop through each remaining adjacent pair, calculate its absolute difference and update largest if the new difference is greater. Output largest.

Marking: One mark for calculating adjacent absolute differences; one for tracking and updating the maximum; one for examining all adjacent pairs and returning or outputting the result.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

A program checks whether a list contains any duplicate values. One method compares every pair of positions; another stores previously seen values in a hash set. Explain one time-space trade-off between these methods. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

The hash set requires additional storage for previously seen values, but membership checks are typically constant time on average, so the list can be checked in expected linear time rather than quadratic time.

Marking: One mark for extra memory used by the set; one for explaining the expected reduction in time or repeated comparisons.
