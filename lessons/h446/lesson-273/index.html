Compilers, interpreters and assemblers

By the end you can…
  • A compiler translates source code into another representation, often creating executable machine code via linking.
  • An interpreter executes program statements with a runtime, often without a separate standalone compiled executable.
  • An assembler translates assembly mnemonics and operands into processor machine instructions; translation strategies can overlap in modern environments.

QUESTION 2 OF 3

Explain two differences between compiling native code and interpreting source at runtime. [6]

WORKED ANSWER

Compiled output may be distributed separately [2]; interpreter/runtime required for interpreted execution [2]; translation timing and error reporting can differ [2].

QUESTION 3 OF 3

Evaluate using an interpreter in a classroom programming exercise versus distributing a native compiled application. [6]

WORKED ANSWER

Interactive execution/feedback [2]; convenient debugging [1]; runtime dependency [1]; compiled deliverable useful for native deployment [1]; performance/cross-platform trade-offs [1].
