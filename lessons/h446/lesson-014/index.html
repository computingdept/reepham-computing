QUESTION 1 OF 4

Last lesson

What two parts must a recursive method have so that it can terminate correctly?

ANSWER

A base case and a recursive case.

The recursive case must move toward the base case.

QUESTION 2 OF 4

2–3 lessons back

Why might a class-level variable be useful when several methods need the same data?

ANSWER

It has a wider scope, so several methods can access the same shared value or structure.

QUESTION 3 OF 4

Earlier retrieval

For string[,] board = new string[3,3];, what do GetLength(0) and GetLength(1) return?

ANSWER

3 and 3.

GetLength(0) gives rows; GetLength(1) gives columns.

QUESTION 4 OF 4

Challenge

Which is the better fit for repeatedly taking turns until a game ends: iteration or recursion?

ANSWER

Iteration.

A game loop naturally repeats while a condition remains true. Recursion would add unnecessary method calls.

Draw the board with nested loops

for (int row = 0; row < board.GetLength(0); row++)

    {

    }

    Console.WriteLine();
}

The outer loop changes row; the inner loop visits each column in that row.

STEP 3 OF 4

Turn 1–9 into row and column

int row = (move - 1) / 3;
int column = (move - 1) % 3;

Integer division finds the row. Remainder finds the column.

Move 8 → row 2, column 1 → board[2,1].

{
}

It displays the board but returns no value, so its return type is void.

STEP 3 · NESTED ITERATION

Visit every square

for (int row = 0; row < board.GetLength(0); row++)
{
    for (int column = 0; column < board.GetLength(1); column++)
    {
        Console.Write(board[row, column] + " ");
    }

    Console.WriteLine();
}

The inner loop finishes one row before the outer loop moves to the next.

STEP 4 · CALL IT
