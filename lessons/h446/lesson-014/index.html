NOUGHTS & CROSSES · PART 2

Yesterday: three similar instructions

Console.WriteLine(board[0,0] + " | " + board[0,1] + " | " + board[0,2]);
Console.WriteLine(board[1,0] + " | " + board[1,1] + " | " + board[1,2]);
Console.WriteLine(board[2,0] + " | " + board[2,1] + " | " + board[2,2]);
The problem: repeated code is harder to maintain. Today we will discover why iteration makes the same board easier to draw.
STEP 1 OF 5

Notice the repeated statements

Look at the three explicit row-printing instructions. The operation is the same; only the row index changes: 0, 1, 2.

Console.WriteLine(board[0,0] + " | " + board[0,1] + " | " + board[0,2]);
Console.WriteLine(board[1,0] + " | " + board[1,1] + " | " + board[1,2]);
Console.WriteLine(board[2,0] + " | " + board[2,1] + " | " + board[2,2]);
1 of 5
STEP 2 OF 5

Replace the rows with one loop

The first loop repeats the same row-print statement. row changes automatically; each repetition chooses a different row.

for (int row = 0; row < board.GetLength(0); row++)
{
    Console.WriteLine(board[row,0] + " | " +
                      board[row,1] + " | " +
                      board[row,2]);
}
2 of 5
STEP 3 OF 5

Spot the second repetition

Inside each row, we still refer to columns 0, 1 and 2. A second loop can move across the columns of one row.

for (int col = 0; col < board.GetLength(1); col++)
{
    Console.Write(board[0,col]);
    if (col < board.GetLength(1)-1)
        Console.Write(" | ");
}
Console.WriteLine();
3 of 5
STEP 4 OF 5

Put one loop inside the other

Outer loop = down the rows. Inner loop = across the columns. This is called nested iteration.

for (int row = 0; row < board.GetLength(0); row++)
{
    for (int col = 0; col < board.GetLength(1); col++)
    {
        Console.Write(board[row,col]);
        if (col < board.GetLength(1)-1)
            Console.Write(" | ");
    }
    Console.WriteLine();
}
4 of 5
STEP 5 OF 5

Make it reusable

GetLength(0) gives the row count; GetLength(1) gives the column count. Place the loops in DrawBoard(), then call it whenever the display needs refreshing.

DrawBoard(); // called from Main once the board exists

Keep the board array as a class-level field so DrawBoard() can access it. Lesson 015 uses the same board for moves.

STEP 3 · COLUMNS

Replace the repeated columns

Now each column is selected by col. After the third column, finish the row.

STEP 4 · NESTED

Combine both loops

for (int row = 0; row < board.GetLength(0); row++)
{
    for (int col = 0; col < board.GetLength(1); col++)
    {
        Console.Write(board[row,col]);
        if (col < board.GetLength(1)-1)
            Console.Write(" | ");
    }
    Console.WriteLine();
}

Predict how many times Console.Write(board[row,col]) executes: 9.

STEP 5 · METHOD

Refine into DrawBoard()

public static void DrawBoard()
{
    for (int row = 0; row < board.GetLength(0); row++)
    {
        for (int col = 0; col < board.GetLength(1); col++)
        {
            Console.Write(board[row,col]);
            if (col < board.GetLength(1)-1)
                Console.Write(" | ");
        }
        Console.WriteLine();
    }
}

This method assumes board is stored at class level. Call DrawBoard() from Main(). You can reuse it after every move in Lesson 015.
