Scope, modularity and parameters

By the end, you can…
  • Trace local versus class-level scope without guessing
  • Compare value and reference parameter passing
  • Refactor repeated logic into testable functions

Key vocabulary

scopelocalglobal/class-levelby valueby reference
NEW LEARNING · CODE FIRST

Track the changes step by step

static void Increase(ref int value) {
  value += 3;
}
int a = 5;
int b = a;
Increase(ref a);
// a = 8; b = 5
STEP 1 OF 3

Copying an integer

Assignment b=a copies the integer 5, not a reference to a storage location.

STEP 2 OF 3

Passing by reference

Increase(ref a) gives parameter value an alias of a, so the caller a changes to 8.

STEP 3 OF 3

Use modular methods

A short reusable method has a clear input effect, can be tested, and reduces repeated code.

I DO · MODEL EXAMPLE

Trace AddFour(x) by value when caller x starts at 6.

static void AddFour(int number) {
 number += 4;
}
int x=6; AddFour(x);
STEP 1 OF 3

Predict first

The function parameter number receives a copy of 6.

STEP 2 OF 3

Model and check

Inside the function number becomes 10; caller x remains 6.

STEP 3 OF 3

Model and check

The parameter leaves scope at the end of the call.

WE DO · DIFFERENT GUIDED EXAMPLE

Trace AddFour(ref y) when caller y starts at 9.

static void AddFour(ref int number) {
 number += 4;
}
int y=9; AddFour(ref y);
STEP 1 OF 2

Predict first

The ref parameter number refers to y, not a fresh copy.

STEP 2 OF 2

Model and check

Adding four changes caller y from 9 to 13.

Foundation · 3 marks · QUESTION 1 OF 3

Method AddTwo(int n) adds 2 to n. Caller x=7 is passed by value. What is x after the call?

WORKED ANSWER

[3] n is a copy of 7 [1], becomes 9 inside method [1], caller x remains 7 [1].

Core · 6 marks · QUESTION 2 OF 3

Write an OCR-style subroutine Swap with two by-reference integer parameters and explain why by-reference is required.

WORKED ANSWER

[6] procedure Swap(byRef a,byRef b) [1]; temp=a [1]; a=b [1]; b=temp [1]; caller variables must be updated rather than local copies [2].

Stretch · 6 marks · QUESTION 3 OF 3

Compare `int result=Double(x);` with `Double(ref x);` as ways of updating a number. Give advantages of one method for a pure calculation.

WORKED ANSWER

[6] Return version computes a result [1] and caller controls assignment [1]; ref version can update x in place [1]; returning avoids hidden state changes [1], is easier to reason about [1] and can be tested using input/output assertions [1].

TERM 1 OF 5

scope

Where a name can be accessed.

TERM 2 OF 5

local

Variable with block or method-level scope.

TERM 3 OF 5

global/class-level

Variable accessible in a wider scope, subject to access rules.

TERM 4 OF 5

by value

Pass a copy of the value.

TERM 5 OF 5

by reference

Pass an alias of the caller's variable.

True or false?

Passing an integer by value in C# changes the caller's integer when the parameter changes.

Model answer

False. A copy is passed unless a reference-passing mechanism such as ref is used.
