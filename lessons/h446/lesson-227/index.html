NEW LEARNING · CODE FIRST

Study the code and predict the state

// C# top-level statements must precede type declarations.
Counter c = new();
c.Add(4); // Set a breakpoint after this call.
Console.WriteLine(c.Count); // 4

class Counter {
  public int Count { get; private set; }
  public void Add(int n) { Count += n; }
}
STEP 1 OF 3

Set a breakpoint

Pause at a method call or the following instruction to inspect current state.

STEP 2 OF 3

Step into to inspect internals

Step Into executes the called method one instruction at a time. Watch Count and parameter n.

STEP 3 OF 3

Step over to skip internals

Step Over runs the entire call and pauses at the next statement, allowing you to inspect the result.

I DO · TEACHER MODEL

A Score class has Points=3. Add(5) should change Points to 8. Identify a wrong line.

void Add(int amount) {
  int points = Points + amount; // wrong
}
STEP 1 OF 3

Predict first

Step Into Add and inspect the local points and the field Points.

STEP 2 OF 3

Model the reasoning

The local becomes 8 while the object field remains 3; the assignment targets the wrong variable.

STEP 3 OF 3

Model the reasoning

Replace it with Points += amount; and rerun. The field should be 8.

WE DO · DIFFERENT GUIDED PROBLEM

A Lamp starts IsOn=false. Toggle() sets IsOn=true on every call. Diagnose the second-call error.

void Toggle() {
  IsOn = true; // wrong
}
STEP 1 OF 2

Predict first

After the first call, true is correct; after the second, IsOn should become false.

STEP 2 OF 2

Model the reasoning

The method always assigns true, so the second call fails. Fix to IsOn = !IsOn; and test twice.

Foundation · 3 marks · QUESTION 1 OF 3

Explain Step Into and Step Over at a method call.

WORKED ANSWER

[3] Step Into opens the called method for line-by-line execution [2]; Step Over executes it and stops at the next calling statement [1].

Core · 5 marks · QUESTION 2 OF 3

A class method Increase(int n) contains `int Total = Total + n;` while Total is an existing property. Identify the issue and write correct C# code.

WORKED ANSWER

[5] Local variable shadows property and may be uninitialised/invalid [2]; use `this.Total += n;` [2]; verify by testing initial Total=4, Increase(3) gives 7 [1].

Stretch · 6 marks · QUESTION 3 OF 3

Design an IDE-debugging workflow for a temperature sensor whose Readings list gains two entries after a single AddReading() call.

WORKED ANSWER

[6] Set breakpoint before call [1]; step into method [1]; inspect list count before update [1]; step through every append [1]; find duplicate append or duplicate caller invocation [1]; fix and retest one append [1].

True or false?

Step Over a method call means it is not executed.
