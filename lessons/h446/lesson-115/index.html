I DO · TEACHER MODEL

Explain the stages for the expression 'total = cost + 2' in a high-level source file.

WORKED REASONING

Model answer

Lexer identifies identifier, assignment, identifier, plus, integer. Parser checks grammatical structure. The compiler creates suitable target instructions; optimisation might fold constants only where semantics permit.

STEP 3 · EXPLAIN

Shared worked answer

Lexical analysis can still recognise tokens. Syntax analysis detects a missing closing delimiter because token order violates grammar. No valid final executable follows until corrected.
