OOP · Synoptic Exam Practice

Device d = new Laptop("L01");
Console.WriteLine(d.Label());

class Device {
  public string Id;
  public Device(string id) { Id = id; }
  public virtual string Label() { return "Device"; }
}

class Laptop : Device {
  public Laptop(string id) : base(id) { }
  public override string Label() { return "Laptop"; }
}
THINK

Explain the design decision

The Laptop constructor passes an ID to Device, and the virtual Label call dispatches to Laptop's override.
