Recursion and algorithm tracing

  • Trace recursive calls downward before calculating values on return.
  • Name the base case and variable that progresses toward it.
  • Recursion depth consumes call-stack memory even when total time is linear.

NEW LEARNING · MODEL FIRST

Follow the trace

static int SumOdds(int n){
 if(n<=0)return 0;
 int add=(n%2==1)?n:0;
 return add+SumOdds(n-1);
}
// SumOdds(5)=5+3+1=9.

EXAM QUESTION 1 OF 4 · 3 MARKS · 3 MINUTES

Describe three key characteristics that make this a recursive function. [3]

GIVEN INFORMATION
A learning game uses this function:
01 function recursiveScore(number)
02   if number <= 0 then
03     return 1
04   else
05     return number + recursiveScore(number - 3)
06   endif
07 endfunction

OCR H446/02 · June 2023 · Q5(a) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

recursiveScore calls itself; each call has its own parameter value and return point stored on a call stack; a base case stops further calls when number <= 0.

Marking: Up to three distinct accurate features, maximum three. A base case must be identified.

EXAM QUESTION 2 OF 4 · 5 MARKS · 5 MINUTES

Trace sumTrail(5). For each argument 5,4,3,2,1, give the value returned by that call and the final result. [5]

GIVEN INFORMATION
A school game uses this original six-line recursive function:
01 function sumTrail(n)
02   if n <= 1 then
03     return n
04   endif
05   return sumTrail(n - 1) + n
06 endfunction

OCR H446/02 · June 2022 · Q7(b) · RHS exam-style scenario

MODEL ANSWER · 5 MARKS

sumTrail(1)=1; sumTrail(2)=3; sumTrail(3)=6; sumTrail(4)=10; sumTrail(5)=15. Final return 15.

Marking: One mark per correctly calculated call/return pairing, five total; a list of only the final answer earns at most the final mark.
