QUESTION 1 OF 4

Last lesson

Why would Unicode be chosen instead of standard ASCII for a multilingual application?

ANSWER

Unicode supports a much larger repertoire of characters from many writing systems.

Standard ASCII has 128 codes and is centred on a limited character set. Unicode provides code points for many languages and symbols.

QUESTION 2 OF 4

2–3 lessons back

Decode 01011000 0011 in 8+4 two’s-complement floating-point format.

ANSWER

5.5

Mantissa 01011000 = 0.6875; exponent 0011 = 3; 0.6875 × 2³ = 5.5.

QUESTION 3 OF 4

Earlier retrieval

Convert 6D₁₆ to eight-bit binary.

ANSWER

01101101₂

6 → 0110 and D → 1101.

QUESTION 4 OF 4

Challenge

Decode 11110110 as an 8-bit two’s-complement integer. Show the signed place values.

ANSWER

−10

−128 + 64 + 32 + 16 + 4 + 2 = −10.

STEP 1 OF 4

Sequence = instructions in order

Sequence is the normal top-to-bottom execution of statements. Each statement happens after the previous one unless another construct changes the flow.

Console.Write("Name: ");
string name = Console.ReadLine();
Console.WriteLine("Hello " + name);
1 of 4
STEP 2 OF 4

Input arrives as text

Console.ReadLine() returns a string. If the program needs a whole number, parse the input into an int.

Console.Write("Age: ");
int age = int.Parse(Console.ReadLine());
Declare the type before the variable name: int age, string name, bool valid.
2 of 4
STEP 3 OF 4

Branching chooses a route

An if condition must evaluate to true or false. Only the matching branch is executed.

if (age >= 18)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Under 18");
}
3 of 4
STEP 4 OF 4

Conditions and order matter

Use == to compare equality, not =. Use &&, || and ! for AND, OR and NOT.

With else if, conditions are tested from top to bottom. Put the most demanding threshold first.

Test your code with normal, boundary and invalid/unexpected values.
