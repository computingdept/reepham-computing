CODING CHALLENGE 1

Positive, negative or zero

using System;

public class Program
{
    public static void Main()
    {
        Console.Write("Enter an integer: ");
        int number = int.Parse(Console.ReadLine());

        if (number > 0)
        {
            Console.WriteLine("Positive");
        }
        else if (number < 0)
        {
            Console.WriteLine("Negative");
        }
        else
        {
            Console.WriteLine("Zero");
        }
    }
}

Why it works: the first two conditions remove positive and negative values; the only remaining possibility is zero.

8 → Positive−3 → Negative0 → Zero
CODING CHALLENGE 2

Ticket category

using System;

public class Program
{
    public static void Main()
    {
        Console.Write("Enter age: ");
        int age = int.Parse(Console.ReadLine());

        if (age <= 11)
        {
            Console.WriteLine("Child");
        }
        else if (age <= 17)
        {
            Console.WriteLine("Teen");
        }
        else
        {
            Console.WriteLine("Adult");
        }
    }
}

Why the order works: once ages 11 and below have been removed, age <= 17 means 12–17.

11 → Child12 → Teen17 → Teen18 → Adult
CODING CHALLENGE 3

Delivery charge

using System;

public class Program
{
    public static void Main()
    {
        Console.Write("Order total: ");
        double total = double.Parse(Console.ReadLine());

        Console.Write("Member? yes/no: ");
        string member = Console.ReadLine();

        if (total >= 30 && member == "yes")
        {
            Console.WriteLine("Free delivery");
        }
        else
        {
            Console.WriteLine("Delivery charge applies");
        }
    }
}

Key idea: && means both Boolean expressions must be true.

35 + yes → Free25 + yes → Charge35 + no → Charge
CODING CHALLENGE 4

Simple login

using System;

public class Program
{
    public static void Main()
    {
        Console.Write("Username: ");
        string username = Console.ReadLine();

        Console.Write("PIN: ");
        int pin = int.Parse(Console.ReadLine());

        if (username == "admin" && pin == 2468)
        {
            Console.WriteLine("Access granted");
        }
        else
        {
            Console.WriteLine("Access denied");
        }
    }
}

Key idea: equality uses ==. The login succeeds only when both comparisons are true.

admin + 2468 → Grantedwrong + 2468 → Deniedadmin + 1111 → Denied
