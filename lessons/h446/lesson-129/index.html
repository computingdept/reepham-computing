CHALLENGE · QUESTION 3 OF 3

Evaluate dictionary coding for a document with frequent terms versus already-compressed random-looking data. [8]

MARK SCHEME / WORKED ANSWER

Repeated sequences help [2], tokens shorten recurring data [2], dictionary overhead matters [2], little redundancy in high-entropy data and justified choice [2].

TERM 1/4

dictionary coding

Encodes recurring sequences by referring to dictionary entries.

TERM 2/4

token

Short code representing a longer sequence.

TERM 3/4

overlap

Repeated sequence used by more than one part of the source.

TERM 4/4

lossless

Reconstruction is exact when dictionary and token mapping are known.

True or false?

Dictionary coding requires permanently discarding repeated words.

Model answer

False. The dictionary allows exact replacement when decoding.
