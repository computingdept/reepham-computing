QUESTION 4 · OCR 2019 Q16(b) · [2]

Why pass by value?

Passing by value gives each call its own copy of num1.

That means one recursive call does not overwrite the value being used by an earlier call.

If num1 were passed by reference, the calls would refer to the same original variable, so changing it could alter earlier calls and produce the wrong result.
