QUESTION 1 OF 4 · LAST LESSON · RECURSION

Retrieval

For Factorial(3), list the successive input values before any returns occur.

MODEL ANSWER

3, 2, 1, 0. Each call reduces n by one until the base case.

QUESTION 2 OF 4 · RECENT · FUNCTIONS

Retrieval

What is the difference between a function calling another function and returning a value to its caller?

MODEL ANSWER

A call transfers control into a function; return finishes that invocation and gives its result to the caller.

QUESTION 3 OF 4 · OLDER · STACKS

Retrieval

A stack contains bottom to top P, Q, R. After one pop, what is at the top?

MODEL ANSWER

Q. The topmost R is removed first.

QUESTION 4 OF 4 · CHALLENGE · TRACING

Challenge

A function Square(x) returns x*x. Find Square(2)+Square(3), showing both calls.

MODEL ANSWER

Square(2)=4 and Square(3)=9; the total is 13.

NEW LEARNING · CODE FIRST

What is the program actually doing?

int SumTo(int n)
{
    if (n == 1) return 1;
    return n + SumTo(n - 1);
}

Each call has its own n. The next call is placed on top of the previous one.

STEP 1 OF 3

Build the stack

SumTo(4) waits for SumTo(3), which waits for SumTo(2), which waits for SumTo(1).

STEP 2 OF 3

Separate the local values

Each stack frame holds its own n: 4, 3, 2 or 1. The values do not overwrite one another.

STEP 3 OF 3

Unwind from the top

SumTo(1) returns 1; SumTo(2) returns 3; SumTo(3) returns 6; SumTo(4) returns 10.

I DO · MODEL EXAMPLE

Draw the call-stack frames for SumTo(3). Which call returns first?

return n + SumTo(n - 1);

STEP 1 OF 3

Push

The frames are SumTo(3), SumTo(2), then SumTo(1), with SumTo(1) at the top.

STEP 2 OF 3

Stop

SumTo(1) is the base case; it returns 1 first.

STEP 3 OF 3

Unwind

SumTo(2)=2+1=3, followed by SumTo(3)=3+3=6.

WE DO · GUIDED PRACTICE · NEW INPUT

Trace SumTo(5). Label the top of the stack immediately before the first return.

5 → 4 → 3 → 2 → 1

Predict the next step before revealing the explanation.

STEP 1 OF 3

Call sequence

SumTo(5) → SumTo(4) → SumTo(3) → SumTo(2) → SumTo(1).

STEP 2 OF 3

Top frame

SumTo(1) is on top immediately before the first return.

STEP 3 OF 3

Returns

1, 3, 6, 10, 15. SumTo(5) returns 15.

Foundation · QUESTION 1 OF 3

List the call-stack frames from bottom to top for SumTo(4).

MODEL ANSWER

SumTo(4), SumTo(3), SumTo(2), SumTo(1). SumTo(1) is the top frame.

Core · QUESTION 2 OF 3

Trace the returned values for SumTo(6).

MODEL ANSWER

1, 3, 6, 10, 15, 21 in the order calls return; the outer function returns 21.

Stretch · QUESTION 3 OF 3

A pupil writes that SumTo(4) returns 4+3+2+1 before SumTo(1) has executed. Explain the order error.

MODEL ANSWER

The expression describes the final arithmetic but not execution order. The deepest call SumTo(1) must return first; only then can waiting calls compute their sums.

TERM 1 OF 5

stack frame

An entry containing the state for one active function call.

TERM 2 OF 5

unwind

Return from calls in reverse order after a base case is reached.

TERM 3 OF 5

local variable

A variable owned by a particular invocation.

TERM 4 OF 5

call stack

Last-in, first-out storage for active calls.

TERM 5 OF 5

base case

A condition that ends recursion.

True or false?

Every recursive call uses the same local-variable storage.

MODEL ANSWER

False. Each active call has its own stack frame and local values.
