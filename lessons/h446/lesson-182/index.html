QUESTION 1 OF 4

Parameter vs argument

What is the difference?

ANSWER

A parameter is the named input in a subroutine definition; an argument is the value supplied when it is called.

QUESTION 2 OF 4

DIV and MOD

Calculate 17 DIV 4 and 17 MOD 4.

ANSWER

17 DIV 4 = 4 and 17 MOD 4 = 1.

QUESTION 3 OF 4

Scope

Local vs global?

ANSWER

A local variable is accessible only within its subroutine/block; a global variable can be accessed from multiple parts of the program.

QUESTION 4 OF 4

Recursive call

Which part calls the function again?

ANSWER

generate(n + 1).

RECURSION TRACE · CORE METHOD

Call down → Base case → Unwind up

1. Write each new call
2. Stop at the base case
3. Record its return value
4. Work backwards
5. Calculate each waiting return
Key idea: never calculate an outer return before the inner recursive call has returned a value.
STEP 1 OF 4

Call down

build(2)
→ build(3)
→ build(4)
→ build(5)

Each recursive call creates a new active call with its own parameter value.

1 of 4
STEP 2 OF 4

Hit the base case

build(5) returns 8

This is the first value we can actually use. Everything above it has been waiting.

2 of 4
STEP 3 OF 4

Unwind one level at a time

build(4)
= 4 + (8 DIV 2)
= 8

Use the deepest returned value first, then move back to the previous call.

3 of 4
STEP 4 OF 4

Keep working backwards

build(3) = 3 + (8 DIV 2) = 7
build(2) = 2 + (7 DIV 2) = 5

DIV is applied at each level using the value returned by the deeper call.

4 of 4
ONE COMPLETE WORKED EXAMPLE

Trace build(2)

function build(n)
    if n > 4 then
        return 8
    else
        return n + (build(n + 1) DIV 2)
    endif
endfunction
Model the layout, not just the answer
STEP 1 · CALL DOWN

Record every new call

build(2)
= 2 + (build(3) DIV 2)

build(3)
= 3 + (build(4) DIV 2)

build(4)
= 4 + (build(5) DIV 2)

Do not try to finish any of these yet.

STEP 2 · BASE CASE

Find the first definite return

build(5)
→ 5 > 4
→ return 8

Now the unwinding can begin.

STEP 3 · UNWIND

Work from deepest to shallowest

build(4) = 4 + (8 DIV 2) = 8
build(3) = 3 + (8 DIV 2) = 7

Each completed return gives the previous call the value it was waiting for.

STEP 4 · FINAL RETURN

Finish the original call

build(2)
= 2 + (7 DIV 2)
= 2 + 3
= 5

Final return value: 5.

Trace IsOdious(2)

FUNCTION IsOdious(n : INTEGER)
    IF n = 0 THEN
        RETURN FALSE
    ELSE
        IF n MOD 2 = 0 THEN
            RETURN IsOdious(n DIV 2)
        ELSE
            RETURN NOT(IsOdious(n DIV 2))
        END IF
    END IF
END FUNCTION

Trace a recursive binary search

Given: 
Index: 0  1  2  3  4  5  6  7
Data:  5 10 15 20 25 30 35 40

function thisFunction(theArray, num1, num2, num3)
    result = num1 + ((num2 - num1) DIV 2)
    if num2 < num1 then
        return -1
    else
        if theArray[result] < num3 then
            return thisFunction(theArray, result + 1, num2, num3)
        elseif theArray[result] > num3 then
            return thisFunction(theArray, num1, result - 1, num3)
        else
            return result
        endif
    endif
endfunction
