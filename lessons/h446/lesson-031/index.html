Retrieval

A half adder receives A = 1 and B = 0. Calculate Sum and Carry. Explain which logic operation produces each output.

MODEL ANSWER

Sum = 1 because 1 XOR 0 = 1. Carry = 0 because 1 AND 0 = 0.

QUESTION 2 OF 4 · EARLIER · L028 · DE MORGAN

Retrieval

Apply De Morgan’s law to simplify ¬(A ∨ B).

MODEL ANSWER

¬A ∧ ¬B. Negate both inputs and change OR to AND.

QUESTION 3 OF 4 · OLDER · L022 · BINARY SEARCH TREE

Retrieval

Insert 40, 20, 60, 30 into an empty binary search tree. State the parent of 30 and whether 30 is its left or right child.

MODEL ANSWER

30 is the right child of 20: 30 is less than 40, but greater than 20.

QUESTION 4 OF 4 · CHALLENGE · EARLIER FLOATING POINT

Challenge

A = 0.1100₂ × 2³ and B = 0.0100₂ × 2³. Calculate A − B, showing the mantissa calculation and decimal result.

MODEL ANSWER

The exponents already match. 0.1100₂ − 0.0100₂ = 0.1000₂. The result is 0.1000₂ × 2³ = 4₁₀.

NEW LEARNING · 2 OF 9

Meet the D-type flip-flop

D is the data input. Q is the stored output. CLK determines when Q can update.

NEW LEARNING · 3 OF 9

Clock edges: up or down?

↑ Rising edge: CLK goes from 0 to 1 and the flip-flop samples D. ↓ Falling edge: CLK goes from 1 to 0 and Q holds. This D flip-flop triggers on the rising edge only.

NEW LEARNING · 4 OF 9

When does Q actually change?

At a rising clock edge (↑), Q copies D. Compare the old Q with D: if they differ, Q changes; if they match, Q stays the same.

No rising edge? Q keeps its old value, even if D changes or CLK falls. The arrows in the result column show the direction of Q's change, not a different clock trigger.

STEP 1 OF 5 · LOCATE

Identify which edges count

Point to CLK: ↑ is LOW → HIGH and samples D. ↓ is HIGH → LOW and does not update Q. Find all three ↑ edges before reading D.

STEP 2 OF 5 · EDGE 1

↑1: Q changes from 1 to 0

CLK rises. Read D = 0. Q was 1, so copying 0 causes a visible change. On the following falling edge Q holds 0, even though CLK moves.

STEP 3 OF 5 · BETWEEN

D changes, but Q stays 0

Look where D rises between ↑1 and ↑2. The clock has not risen again, so Q does not follow D. The falling clock edge also leaves Q unchanged.

STEP 4 OF 5 · EDGE 2

↑2: Q changes from 0 to 1

CLK rises again. D is now 1, and Q was 0. Sampling D makes Q change to 1. Q holds at 1 after CLK falls.

STEP 5 OF 5 · EDGE 3

↑3: Q stays 1 — despite a rising edge

CLK rises and samples D = 1. But Q already stores 1, so the output does not visibly change. The rule is: at ↑ copy D; otherwise hold Q.

GUIDED PRACTICE · WHAT ACTUALLY CHANGES?

Rising edge or falling edge?

Q starts at 0. Follow the signals left to right. Which events can update Q?

Example 2 of 4
YOUR TURN

Find the update events

At A, B, C, D, E and F, say whether Q changes or holds. Explain using the clock and D input.

CHECK · A AND B

A holds; B changes

A: D changes to 1, but CLK remains 0, so Q stays 0. B: CLK rises from 0 to 1, so Q copies D = 1 and changes to 1.

CHECK · C AND D

Both hold Q = 1

C: the clock falls (1 → 0), which does not trigger this flip-flop. D: D falls to 0 without a rising clock edge. Q still stores 1.

CHECK · E AND F

E changes; F stays 0

E: rising edge samples D = 0, so Q changes from 1 to 0. F: another rising edge samples D = 0, but Q already stores 0 — an update can leave Q unchanged.

THE RULE

Sample on ↑, hold otherwise

A rising clock edge makes Q copy D. Q visibly changes only if the sampled D differs from its stored value. A falling edge or a change in D alone never updates this rising-edge-triggered flip-flop.
