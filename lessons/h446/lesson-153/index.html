I DO · TEACHER MODEL

An online form permits Years 12 or 13. Where must that rule be checked?

STEP 1 OF 3

HTML accepts input

Identify the input or diagram and predict the first result.

STEP 2 OF 3

Browser checks locally

Follow the second stage and explain its importance.

STEP 3 OF 3

Server revalidates

HTML min/max and JavaScript improve normal experience; the server must check the supplied value independently. Client code can be changed or bypassed; no database update should trust it.

WE DO · DIFFERENT CASE

STEP 1 OF 3

STEP 2 OF 3

Follow the second stage and explain its importance.

STEP 3 OF 3

Authorise real total

Calculate actual price using a server-controlled catalogue, validate quantity and permissions, and use authoritative stock records; never trust a submitted total.
