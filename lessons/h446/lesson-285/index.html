MODEL ANSWER

Retrieval

MODEL ANSWER

Deny; AND requires both conditions true.

Why can an open port be useful but also increase risk?

MODEL ANSWER

It permits needed service connections, but exposes that service to network-originated attacks or probing.

Forward proxy:
Client → Proxy → Web server
STEP 1 OF 3

Check a firewall rule

A firewall applies configured rules to traffic according to properties such as direction, source/destination, ports and state. A basic rule example can allow TCP port 443 but deny 22.

STEP 2 OF 3

Different request, different decision

A TCP connection to port 22 is denied by the illustrated policy. A firewall rule is not automatically a guarantee that the permitted service is safe.

STEP 3 OF 3

A proxy is an intermediary

A forward proxy makes requests on behalf of clients, potentially enforcing policy or caching suitable resources. HTTPS content remains encrypted unless a controlled interception mechanism is in place.

I DO · WORKED EXAMPLE

For an inbound rule set allowing TCP 443 and denying TCP 22, decide whether two connection requests are permitted.

STEP 1 OF 3

443

An inbound TCP connection destined for port 443 matches the allow rule and is permitted.

STEP 2 OF 3

22

An inbound TCP connection destined for port 22 matches the deny rule and is blocked.

STEP 3 OF 3

Scope

An allow rule permits traffic; it does not prove that an application or connection is harmless.

WE DO · DIFFERENT GUIDED TASK

A school uses a forward proxy to restrict browsing. Explain the route for a permitted request and for a blocked site.

STEP 1 OF 2

Allowed resource

The student's request reaches the proxy, which permits it and contacts the website; a suitable cached response may be used instead.

STEP 2 OF 2

Blocked resource

If the proxy's policy denies the destination, it does not forward the request to that site; the student receives a blocking response.

WORKED ANSWER

TERM 1 OF 5

firewall

Security control that permits or blocks network traffic according to rules.

TERM 2 OF 5

forward proxy

Intermediary that makes requests on a client's behalf.

TERM 3 OF 5

filter rule

A condition and action defining whether traffic is permitted.

TERM 4 OF 5

cache

Stored copy of suitable data for reuse.

TERM 5 OF 5

defence in depth

Use multiple complementary security controls rather than trusting one.

True or false?

A forward proxy and firewall are identical because both can restrict access.

Model answer

False. A proxy acts as an intermediary for requests; a firewall enforces rules on traffic.
