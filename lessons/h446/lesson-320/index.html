CHALLENGE · QUESTION 3 OF 3

Q3 [9]: Evaluate cloud storage versus USB-only storage for an inclusive school revision service; weigh access, reliability, security. [9]

MARK SCHEME / MODEL ANSWER

Indicative content: availability across devices, offline access, connectivity, inclusive accessibility, confidentiality, school account permissions, backup and recovery, and cost. Practice marking (authored guidance, not an OCR mark scheme): 7–9 = accurate, sustained evaluation of both options, applied to this scenario with a supported judgement; 4–6 = relevant comparison with some development and a partly justified decision; 1–3 = basic statements, limited context or unsupported decision; 0 = no creditworthy response. Use best-fit and credit equivalent valid arguments.

Model evaluation: Cloud storage gives pupils access to revision materials across school and home devices and helps teachers distribute updates without copying files manually. However, some pupils have unreliable internet or limited access to suitable devices, and any outage can interrupt revision. USB-only storage works without a connection but is easy to lose, can be outdated and may create a safeguarding or data-security risk if sensitive content is included. For an inclusive revision service I would use an access-controlled cloud platform as the main source, while providing approved offline downloads or school-based access where needed. Accessibility settings, restricted permissions, tested backups and a procedure for updating offline copies should be part of the design. The best decision depends on actual pupil connectivity and devices.
