Software testing: finding and correcting faults

By the end you can…
  • Identify an incorrect range check
  • Correct its Boolean operators
  • Demonstrate the repair with boundary tests

Key vocabulary

logic errorinclusive boundaryvalidationdebuggingregression test
NEW LEARNING · CODE FIRST

Follow the example

// Intended ages 12–18 INCLUSIVE
static bool Eligible(int age)
  => age > 12 && age < 18; // BUG
// FIX: age >= 12 && age <= 18
STEP 1 OF 3

Read the stated rule

Because the permitted ages are inclusive, both age 12 and age 18 must be accepted.

STEP 2 OF 3

Locate the Boolean error

The strict comparison operators > and < exclude both valid boundaries.

STEP 3 OF 3

Repair and test

Change to >= and <=; retest the boundaries plus values just outside the range.

I DO · TEACHER MODEL

A score validator intended for 0–10 uses score>0 && score<10. Fix it.

return score>=0 && score<=10;
STEP 1 OF 2

Predict first

The valid endpoints were incorrectly rejected.

STEP 2 OF 2

Model and check

Change the operators to >= and <=, and test −1 and 11 as invalid values.

WE DO · DIFFERENT PROBLEM

A duration validator for 1–60 accepts 61 because it uses OR. Correct it.

return seconds >= 1 && seconds <= 60;
STEP 1 OF 2

Predict first

OR accepts 61 because only one side needs to be true.

STEP 2 OF 2

Model and check

AND requires both limits to hold and correctly rejects 61.

Foundation · 4 marks · QUESTION 1 OF 3

Correct x>5 && x<15 for values 5–15 inclusive, and state whether 5 and 15 are valid.

WORKED ANSWER

[4] Use the lower inclusive boundary x >= 5 [1] and upper inclusive boundary x <= 15 [1] together with AND: x >= 5 && x <= 15; x=5 is accepted [1] and x=15 is accepted [1]. Both clauses must be combined in the final condition.

Core · 6 marks · QUESTION 2 OF 3

Explain why `age>=12 || age<=18` accepts 100, correct it, and give outputs for 11,12,18,19.

WORKED ANSWER

[6] 100>=12 is true [1]; use && [1]; 11 false [1], 12 true [1], 18 true [1], 19 false [1].

Stretch · 6 marks · QUESTION 3 OF 3

Outline a debugging and regression-testing process after correcting a validator.

WORKED ANSWER

[6] Reproduce failing case [1]; identify faulty condition [1]; correct code [1]; retest valid boundaries [1] and invalid neighbours [1]; retain automated regression tests [1].
