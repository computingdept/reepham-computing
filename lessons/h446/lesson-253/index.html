QUESTION 4 OF 4 · YEAR 12 CHALLENGE · LESSON 031 · D FLIP-FLOPS

Year 12 challenge

A rising-edge D flip-flop initially has Q=0. D changes 0→1 between edges, then 1→0 just before the next rising edge. What is Q immediately after that edge? Justify.

MODEL ANSWER

Q=0. The flip-flop samples D at the rising edge (D=0 at that instant); an earlier pulse between clock edges is not stored.

Clock speed, cache and pipelining

By the end, you can…

Key vocabulary

clock speedcachepipelinehazardthroughput
NEW LEARNING · CODE OR MODEL FIRST

Trace the mechanism

// Simplified 3-stage pipeline: F=Fetch, D=Decode, E=Execute
// Independent instructions I1, I2, I3:
// Cycle 1: I1 F
// Cycle 2: I1 D | I2 F
// Cycle 3: I1 E | I2 D | I3 F
// Cycle 5: I3 E (all complete)
STEP 1 OF 3

Different performance factors

Clock speed indicates cycles per second; multiple cores can execute independent work; cache reduces some slower-memory access.

STEP 2 OF 3

Overlap pipeline stages

Without overlap, three three-stage instructions need nine stage slots; an ideal pipeline finishes them by the fifth cycle.

STEP 3 OF 3

Account for hazards

Branches, data dependencies and waiting for memory may cause stalls or pipeline flushing; pipelining does not make every instruction individually three times faster.

I DO · FULL MODEL

Trace two independent instructions through a 3-stage F–D–E pipeline.

I1: F1 D2 E3
I2: F2 D3 E4
STEP 1 OF 2

Predict first

Cycle 1 fetch I1. In cycle 2 decode I1 while fetching I2.

STEP 2 OF 2

Explain and check

Cycle 3 executes I1 and decodes I2; I2 executes in cycle 4.

WE DO · DIFFERENT QUESTION

Trace four independent instructions through the same pipeline. In which cycle does I4 finish?

3 stages; 4 independent instructions.
Ideal completion cycle = 3+4−1=6
STEP 1 OF 2

Predict first

Begin a new fetch on each clock cycle, while older instructions advance to Decode or Execute.

STEP 2 OF 2

Explain and check

Instruction four starts Fetch in cycle 4, Decodes in 5 and Executes in 6.

Foundation · 4 marks · QUESTION 1 OF 3

State two processor performance factors and explain one way each might improve throughput.

WORKED ANSWER

[4] Higher clock rate may allow more cycles each second [2]; larger/faster cache can reduce average memory latency [2]; alternatively cores can run independent tasks.

Core · 6 marks · QUESTION 2 OF 3

For a three-stage F–D–E pipeline with three independent instructions, write the stages occupied in cycles 1–5 and the completion cycle for I3.

WORKED ANSWER

[6] C1 I1:F [1]; C2 I1:D, I2:F [1]; C3 I1:E, I2:D, I3:F [2]; C4 I2:E, I3:D [1]; C5 I3:E [1].

Stretch · 6 marks · QUESTION 3 OF 3

Explain why doubling clock speed does not necessarily double an application's performance. Include one pipeline hazard.

WORKED ANSWER

[6] Memory stalls/cache misses [1], non-parallel parts of software [1], instructions per cycle vary [1], branch hazards can flush a pipeline [1], data dependencies stall instructions [1]; measured speedup depends on the bottleneck [1].

TERM 1 OF 5

clock speed

Number of processor clock cycles each second.

TERM 2 OF 5

cache

Small, fast memory that reduces some main-memory accesses.

TERM 3 OF 5

pipeline

Overlap stages of several instructions.

TERM 4 OF 5

hazard

Dependency or uncertainty disrupting smooth pipelining.

TERM 5 OF 5

throughput

Amount of work completed in a given time.

True or false?

Pipelining always reduces the number of stages required for an individual instruction.

Model answer

False. It usually overlaps stages to improve throughput, but each instruction still passes through its stages.
