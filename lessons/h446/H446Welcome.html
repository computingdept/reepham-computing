I DO — DEVELOP THE REASONING

Move from GCSE point to A Level explanation

Prompt

Explain why an array may be more suitable than separate variables for storing many related values.

Step 1 — Identify the property.
An array stores multiple values under one identifier.
Step 2 — Develop the consequence.
The values can be accessed systematically using an index.
Step 3 — Apply the judgement.
This makes processing many related values with loops simpler and more scalable than separate variables.

A Level habit

Do not stop at naming a fact. Link the property to a consequence and then to the context.

That pattern helps in both written papers.
