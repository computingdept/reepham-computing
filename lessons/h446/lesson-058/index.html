7 removed; 2 remains.
WORKED EXPLANATION

Unmarked warm-up: queue receives A then B. Dequeue once. State remaining item.

A leaves; B remains.
WORKED EXPLANATION

Explain

FIFO removes earliest arrival first.

FOUNDATION · QUESTION 1/3

Q1 [15]: (a) List [2,4,6] Insert(1,3), then RemoveAt(2). Give both states. [6] (b) Stack push A,B,C then pop then peek; give output and remaining. [5] (c) Queue enqueue 4,7,2 then dequeue twice. [4]

WORKED ANSWER

/15 (a) [2,3,4,6] [3], [2,3,6] [3]. (b) Pop C [2], Peek B [1], remaining [A,B] [2]. (c) dequeued 4,7 [2], remaining [2] [2].

CORE · QUESTION 2/3

Q2 [15]: (a) Draw HEAD→2→6→NULL inserting 4 after2. [5] (b) BST root8 left3 right10, 3 right6; inorder and postorder. [6] (c) BFS undirected edges A-B,A-C,B-D with B before C. [4]

WORKED ANSWER

/15 (a) 2.next→4 [2], 4.next→6 [2], final linked list [1]. (b) inorder 3,6,8,10 [3], postorder 6,3,10,8 [3]. (c) queue BFS A,B,C,D [4].
