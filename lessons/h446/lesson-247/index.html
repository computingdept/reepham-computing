QUESTION 4 OF 4 · YEAR 12 CHALLENGE · LESSON 020 · STACKS & QUEUES

Year 12 challenge

Push 4,9,2 onto a stack; pop once; enqueue the popped value to queue [7,8], then dequeue. Give remaining stack and queue.

MODEL ANSWER

Stack bottom-to-top [4,9]; pop gives 2; queue [7,8,2] then dequeue 7 leaves [8,2].

5↔2 → [2,5,4]

Q1 · 15 marks · QUESTION 1 OF 3

(a) State binary search's key precondition. [2] (b) Trace binary search for 11 in [1,3,5,7,9,11,13], giving low/high/mid at each step and resulting index. [7] (c) Compare worst-case complexities of linear and binary searches. [6]

FULL MODEL ANSWER

MARK SCHEME /15. (a) Sorted input [2]. (b) Start low0 high6 mid3→7 [2]; set low4 [1]; low4 high6 mid5→11 [2]; return index5 [2]. (c) Linear O(n) [2], may check all n [1]; binary O(log n) [2], halves the sorted candidate interval [1].

Q2 · 15 marks · QUESTION 2 OF 3

(a) Starting with [5,1,4,2], show the array after ascending bubble-sort Pass 1, Pass 2 and a final no-swap checking Pass 3. [9] (b) Compare bubble sort with merge sort in worst-case time complexity and auxiliary space. [6]

FULL MODEL ANSWER

MARK SCHEME /15. (a) Pass 1: [1,4,2,5] [3]; pass 2: [1,2,4,5] [3]; Pass 3 compares remaining adjacent values, makes no swaps, and stays [1,2,4,5] [3]. The no-swap pass confirms completion. (b) Bubble worst O(n²) [2]; merge sort worst O(n log n) [2]; merge generally uses O(n) auxiliary storage for merging while in-place bubble uses O(1) auxiliary [2].

Q3 · 15 marks · QUESTION 3 OF 3

(a) Write recursive C# function SumTo(n) returning 1+…+n for n≥0, with base case. [8] (b) Trace SumTo(3) showing the recursive calls and returned value. [5] (c) State one drawback of recursive solutions. [2]

FULL MODEL ANSWER

MARK SCHEME /15. (a) static int SumTo(int n) [2]; if(n==0)return 0; [2]; return n+SumTo(n-1); [4] with valid braces/structure. (b) SumTo(3)=3+SumTo(2) [1], =3+2+SumTo(1) [1], =3+2+1+SumTo(0) [1], SumTo(0)=0 [1], result 6 [1]. (c) Further call-stack memory [1] and possible stack overflow on deep recursion [1].
