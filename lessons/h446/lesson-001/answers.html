QUESTION 1 · DATA TYPES

A weather-monitoring system

number of readings → Integer
Reason: a whole-number count.

air temperature, e.g. 18.5 → Real / floating point
Reason: may contain a fractional part.

one-letter category → Character
Reason: one character is stored.

station identifier "0042" → String
Reason: it is an identifier and the leading zeros must be preserved.

sensor working → Boolean
Reason: only two states are required: true/false.

QUESTION 4 · RANGE & JUSTIFICATION

Choose a storage width

Largest unsigned 8-bit value:
2^8 - 1 = 255

8 bits are insufficient because:
300 > 255

9 bits give:
0 to 2^9 - 1
= 0 to 511

Minimum required width = 9 bits
