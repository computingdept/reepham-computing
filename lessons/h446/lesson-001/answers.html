Original question · 1 of 4 QUESTION 1 · DATA TYPES Suggested classroom marks: 10

A weather-monitoring system

For each field, state a suitable data type and justify it:

  1. number of readings collected;
  2. air temperature, e.g. 18.5 °C;
  3. a one-letter category, e.g. A;
  4. station identifier "0042";
  5. whether the sensor is working.
Completed answer
FINAL ANSWER
Integer · Real · Character · String · Boolean
Working and marking guidance 
number of readings → Integer
Reason: a whole-number count.

air temperature, e.g. 18.5 → Real / floating point
Reason: may contain a fractional part.

one-letter category → Character
Reason: one character is stored.

station identifier "0042" → String
Reason: it is an identifier and the leading zeros must be preserved.

sensor working → Boolean
Reason: only two states are required: true/false.
Original question · 2 of 4 QUESTION 2 · DENARY → BINARY Suggested classroom marks: 6

Encode the readings

Convert each value into unsigned 8-bit binary. Show a place-value decomposition.

a) 37
b) 92
c) 200

Classroom adaptation of the conversion skill used in OCR June 2017 Q6(a)(i).

Completed answer
FINAL ANSWER
37 → 00100101 · 92 → 01011100 · 200 → 11001000
Working and marking guidance 
37 = 32 + 4 + 1
37 = 00100101

92 = 64 + 16 + 8 + 4
92 = 01011100

200 = 128 + 64 + 8
200 = 11001000

Original question · 4 of 4 QUESTION 4 · RANGE & JUSTIFICATION Suggested classroom marks: 4

Choose a storage width

A system must store whole-number readings from 0 to 300 inclusive.

  1. State the largest unsigned 8-bit value.
  2. Explain why 8 bits are insufficient.
  3. Determine the minimum number of bits required and justify it using the unsigned range.
Completed answer
FINAL ANSWER
Minimum unsigned width: 9 bits
Working and marking guidance 
Largest unsigned 8-bit value:
2^8 - 1 = 255

8 bits are insufficient because:
300 > 255

9 bits give:
0 to 2^9 - 1
= 0 to 511

Minimum required width = 9 bits
