# Lesson 1: Data types and binary

A standalone 60-minute OCR A Level Computer Science lesson, prepared for format review. Open `index.html` in a browser. No installation, build or internet connection is needed. Keep `index.html`, `style.css`, `script.js` and the `assets` folder together.

## GitHub Pages

Upload these files and the assets folder to your chosen GitHub Pages publishing folder, preserving their filenames. This folder can be a lesson subdirectory in an existing Pages site. The lesson has no external dependencies or absolute asset paths. It has not been published or pushed to a GitHub repository.

## Teaching

Do Now retrieval (5 min), objectives (2), new learning (5), I do (10), We do (8), You do (25), exit ticket (5). Answers are collapsed and can be revealed per activity. Students answer on mini whiteboards; responses are not saved. All answers are present in the public source and are not access-controlled. For printing, expand only the answer panels you want included.

The five-lesson plan is available in the page overview. Only lesson 1 is implemented. This is a proposed revision sequence; first teaching may need more time, especially floating point.

Source: user-supplied PMT OCR Computer Science A Level, 1.4.1 Data Types, Advanced Notes, pages 2–6 for this lesson; pages 2–17 inform the sequence. The source PDF also contains unrelated data-structure questions and Boolean algebra pages; those have not been included. Original activities and indicative classroom marks are not official OCR examination material. The source PDF is not redistributed.

## HTML Lesson Builder format

Uses the phase-menu and classroom-signal layout recovered from the HTML Lesson Builder project’s CS Lesson HTML Format chat and published H446Lesson009. Original supplied PNG classroom logos are included unmodified. One section is shown at a time. Use the phase menu, Previous, Reveal/Continue or left/right arrow keys. I Do reveals the second worked example on demand; vocabulary alternates missing keywords and definitions, revealing one answer at a time with Cold Calling. All lesson content remains specific to this data-types lesson.

We Do uses OCR H446/01 June 2017 Q6(a)(i), with an original guided explanation. You Do lasts 25 minutes and contains 24 classroom marks: adapted unsigned-conversion practice and original contextual exam-style items. Sources and adaptations are labelled in the lesson.

You Do answers open in the separate scrollable `answers.html` page, with a return link to the questions. Include this file when publishing. All classroom signals use equal-sized display slots while preserving the original PNG proportions.
