Data types & binary

Choose the right data type. Understand how positive whole numbers become binary.

By the end, you can…
  • choose and justify a suitable primitive data type;
  • convert between denary and unsigned 8-bit binary;
  • explain place values and the range of an unsigned byte.

  1. Data types & binary — primitive types, positive integers and conversions (a, b, part of f).
  2. Signed integers & arithmetic — sign magnitude, two’s complement, addition, subtraction and overflow (c, d).
  3. Hexadecimal & bit manipulation — base conversions, logical shifts, AND, OR and XOR masks (e, f, i).

Do Now

CHALLENGE 1 · RECALL

Which data type?

Name the most suitable data type for each value:

  1. A count of 27 students.
  2. A temperature of 18.5 °C.
CHALLENGE 2 · APPLY

Digits or a number?

A student ID is "0042". Choose a suitable data type and explain why an integer would be unsuitable.

CHALLENGE 3 · CONVERT

Read the bits

Convert 00101101₂ into denary. Show the place values you add together.

CHALLENGE 4 · REASON

Find and fix the mistake

A pupil says: “The largest unsigned value in 8 bits is 256 because 2⁸ = 256.”

Explain the mistake. State the correct maximum and the minimum number of bits needed to store 256.

Reveal Do Now answers
  1. Integer for the student count: whole numbers. Real / floating point for temperature: it can have a fractional part.
  2. String: the ID is an identifier and its leading zeros matter. An integer stores the numerical value 42 without preserving those zeros.
  3. 32 + 8 + 4 + 1 = 45.
  4. 2⁸ counts the 256 different patterns, including zero. The unsigned range is 0–255, so the maximum is 255. Storing 256 needs 9 bits: 100000000₂.
NEW LEARNING · 5 MINUTES

Choose the right data type

1. Choose the type for the purpose

A data type describes the kind of value being stored and the operations that make sense for it. All these values are ultimately represented using bits.

Data typeWhat it storesExample & reason
IntegerA whole number, including zero or a negative value28 students — a count
Real / floating pointA numerical value that can have a fractional part18.5 °C — a measurement
CharacterOne character'A' — a single grade letter
StringA sequence of characters"0042" — an ID whose zeros matter
BooleanTrue or FalseTrue — permission granted
Think aloud: “A phone number contains digits, but I do not add phone numbers together. I choose a string to preserve its leading zero and any + sign.”

Language conventions vary: some languages use a one-character string rather than a separate character type. Floating point has limited precision; it cannot store every real number exactly.

03WATCH & LISTEN10 minutes

1. Binary → denary

Denary is base 10. Binary is base 2: each place is worth twice the place to its right. For unsigned binary, every place value is positive.

WORKED EXAMPLE 00101101₂ → ?₁₀
1286432168421
00101101
Most significant bit ←→ Least significant bit

32 + 8 + 4 + 1 = 45

Model: Write the place values. Select only the columns containing a 1. Add those values. A 0 contributes nothing.

2. Denary → binary

Convert 74 into an 8-bit unsigned value. Move left to right: if a place value fits into the remainder, write 1 and subtract it; otherwise write 0.

Place value1286432168421
Write01001010
Remainder741010102200

Result: 74₁₀ = 01001010₂. Check: 64 + 8 + 2 = 74. Leading zeros keep the answer at eight bits without changing its unsigned value.

Boundary check: Eight bits give 2⁸ = 256 different patterns, representing unsigned integers from 0 to 255. The largest value is 2⁸ − 1 because zero uses one pattern.
GUIDED EXAM PRACTICE8 minutes
OCR H446/01 · JUNE 2017 · Q6(a)(i) · [1 MARK]

Represent an unsigned integer

Convert the denary number 188 to an unsigned 8-bit binary number.

Source: OCR June 2017 question paper, page 12. Original exam question; the prompts below are added classroom scaffolding.

Build the answer together

  1. Identify the command word and the required number of bits.
  2. Write the eight unsigned place values on your MWB.
  3. Choose the places that total 188. Check each choice with a partner.
  4. Write the final eight-bit answer and check it in denary.
1286432168421
00000000₂=0denary
Reveal model answer

188 = 128 + 32 + 16 + 8 + 4.

Answer: 10111100 [1 mark].

The 64, 2 and 1 columns contain zero. The leading 1 contributes 128 because the question specifies unsigned binary.

The answer is calculated for this lesson; this explanation is not a reproduced OCR mark scheme.

CHECK UNDERSTANDING · CLASSROOM FOLLOW-UP

A pupil writes 00111100. Explain which place value is missing and why this answer represents 60 rather than 188.

Reveal explanation

The 128 column is zero instead of one. The remaining selected places total 32 + 16 + 8 + 4 = 60. Setting the 128 bit gives 188.

QUESTION 4 · RANGE & JUSTIFICATION · [4 MARKS]

Choose a suitable storage width

The system must store whole-number readings from 0 to 300 inclusive.

  1. State the largest unsigned integer representable using 8 bits. [1]
  2. Explain why 8 bits are insufficient for these readings. [1]
  3. Determine the minimum number of bits needed and justify your answer using its unsigned range. [2]
Need a starting point?

Use 128, 64, 32, 16, 8, 4, 2, 1. For a justification, connect the data type to what the field stores. For n unsigned bits, the range is 0 to 2ⁿ − 1.
