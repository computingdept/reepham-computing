QUESTION 1 OF 4

Recall

Choose the most suitable data type for 27 students and for a temperature of 18.5 °C.

ANSWER

Integer for 27; real / floating point for 18.5.

A count uses whole numbers. A temperature may contain a fractional part.

QUESTION 2 OF 4

Apply

A student ID is "0042". Which data type would you use, and why would an integer be unsuitable?

ANSWER

String.

The value is an identifier rather than a number for calculation. A string preserves the leading zeros; an integer would store the numerical value 42.

QUESTION 3 OF 4

Convert

Convert 00101101₂ into denary. Show the place values you add.

ANSWER

45

32 + 8 + 4 + 1 = 45
QUESTION 4 OF 4

Reason

A student says: “The largest unsigned 8-bit value is 256 because 2⁸ = 256.” Explain the mistake.

ANSWER

There are 256 different bit patterns, but the unsigned range starts at 0.

Eight bits represent 0–255. The value 256 needs 9 bits: 100000000₂.

CHOOSING A DATA TYPE

Store the value for its purpose

Integer — whole number, e.g. 28 students.

Real / floating point — may contain a fractional part, e.g. 18.5.

Character — one character, e.g. 'A'.

String — a sequence of characters, e.g. "0042".

Boolean — True or False.

Key idea: digits do not automatically mean integer. An identifier can be better stored as a string.
UNSIGNED BINARY

Each bit has a place value

128  64  32  16   8   4   2   1
  0   0   1   0   1   1   0   1
             ↓
       32 + 8 + 4 + 1 = 45

An 8-bit unsigned value has 256 possible patterns.

Range: 0 to 2⁸ − 1 = 255.

To convert denary to binary, choose place values that add to the target and write 1 in those positions.
