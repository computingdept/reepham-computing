Lesson 059 · Thinking Abstractly: What's the Model?

By the end you can…
  • Abstraction selects only the information required for the task and deliberately excludes irrelevant real-world detail.
  • An abstract model is a simplification of reality: here distance and child/adult status determine the fare; hair colour does not.
  • The model is only as good as its assumptions. If peak pricing or concessions apply, the abstraction needs refinement.

Key vocabulary

abstractionmodelassumptionirrelevant
NEW LEARNING · CODE FIRST

Trace the example

// Bus ticket fare model: ignore passenger clothing.
// Inputs: isChild, distanceKm.
decimal Fare(bool isChild,int distanceKm){
 decimal baseFare=distanceKm<=5?2m:4m;
 return isChild?baseFare/2m:baseFare;
}
// Fare(true,4) = £1, under stated rules.

I DO · MODEL

Choose relevant inputs for calculating parking fee at £2 per hour, rounded to whole hours.

Required: number of chargeable hours; irrelevant: car colour or radio station.
WORKED EXPLANATION

Explain

ParkingFee(hours)=hours×£2 for the simplified model; define non-negative hours and rounding rules.

WE DO · DIFFERENT PROBLEM

Model a library overdue fee of 20p per late day; decide which real-world details matter.

Input lateDays (non-negative); rate £0.20/day; output fee. Book cover colour is irrelevant.
WORKED EXPLANATION

Explain

Fee=0.20×lateDays in this simplified rule; real libraries might cap fees or exempt users.

FOUNDATION · QUESTION 1/3

For an automated bus fare model, identify three relevant and two irrelevant details. [5]

WORKED ANSWER

Relevant child category, distance, fare rules [3]; clothing colour, phone brand etc irrelevant [2].

CORE · QUESTION 2/3

Define inputs, processing and output for library overdue-fee model at 20p/day capped at £2. [6]

WORKED ANSWER

Input daysLate [1] non-negative validation [1]; fee=MIN(0.20×days,2.00) [3]; output fee [1].

CHALLENGE · QUESTION 3/3

Evaluate the risks of abstracting a school attendance intervention down to attendance percentage alone. [6]

WORKED ANSWER

Simple measurable indicator [1] but misses illness/SEND/context [2]; can bias decisions [1]; human review and further relevant variables [2].
