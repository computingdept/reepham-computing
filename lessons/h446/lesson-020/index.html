1.4.2(b)(c) · GRAPH

Use a 2D array as an adjacency matrix

    A B C
A   0 1 0
B   1 0 1
C   0 1 0

A — B — C
Undirected edges set two matrix positions. Directed edges set only the stated direction.
STEP 1 OF 4

Create

int[,] graph = new int[3,3];

Three vertices (A, B and C) produce a 3 by 3 matrix: one row and one column per vertex. The four-vertex 4×4 example comes later in You Do.

1 of 4
STEP 2 OF 4

Add undirected edge

graph[a,b] = 1;
graph[b,a] = 1;

The matrix is symmetrical for an undirected connection.

2 of 4
STEP 3 OF 4

Add directed edge

graph[a,b] = 1;

Only A→B is stored.

3 of 4
STEP 4 OF 4

Remove and inspect

graph[a,b] = 0;

for (int v = 0; v < graph.GetLength(1); v++)
{
    if (graph[a,v] == 1)
        Console.WriteLine(v);
}

Clearing removes an edge; scanning a row finds neighbours.
