Key vocabulary for today
stackLIFOpushpopqueueFIFOenqueuedequeue
1.4.2(b)(c) · STACK + QUEUE

Same items, different removal order

Add A, then B, then C

STACK pop:       C, B, A
QUEUE dequeue:   A, B, C
The defining feature is the order in which data can be added and removed.
STEP 1 OF 4

Stack = LIFO

Stack<string> history = new Stack<string>();
history.Push("A");
history.Push("B");
history.Push("C");

C is now on top because it was pushed last.

1 of 4
STEP 2 OF 4

Pop removes the top

Console.WriteLine(history.Pop()); // C

Peek inspects the top without removing it.

2 of 4
STEP 3 OF 4

Queue = FIFO

Queue<string> jobs = new Queue<string>();
jobs.Enqueue("A");
jobs.Enqueue("B");
jobs.Enqueue("C");

A is at the front because it arrived first.

3 of 4
STEP 4 OF 4

Dequeue removes the front

Console.WriteLine(jobs.Dequeue()); // A

Traversal can inspect the remaining items without changing their logical order.

4 of 4

STEP 4 · DEQUEUE

Remove twice

queue.Dequeue(); // A
queue.Dequeue(); // B
