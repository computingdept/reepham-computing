I DO · TEACHER MODEL

A small team repeatedly breaks existing features after changes. Which XP practices help?

WORKED REASONING

Model answer

Automated tests written before/with code (TDD) define intended behaviour, continuous integration runs regression tests on each change, and refactoring improves design without changing observable behaviour.

WE DO · DIFFERENT PROBLEM

A local club cannot describe its booking interface but can test clickable prototypes. Explain RAD.

STEP 1 · IDENTIFY

What must we decide?

Identify the inputs, relevant facts and exact output or judgement required.

STEP 2 · APPLY

Work through the method

Use the middle stage of the visual to follow the process and state each intermediate result.

STEP 3 · EXPLAIN

Shared worked answer

Create an early working prototype, invite feedback, revise the interface rapidly and iteratively converge on requirements. Beware treating a rushed prototype as production-quality architecture without further work.
