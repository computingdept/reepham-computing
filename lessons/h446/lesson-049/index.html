Lesson 049 · Stack<T>: LIFO and Program State

By the end you can…
  • A stack is last-in, first-out (LIFO). Push places a value on top, Pop removes the top, and Peek reads without removing.
  • A stack can support undo histories and recursive call frames. The physical call stack is a related example but not this Stack<T> collection.
  • Always check Count or otherwise handle an empty-stack exception before Pop/Peek.

Key vocabulary

LIFOPushPopPeek
NEW LEARNING · C# EXAMPLE FIRST

Trace the code

var jobs=new Stack<string>();
jobs.Push("A"); jobs.Push("B");
jobs.Push("C");
Console.WriteLine(jobs.Pop());  // C
Console.WriteLine(jobs.Peek()); // B
STEP 1 OF 3

Observe

A stack is last-in, first-out (LIFO). Push places a value on top, Pop removes the top, and Peek reads without removing.

STEP 2 OF 3

Explain

A stack can support undo histories and recursive call frames. The physical call stack is a related example but not this Stack<T> collection.

STEP 3 OF 3

Apply

Always check Count or otherwise handle an empty-stack exception before Pop/Peek.

I DO · MODEL

Trace stack push RED, push BLUE, pop.

var s=new Stack<string>();
s.Push("RED");s.Push("BLUE");
string x=s.Pop();
MODEL EXPLANATION

Trace and justify

Popped BLUE; remaining stack top RED. Most recent value leaves first.

WE DO · DIFFERENT DATA

Trace a different stack: push 2, push 5, pop, push 9. What is the top?

var s=new Stack<int>();
s.Push(2);s.Push(5);s.Pop();s.Push(9);
MODEL EXPLANATION

Trace and justify

Stack bottom-to-top [2,9], Peek returns 9; popped value was 5.

FOUNDATION · Q1 OF 3

WORKED ANSWER / MARKS

CORE · Q2 OF 3

Write C# to push 3,6,9 and safely pop one value. [6]

WORKED ANSWER / MARKS

var s=new Stack<int>(); [1], Push(3),Push(6),Push(9) [3], if(s.Count>0) [1] s.Pop() [1].

CHALLENGE · Q3 OF 3

Explain why stack suits undo history but queue suits printing jobs; include two operations. [6]

WORKED ANSWER / MARKS

Undo reverses most recent action [2] using Push/Pop [1]; printing queue serves earliest job [2] with Enqueue/Dequeue [1].
