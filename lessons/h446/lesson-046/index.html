Lesson 046 · Objects in Arrays and Lists

By the end you can…
  • A class describes an object; the array stores references to two Book instances.
  • Indexes start at 0. shelf[1] identifies the second reference, then .Title reads its property.
  • An array has a fixed length after creation; individual array elements can refer to objects whose properties change.

Key vocabulary

objectreferencealiasingindex
NEW LEARNING · C# EXAMPLE FIRST

Trace the code

class Book { public string Title {get;set;}=""; }
Book[] shelf={new Book{Title="Dune"},new Book{Title="Holes"}};
Console.WriteLine(shelf[1].Title); // Holes
STEP 1 OF 3

Observe

A class describes an object; the array stores references to two Book instances.

STEP 2 OF 3

Explain

Indexes start at 0. shelf[1] identifies the second reference, then .Title reads its property.

STEP 3 OF 3

Apply

An array has a fixed length after creation; individual array elements can refer to objects whose properties change.

I DO · MODEL

Trace the title stored at books[0] in a two-object Book array.

Book[] books={new Book{Title="Ada"},new Book{Title="Grace"}};
Console.WriteLine(books[0].Title);
MODEL EXPLANATION

Trace and justify

Index 0 refers to the first object; its Title is Ada.

WE DO · DIFFERENT DATA

In a different array, which title prints after updating the object at index 1?

Book[] b={new Book{Title="One"},new Book{Title="Two"}};
b[1].Title="Updated";
Console.WriteLine(b[1].Title);
MODEL EXPLANATION

Trace and justify

Index 1 refers to the second object. The property update changes its Title; output is Updated.

FOUNDATION · Q1 OF 3

Given shelf titles Dune,Holes, give output of shelf[1].Title and reason. [4]

WORKED ANSWER / MARKS

Holes [2]; 0-based index 1 selects second element and its Title [2].

CORE · Q2 OF 3

Write C# to create an array of two Book objects with titles A and B, then print first title. [6]

WORKED ANSWER / MARKS

Book[] b={new Book{Title="A"},new Book{Title="B"}}; [4] Console.WriteLine(b[0].Title); [2], assuming Book declares Title property.

CHALLENGE · Q3 OF 3

Two array elements reference the SAME Book object. Changing its title via first reference is then printed via second. Explain. [6]

WORKED ANSWER / MARKS

Both elements hold references [2] to same instance [2]; mutation visible through either reference [2]; this is aliasing, not array-index copying.
