OCR idea: global variables can be accessed across the program; local variables exist only within the subroutine/block in which they are declared.
STEP 1 OF 4

Scope controls where a variable can be used

A local variable is declared inside a method or block and can only be used within that scope.

For this course, we use a class-level static field to demonstrate the OCR idea of a global variable that can be accessed by multiple methods.

Prefer local variables where possible: their purpose and lifetime are easier to control.
1 of 4
STEP 2 OF 4

Parameters are local to the method

A parameter receives data when a method is called and behaves as a local variable inside that method.

public static int Triple(int number)
{
    return number * 3;
}

number exists within Triple. The value supplied in the call is the argument.

2 of 4
STEP 3 OF 4

By value = the method receives a copy

public static void Change(int number)
{
    number = 100;
}

Changing number changes only the method's local copy. The original variable in Main() is unchanged.

C# parameters are passed by value unless you explicitly use a reference-passing keyword such as ref.
3 of 4
STEP 4 OF 4

ref gives access to the original variable

public static void Change(ref int number)
{
    number = 100;
}

// call
Change(ref value);

Write ref in both places: in the method parameter and in the method call.

Changes made through the ref parameter remain after the method finishes.

Why doesn't the original value change?

Worked example
STEP 1 · ORIGINAL VARIABLE

Start in Main

int score = 10;

The variable score belongs to Main() and currently stores 10.

STEP 2 · PASS BY VALUE

The method receives a copy

public static void ChangeByValue(int number)
{
    number = 100;
}

The parameter number is a separate local variable initialised with the value 10.

STEP 3 · CHANGE THE COPY

Only number becomes 100

ChangeByValue(score);

inside method:
number = 100

back in Main:
score = 10

When the method ends, its local parameter is no longer needed.

STEP 4 · COMPARE WITH REF

Reference passing changes the original

ChangeByReference(ref score);

// method
public static void ChangeByReference(ref int number)
{
    number = 100;
}
By value → original stays 10. With ref → original becomes 100.
