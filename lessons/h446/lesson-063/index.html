Lesson 063 · Thinking Logically: Conditions and Decisions

By the end you can…
  • Identify decisions in the solution and write precise Boolean conditions, including valid-data boundaries.
  • Order conditions so cases are mutually understood: mark>=70 must be considered before mark>=40.
  • Use truth tables or decision tables to test normal, erroneous and boundary input values.

NEW LEARNING · CONTEXT FIRST

Trace the model

static string Grade(int mark){
 if(mark<0 || mark>100)return "Invalid";
 if(mark>=70)return "High";
 if(mark>=40)return "Pass";
 return "Below pass";
}
// Grade(70) -> High; Grade(39) -> Below pass.

CHALLENGE · QUESTION 3 OF 3

A program checks if(mark>=40) before else-if(mark>=70), then outputs Pass for 85. Explain bug and repair. [6]

WORKED ANSWER

85 meets first condition [2], second branch never reached [1], test >=70 first [2], 85 then High [1].
