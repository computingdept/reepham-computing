I DO · WORKED MODEL

Trace search for 3 in [1,3,5,7,9].

mid2→5; high1; mid0→1; low1; mid1→3 found.
WORKED EXPLANATION

Explain the method

The midpoint is excluded after a failed comparison, so bounds shrink.

WE DO · DIFFERENT EXAMPLE

Repair recursive SumTo for n=2.

if(n==0)return 0; else return n+SumTo(n-1);
WORKED EXPLANATION

Explain the method

SumTo(2)=2+SumTo(1)=2+1+SumTo(0)=3.
