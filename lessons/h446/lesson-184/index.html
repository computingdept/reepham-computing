NEW LEARNING · CODE FIRST

Read the code; predict its effect

int[] a = { 5, 1, 4, 2 };
for (int pass = 0; pass < a.Length - 1; pass++)
{
    bool swapped = false;
    for (int j = 0; j < a.Length - 1 - pass; j++)
        if (a[j] > a[j + 1])
        {
            (a[j], a[j + 1]) = (a[j + 1], a[j]);
            swapped = true;
        }
    if (!swapped) break;
}
STEP 1 OF 3

Compare neighbours

Compare positions j and j+1. Swap only if the earlier value is greater.

STEP 2 OF 3

Finish one pass

The greatest unsorted value moves to the right-hand end of the unsorted section.

STEP 3 OF 3

Repeat less work

Each completed pass fixes one final position; an entire pass with no swaps proves the array is sorted.

EXAM QUESTION 1 OF 2 · 5 MARKS · 5 MINUTES

A wildlife-rescue centre needs to order animal weights from smallest to largest using bubble sort. Describe a complete bubble-sort procedure that would work for an array of weights, including how comparisons, swaps and repeated passes are handled. [5]

OCR H446/02 · June 2025 · Q1(a)(i) · RHS exam-style scenario

MODEL ANSWER · 5 MARKS

Set a Boolean swap flag or similar. Compare each adjacent pair. If already ordered, leave the pair unchanged; if out of order, exchange them (a temporary variable is one option) and record that a swap happened. Repeat adjacent comparisons across the array and perform further passes until no swaps occur or the maximum number of passes has been reached.

Marking: Five marks for five distinct accurate stages from: flag/condition; adjacent comparison; no swap for ordered pair; swap disordered pair; exchange using temporary storage; update flag; finish full pass; repeat passes until ordered. The explanation of multiple passes must be clear.

EXAM QUESTION 2 OF 2 · 2 MARKS · 2 MINUTES

The same rescue centre improves its bubble sort by recording whether a swap happened in each pass. Explain how this can allow the algorithm to stop early, rather than always performing its maximum number of passes. [2]

OCR H446/02 · June 2025 · Q1(a)(ii) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

Reset the Boolean swap flag at the start of each pass. Set it when any two items are exchanged; if the pass finishes with the flag still false, there were no swaps so all items are in order and further passes stop.

Marking: One mark for tracking whether swaps occurred, one for stopping when the most recent complete pass had no swaps. A reference to the flag or equivalent condition is required.
