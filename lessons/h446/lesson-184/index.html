QUESTION 1 OF 4

Index 0

In an array A, what does A[0] refer to?

ANSWER

The first element in the array.

QUESTION 2 OF 4

Iteration

Which construct is used to repeat instructions?

ANSWER

A loop, such as for, while or do...until.

QUESTION 3 OF 4

Temporary value

Why might a temporary variable be needed when swapping two values?

ANSWER

It stores one value so it is not overwritten before the swap is complete.

QUESTION 4 OF 4

Stopping early

What would make a sorting algorithm stop early?

ANSWER

A complete pass in which no swaps are made shows the data is already sorted.

C# MODEL · BUBBLE SORT

First: make bubble sort actually run

Open .NET Fiddle →
using System;

public class Program
{
    public static void Main()
    {
        int[] values = { 7, 3, 5, 2 };

        for (int pass = 0; pass < values.Length - 1; pass++)
        {
            for (int i = 0; i < values.Length - 1 - pass; i++)
            {
                if (values[i] > values[i + 1])
                {
                    int temp = values[i];
                    values[i] = values[i + 1];
                    values[i + 1] = temp;
                }
            }
        }

        Console.WriteLine(string.Join(", ", values));
    }
}
Run it: the output should be 2, 3, 5, 7.

WORKED C# EXAMPLE · INSERTION SORT

Now code insertion sort

Open .NET Fiddle →
using System;

public class Program
{
    public static void Main()
    {
        int[] values = { 7, 3, 5, 2 };

        for (int i = 1; i < values.Length; i++)
        {
            int key = values[i];
            int j = i - 1;

            while (j >= 0 && values[j] > key)
            {
                values[j + 1] = values[j];
                j--;
            }

            values[j + 1] = key;
        }

        Console.WriteLine(string.Join(", ", values));
    }
}
Runnable example
STEP 1

Start from index 1

for (int i = 1; i < values.Length; i++)

The first value is treated as an already-sorted section of one.

STEP 2

Store the key

int key = values[i];
int j = i - 1;

The key is the value we are trying to insert.

STEP 3

Shift larger values right

while (j >= 0 && values[j] > key)
{
    values[j + 1] = values[j];
    j--;
}

This creates a gap in the correct place.

STEP 4

Insert the key

values[j + 1] = key;

Repeat until every value has been inserted into the sorted section.
