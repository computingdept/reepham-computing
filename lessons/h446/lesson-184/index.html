NEW LEARNING · CODE FIRST

Read the code; predict its effect

int[] a = { 5, 1, 4, 2 };
for (int pass = 0; pass < a.Length - 1; pass++)
{
    bool swapped = false;
    for (int j = 0; j < a.Length - 1 - pass; j++)
        if (a[j] > a[j + 1])
        {
            (a[j], a[j + 1]) = (a[j + 1], a[j]);
            swapped = true;
        }
    if (!swapped) break;
}
STEP 1 OF 3

Compare neighbours

Compare positions j and j+1. Swap only if the earlier value is greater.

STEP 2 OF 3

Finish one pass

The greatest unsorted value moves to the right-hand end of the unsorted section.

STEP 3 OF 3

Repeat less work

Each completed pass fixes one final position; an entire pass with no swaps proves the array is sorted.

Foundation · 1 OF 3

Show one left-to-right pass on [7,3,6,2].

WORKED ANSWER

[3,6,2,7]. Compare and swap 7 with 3, 6, then 2.

Core · 2 OF 3

Show two complete passes on [7,3,6,2].

WORKED ANSWER

Pass 1 [3,6,2,7]; pass 2 [3,2,6,7].

Stretch · 3 OF 3

Why can the early-exit optimisation finish immediately on [1,2,3,4]?

WORKED ANSWER

The first pass makes no swaps. swapped remains false, so the loop breaks because the sequence is already sorted.
