Lesson 047 · Two- and Three-dimensional Arrays in C#

By the end you can…
  • A rectangular C# 2D array uses [row,column]. Example seats has 2 rows and 3 columns.
  • A 3D array uses [layer,row,column]. new int[2,3,4] holds 24 integers; its last valid index is [1,2,3].
  • Each dimension starts at zero; distinguish [1,2,3] from a single flat offset and never exceed a dimension's length.

Key vocabulary

dimensionrowcolumnvoxel
NEW LEARNING · C# EXAMPLE FIRST

Trace the code

int[,] seats={{2,4,6},{8,10,12}};
Console.WriteLine(seats[1,2]); // 12
int[,,] voxels=new int[2,3,4];
voxels[1,2,3]=9;
Console.WriteLine(voxels[1,2,3]); // 9
STEP 1 OF 3

Observe

A rectangular C# 2D array uses [row,column]. Example seats has 2 rows and 3 columns.

STEP 2 OF 3

Explain

A 3D array uses [layer,row,column]. new int[2,3,4] holds 24 integers; its last valid index is [1,2,3].

STEP 3 OF 3

Apply

Each dimension starts at zero; distinguish [1,2,3] from a single flat offset and never exceed a dimension's length.

I DO · MODEL

Find seats[0,2] in {{3,5,7},{9,11,13}}.

int[,] a={{3,5,7},{9,11,13}};
Console.WriteLine(a[0,2]);
MODEL EXPLANATION

Trace and justify

First row, third column gives 7. The column index 2 is valid because there are three columns.

WE DO · DIFFERENT DATA

Work out final value from a different 3D array.

int[,,] cubes=new int[2,2,3];
cubes[1,0,2]=14;
Console.WriteLine(cubes[1,0,2]);
MODEL EXPLANATION

Trace and justify

Output 14: second layer, first row, third column. Six values per layer, twelve total.

FOUNDATION · Q1 OF 3

WORKED ANSWER / MARKS

CORE · Q2 OF 3

A 3D array has sizes [2,3,4]. Calculate items and last index triple. [6]

WORKED ANSWER / MARKS

2×3×4=24 [3], last triple [1,2,3] [3].

CHALLENGE · Q3 OF 3

Write two nested C# loops that print all values in int[,] a of 3 rows and 2 columns, explaining order. [6]

WORKED ANSWER / MARKS

for(int r=0;r<3;r++) [2] for(int c=0;c<2;c++) [2] Console.WriteLine(a[r,c]); [2]. Row-major traversal visits (0,0)..(2,1).
