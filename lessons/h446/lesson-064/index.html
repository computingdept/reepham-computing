Lesson 064 · Thinking Concurrently: Independent Work

By the end you can…
  • Find tasks that do not depend on each other's intermediate results. Independent work can overlap.
  • Distinguish concurrency (progress interleaved) from parallelism (truly simultaneous hardware execution).
  • Evaluate scheduling overhead and shared-resource/race risks, and explain why dependencies limit possible speedup.

I DO · MODEL

Calculate minimum ideal time for independent image operations 6s and 4s on separate cores.

Sequential10s; ideal parallel6s, as slower task determines finish.
WORKED EXPLANATION

Explain the decision

Only independent tasks can safely overlap without waiting for each other.

WE DO · NEW SCENARIO

Task B takes 3s but depends on Task A's output (A takes 5s). Can separate cores shorten ideal 8s chain?

No: B cannot begin until A completes, so critical path is 5+3=8s.
WORKED EXPLANATION

Explain the decision

Extra processors do not remove logical dependency.
