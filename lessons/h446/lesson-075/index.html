Lesson 075 · Big O: Quadratic, Exponential and Growth

By the end you can…
  • Two nested n loops perform n×n operations, producing O(n²) time when each inner operation is constant.
  • A binary decision at each of n positions can create 2ⁿ possibilities. This exponential growth quickly outruns polynomial methods.
  • Big O ignores constants and lower-order terms; compare classes by input growth while acknowledging memory, workload and implementation detail.

for(int i=0;i<n;i++)
 for(int j=0;j<n;j++) count++;
// Exponential O(2ⁿ) subset branches:

// n=5 => 32 possible subsets.
STEP 1 OF 3

Observe

Two nested n loops perform n×n operations, producing O(n²) time when each inner operation is constant.

STEP 2 OF 3

Explain

A binary decision at each of n positions can create 2ⁿ possibilities. This exponential growth quickly outruns polynomial methods.

STEP 3 OF 3

Evaluate

Big O ignores constants and lower-order terms; compare classes by input growth while acknowledging memory, workload and implementation detail.

I DO · MODEL

For n=6, calculate total iterations of two independent nested n loops.

6×6=36; O(n²) because the count scales with n squared.
WORKED METHOD

Explain

Each of the six outer iterations runs six inner iterations.

WE DO · DIFFERENT PROBLEM

For n=6 decisions, calculate binary include/exclude combinations.

2⁶=64 possibilities, O(2ⁿ) in full enumeration.
WORKED METHOD

Explain

Every new independent binary choice doubles the count.

FOUNDATION · Q1/3

For n=5 and n=10, calculate n² and 2ⁿ values. [6]

WORKED ANSWER

n5 n²25 [1] 2⁵32 [1]; n10 n²100 [2] 2¹⁰1024 [2].

APPLY · Q2/3

Explain time growth of a nested n×n loop and classify. [6]

WORKED ANSWER

Outer n iterations [2], inner n per outer [2], n² total [1], O(n²) [1].

CHALLENGE · Q3/3

A problem has 30 binary choices. Evaluate full subset enumeration and one way to reduce exploration. [6]

WORKED ANSWER

2³⁰≈1,073,741,824 subsets [2]; impractical exhaustive work may occur [1]; backtracking pruning with valid bound [2], depends on safe assumptions [1].
