ALGORITHM FIRST

Quicksort: split, sort, combine

function quickSort(values)
  if length(values) <= 1 then
    return values
  end if
  pivot = values[0]
  smaller = values after pivot < pivot
  larger = values after pivot >= pivot
  return quickSort(smaller) + [pivot]
         + quickSort(larger)
end function
STEP 1 OF 3

Choose a pivot

Take the first element, 6. In this example, we consistently use the first element of each sublist as its pivot.

STEP 2 OF 3

Partition the list

Put values smaller than 6 on the left; values greater than or equal to 6 on the right.

STEP 3 OF 3

Apply quicksort again

Recursively sort each sublist, then join smaller + pivot + larger. Other valid quicksort implementations may use a different pivot.

I DO · MODEL

Quicksort [5,3,8,2,6] using the first value as pivot.

STEP 1 OF 3

Identify the pivot

Choose 5 as the first pivot. Compare the remaining values with 5.

STEP 2 OF 3

Reveal the partition

3 and 2 are smaller; 8 and 6 are larger. The left and right sublists still need sorting.

STEP 3 OF 3

Reveal the full result

Sort [3,2] to [2,3] and [8,6] to [6,8]. Combine them with pivot 5: [2,3,5,6,8].

WE DO · TRY → DISCUSS → IMPROVE

Quicksort [6,8,1,7,3] using the first pivot.

Try

STEP 2 OF 3

Discuss

Left: [1,3]. Right: [8,7]. Why is [8,7] not yet sorted?

STEP 3 OF 3

Improve

Recursively sort [8,7] into [7,8]. Final list: [1,3,6,7,8].

MODEL ANSWER

[5] First pivot = 6 [1]; smaller [2,5,1] [1]; larger [9] [1]; sort the left sublist to [1,2,5] [1]; final result [1,2,5,6,9] [1].

Stretch · 4 marks · QUESTION 3 OF 3

Explain why the first-element pivot can produce O(n²) time on already sorted data. Suggest an improvement.

MODEL ANSWER

[4] Each pivot can be an extreme value [1]; partitions become 0 and n−1 elements [1]; repeated unbalanced recursion causes O(n²) comparisons [1]; choosing a random or middle/median pivot can reduce the risk [1].

TERM 1 OF 5

pivot

Value chosen to divide a list during quicksort.

TERM 2 OF 5

partition

Separate values into smaller and larger groups relative to the pivot.

TERM 3 OF 5

sublist

Smaller list created by partitioning.

TERM 4 OF 5

recursion

A function calling itself on a smaller input, with a stopping condition.

TERM 5 OF 5

divide and conquer

Divide into smaller problems, solve them and combine the results.

True or false?

1. Quicksort chooses a pivot.
2. Both sublists are always sorted after one partition.
3. Quicksort can call itself recursively.

Model answers

1. True — a pivot is chosen.
2. False — the sublists may still need sorting.
3. True — it recursively sorts the sublists.
