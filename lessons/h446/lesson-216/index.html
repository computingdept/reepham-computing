Quicksort: pivot and partition

CODE / ALGORITHM FIRST

Work through the algorithm

// Lomuto partition: use the final element as pivot.
int pivot = a[high];
int i = low;
for (int j = low; j < high; j++) {
  if (a[j] <= pivot) {
    (a[i],a[j]) = (a[j],a[i]); i++;
  }
}
(a[i],a[high]) = (a[high],a[i]);
STEP 1 OF 3

Pick a pivot

Use the rightmost element, 6. A left boundary i tracks where the next small value belongs.

STEP 2 OF 3

Scan and move

Only values less than or equal to 6 move left. We move 2, then 4, without sorting those two values.

STEP 3 OF 3

Place the pivot

Swap 6 into index 2; elements to the left are <=6, and those to the right are >6. Each side still needs sorting.

I DO · MODEL

Partition [6,3,8,2,5] around final-element pivot 5.

Scan j from 0 to 3; move <=5 left; place 5.
STEP 1 OF 3

Predict the next state

6 is larger than 5; 3 is smaller and swaps into the left boundary.

STEP 2 OF 3

Reveal and explain

8 is larger; 2 swaps to index 1, giving [3,2,8,6,5].

STEP 3 OF 3

Reveal and explain

Swap pivot 5 with position 2: [3,2,5,6,8]. The two sides are not yet necessarily sorted.

WE DO · DIFFERENT PROBLEM

Partition [8,1,7,3,6] using final pivot 6.

Record every move of a value <= 6.
STEP 1 OF 3

Predict the next state

Compare 8 and 1 with pivot 6. Move 1 into index 0.

STEP 2 OF 3

Reveal and explain

7 is too large, then 3 moves to index 1: [1,3,7,8,6].

STEP 3 OF 3

Reveal and explain

Put pivot at index 2: [1,3,6,8,7]. The right side [8,7] still needs sorting.

Stretch · 4 marks · QUESTION 3 OF 3

Explain why choosing the last element as pivot can lead to O(n²) work on already sorted data, and suggest an improvement.

MODEL ANSWER

[4] An already sorted input can place each pivot at one extreme [1]; partitions become n−1 and 0 elements [1]; recursion depth and comparisons become quadratic [1]; randomised/median-of-three pivot selection can reduce repeated poor pivots in practice [1].

TERM 1 OF 5

pivot

Element selected to split a quicksort partition.

TERM 2 OF 5

partition

Rearrange values so smaller/equal values are on one side of the pivot.

TERM 3 OF 5

Lomuto

A partition approach scanning left to right and placing the pivot last.

TERM 4 OF 5

index

Zero-based position within the array.

TERM 5 OF 5

divide and conquer

Solve smaller subproblems and combine results.

True or false?

A quicksort partition automatically fully sorts the two sides of the pivot.

Model answer

False. Partition places the pivot correctly; the two sides require further sorting.
