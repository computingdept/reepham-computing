Lesson 082 · Quicksort: Partition Around a Pivot

By the end you can…
  • Partitioning reorders values around a chosen pivot so values to its left are no larger and those right are larger, for this partition rule.
  • The pivot's final index is fixed after partition, but neither side is necessarily fully sorted; quicksort continues with the two subarrays.
  • Average and best-case time O(n log n), worst O(n²) with poor pivot choices; recursion consumes stack space depending on partition balance.

NEW LEARNING · ALGORITHM STATE VISUALISATION

Follow the worked example

// Lomuto partition, pivot = last value.
static int Partition(int[] a,int lo,int hi){
 int pivot=a[hi],i=lo;
 for(int j=lo;j<hi;j++){
  if(a[j]<=pivot){(a[i],a[j])=(a[j],a[i]);i++;}
 }
 (a[i],a[hi])=(a[hi],a[i]);
 return i;
}
// Recursively quicksort subarrays around returned pivot.
