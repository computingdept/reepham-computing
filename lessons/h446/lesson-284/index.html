NEW LEARNING · CONCRETE EXAMPLE FIRST
Packet 1: seq=1, data='HEL'
Packet 2: seq=2, data='LO'
Packets can take different routes.
If packet 2 arrives first, TCP buffers/reorders:
seq 1 + seq 2 → 'HELLO'
STEP 1 OF 3

Split a message into packets

The sender can split data into separate packets or segments. Each includes control information such as addressing and/or sequence information at relevant protocol layers.

STEP 2 OF 3

Packets may take different routes

Packet switching lets network traffic share links. IP forwarding can choose different paths; it does not guarantee the same arrival order.

STEP 3 OF 3

Restore order when needed

TCP provides a reliable ordered byte stream, using acknowledgements and retransmission if required. Do not confuse TCP guarantees with best-effort IP delivery.

I DO · WORKED EXAMPLE

Two TCP segments with sequence positions 1 and 2 travel on different routes and arrive 2, then 1. Explain the final data order.

STEP 1 OF 3

Route

The network may forward them along different paths, so arrival order is not guaranteed.

STEP 2 OF 3

Receive

TCP uses sequence information to buffer out-of-order data.

STEP 3 OF 3

Deliver

When missing earlier bytes arrive, TCP makes data available to the application in the correct order: first 1, then 2.

WE DO · DIFFERENT GUIDED TASK

Three TCP data segments arrive as 1, 3, with segment 2 missing. Explain what TCP can do.

STEP 1 OF 2

Detect gap

The receiver recognises that data between segment 1 and segment 3 is missing.

STEP 2 OF 2

Recover

TCP can cause the missing data to be retransmitted; once the gap is filled, data is delivered in order.

Foundation · QUESTION 1 OF 3

Give one difference between packet switching and circuit switching.

WORKED ANSWER

Packet switching shares links and forwards separate packets; circuit switching establishes a reserved communication path/resources for the duration of a connection.

Core · QUESTION 2 OF 3

Data labelled 1,2,3 arrives as 2,1,3 using TCP. Describe what the application receives.

WORKED ANSWER

TCP restores the correct byte order, so the application receives 1,2,3 in sequence (simplified labelled-segment example).

Stretch · QUESTION 3 OF 3

Explain one advantage of packet switching and why standards are important.

WORKED ANSWER

Packet switching uses shared network capacity efficiently and can route around disruptions. Common standards let devices and software made by different organisations communicate predictably.

TERM 1 OF 5

packet switching

Data is split and forwarded across shared network links.

TERM 2 OF 5

circuit switching

Communication uses a pre-established reserved path.

TERM 3 OF 5

sequence information

Control information that allows ordered reconstruction.

TERM 4 OF 5

retransmission

Sending missing or unacknowledged data again.

TERM 5 OF 5

standard

Agreed specification supporting compatibility and interoperability.

True or false?

IP guarantees that packets always arrive in the order sent.

Model answer

False. IP is best effort; protocols such as TCP offer reliable ordered delivery.
