OOP · Classes and Objects

Student a = new Student();
Student b = new Student();
a.Name = "Ada";
b.Name = "Ben";
Console.WriteLine(a.Name);

class Student {
  public string Name = "";
}
THINK

Explain the design decision

Student is the class; a and b are distinct objects. Each object holds its own Name value.

CONNECT TO PRIOR KNOWLEDGE

Procedural programming was taught in Lessons 009–012. Now focus on how classes and objects organise related data and behaviour.

One worked example
STEP 1

Identify the blueprint

The Student class defines the Name attribute.

STEP 2

Instantiate twice

new Student() creates a separate instance for each reference.

STEP 3

Trace the output

The output is Ada. Changing a.Name does not affect b.Name.
