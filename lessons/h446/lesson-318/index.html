I DO · WORKED MODEL

A sequential fetch starts PC=120. Explain what MAR, MDR and CIR do.

PC120→MAR120; instruction arrives via MDR→CIR; sequential PC121.
WORKED EXPLANATION

Explain the method

MAR holds address, MDR transfers contents, and CIR holds instruction for decoding.

WE DO · DIFFERENT EXAMPLE

Show all steps for 8-bit two's complement −6.

00000110 → invert11111001 → add1 11111010.
WORKED EXPLANATION

Explain the method

Use exactly eight bits; inversion alone represents the wrong number.

FOUNDATION · QUESTION 1 OF 3

In a simple sequential fetch-decode-execute cycle, PC initially holds 70 and memory location 70 contains the instruction LOAD 25. State MAR, MDR, CIR and the next PC value, and explain one action of the control unit. Assume no branch or interrupt. [6]

MARK SCHEME / MODEL ANSWER

MAR=70 [1]; the instruction LOAD 25 is fetched from M[70] into MDR [2]; CIR receives LOAD 25 from MDR [1]; PC advances to 71 [1]; the control unit decodes the instruction in CIR [1].

CORE · QUESTION 2 OF 3

Convert −18 to eight-bit two's complement and explain sign. [6]

MARK SCHEME / MODEL ANSWER

+18=00010010 [2], invert11101101 [2], add1=11101110 [1], leading1 indicates negative [1].

CHALLENGE · QUESTION 3 OF 3

Student(ID,Name) contains (1,Ada),(2,Ben). Mark(ID,Score) contains (2,80). Write an INNER JOIN using Student.ID=Mark.ID to select Name and Score, and state the output row. [6]

MARK SCHEME / MODEL ANSWER

SELECT Student.Name,Mark.Score [1] FROM Student [1] INNER JOIN Mark [1] ON Student.ID=Mark.ID [2]; output Ben80 [1].
