Retrieval

Why doesn't a smaller assembly instruction count guarantee a faster program?

MODEL ANSWER

Different instructions have different costs, and decoding, caches and pipelining affect performance.

QUESTION 2 OF 4 · RECENT · CPU

Retrieval

What is a core?

MODEL ANSWER

An execution unit capable of carrying out its own instruction stream.

QUESTION 3 OF 4 · OLDER · CONCURRENCY

Retrieval

Two independent tasks each take 4 minutes; what is ideal concurrent time?

MODEL ANSWER

4 minutes, ignoring overhead.

QUESTION 4 OF 4 · YEAR 12 CHALLENGE · LESSON 017 · ARRAYS

Year 12 challenge

Given int[] a={1,2,3,4}, perform a[i]=a[i]*2 for even indexes 0 and 2 only. Give final array and its sum.

MODEL ANSWER

Final [2,2,6,4], sum=14. Indexes 0 and 2 were changed, not the even-valued elements.

NEW LEARNING · CODE OR MODEL FIRST

Trace the mechanism

// A million pixels each need their brightness adjusted.
// Each pixel can be processed independently:
// output[i] = min(255,input[i]+20)
// A GPU may process many independent elements
// concurrently, subject to bandwidth and overhead.
STEP 1 OF 3

GPUs and data parallelism

A GPU contains many execution resources suited to repeating similar calculations across graphics pixels or machine-learning tensors.

STEP 2 OF 3

Multicore CPUs

Multiple CPU cores can run independent threads/processes, enabling greater throughput when tasks can be parallelised.

STEP 3 OF 3

Evaluate overhead

Data transfers, branching, synchronisation and sequential tasks can reduce the ideal speedup. A GPU is not automatically best for every problem.

I DO · FULL MODEL

Compare 12 independent image tiles split across four cores under an ideal equal-work model.

12 equal tiles / 4 cores → 3 per core
Ignore communication overhead.
STEP 1 OF 2

Predict first

Divide 12 independent equal-sized tiles among four available cores.

STEP 2 OF 2

Explain and check

Each core processes three tiles, so ideal completion is around one quarter of serial time only if work and overhead allow.

WE DO · DIFFERENT QUESTION

An encryption batch has 20 independent blocks and five worker cores. How many blocks per core ideally?

20 blocks / 5 workers = 4 blocks each
STEP 1 OF 2

Predict first

The blocks can be divided evenly into five independent groups.

STEP 2 OF 2

Explain and check

Each core receives four blocks; coordination overhead and data movement may affect real runtime.

Core · 6 marks · QUESTION 2 OF 3

A task has 24 independent identical chunks and six CPU cores. Calculate ideal work per core and describe two constraints on real speedup.

WORKED ANSWER

[6] 24/6=4 chunks per core [2]; serial work limits speedup [2]; synchronisation, memory-bandwidth or scheduling overhead [2].

Stretch · 6 marks · QUESTION 3 OF 3

A video-editing workflow must first decode frames sequentially, then apply the same filter independently to each frame, before assembling output. Explain which parts suit GPU execution and why.

WORKED ANSWER

[6] Independent per-frame filter calculations can be parallel [2]; GPU data-parallel execution benefits them [1]; decoding dependencies may constrain speedup [1]; assembly waits for processed frames [1]; host–GPU transfer and memory bandwidth reduce ideal gains [1].

True or false?

GPUs always execute any sequential algorithm faster than a CPU.

Model answer

False. Highly dependent tasks may not benefit and transfer/launch overhead can dominate.
