Network types, architecture and hardware

By the end you can…
  • A LAN covers a local area such as a school building; a WAN connects networks across wider geography.
  • Client-server uses dedicated service systems; peer-to-peer allows peers to exchange roles and resources, with different management implications.
  • NICs connect devices, switches forward local Ethernet frames, wireless APs bridge Wi-Fi, and routers forward IP packets between networks.

QUESTION 1 OF 3

Define LAN, WAN, switch and router. [4]

WORKED ANSWER

LAN local network [1], WAN wide-area connection [1], switch forwards LAN frames [1], router joins IP networks [1].

QUESTION 2 OF 3

Describe a laptop's network path via wireless access point, switch and router to the Internet. [6]

WORKED ANSWER

NIC/Wi-Fi interface [1], AP receives frame [1], switch forwards on LAN [1], router selects external network [1], ISP/WAN carries traffic [1], return follows appropriate route [1].

QUESTION 3 OF 3

Compare client-server and peer-to-peer for school file sharing, giving strengths and limits. [6]

WORKED ANSWER

Client-server central storage/permission policies [2] but server dependency/cost [1]; P2P direct resource sharing [2] but decentralised management [1].
