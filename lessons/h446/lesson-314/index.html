EXAM QUESTION 1 OF 4 · 5 MARKS · 5 MINUTES

Write a complete SQL query that shows ONLY UserName and FirstName of customers who consented to adverts. Join TblMember to TblPlan by PlanID and qualify the join fields. [5]

GIVEN INFORMATION

A museum's video service stores two connected tables: TblMember(MemberID PK, UserName, FirstName, PlanID FK, Adverts BOOLEAN) TblPlan(PlanID PK, PlanName, MonthlyCost REAL) A member's PlanID references TblPlan.PlanID. Adverts=TRUE indicates marketing consent.

OCR H446/01 · June 2022 · Q2(b) · RHS exam-style scenario

MODEL ANSWER · 5 MARKS

SELECT TblMember.UserName, TblMember.FirstName FROM TblMember JOIN TblPlan ON TblMember.PlanID = TblPlan.PlanID WHERE TblMember.Adverts = TRUE;

Marking: Five points: select the two requested fields; correct FROM; valid two-table JOIN; table-qualified join fields; WHERE Adverts=TRUE. A fully working query is required for full marks.

EXAM QUESTION 2 OF 4 · 4 MARKS · 4 MINUTES

A school concert website is built using HTML and CSS. Describe how each language contributes to what visitors see, giving two technically distinct roles or features for each. [4]

OCR H446/01 · November 2021 · Q3(a) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

HTML provides semantic page structure/content using tags such as headings and anchors. CSS styles elements using properties and selectors, controls colours/fonts/appearance and can be external or embedded.

Marking: Two marks for meaningful HTML roles and two for CSS roles. Do not give 'formatting' as the only definition of HTML.

EXAM QUESTION 3 OF 4 · 3 MARKS · 3 MINUTES

Explain THREE reasons why the pool's SERVER should recalculate the fee before accepting a payment, even if the browser has already calculated it. [3]

GIVEN INFORMATION
A community swimming pool sells tickets through a web page. It charges a booking fee of 2.99 per ticket; if the customer is outside the UK, a surcharge of 4.99 is added to EACH ticket's fee. The original RHS JavaScript is:
function calculateFee(numtickets, country) {
  let nonUKprice = 4.99;
  let perTicket = ______;
  if (country !== "UK") {
    perTicket = perTicket + ______;
  }
  let fee = perTicket * ______;
  ______ fee;
}

OCR H446/01 · November 2021 · Q3(d)(i) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

Client-side JavaScript can be modified/bypassed by the buyer; their browser may disable scripts or fail to execute them; the server needs an authoritative correct total for quantity and international surcharge before charging money.

Marking: One mark per distinct relevant reason; focus on security/untrusted clients and consistent totals.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 3 MARKS · 3 MINUTES

A concert website stores bookings in TblBooking(BookingID, CustomerName, Seats). Write an SQL query to return CustomerName and Seats for bookings of at least four seats, ordered by Seats from largest to smallest. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

SELECT CustomerName, Seats FROM TblBooking
WHERE Seats >= 4
ORDER BY Seats DESC;

Marking: One mark for the correct SELECT and FROM; one for WHERE Seats >= 4; one for ORDER BY Seats DESC.
