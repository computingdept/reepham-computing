By the end you can…
  • A primary key identifies rows; a foreign key creates the relationship across tables.
  • An INNER JOIN returns matching rows; a WHERE clause then filters them.
  • HTML structures user forms, CSS styles them, and JS can respond to events. Server-side checks remain authoritative.

NEW LEARNING · EXAMPLE FIRST

Trace and explain

Student(ID,Name): (1,Ada),(2,Ben),(3,Cleo)
Score(ID,Mark): (1,60),(3,80)
SELECT Student.Name, Score.Mark
FROM Student INNER JOIN Score
ON Student.ID=Score.ID
WHERE Score.Mark>=70;
// Cleo 80
