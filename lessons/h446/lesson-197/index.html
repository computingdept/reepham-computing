Key vocabulary for today

CODE FIRST · WORKED REPRESENTATION

Predict what changes

var stack = new Stack<int>();
stack.Push(4);
stack.Push(7);
int result = stack.Pop(); // 7
STEP 1 OF 3

Push

Adding an item puts it on top of a stack.

STEP 2 OF 3

Pop

Removing an item takes the most recently pushed item: 7.

STEP 3 OF 3

Contrast with a queue

A queue removes the oldest item instead (FIFO); it is suited to arrival-order processing.

I DO · WORKED

A stack receives 3, 8, 5, then Pop once. Give removed value and remaining stack bottom-to-top.

var stack = new System.Collections.Generic.Stack<int>();
stack.Push(3);
stack.Push(8);
stack.Push(5);
int removed = stack.Pop(); // 5
STEP 1 OF 2

Predict

The newest value 5 is on top, so Pop removes 5.

STEP 2 OF 2

Confirm and explain

The stack remains [3,8] from bottom to top.

WE DO · DIFFERENT TASK

Trace a circular queue of capacity 3.

// Pseudocode: initially front=rear=count=0.
// Trace enqueue A,B,C; dequeue; enqueue D.
Enqueue(v): reject and stop if count==3
  q[rear]=v; rear=(rear+1) MOD 3; count++
Dequeue(): reject and stop if count==0
  value=q[front]; front=(front+1) MOD 3; count--
// rear means NEXT FREE slot; q has 3 slots.
STEP 1 OF 2

Predict

After A,B,C: front=0, rear=0, count=3. The queue is full even though front==rear. rear means next free slot here, unlike Lesson 020.

STEP 2 OF 2

Confirm and explain

Remove A: front=1, count=2. Insert D at slot0: rear=1, count=3. Physical D,B,C differs from logical B,C,D; modulo reuses the freed slot.

Foundation · 1 OF 3

Push A, B, C onto a stack then Pop twice. What remains?

MODEL ANSWER

A remains. The pops remove C then B.

Core · 2 OF 3

A circular array queue has capacity 3. Starting empty, enqueue 10,20,30; dequeue once; enqueue 40. State physical slots, front/rear/count and logical order. Use rear as the next free slot.

MODEL ANSWER

Physical slots [40,20,30]; front=1, rear=1, count=3. Logical order is 20,30,40. Reject enqueue when count==3 and dequeue when count==0; increment indexes modulo 3.

Stretch · 3 OF 3

Explain why an undo history usually uses a stack rather than a queue.

MODEL ANSWER

The most recent change must be undone first, which follows LIFO; FIFO would undo oldest changes first.
