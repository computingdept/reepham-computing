Stacks and queues

By the end, you can…
  • Trace push/pop and enqueue/dequeue operations
  • Distinguish last-in-first-out from first-in-first-out
  • Justify a suitable data structure in context

Key vocabulary for today

stackpushpopqueuedequeue
CODE FIRST · WORKED REPRESENTATION

Predict what changes

var stack = new Stack<int>();
stack.Push(4);
stack.Push(7);
int result = stack.Pop(); // 7
STEP 1 OF 3

Push

Adding an item puts it on top of a stack.

STEP 2 OF 3

Pop

Removing an item takes the most recently pushed item: 7.

STEP 3 OF 3

Contrast with a queue

A queue removes the oldest item instead (FIFO); it is suited to arrival-order processing.

I DO · WORKED

A stack receives 3, 8, 5, then Pop once. Give removed value and remaining stack bottom-to-top.

var stack = new System.Collections.Generic.Stack<int>();
stack.Push(3);
stack.Push(8);
stack.Push(5);
int removed = stack.Pop(); // 5
STEP 1 OF 2

Predict

The newest value 5 is on top, so Pop removes 5.

STEP 2 OF 2

Confirm and explain

The stack remains [3,8] from bottom to top.

WE DO · DIFFERENT TASK

A queue receives A, B, C, then Dequeue once. Which item leaves and what remains?

var queue = new System.Collections.Generic.Queue<char>();
queue.Enqueue('A');
queue.Enqueue('B');
queue.Enqueue('C');
char removed = queue.Dequeue(); // 'A'
STEP 1 OF 2

Predict

The earliest item A is at the front, so it is removed first.

STEP 2 OF 2

Confirm and explain

The remaining queue is B then C (front to rear).

Foundation · 1 OF 3

Push A, B, C onto a stack then Pop twice. What remains?

MODEL ANSWER

A remains. The pops remove C then B.

Core · 2 OF 3

Enqueue 10, 20, 30; dequeue; enqueue 40. What remains front-to-rear?

MODEL ANSWER

20, 30, 40.

Stretch · 3 OF 3

Explain why an undo history usually uses a stack rather than a queue.

MODEL ANSWER

The most recent change must be undone first, which follows LIFO; FIFO would undo oldest changes first.

A queue removes the most recently inserted item first.

Model answer
