NEW LEARNING · EXAMPLE FIRST

Study the worked scenario

// Scenario: a school requests a booking system.
// WATERFALL: agree requirements before build.
// AGILE: deliver a small working feature in each sprint.
// XP: agile practices include pair programming,
// test-driven development and frequent integration.
STEP 1 OF 3

Waterfall is sequential

Agree requirements, then design, implementation, testing and deployment. Revisiting an earlier stage can be costly.

STEP 2 OF 3

Agile delivers incrementally

Each short iteration produces working software and seeks feedback, so priorities can change between iterations.

STEP 3 OF 3

Extreme Programming (XP)

XP is an agile methodology emphasising practices such as test-driven development, pair programming, refactoring and continuous integration.

I DO · TEACHER MODEL

A hospital requests software with a carefully agreed specification and formal approvals. Why might Waterfall suit it?

APPROVAL → DESIGN → IMPLEMENT → TEST → SIGN-OFF
STEP 1 OF 2

Predict first

Requirements and approval milestones can be documented before later stages proceed.

STEP 2 OF 2

Model and explain

Waterfall offers clear documentation and control, but late changes can require expensive rework.

WE DO · DIFFERENT GUIDED PROBLEM

A pupil revision app changes after each group of students tries it. Which approach fits and why?

SPRINT 1: quiz → feedback
SPRINT 2: revision history → feedback
SPRINT 3: accessibility improvements
STEP 1 OF 2

Predict first

Changing needs and quick feedback favour Agile iterations over a rigid up-front plan.

STEP 2 OF 2

Model and explain

A usable quiz is released first, then revision history and accessibility features improve in later sprints.

Foundation · 3 marks · QUESTION 1 OF 3

State a defining characteristic of Waterfall, Agile and XP.

WORKED ANSWER

[3] Waterfall follows largely sequential planned stages [1]; Agile develops in short iterations with feedback [1]; XP uses practices such as pair programming and test-driven development [1].

Core · 5 marks · QUESTION 2 OF 3

A mobile app company receives new customer requirements each fortnight. Recommend a methodology and explain two advantages and one disadvantage.

WORKED ANSWER

[5] Recommend Agile [1]; frequent releases/feedback [1]; priorities can change between sprints [1]; customer involvement helps reveal errors early [1]; less predictable full scope/timescale [1].

Stretch · 6 marks · QUESTION 3 OF 3

Explain how test-driven development and continuous integration in XP could reduce defects, and why neither guarantees fault-free software.

WORKED ANSWER

[6] Write a failing test before implementation [1]; implement just enough to pass [1]; refactor with tests [1]; integrate changes frequently [1] to detect conflicts early [1]; tests cannot cover every case and may themselves be incomplete [1].
