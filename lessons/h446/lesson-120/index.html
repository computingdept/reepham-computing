I DO · TEACHER MODEL

Trace total ← 0; FOR n = 1 TO 4: IF n MOD 2 = 0 THEN total ← total + n; NEXT n; OUTPUT total.

WORKED REASONING

Model answer

At n=1 total 0; n=2 total 2; n=3 total 2; n=4 total 6; output 6. Record n and total at each loop step.

Check: link each claim to the scenario and use precise OCR terminology.

WE DO · DIFFERENT PROBLEM

Trace largest ← 0; values=[3,8,5]; FOR each value IF value>largest THEN largest←value; OUTPUT largest.

STEP 1 · IDENTIFY

What must we decide?

Identify the inputs, relevant facts and exact output or judgement required.

STEP 2 · APPLY

Work through the method

Use the middle stage of the visual to follow the process and state each intermediate result.

STEP 3 · EXPLAIN

Shared worked answer

Progress: initial 0; after 3 → 3; after 8 → 8; after 5 stays 8; final output 8. The initial zero fails if all values are negative; use first element instead.

FOUNDATION · QUESTION 1 OF 3

Trace count ← 0; FOR i = 1 TO 5: IF i MOD 2=1 THEN count←count+1; NEXT; OUTPUT count. [6]

MARK SCHEME / WORKED ANSWER

Odd i values 1,3,5 cause increments; count progresses 1,2,3; output 3. Credit correctly labelled trace columns and output.

APPLICATION · QUESTION 2 OF 3

Explain why initialising max ← 0 can cause a fault when finding the maximum of negative values. [6]

MARK SCHEME / WORKED ANSWER

Zero exceeds all negative inputs [2], result incorrectly remains 0 [2], initialise from first actual element and iterate remainder [2].
