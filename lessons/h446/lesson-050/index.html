Lesson 050 · Queue<T>: FIFO and Service Order

By the end you can…
  • A queue is first-in, first-out (FIFO). Enqueue joins the rear; Dequeue removes from the front.
  • Queues are suitable for ordered service requests such as print jobs or breadth-first exploration, if the queueing policy is FIFO.
  • Peek inspects the front without removing. An empty Queue<T> throws on Dequeue/Peek unless the code guards against it.

Key vocabulary

FIFOEnqueueDequeuefront
NEW LEARNING · C# EXAMPLE FIRST

Trace the code

var print=new Queue<string>();
print.Enqueue("Ada");
print.Enqueue("Ben");
print.Enqueue("Cleo");
Console.WriteLine(print.Dequeue()); // Ada
Console.WriteLine(print.Peek());    // Ben

I DO · MODEL

q.Enqueue("Jo");q.Enqueue("Kai");
string served=q.Dequeue();
MODEL EXPLANATION

Trace and justify

Jo is served first; Kai remains at the front.

A different queue receives jobs 4, 7, 2. Dequeue twice, enqueue 9. What remains?

var q=new Queue<int>();
q.Enqueue(4);q.Enqueue(7);q.Enqueue(2);
q.Dequeue();q.Dequeue();q.Enqueue(9);
MODEL EXPLANATION

Trace and justify

Dequeue returns 4 then 7. Remaining front-to-back [2,9].
