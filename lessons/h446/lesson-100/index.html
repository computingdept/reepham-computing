Lesson 100 · GPUs: Parallel Work Beyond Graphics

By the end you can…
  • GPUs provide many execution units designed for high-throughput parallel operations on large batches of data.
  • Besides graphics, GPUs can accelerate machine learning, physical simulations, image processing and some scientific calculations.
  • Transfers between memory/device, limited parallelism and divergent branching can outweigh GPU speedup on small or sequential tasks.

I DO · WORKED MODEL

Explain why processing one million independent pixels may suit a GPU.

MODEL ANSWER

Follow the reasoning

Each pixel can receive similar operation in parallel; many GPU threads process different positions.

WE DO · DIFFERENT PROBLEM

A sequential data-dependent algorithm calculates next item using previous result. Does GPU automatically accelerate it?

MODEL ANSWER

Follow the reasoning

Not necessarily: dependence limits simultaneous work, and data-transfer overhead may dominate.
