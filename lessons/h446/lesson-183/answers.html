QUESTION 1 · OCR EXAMBUILDER Q1(c) · [4]

Compare recursion and iteration

Any two clear paired differences, for example:

• Recursion uses repeated function calls and stores active calls on the call stack; iteration repeats using a loop and normally reuses the same variables.

• Recursion can use more memory because each active call needs a stack frame; iteration normally uses less memory.

• Deep recursion can run out of stack space; iteration does not build up recursive stack frames.

• A recursive solution can be shorter / more elegant for some problems; an iterative version can require more explicit control logic.
QUESTION 2 · OCR EXAMBUILDER Q1(d) · [6]

Iterative binary search

function thisFunction(theArray, num1, num2, num3)
    while true
        result = num1 + ((num2 - num1) DIV 2)

        if num2 < num1 then
            return -1
        else
            if theArray[result] < num3 then
                num1 = result + 1
            elseif theArray[result] > num3 then
                num2 = result - 1
            else
                return result
            endif
        endif
    endwhile
endfunction
QUESTION 3 · OCR EXAMBUILDER Q2(i) · [2]

Benefit and drawback of iteration

One valid benefit:
• usually uses less memory / cannot run out of recursive stack space
or
• can be easier to trace
or
• may run faster.

One valid drawback:
• can require longer or more complex code
or
• some problems are expressed more naturally using recursion.

function newGCD(num1, num2)
