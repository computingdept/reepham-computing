Retrieval

In SumTo(4), which call returns first and which returns last?

MODEL ANSWER

SumTo(1) returns first; SumTo(4) returns last after its nested calls unwind.

QUESTION 2 OF 4 · RECENT · BASE CASE

Retrieval

Why must a recursive function contain a stopping condition?

MODEL ANSWER

Without a reachable base case, calls continue and the call stack grows until failure.

NEW LEARNING · CODE FIRST

What is the program actually doing?

int CountDigits(int n)
{
    if (n < 10) return 1;
    return 1 + CountDigits(n / 10);
}

Assume n is positive. Integer division by 10 removes the final digit at each call.

STEP 1 OF 3

Find the smallest problem

A positive single-digit number needs one digit. So n &lt; 10 is our base case.

STEP 2 OF 3

Make progress

For n ≥ 10, integer division by 10 makes the number shorter: 4827 → 482 → 48 → 4.

STEP 3 OF 3

Count on the way back

4 returns 1. Then 48 returns 2; 482 returns 3; 4827 returns 4.

I DO · MODEL EXAMPLE

Model CountDigits(582). Why is integer division essential?

CountDigits(582) → CountDigits(58) → CountDigits(5)

STEP 1 OF 3

Calls

582 → 58 → 5. Each integer division by 10 discards the last digit.

STEP 2 OF 3

Base case

5 is a single digit, so CountDigits(5) returns 1.

STEP 3 OF 3

Returns

CountDigits(58)=2; CountDigits(582)=3. The original number has 3 digits.

WE DO · GUIDED PRACTICE · NEW INPUT

Trace CountDigits(9031). Predict each call and returned value.

9031 → 903 → 90 → 9

Predict the next step before revealing the explanation.

STEP 1 OF 3

Calls

9031, 903, 90, 9.

STEP 2 OF 3

Base case

9 is a single digit so returns 1.

STEP 3 OF 3

Returns

9 returns 1; 90 returns 2; 903 returns 3; 9031 returns 4.

Foundation · QUESTION 1 OF 3

Trace CountDigits(67): write the call sequence and final value.

MODEL ANSWER

Calls 67 → 6. Base case returns 1, then the outer call returns 2.

Core · QUESTION 2 OF 3

A pupil writes return CountDigits(n) + 1; for the recursive step. Correct the line and explain the error.

MODEL ANSWER

Correct: return 1 + CountDigits(n / 10);. The original line does not reduce n, so it never reaches the base case for n >= 10.

Stretch · QUESTION 3 OF 3

Extend CountDigits for n = 0 and negative integers without overflowing on the minimum C# int value.

MODEL ANSWER

An example robust implementation: int CountDigits(int n) { long value = Math.Abs((long)n); if (value < 10) return 1; return 1 + CountDigits((int)(value / 10)); } For the most-negative int, the cast is safe here because dividing by 10 reduces the magnitude first.

TERM 1 OF 5

termination

Reaching a condition where the algorithm stops.

TERM 2 OF 5

recursive step

Processing part of a problem before calling the function on a simpler input.

TERM 3 OF 5

precondition

An assumption or input rule required for an algorithm.

TERM 4 OF 5

stack overflow

A failure that can occur when too many active calls consume stack space.

TERM 5 OF 5

integer division

Division discarding any fractional part of the result.

True or false?

An algorithm is recursive whenever it uses a loop.

MODEL ANSWER

False. Recursion requires a function to call itself; iteration uses a loop.
