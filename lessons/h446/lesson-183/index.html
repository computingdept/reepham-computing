SAME PROBLEM · DIFFERENT CONTROL

Recursion vs iteration

RECURSION
function calls itself
base case stops calls
active calls use stack frames

ITERATION
loop repeats instructions
condition stops loop
variables are reused
Key idea: when rewriting recursion iteratively, keep the same changing state but replace the recursive call with variable updates inside a loop.
STEP 1 OF 4

Find what changes

return countDown(n - 1)

The next recursive call changes n. An iterative version must make the same state change itself.

1 of 4
STEP 2 OF 4

Turn the base case into stopping logic

if n == 0 then return 0

The iterative version needs a loop that stops when the same condition is reached.

2 of 4
STEP 3 OF 4

Replace the recursive call

while n != 0
    n = n - 1
endwhile

The loop changes the state directly instead of creating another function call.

3 of 4
STEP 4 OF 4

Compare the trade-off

Recursion: often concise / natural
Iteration: often lower memory / easier to trace

OCR comparison questions require a paired difference, not two unrelated statements.

4 of 4
ONE COMPLETE WORKED EXAMPLE

Rewrite recursively → iteratively

function countDown(n)
    if n == 0 then
        return 0
    else
        output(n)
        return countDown(n - 1)
    endif
endfunction
Preserve the behaviour
STEP 1 · IDENTIFY STATE

What changes?

n → n - 1

The recursive call reduces n by one each time.

STEP 2 · IDENTIFY STOP

What ends recursion?

n == 0

This becomes the stopping condition for the loop.

STEP 3 · BUILD LOOP

Move the changing state into iteration

while n != 0
    output(n)
    n = n - 1
endwhile

The loop now performs the repeated work without making another function call.

STEP 4 · KEEP RETURN BEHAVIOUR

Finish the function

function countDown(n)
    while n != 0
        output(n)
        n = n - 1
    endwhile
    return 0
endfunction

Same task; different control mechanism.

QUESTION 2 · OCR EXAMBUILDER Q1(d) · [6]

Rewrite the recursive binary search

Rewrite this function so that it uses iteration instead of recursion: 
function thisFunction(theArray, num1, num2, num3)
    result = num1 + ((num2 - num1) DIV 2)
    if num2 < num1 then
        return -1
    else
        if theArray[result] < num3 then
            return thisFunction(theArray, result + 1, num2, num3)
        elseif theArray[result] > num3 then
            return thisFunction(theArray, num1, result - 1, num3)
        else
            return result
        endif
    endif
endfunction
