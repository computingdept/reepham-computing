QUESTION 1 OF 4

LAST LESSON · L038 · OBJECTS

What is the difference between a class and an object?

ANSWER

A class defines a blueprint; an object is one instance with its own attribute values.

QUESTION 2 OF 4

EARLIER · L018 · RECORDS

A record stores Name and Age. How does it organise values differently from an array?

ANSWER

A record uses named fields, possibly of different types. An array uses indexed elements of a common element type.

QUESTION 3 OF 4

EARLIER · L025 · BINARY SEARCH

In binary search of a sorted ascending array, the target is smaller than the middle value. Which part of the array remains to search?

ANSWER

The lower (left) half; the middle and all larger values can be discarded.

QUESTION 4 OF 4

CHALLENGE · L038 · OBJECT STATE

Two separate Student objects have Name values Ada and Ben. If the second student's Name changes to Eve, what is the first student's Name? Explain.

ANSWER

Ada. Changing one object's state does not change the separate instance.

OCR H446 · 1.2.4(e) · 2.2.1(f)

One class · two independent Pokémon

class Pokemon
  public HP
  public attack
  public procedure fight(opponent)
    opponent.HP = opponent.HP - attack
  endprocedure
endclass

Focus extract: the full class and starting values appear in I Do.

THINK

What changes, and what stays the same?

Attributes store each object’s values. Methods describe actions. An attack changes the opponent’s HP, not every Pokémon’s HP.

CONNECT TO PRIOR KNOWLEDGE

Lesson 038 introduced classes and objects. Here we trace their behaviour and changing state. The new(...) constructor is supplied for now; Lesson 040 studies it properly.

MODELLED EXAMPLE · OCR PSEUDOCODE

Build and trace a Pokémon attack

class Pokemon
  public name
  public type
  public HP
  public attack
  public procedure new(n, t, h, a)
    name = n
    type = t
    HP = h
    attack = a
  endprocedure
  public function getType()
    return type
  endfunction
  public procedure fight(opponent)
    opponent.HP = opponent.HP - attack
  endprocedure
endclass
pokemon1 = new Pokemon("Charizard","fire",1000,160)
pokemon2 = new Pokemon("Squirtle","water",1800,90)
pokemon1.fight(pokemon2)
print(pokemon1.getType(), pokemon2.HP)
One worked example · reveal each step
STEP 1

Identify state and behaviour

Attributes: name, type, HP, attack. Methods: getType() returns data; fight(opponent) changes it.

STEP 2

Create two independent objects

pokemon1 starts with 1000 HP; pokemon2 starts with 1800 HP. The constructor supplies their initial values.

STEP 3

Trace the method call

Charizard deals 160 damage to Squirtle: 1800 − 160 = 1640 HP. Charizard remains on 1000 HP. Output: fire, 1640.
