QUESTION 3 · MODEL ANSWER · 4 MARKS

Write heal(amount)

public procedure heal(amount)
  HP = HP + amount
endprocedure
  • Public procedure heal accepts amount.[1]
  • Updates the current object’s HP attribute.[1]
  • Adds amount to the existing HP rather than replacing it.[1]
  • Squirtle’s resulting HP is 1640 + 50 = 1690.[1]

QUESTION 4 · MODEL ANSWER · 4 MARKS

Correct the battle loop

while pokemon1.HP > 0 AND pokemon2.HP > 0
  pokemon1.fight(pokemon2)
  if pokemon2.HP > 0 then
    pokemon2.fight(pokemon1)
  endif
endwhile
  • OR permits the loop to continue when one Pokémon is defeated.[1]
  • The second Pokémon may attack after its HP has fallen to zero or below.[1]
  • Use AND so both Pokémon must have positive HP to start another round.[1]
  • Check pokemon2.HP > 0 before allowing its counterattack.[1]

QUESTION 5 · MODEL ANSWER · 6 MARKS

Write specialAttack(opponent)

public procedure specialAttack(opponent)
  opponent.HP = opponent.HP - (2 * attack)
  if opponent.HP < 0 then
    opponent.HP = 0
  endif
endprocedure
  • Public procedure specialAttack accepts opponent.[1]
  • Uses the current attacker’s attack attribute.[1]
  • Doubles the attack damage.[1]
  • Subtracts this damage from opponent.HP.[1]
  • Clamps negative opponent HP to zero (equivalent max logic accepted).[1]
  • 250 − 2 × 160 = −70, so resulting HP is 0.[1]
