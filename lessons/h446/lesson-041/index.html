QUESTION 1 OF 4

LAST LESSON · L040 · CONSTRUCTORS

A Book constructor stores its string parameter in Title. What does Title contain after new Book("Dune")?

ANSWER

Dune. The string argument is passed to the constructor, which stores it in Title.

QUESTION 2 OF 4

EARLIER · L024 · BINARY SEARCH

Binary search looks for 11 in the sorted array [2, 5, 8, 11, 14]. The middle value is 8. Which half remains to search?

ANSWER

The right half, [11, 14], because 11 is greater than 8.

QUESTION 3 OF 4

EARLIER · L030 · FULL ADDERS

A full adder receives A = 1, B = 1 and CarryIn = 0. Calculate Sum and CarryOut.

ANSWER

Sum = 0 and CarryOut = 1, because 1 + 1 + 0 = 10 in binary.

QUESTION 4 OF 4

CHALLENGE · L038–040 · INSTANCES

One Book object is created with Title "Dune" and a separate Book with Title "1984". The first Title is changed to "Foundation". What is the second Title, and why?

ANSWER

1984. Each separately instantiated Book stores independent attribute values.

Account a = new Account();
a.Deposit(20);
a.Deposit(-5);

class Account {
  private int balance = 0;
  public void Deposit(int amount) {
    if (amount > 0) balance += amount;
  }
  public int GetBalance() { return balance; }
}
THINK

Explain the design decision

Code outside Account cannot assign balance directly. Public methods control changes and can enforce validation.
