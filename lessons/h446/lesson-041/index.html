OOP · Encapsulation and Access

Account a = new Account();
a.Deposit(20);
a.Deposit(-5);

class Account {
  private int balance = 0;
  public void Deposit(int amount) {
    if (amount > 0) balance += amount;
  }
  public int GetBalance() { return balance; }
}
THINK

Explain the design decision

Code outside Account cannot assign balance directly. Public methods control changes and can enforce validation.

One worked example
STEP 1

Identify private data

balance is private, so callers cannot access a.balance.

STEP 2

Follow a valid call

Deposit(20) changes balance from zero to 20.

STEP 3

Reject an invalid call

Deposit(-5) fails the check. GetBalance still returns 20.
