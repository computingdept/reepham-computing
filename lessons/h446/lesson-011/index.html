ANSWER

&& means AND.

ANSWER

    }

OCR language: a function returns a value. A procedure does not. In C#, both are methods.
STEP 1 OF 4

Modularity breaks a problem into parts

A large program is easier to understand when separate jobs are placed in separate subroutines.

Benefits include reuse, easier testing, easier maintenance and clearer code.

A procedure performs a job

A C# procedure-style method uses void because it does not return a value to the caller.

public static void Greeting(string name)
{
    Console.WriteLine("Hello " + name);

STEP 3 OF 4

A function returns a value

The return type replaces void. A return statement sends the result back to the calling code.

public static int Triple(int number)
{
    return number * 3;
}
The returned value can be stored: int answer = Triple(7);

ONE COMPLETE WORKED EXAMPLE

Build an IsEven function

Create a function that accepts a whole number and returns true when it is even.

IsEven(12) → true
IsEven(7) → false

The result is data, so this should be a function.

Worked example
STEP 1 · DEFINE THE JOB

Choose the return type

public static bool IsEven(int number)
{
}

The result is true/false, so the return type is bool.

STEP 2 · RETURN THE RESULT

Use the remainder test

public static bool IsEven(int number)
{
    return number % 2 == 0;
}

The Boolean expression itself already produces true or false.

STEP 3 · CALL THE FUNCTION

Use it from Main

public static void Main()
{
    bool result = IsEven(12);
    Console.WriteLine(result);
}

The argument 12 is received by the parameter number.

STEP 4 · TEST

Use contrasting values

IsEven(12) → True
IsEven(7)  → False
IsEven(0)  → True
A function returns a value; the caller can store or use that value.
