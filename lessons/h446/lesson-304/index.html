I DO · UNMARKED MODEL

Evaluate the claim 'all sorts take O(n log n) in the worst case'.

Bubble sort worst O(n²).
Merge sort worst O(n log n).
STEP 1 OF 2

Predict first

Bubble sort has quadratic worst-case growth due to repeated adjacent comparisons.

STEP 2 OF 2

Check reasoning

Merge sort has O(n log n) worst-case growth and generally needs O(n) auxiliary memory.

WE DO · DIFFERENT UNMARKED EXAMPLE

Identify a paper-crossing weakness: a candidate knows binary search but cannot implement it.

Knowledge: sorted input and halving.
Implementation: low, high, mid updates.
Intervention: trace then code.
STEP 1 OF 2

Predict first

Identify exactly which implementation state is wrong, e.g. high never decreases.

STEP 2 OF 2

Check reasoning

Set a small test with a target below the midpoint to check the high-bound update independently.
