By the end you can…
  • Distinguish DNS addressing, IP routing, TCP transport and TLS security: each serves a different purpose.
  • RLE is lossless and suitable for runs; dictionary coding uses references. Lossy methods can discard detail.
  • Hashing produces an integrity digest; symmetric and asymmetric encryption protect confidentiality using keys.
