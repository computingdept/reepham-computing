NEW LEARNING · CODE FIRST

Read the code; predict its effect

int LinearSearch(int[] a, int target)
{
    for (int i = 0; i < a.Length; i++)
        if (a[i] == target) return i;
    return -1;
}
STEP 1 OF 3

Begin at index zero

Linear search examines one value at a time, in order.

STEP 2 OF 3

Stop at the first match

When a[i] equals target, return i immediately.

STEP 3 OF 3

No match

After scanning every element, return -1; no ordering assumption is needed.

Stretch · 3 OF 3

Modify the function to count comparisons without returning early; explain the output for a 5-element array.

WORKED ANSWER

Track int comparisons=0 and increment each iteration; if searching all elements, comparisons=5. To report both location and count, return a tuple (index, comparisons) or use an out parameter.
