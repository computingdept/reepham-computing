I DO · TEACHER MODEL

A council wants to adapt an accessible web service using its development team. Explain an open-source advantage and a risk.

WORKED REASONING

Model answer

Relevant open-source licence can permit modification and inspection, allowing accessibility changes. Risk: the council must ensure support, security patching and licence compliance; source availability alone guarantees neither quality nor safety.

STEP 3 · EXPLAIN

Shared worked answer

A proprietary supported package may offer a service contract and managed upgrades; assess data export, recurring licensing, vendor lock-in and contract quality. Source model alone does not decide security.

MARK SCHEME / WORKED ANSWER

APPLICATION · QUESTION 2 OF 3

Explain why free-of-charge software is not necessarily open source. [4]

MARK SCHEME / WORKED ANSWER

Price and source-code rights differ [2]; a free proprietary program can withhold code/modification rights [2].

TERM 1/4

open source

Code distributed under a licence allowing inspection and specified reuse.

TERM 2/4

closed source

Source and modification rights normally controlled by owner.

TERM 3/4

licence

Legal conditions attached to software use.

TERM 4/4

vendor lock-in

Difficult or expensive dependence on one supplier.

True or false?

Open-source software is automatically more secure than closed-source software.

Model answer

False. Security depends on implementation, maintenance and context.
