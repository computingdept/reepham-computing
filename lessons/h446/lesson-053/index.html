Lesson 053 · Graphs: Adjacency Lists and Traversal

By the end you can…
  • An adjacency list records each vertex and its neighbours. For undirected graphs, an edge is represented in both vertices' neighbour lists.
  • For BFS, enqueue a starting vertex, mark it visited, and repeatedly dequeue and enqueue undiscovered neighbours.
  • Traversal order depends on neighbour ordering. A visited set prevents infinite revisiting when the graph contains cycles.

I DO · MODEL

Trace BFS from A given neighbours A:[B,C], B:[A,D], C:[A], D:[B].

Queue [A] → visit A, enqueue B,C
Queue [B,C] → visit B, enqueue D
Queue [C,D] → visit C,D
WORKING

Explain the trace

With B before C, BFS visit order A,B,C,D. Each vertex is marked on enqueue.

WE DO · DIFFERENT PROBLEM

Trace a different BFS: X connects Y and Z; Y connects W. Visit from X, Y before Z.

X:[Y,Z], Y:[X,W], Z:[X], W:[Y]
Queue X → Y,Z → Z,W → W
WORKING

Explain the trace

BFS visit order X,Y,Z,W. FIFO queue processes all distance-one vertices before W.
