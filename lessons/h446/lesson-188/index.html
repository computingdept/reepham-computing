NEW LEARNING · CODE FIRST

Read the code; predict its effect

int BinarySearch(int[] a, int target)
{
    int low = 0, high = a.Length - 1;
    while (low <= high)
    {
        int mid = low + (high - low) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
STEP 1 OF 3

Sort before searching

Binary search relies on a sorted array; otherwise discarding half may lose the target.

STEP 2 OF 3

Inspect the middle

Compare target to the midpoint and keep only the half that could contain it.

STEP 3 OF 3

Stop correctly

Return an index when found; return -1 if low becomes greater than high.

Stretch · 3 OF 3

Explain why setting low = mid instead of mid + 1 can cause failure.

WORKED ANSWER

With low=mid and only two candidates left, mid may equal low repeatedly; the interval does not shrink, potentially creating an infinite loop.
