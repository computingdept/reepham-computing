TERM 1 OF 8

linear search

DEFINITION

A search that checks items one at a time from the start until the target is found or the data ends.

TERM 2 OF 8

binary search

DEFINITION

A search that repeatedly checks the middle of sorted data and discards half of the remaining search area.

TERM 3 OF 8

target

DEFINITION

The value the algorithm is trying to find.

TERM 4 OF 8

precondition

DEFINITION

A condition that must already be true before an algorithm is used.

TERM 5 OF 8

midpoint

DEFINITION

The middle position of the current binary-search range.

TERM 6 OF 8

lower bound

DEFINITION

The first index still included in the current binary-search range.

TERM 7 OF 8

upper bound

DEFINITION

The last index still included in the current binary-search range.

TERM 8 OF 8

discard

DEFINITION

Remove a section from further consideration.

STANDARD ALGORITHMS · SEARCHING

Linear: check each item | Binary: halve sorted data

LINEAR
start → compare → next → next → ...

BINARY
sorted data
low ... mid ... high
compare at mid
discard one half
repeat
Key idea: Binary search is only valid when the data is ordered. Linear search makes no such requirement.
STEP 1 OF 4

Linear search

check item 0
check item 1
check item 2
...
stop when found / end reached

Simple and valid on unsorted data.

1 of 4
STEP 2 OF 4

Binary search precondition

data must be sorted

Without ordering, discarding half of the data is not valid.

2 of 4
STEP 3 OF 4

Track bounds

low = first index
high = last index
mid = middle

The bounds define the remaining search area.

3 of 4
STEP 4 OF 4

Discard half

target > A[mid] → low = mid + 1
target < A[mid] → high = mid - 1

Repeat until found or no search area remains.

4 of 4
WORKED EXAMPLE

Binary search for 23

4  8  15  16  23  42
target = 23
Model the method clearly
STEP 1

Set bounds

low = 0
high = 5
mid = 2 → value 15

23 is greater than 15.

STEP 2

Discard lower half

low = 3
high = 5

Only indices 3–5 remain.

STEP 3

New midpoint

mid = 4 → value 23

The target matches.

STEP 4

Return found

return true / index 4

The search stops.
