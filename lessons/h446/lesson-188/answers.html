QUESTION 4 · OCR EQ Q6(b) · [8]

One valid iterative solution

function binarySearch(A, target)
    low = 0
    high = A.length - 1

    while low <= high
        mid = (low + high) DIV 2

        if A[mid] == target then
            return true
        elseif A[mid] < target then
            low = mid + 1
        else
            high = mid - 1
        endif
    endwhile

    return false
endfunction

Key mark-scheme ideas: midpoint, target comparison, bounds updates and correct found/not-found termination.
