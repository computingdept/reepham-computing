NEW LEARNING · INSTRUCTIONS AND REGISTERS

Trace the machine state

STEP 1 OF 3

Mailboxes

Instructions and numeric data occupy addressed memory mailboxes. DAT reserves a data location. Programs execute the instructions addressed by the program counter.

STEP 2 OF 3

Accumulator and PC

INP reads into ACC; LDA reads memory into ACC; STA writes ACC to memory. The PC normally advances after a fetch, unless a branch selects a new address.

STEP 3 OF 3

Branches and stopping

ADD and SUB update ACC; OUT prints ACC; BRA always branches; BRZ tests for zero; BRP tests a non-negative result in standard LMC; HLT ends the program.

I DO · MODELLED TRACE

Input is 7. Trace this program, including the accumulator, data mailbox and output.

00 INP
01 STA 10
02 LDA 10
03 ADD 10
04 OUT
05 HLT
10 DAT 0
WORKED TRACE

Track each change

00 INP: ACC = 7.

01 STA 10: mailbox 10 becomes 7; ACC remains 7.

02 LDA 10: ACC = 7.

03 ADD 10: ACC = 14.

04 OUT: output is 14.

05 HLT: stop. Data mailbox 10 is separate from instruction addresses 00–05.

WE DO · DIFFERENT TRACE

Input is 9, and mailbox 21 contains 4. What is the output and why?

00 INP
01 STA 20
02 LDA 20
03 SUB 21
04 OUT
05 HLT
20 DAT 0
21 DAT 4
STEP 1 · INPUT AND STORE

Predict the registers

What are ACC and mailbox 20 after the first two instructions?

STEP 2 · LOAD AND SUBTRACT

Calculate ACC

Follow LDA 20 and SUB 21. Use the stored value 9 and constant 4.

STEP 3 · ANSWER

Completed trace

INP sets ACC to 9. STA 20 saves 9. LDA 20 reloads it. SUB 21 subtracts 4, leaving ACC = 5. OUT prints 5; HLT stops.

FOUNDATION · QUESTION 1 OF 3

Explain what the PC, accumulator and memory mailboxes represent in LMC. [6]

MARK SCHEME / WORKED ANSWER

PC identifies next instruction to fetch [2]; accumulator holds data/arithmetic results [2]; mailboxes hold numbered instructions or data [2].

APPLICATION · QUESTION 2 OF 3

Trace INP; STA 30; LDA 30; ADD 31; OUT; HLT, with input 5 and mailbox 31 containing 3. [6]

MARK SCHEME / WORKED ANSWER

ACC=5 after INP [1]; mailbox 30 gets 5 [1]; LDA restores 5 [1]; ADD makes 8 [2]; OUT displays 8 [1].

CHALLENGE · QUESTION 3 OF 3

Write LMC instructions to read an integer and output it, using a BRZ branch when zero. Explain how you would test both paths. [8]

MARK SCHEME / WORKED ANSWER

One valid approach: INP; BRZ ZERO; OUT; HLT; ZERO OUT; HLT. BRZ branches if ACC=0 [2]; the nonzero path outputs entered number [2]; zero path outputs 0 [2]; HLT terminates and test values 0 and 7 exercise both paths [2].

True or false?

In LMC, STA n loads the accumulator with the contents of mailbox n.

Model answer

False. STA stores ACC into memory. LDA reads a value from memory into ACC.
