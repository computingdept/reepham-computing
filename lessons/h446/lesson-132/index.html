I DO · MODEL

Explain why a modern web connection does not encrypt every file byte directly with an asymmetric cipher.

STEP 1 OF 3

Check server certificate

Predict the first step from the prompt.

STEP 2 OF 3

Derive symmetric traffic key

Explain the intermediate result or decision.

STEP 3 OF 3

Encrypt application data

Modern secure connections typically authenticate with public-key credentials, establish shared session keys (often via ephemeral key agreement) and use efficient symmetric encryption for bulk traffic. Identity checks guard against impostors.

No. HTTPS can establish an encrypted connection even with a harmful operator. Verify the domain and service, not just the presence of encrypted transport; a certificate proves control of an identity/domain to varying levels.
