STEP 2 OF 3

DNS returns an IP address

Explain the change using correct technical terms.

STEP 3 OF 3

Connect to web server

DNS maps the hostname to relevant resource records such as an A/AAAA address. DNS does not directly transmit the web page. Browser makes a separate connection to the chosen server address and requests content, often over HTTPS.

WE DO · DIFFERENT PROBLEM

A DNS answer has been cached but website server has moved. Explain a possible issue and resolution.

STEP 1 OF 3

Cached old address

Identify the relevant information and make a prediction.

STEP 2 OF 3

Server address changes

Explain the change using correct technical terms.

STEP 3 OF 3

Refresh after TTL

The cached address may remain until its TTL expires; client may contact an outdated endpoint. The resolver can refresh after expiry. DNS propagation and authoritative changes do not guarantee immediate worldwide consistency.
