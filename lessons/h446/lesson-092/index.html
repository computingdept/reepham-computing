Lesson 092 · The Three Buses: City Highways

By the end you can…
  • Address bus identifies the location the processor wants to access; typically the CPU drives address lines on a simple memory read.
  • Data bus transfers the contents between memory and processor; for ordinary memory reads the bits travel memory-to-CPU.
  • Control bus signals operation and coordination, including read/write; distinguish purpose and direction rather than treating all buses as one road.

Trace the hardware

// READ memory address 300 in a conceptual CPU
MAR = 300
ADDRESS BUS → 300 (location)
CONTROL BUS → READ command
DATA BUS ← memory[300] contents, e.g. 42
MDR = 42
// A bus carries a category of signals,
// not physical vehicles or letters.

I DO · WORKED MODEL

CPU reads memory[12]=99. Label each bus with what it carries.

MODEL EXPLANATION

Explain the mechanism

Address bus12; control bus READ; data bus returns99, placed in MDR.

Address12 and content99 are different types of information.

WE DO · DIFFERENT QUESTION

CPU writes value25 to memory address44. State bus role for each.

MODEL EXPLANATION

Explain the mechanism

Address bus44, data bus25 from CPU to memory, control bus WRITE.

On writing, data flows towards memory while address still identifies destination.
