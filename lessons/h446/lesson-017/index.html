1.4.2(a) · CHOOSE THE STRUCTURE

Different shapes of data

Array  → fixed ordered values
Record → named fields for one item
List   → ordered values that can grow/shrink
Tuple  → small fixed group of values
Know what each structure is, when it is useful, and how to use it in a program.
STEP 1 OF 4

Records group fields

Student
Name = "Amelia"
CandidateNo = 1037
Score = 72

A record represents one entity using several related fields. The OCR concept is more important here than a particular language keyword.

1 of 4
STEP 2 OF 4

Lists can change size

List<string> names = new List<string>();
names.Add("Amelia");
names.Add("Ben");
names.Remove("Ben");

A list is ordered like an array, but its size can change while the program runs.

2 of 4
STEP 3 OF 4

Tuples group a few values

var result = (Name: "Amelia", Score: 72);
Console.WriteLine(result.Name);
Console.WriteLine(result.Score);

A tuple is useful when a small fixed set of values should travel together.

3 of 4
STEP 4 OF 4

Choose by behaviour

fixed size?       → array
one item / fields? → record
grow or shrink?    → list
small grouped set? → tuple

The exam may ask why one structure suits a context better than another.
