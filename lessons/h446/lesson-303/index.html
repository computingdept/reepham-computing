STEP 1 OF 3

Use exact indexing

OCR arrays use zero-based indexing; the number in array declaration is the number of elements.

STEP 2 OF 3

Trace subroutines and parameters

A procedure does not produce a return value; a function returns a result. byVal passes a copy; byRef allows the original parameter to change.

STEP 3 OF 3

Read file operations

openRead, readLine, endOfFile and close follow the OCR Appendix 5d conventions. Always close an opened file.

I DO · UNMARKED MODEL

Trace a 3-element OCR array and identify the valid indexes.

array scores[3]
scores[0]=2
scores[1]=4
scores[2]=6
print(scores[1])
STEP 1 OF 2

Predict first

Array declaration creates three positions: indexes 0,1,2.

STEP 2 OF 2

Check reasoning

scores[1] holds 4, so output is 4.

WE DO · DIFFERENT UNMARKED EXAMPLE

Trace a function and a procedure that changes an argument by reference.

procedure addOne(x:byRef)
 x=x+1
endprocedure
n=6
addOne(n)
print(n)
STEP 1 OF 2

Predict first

The parameter is passed by reference, so assignment to x changes the caller's n.

STEP 2 OF 2

Check reasoning

After addOne(n), n=7 and print displays 7.

PRACTICE · Q3/3

Compare procedure addTwo(x:byVal) with addTwo(x:byRef), each executing x=x+2, for caller n=5. [6]

MARK SCHEME / MODEL ANSWER

byVal called with n=5 uses copy and n remains5 [3]; byRef updates n to7 [3].
