STEP 1 OF 3

Use exact indexing

OCR arrays use zero-based indexing; the number in array declaration is the number of elements.

STEP 2 OF 3

Trace subroutines and parameters

A procedure does not produce a return value; a function returns a result. byVal passes a copy; byRef allows the original parameter to change.

STEP 3 OF 3

Read file operations

openRead, readLine, endOfFile and close follow the OCR Appendix 5d conventions. Always close an opened file.

I DO · UNMARKED MODEL

Trace a 3-element OCR array and identify the valid indexes.

array scores[3]
scores[0]=2
scores[1]=4
scores[2]=6
print(scores[1])
STEP 1 OF 2

Predict first

Array declaration creates three positions: indexes 0,1,2.

STEP 2 OF 2

Check reasoning

scores[1] holds 4, so output is 4.

WE DO · DIFFERENT UNMARKED EXAMPLE

Trace a function and a procedure that changes an argument by reference.

procedure addOne(x:byRef)
 x=x+1
endprocedure
n=6
addOne(n)
print(n)
STEP 1 OF 2

Predict first

The parameter is passed by reference, so assignment to x changes the caller's n.

STEP 2 OF 2

Check reasoning

After addOne(n), n=7 and print displays 7.

EXAM QUESTION 1 OF 4 · 3 MARKS · 3 MINUTES

Explain the specific role of line 03, line 04 and line 09 in this reusable program. [3]

GIVEN INFORMATION
A school produces a reusable text-validation function that checks whether every character of an input string is a decimal digit:
01 function isPositiveInteger(textValue)
02   valid = true
03   for index = 0 to textValue.length - 1
04     charCode = ascii(textValue[index])
05     if charCode < 48 or charCode > 57 then
06       valid = false
07     endif
08   next index
09   return valid
10 endfunction

OCR H446/02 · June 2023 · Q4(b) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

Line 03 loops over each character in textValue; line 04 obtains the character's ASCII code; line 09 returns whether every checked character passed the digit test.

Marking: One mark for each correct line-specific explanation, maximum three.

RHS ADDITIONAL PRACTICE · QUESTION 3 OF 4 · 3 MARKS · 3 MINUTES

Using OCR-style pseudocode, write a function named countEven(values) that returns how many integers in a non-empty array are even. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

function countEven(values)
  count = 0
  for i = 0 to values.length - 1
    if values[i] MOD 2 == 0 then
      count = count + 1
    endif
  next i
  return count
endfunction

Marking: One mark for initialising the counter and iterating over the array; one for testing evenness and incrementing correctly; one for returning the count.
