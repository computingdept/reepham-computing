QUESTION 2 OF 4 · RECENT · L031 · FLIP-FLOPS

Retrieval

A D-type flip-flop currently stores Q = 1. D changes to 0 but there is no triggering clock edge. What is Q?

MODEL ANSWER

Q remains 1. The input is sampled only when the triggering clock edge occurs.

QUESTION 3 OF 4 · OLDER · L019–021 · QUEUES

Retrieval

A queue receives A, B and C in that order. Remove one item, then enqueue D. List the remaining items from front to rear.

MODEL ANSWER

B, C, D. A leaves first because a queue is FIFO.

QUESTION 4 OF 4 · CHALLENGE · L023 · HASH COLLISIONS

Challenge

A five-bucket hash table uses h(k) = k MOD 5 with linear probing. Insert keys 7, 12 and 17 in that order into an empty table. State each final index.

MODEL ANSWER

7 hashes to 2 and is stored at 2. 12 also hashes to 2, so probes to 3. 17 also hashes to 2; 2 and 3 are occupied, so it goes to 4.

Implement hashing and collisions

Classroom demonstration only. Never type, collect or store real passwords.

STEP 1 OF 6

The problem: more than one user

A single username comparison is not scalable. We need a way to store and find many usernames.

1 of 6
STEP 2 OF 6

What is a hash function?

Convert the username to a number, then use % tableSize to choose a bucket index. Our small function is deliberately simple for learning.

2 of 6
STEP 3 OF 6

What if two names choose one bucket?

That is a collision. Use linear probing: try the next bucket, wrapping to the beginning when necessary.

3 of 6
STEP 4 OF 6

Lookups must use the same rule

Recalculate the starting bucket from the username, then probe through occupied buckets until the username or an empty bucket is found.

4 of 6
STEP 5 OF 6

Hash-table lookup versus password hashing

The hash-table function locates an account. It does NOT securely protect a password. Use invented demo passwords only.

TEACHER MODELS · C#

Build a real hash-table index

Create the bucket array manually: the hash function is visible, not hidden inside Dictionary.

Model in small steps
STEP 1 OF 3

Create the buckets

const int SIZE = 7;
string?[] usernames = new string?[SIZE];
STEP 2 OF 3

Write the index function

static int Hash(string key, int size)
{
    int total = 0;
    foreach (char letter in key)
        total += (int)letter;
    return total % size;
}
STEP 3 OF 3

Explain the limitation

// Hash("ab", 7) == Hash("ba", 7)
// Same total -> collision.
// This is an educational hash function,
// NOT a secure password hash.

What happens when a bucket is already occupied?

CHECK · MODEL RESPONSE

Insert with linear probing

int index = Hash(username, SIZE);
while (usernames[index] != null)
{
    index = (index + 1) % SIZE;
}
usernames[index] = username;

How can we find a name after a collision?

CHECK · MODEL RESPONSE

Search using the same probing sequence

int index = Hash(username, SIZE);
int checkedBuckets = 0;
while (checkedBuckets < SIZE && usernames[index] != null)
{
    if (usernames[index] == username) break;
    index = (index + 1) % SIZE;
    checkedBuckets++;
}
