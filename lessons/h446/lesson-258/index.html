NEW LEARNING · EXAMPLE FIRST

Trace the concept

PC=72 → MAR=72
Memory[72] → MDR → CIR
Sequential PC advances to 73.
Multiple cores help only independent work.
STEP 1 OF 3

Fetch the instruction

PC identifies address 72, which MAR sends to memory. MDR transfers its contents to CIR.

STEP 2 OF 3

Differentiate performance improvements

Cores can execute independent work; cache helps when needed data/instructions are present.

STEP 3 OF 3

Explain limits

Branching, shared memory bandwidth, serial dependencies and software constrain real speedup.

Predict

STEP 2 OF 2

Explain

WE DO · DIFFERENT PROBLEM

Two independent jobs take 5 and 3 minutes. Calculate ideal two-core completion time.

Sequential: 5+3 = 8
Concurrent: max(5,3) = 5
STEP 1 OF 2

Predict

Each available core receives a separate independent job.

STEP 2 OF 2

Explain

Ideal duration is the longer job, five minutes; serial execution would take eight.

EXAM QUESTION 1 OF 4 · 3 MARKS · 3 MINUTES

The processor in a classroom robot overlaps parts of consecutive instructions through pipelining. Explain three ways this can improve its performance. [3]

OCR H446/01 · June 2024 · Q1(c) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

It may fetch the next instruction while decoding/executing an earlier one. This overlaps instruction stages, reduces unused CPU-unit time and increases throughput.

Marking: One mark for overlapping stages, one for higher instruction throughput, one for less idle hardware/waiting. Do not give credit for a claim that a single entire FDE cycle becomes faster.

EXAM QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A car-repair cooperative processes large numbers of insurance quotations. Name TWO different CPU characteristics which can influence the time required to complete the calculations. [2]

OCR H446/01 · November 2021 · Q1(a)(i) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

Clock speed; number of processor cores; cache size; pipeline design; support for vector instructions.

Marking: One mark per distinct accurate performance factor.

EXAM QUESTION 3 OF 4 · 3 MARKS · 3 MINUTES

A design studio upgrades the RAM in computers used for large graphics projects. Explain how this could improve performance. [3]

OCR H446/01 · June 2024 · Q1(g) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

More currently running programs and working data can be held in RAM, reducing reliance on much slower virtual memory/secondary-storage swapping and the risk of thrashing.

Marking: Up to three separate points: more active working data in RAM; less use of disk virtual memory; RAM access faster; less swapping/thrashing.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

A computer slows down when several large applications are open, and its storage drive shows heavy activity. Explain how adding RAM might improve performance. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

Extra RAM can hold more active program data, reducing paging or swapping to slower secondary storage and therefore reducing delays.

Marking: One mark for holding more active data in RAM; one for reduced disk paging/swapping.
