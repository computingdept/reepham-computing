QUESTION 4 OF 4 · YEAR 12 CHALLENGE · LESSON 031 · D-TYPE FLIP-FLOPS

Year 12 challenge

A rising-edge D flip-flop has Q=0. D changes to 1 between clock edges; the next rising edge occurs while D=1. State Q before and after that edge, and explain why.

MODEL ANSWER

Before edge Q stays 0; at rising edge D=1 is sampled so Q becomes 1. It changes on the active edge, not merely when D changes.

Fetch–decode–execute and buses

By the end you can…
  • Trace the three main stages of the instruction cycle
  • Distinguish address, data and control buses
  • Explain the effect of a branch or interrupt on instruction flow

Key vocabulary

fetchdecodeexecuteaddress busdata buscontrol bus
NEW LEARNING · CODE FIRST

Predict the next state

// Simplified processor cycle
FETCH:  MAR ← PC; MDR ← Memory[MAR]
        CIR ← MDR; PC ← PC + 1
DECODE: CU identifies opcode and operands
EXECUTE: ALU/registers/memory perform instruction
// A branch may replace sequential PC.
STEP 1 OF 3

Fetch uses the buses

The address bus carries the address selected by MAR; memory returns instruction data on the data bus; control signals coordinate the transfer.

STEP 2 OF 3

Decode interprets instruction

The control unit examines CIR to decide which operation and operands are involved.

STEP 3 OF 3

Execute changes state

An instruction may update ACC or memory, or alter PC for a jump. Interrupt handling is coordinated at appropriate points and can temporarily redirect execution.

I DO · MODEL

Fetch the instruction at address 40 and explain what each bus contributes.

PC=40; MAR=40;
MDR=Memory[40]; CIR=MDR;
PC=41;
STEP 1 OF 2

Predict first

MAR identifies location 40; the address bus carries that location to memory, accompanied by a read control signal.

STEP 2 OF 2

Explain the answer

The data bus transfers instruction content to MDR, then CIR; sequential PC becomes 41.

WE DO · DIFFERENT PROBLEM

An instruction at address 81 is an unconditional jump to 120. What happens to PC?

Fetch at 81: PC advances to 82.
Execute JMP 120: PC becomes 120.
STEP 1 OF 2

Predict first

The initial fetch advances PC from 81 to 82, as in a sequential instruction.

STEP 2 OF 2

Explain the answer

Executing the unconditional branch overwrites PC with target address 120. The next fetch occurs there, not at 82.

WORKED ANSWER

Stretch · 6 marks · QUESTION 3 OF 3

Compare what happens in the instruction cycle during a normal arithmetic instruction and while responding to an interrupt.

WORKED ANSWER

[6] Both use fetch/decode/execute [1]; arithmetic instruction may update ACC [1]; interrupt signals an event [1]; processor preserves enough execution state [1], transfers control to an ISR [1] and restores/resumes after service [1].
