Interrupts and service routines

By the end you can…
  • An interrupt signals an event such as device completion to the processor.
  • The CPU saves sufficient execution context before servicing the event.
  • An ISR handles the interrupt, acknowledges it, then restores normal execution state.

Follow the trace

Device raises interrupt request.
CPU finishes suitable instruction boundary.
Save required context → run ISR.
Acknowledge event → restore state → resume.

EXAM QUESTION 1 OF 4 · 3 MARKS · 3 MINUTES

A school server receives an interrupt while another program runs. Explain three stages of how the processor and operating system might service the interrupt and continue the original program. [3]

OCR H446/01 · June 2023 · Q1(f) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

The CPU detects/accepts the interrupt (subject to priority), saves relevant registers/state, loads and executes the interrupt service routine (ISR), then restores the earlier state and resumes.

Marking: Three different accurate stages, maximum three; references to priority, ISR address and state restoration are relevant.

RHS ADDITIONAL PRACTICE · QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A printer sends an interrupt to the CPU when it finishes a print job. Explain why this is more efficient than the CPU repeatedly checking whether printing has finished. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

The CPU can execute other instructions instead of repeatedly polling the printer. The printer signals completion only when attention is needed.

Marking: One mark for avoiding continuous polling; one for CPU time being available for other work.

RHS ADDITIONAL PRACTICE · QUESTION 3 OF 4 · 2 MARKS · 2 MINUTES

When an interrupt is accepted, the CPU saves the current program counter and registers. Explain why the saved state is needed. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

The interrupted program's execution point and working values must be preserved so they can be restored and the program can continue correctly after the ISR.

Marking: One mark for preserving execution position/values; one for correct resumption after the ISR.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

A computer receives keyboard and storage interrupts almost simultaneously. Explain how interrupt priority could affect the order in which they are serviced. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

The interrupt controller/processor prioritises pending interrupts, so the higher-priority request is normally handled first while a lower-priority request waits until it can be serviced.

Marking: One mark for priorities determining which interrupt is serviced; one for lower-priority pending requests waiting.
