Interrupts and service routines

By the end you can…
  • An interrupt signals an event such as device completion to the processor.
  • The CPU saves sufficient execution context before servicing the event.
  • An ISR handles the interrupt, acknowledges it, then restores normal execution state.

Vocabulary

interruptISRcontextpolling
NEW LEARNING · CODE FIRST

Follow the trace

Device raises interrupt request.
CPU finishes suitable instruction boundary.
Save required context → run ISR.
Acknowledge event → restore state → resume.
STEP 1 OF 3

Understand

An interrupt signals an event such as device completion to the processor.

STEP 2 OF 3

Trace

The CPU saves sufficient execution context before servicing the event.

STEP 3 OF 3

Explain

An ISR handles the interrupt, acknowledges it, then restores normal execution state.

I DO · TEACHER MODEL

Keyboard triggers an interrupt during a text editor. Trace the stages.

Editor → IRQ → save state → keyboard ISR → restore editor
STEP 1

Predict first

The ISR processes keyboard input before restoring the prior program state.

WE DO · DIFFERENT GUIDED PROBLEM

A printer signals I/O completion. Describe ISR and scheduler actions.

Printer complete → interrupt → ISR acknowledges → spool next job
STEP 1

Predict first

The ISR can acknowledge completion and allow queued device work to proceed; the interrupted task resumes.

QUESTION 1 OF 3

Define interrupt, ISR and one source of interrupts. [4]

WORKED ANSWER

Interrupt signals attention [1], ISR is code handling event [2], e.g. keyboard or timer [1].

QUESTION 2 OF 3

Why does CPU context need to be saved/restored around a device ISR? [6]

WORKED ANSWER

Interrupt arrives [1]; preserve PC/required registers [2]; ISR handles event [1]; restore [1]; correct original program continuation [1].

QUESTION 3 OF 3

Compare polling and interrupt-driven I/O for infrequent device input. [6]

WORKED ANSWER

Polling repeatedly checks [2], wastes cycles [1]; interrupt-driven signals events [1], frees CPU for other work [1], adds ISR/context overhead [1].
