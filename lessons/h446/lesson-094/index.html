Lesson 094 · CPU Performance: Clock, Cores and Cache

By the end you can…
  • Clock speed counts clock cycles per second; one cycle is not always one complete instruction. Frequency alone cannot predict program performance.
  • Multiple CPU cores improve performance most for work divided into independently executable threads; a strictly sequential task may gain little.
  • Cache is small, fast storage close to CPU. A cache hit avoids some slower RAM accesses; cache size, locality and hit rate influence results.

I DO · WORKED MODEL

Compare 2 GHz and 3 GHz clock rates under equal work per clock and no bottlenecks.

MODEL EXPLANATION

Explain the mechanism

3 GHz offers 50% more cycles each second than2 GHz; this does not universally imply 50% faster program runtime.

The comparison requires equal microarchitecture and workload assumptions.

WE DO · DIFFERENT QUESTION

A single-threaded algorithm runs on a 2-core or 8-core CPU of equal per-core performance. Explain likely benefit.

MODEL EXPLANATION

Explain the mechanism

It may not be substantially faster from extra cores alone; only one thread is the bottleneck.

Parallel benefits need tasks/threads that can run concurrently.
