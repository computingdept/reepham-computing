Lesson 097 · Little Man Computer: Branches and Loops

By the end you can…
  • BRA always changes which instruction is fetched next; BRZ branches only when ACC is zero.
  • The loop's memory variable COUNT changes after SUB ONE and STA COUNT. Reload it with LDA COUNT at each iteration.
  • Trace ACC, COUNT, branch decision and outputs. Stopping before OUT when COUNT=0 prevents printing zero.

NEW LEARNING · TRACE THE SYSTEM

How it works

LOOP LDA COUNT
     BRZ END
     OUT
     SUB ONE
     STA COUNT
     BRA LOOP
END  HLT
COUNT DAT 3
ONE   DAT 1
// Outputs 3,2,1 then halts.
STEP 1 OF 3

Observe

BRA always changes which instruction is fetched next; BRZ branches only when ACC is zero.

STEP 2 OF 3

Apply

The loop's memory variable COUNT changes after SUB ONE and STA COUNT. Reload it with LDA COUNT at each iteration.

STEP 3 OF 3

Evaluate

Trace ACC, COUNT, branch decision and outputs. Stopping before OUT when COUNT=0 prevents printing zero.

I DO · WORKED MODEL

Start COUNT=2 instead of3. What gets printed and why?

MODEL ANSWER

Follow the reasoning

Outputs2 then1; COUNT reaches0, and BRZ branches before OUT.

WE DO · DIFFERENT PROBLEM

In a separate program, COUNT starts4 and SUB TWO is used, TWO DAT2. Give outputs.

MODEL ANSWER

Follow the reasoning

Outputs4 then2; stored COUNT becomes0, and BRZ exits before the next OUT.
