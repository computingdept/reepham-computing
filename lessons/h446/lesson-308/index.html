QUESTION 1 OF 3 · ASSESSMENT

Q1 [15]: (a) Trace factorial(4), given factorial(1)=1 and factorial(n)=n × factorial(n−1) for n>1. Show the calls and returns. [7] (b) Trace binary search for 11 in [1,3,5,7,9,11,13]. [6] (c) State its worst-case complexity. [2]

WORKED ANSWER / MARK SCHEME

/15: (a) calls factorial(4)→factorial(3)→factorial(2)→factorial(1) [3]; base factorial(1)=1 [1]; unwind returns 2, 6, 24 [3]. (b) low0 high6 mid3→7 [2], low4 high6 mid5→11 [2], returns index5 [2]. (c) O(log n) [2].

QUESTION 2 OF 3 · ASSESSMENT

Q2 [15]: (a) Trace the first two ascending bubble-sort passes on [5,2,4,1], showing each adjacent comparison, every intermediate array after a swap, and whether the result is fully sorted after Pass 2. [8] (b) Compare worst-case time and auxiliary space of bubble and merge sorts. [7]

WORKED ANSWER / MARK SCHEME

/15: pass 1: swap 5 and 2 → [2,5,4,1] [1]; swap 5 and 4 → [2,4,5,1] [1]; swap 5 and 1 → [2,4,1,5] [1]; recognise 5 is fixed at the end [1]. Pass 2: 2 and 4 need no swap [1]; swap 4 and 1 → [2,1,4,5] [1]; recognise 4 is fixed before 5 [1]; recognise the array is NOT yet sorted because 2>1 [1]. (b) Bubble worst O(n²) [2] and O(1) extra [1]; merge worst O(n log n) [2] and typical O(n) extra [2].

QUESTION 3 OF 3 · ASSESSMENT

Q3 [15]: (a) Stack Push4,Push8,Pop,Push2. State popped value and final stack. [5] (b) Starting with an empty queue, enqueue 4, 8 and 2, then dequeue twice. Give both removed values in order and the final front-to-rear queue. [5] (c) Write a C# function CountPositive(int[] a) returning the number of elements strictly greater than zero. It must return 0 for an empty array. [5]

WORKED ANSWER / MARK SCHEME

/15: (a) popped8 [2], stack bottom-to-top [4,2] [3]. (b) dequeue4,8 [3]; remaining [2] [2]. (c) Award: correct int-returning signature [1]; initialise count=0 [1]; traverse the array [1]; increment only for values greater than 0 [1]; return count [1]. The empty array returns 0.

static int CountPositive(int[] a)
{
    int count = 0;
    foreach (int x in a)
    {
        if (x > 0) count++;
    }
    return count;
}

Equivalent correct C# loops also gain full credit.
