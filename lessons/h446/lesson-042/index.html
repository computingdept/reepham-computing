Dog d = new Dog();
d.Name = "Max";
d.Eat(); d.Bark();

class Animal {
  public string Name = "";
  public void Eat() { Console.WriteLine("Eating"); }
}

class Dog : Animal {
  public void Bark() { Console.WriteLine("Woof"); }
}
THINK

Explain the design decision

Dog is an Animal: Dog objects reuse accessible Name and Eat, while adding Bark.

CONNECT TO PRIOR KNOWLEDGE

Procedural programming was taught in Lessons 009–012. Now focus on how classes and objects organise related data and behaviour.
