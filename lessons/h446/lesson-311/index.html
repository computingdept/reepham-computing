What is a loop invariant?

MODEL ANSWER

A property true before and after each completed iteration.

QUESTION 2 OF 4

Retrieval

What distinguishes a run from a distinct value?

MODEL ANSWER

Runs count contiguous groups; distinct counts globally unique values.

Unfamiliar programming challenges

By the end you can…
  • A run is a maximal group of equal consecutive values, not a unique value across the whole array.
  • Maintain invariant: after index i, the count equals the number of runs in the processed prefix.
  • Handle empty input and test all-equal, alternating and separated-repeat arrays.

static int CountRuns(int[] a){
 if(a.Length==0) return 0;
 int runs=1;
 for(int i=1;i<a.Length;i++)
  if(a[i]!=a[i-1]) runs++;
 return runs;
}

CORE · QUESTION 2 OF 3

Write a valid C# CountRuns(int[] a) returning runs and handling empty input. [8]

MARK SCHEME / WORKED ANSWER

Mark scheme [8]: an int-returning method accepting int[] [1]; detect an empty array and return 0 [2]; initialise the run count to 1 [1]; loop from index 1 [1]; compare neighbouring values [1]; increment on change [1]; return the result [1]. Equivalent correct C# earns the same marks.

static int CountRuns(int[] a)
{
    if (a.Length == 0) return 0;
    int runs = 1;
    for (int i = 1; i < a.Length; i++)
    {
        if (a[i] != a[i - 1]) runs++;
    }
    return runs;
}
