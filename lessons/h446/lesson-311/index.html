static int CountRuns(int[] a){
 if(a.Length==0) return 0;
 int runs=1;
 for(int i=1;i<a.Length;i++)
  if(a[i]!=a[i-1]) runs++;
 return runs;
}

A wildlife field recorder stores a non-negative denary identifier. Write an algorithm to input the denary number and display its representation in base 8 (octal). Your method must use division/remainders by 8, put digits in the correct order and work for zero. [6]

OCR H446/02 · June 2023 · Q6 · RHS exam-style scenario

MODEL ANSWER · 6 MARKS

number = int(input("Denary:")) if number == 0 then print("0") else digits = "" while number > 0 remainder = number MOD 8 digits = str(remainder) + digits number = number DIV 8 endwhile print(digits) endif

Marking: Six marks: obtain input; MOD 8; integer DIV 8; loop until zero; prepend/reverse octal remainders into correct order; output complete octal representation. Explicit zero handling is an extension to the source competence.

01 function countOccurrences(numbers)
02   distinct = []
03   counts = []
04   size = numbers.length
05   for i = 0 to size
06     target = numbers[i]

11       endif
12     next j

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 4 MARKS · 4 MINUTES

A program receives a non-empty array of integers named readings. Write a function that returns the number of times a reading is greater than the reading immediately before it. For example, [3, 5, 2, 8] returns 2. [4]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 4 MARKS

function countRises(readings)
  count = 0
  for i = 1 to readings.length - 1
    if readings[i] > readings[i - 1] then
      count = count + 1
    endif
  next i
  return count
endfunction

Marking: One mark for initialising count; one for traversing valid adjacent pairs; one for comparing with the previous reading and incrementing on a rise; one for returning count. A one-element array must return zero.
