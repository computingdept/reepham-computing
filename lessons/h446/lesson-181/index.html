Key vocabulary for today
recursionrecursive callbase caserecursive casecall stackstack frameparameterunwind
TERM 1 OF 8

recursion

DEFINITION

A function calling itself from within the function.

Like Russian dolls: each call contains a smaller version.

TERM 2 OF 8

recursive call

DEFINITION

The statement that calls the same function again.

Like opening the next doll in the set.

TERM 3 OF 8

base case

DEFINITION

The condition that stops further recursive calls.

Like the smallest doll: there is nowhere further to go.

TERM 4 OF 8

recursive case

DEFINITION

The part that makes another recursive call.

Like opening another smaller doll and continuing.

TERM 5 OF 8

call stack

DEFINITION

The structure that keeps track of active function calls.

Like a stack of plates: the newest call sits on top.

TERM 6 OF 8

stack frame

DEFINITION

The stored information for one active function call.

Like one labelled plate holding that call’s own data.

TERM 7 OF 8

parameter

DEFINITION

A value supplied to a function call.

Like information handed to a function when it starts.

TERM 8 OF 8

unwind

DEFINITION

Returning from the deepest call back through earlier calls.

Like taking plates off the stack from the top.

RECURSION · CORE MODEL

A function calls itself

function sumTo(n)
    if n == 1 then
        return 1
    else
        return n + sumTo(n - 1)
    endif
endfunction
Key idea: every useful recursive algorithm needs a route to a stopping condition.
STEP 1 OF 4

Recursive call

sumTo(n - 1)

The function calls itself. That self-call is what makes the algorithm recursive.

1 of 4
STEP 2 OF 4

Base case

if n == 1 then
    return 1

The base case stops another recursive call being made.

2 of 4
STEP 3 OF 4

Each call has its own values

sumTo(4)
sumTo(3)
sumTo(2)
sumTo(1)

Each active call has its own parameter value. The calls are tracked on the call stack.

3 of 4
STEP 4 OF 4

Then the calls unwind

sumTo(1) returns 1
sumTo(2) returns 3
sumTo(3) returns 6
sumTo(4) returns 10

The deepest call returns first. Earlier calls then finish in reverse order.

4 of 4
ONE COMPLETE WORKED EXAMPLE

Trace sumTo(4)

Follow the calls down to the base case, then follow the returned values back up.

sumTo(4)
Worked example
STEP 1 · CALL DOWN

First call

sumTo(4)
= 4 + sumTo(3)

The base case is not met, so another call is made.

STEP 2 · REACH BASE CASE

Continue the calls

4 + sumTo(3)
= 4 + 3 + sumTo(2)
= 4 + 3 + 2 + sumTo(1)
= 4 + 3 + 2 + 1

sumTo(1) reaches the base case and returns 1.

STEP 3 · UNWIND

Return back up

sumTo(1) → 1
sumTo(2) → 3
sumTo(3) → 6
sumTo(4) → 10

The return values travel back through the earlier calls.

STEP 4 · FINAL RESULT

Do not stop at the deepest call

sumTo(4) returns 10
