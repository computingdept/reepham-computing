QUESTION 1 OF 4 · RECENT · YEAR 12 FUNCTIONS

Retrieval

A C# function is declared int Double(int n). What does return n * 2; do when n is 4?

MODEL ANSWER

It sends the value 8 back to the caller. A return statement also ends the current invocation.

QUESTION 2 OF 4 · EARLIER · ITERATION

Retrieval

Starting total = 1, repeat total = total * i for i = 1, 2, 3. What is total after each iteration?

MODEL ANSWER

1, 2 and 6. Each iteration multiplies the previous total by the new i.

QUESTION 3 OF 4 · OLDER · STACKS

Retrieval

Values A, B and C are pushed onto a stack in that order. Which leaves first when popping?

MODEL ANSWER

C. A stack is last in, first out (LIFO).

QUESTION 4 OF 4 · CHALLENGE · CODE TRACE

Challenge

A function AddTwo(x) returns x + 2. Calculate AddTwo(AddTwo(3)) and show the inner and outer calls.

MODEL ANSWER

The inner AddTwo(3) returns 5; then the outer AddTwo(5) returns 7.

NEW LEARNING · CODE FIRST

What is the program actually doing?

int Factorial(int n)
{
    if (n == 0) return 1;   // STOP
    return n * Factorial(n - 1);
}

Think: Why does the input get smaller? What stops another call?

STEP 1 OF 3

Start with a small input

Factorial(4) calls Factorial(3); it cannot finish multiplying until the inner call returns.

STEP 2 OF 3

Reach the stopping rule

Factorial(0) returns 1. It makes no further recursive call.

STEP 3 OF 3

Return through the calls

Factorial(1) = 1 × 1; Factorial(2) = 2 × 1; Factorial(3) = 3 × 2; Factorial(4) = 4 × 6 = 24.

I DO · MODEL EXAMPLE

Trace Factorial(3). Show each call and its return value.

int Factorial(int n)
{
    if (n == 0) return 1;
    return n * Factorial(n - 1);
}
STEP 1 OF 3

Calls

3 → 2 → 1 → 0. The argument decreases by one each time.

STEP 2 OF 3

Base case

Factorial(0) returns 1. No more calls occur.

STEP 3 OF 3

Returns

Factorial(1)=1, Factorial(2)=2, Factorial(3)=6. Final answer: 6.

WE DO · GUIDED PRACTICE · NEW INPUT

Trace Factorial(4) without running the program. Identify the base case and final returned value.

Factorial(4) → ... → Factorial(0)

Predict the next step before revealing the explanation.

STEP 1 OF 3

Predict the next call

4 calls 3; 3 calls 2; 2 calls 1; 1 calls 0.

STEP 2 OF 3

Predict the first return

Factorial(0) returns 1.

STEP 3 OF 3

Complete the return chain

Factorial(1)=1, Factorial(2)=2, Factorial(3)=6, Factorial(4)=24.

Foundation · QUESTION 1 OF 3

Complete the calls and returns for Factorial(2).

MODEL ANSWER

Calls: 2 → 1 → 0. Return from 0 is 1, then 1 returns 1 and 2 returns 2.

Core · QUESTION 2 OF 3

What happens if Factorial has no base case? Explain using the call stack.

MODEL ANSWER

Calls continue without a stopping condition, adding stack frames until the runtime eventually fails (typically stack overflow).

Stretch · QUESTION 3 OF 3

Modify Factorial to reject negative input; write the C# guard and explain the reason.

MODEL ANSWER

Before the base case: if (n < 0) throw new ArgumentOutOfRangeException(nameof(n));. Negative values would otherwise keep decreasing and never reach 0.

TERM 1 OF 5

recursion

TERM 3 OF 5

recursive case

A call to the same function with a smaller or simpler input.

TERM 4 OF 5

call stack

Memory tracking active function calls and their local state.

TERM 5 OF 5

return value

The result passed back to a caller.

True or false?

If a recursive call reaches its base case, all previous calls have already returned.

MODEL ANSWER

False. Previous calls are still waiting; they return as the stack unwinds.
