Simplify the Boolean expression A + A¬B.

MODEL ANSWER

A. Using the absorption law: A ∨ (A ∧ ¬B) = A.

QUESTION 2 OF 4 · RETRIEVAL · L027

Retrieval

Write −5 in 8-bit two’s complement.

MODEL ANSWER

11111011. Start with 00000101, invert to 11111010, then add 1.

QUESTION 3 OF 4 · RETRIEVAL · EARLIER

Retrieval

Why must the data be sorted before binary search?

MODEL ANSWER

Binary search discards half the search space by comparing with the middle value. Without sorted data, it cannot know which half to discard.

QUESTION 4 OF 4 · CHALLENGE · EARLIER

Challenge

Explain why a floating-point number may lose precision when its mantissa is shifted right.

MODEL ANSWER

A fixed-length mantissa can lose least-significant bits when shifted right. If those bits are discarded, the stored value becomes an approximation.
