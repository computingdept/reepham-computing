row,column ≠ value
carry ≠ sum

EXAM TECHNIQUE

weak:
"They remove things differently."
Worked example
STEP 1 · NAME

Stack rule

Stack = LIFO
STEP 2 · CONTRAST

Queue rule

Queue = FIFO
STEP 3 · LINK

Make the contrast explicit

Newest-first versus oldest-first
STEP 4 · FINAL

Concise answer

A stack is LIFO whereas a queue is FIFO.
