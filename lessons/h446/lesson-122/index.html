I DO · TEACHER MODEL

A regional bus service needs journey booking with changing fare rules and a fixed launch date. Choose an approach and an algorithm.

WORKED REASONING

Model answer

Use iterative development for changing fare rules with documented acceptance milestones for launch. Fare algorithm: collect zones and passenger category, select valid tariff, compute fare, reject invalid input and test boundary zones.

Check: link each claim to the scenario and use precise OCR terminology.

WE DO · DIFFERENT PROBLEM

A school canteen needs a pilot ordering system before full deployment. Recommend a lifecycle and decision routine.

STEP 1 · IDENTIFY

What must we decide?

Identify the inputs, relevant facts and exact output or judgement required.

STEP 2 · APPLY

Work through the method

Use the middle stage of the visual to follow the process and state each intermediate result.

STEP 3 · EXPLAIN

Shared worked answer

RAD or agile prototypes gather pupil feedback quickly; keep data security and payment assurance as formal checks. Algorithm checks available stock, valid quantity and eligibility before confirming order.

FOUNDATION · QUESTION 1 OF 3

APPLICATION · QUESTION 2 OF 3

Justify a suitable lifecycle for a well-understood regulated payroll update. [6]

MARK SCHEME / WORKED ANSWER

Documented staged/hybrid development with control [2], traceable tests/compliance [2], limitations or alternative [2].

CHALLENGE · QUESTION 3 OF 3

Design an algorithm for rejecting bookings when capacity is full and explain test cases and lifecycle fit. [8]

MARK SCHEME / WORKED ANSWER

Capacity check [2], valid request/quantity [2], normal/full/over-limit tests [2], method choice linked to changes/risks [2].
