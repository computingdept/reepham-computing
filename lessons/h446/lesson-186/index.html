NEW LEARNING · CODE FIRST

Read the code; predict its effect

// Merge two ALREADY SORTED runs.
int i = 0, j = 0;
while (i < left.Length && j < right.Length)
{
    if (left[i] <= right[j]) output.Add(left[i++]);
    else output.Add(right[j++]);
}
while (i < left.Length) output.Add(left[i++]);
while (j < right.Length) output.Add(right[j++]);
STEP 1 OF 3

Start with ordered runs

At each merge stage, both input runs must already be sorted.

STEP 2 OF 3

Compare front values

Append the smaller current value, then advance that run's pointer.

STEP 3 OF 3

Copy the remainder

When one run finishes, copy all remaining values from the other run; repeated merging doubles run size.

Stretch · 3 OF 3

Explain the O(n log n) time complexity of merge sort.

WORKED ANSWER

There are about log₂n merge levels, and each level processes n elements → O(n log n) time, with O(n) extra array storage for this implementation.
