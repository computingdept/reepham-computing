CODE FIRST · WORKED REPRESENTATION

Predict what changes

// Index-based linked list:
int[] value = {10,20,30,15};
int[] next  = {1, 2,-1, 1};
int head = 0;
next[0] = 3; // insert 15 after 10
STEP 1 OF 3

Follow references

head = 0 means the first node has value 10. next[0] initially points at node 1 (20).

STEP 2 OF 3

Prepare the new node

The new node at index 3 stores 15 and next[3] = 1, preserving the rest of the list.

STEP 3 OF 3

Change the existing link

Set next[0] = 3, producing the chain 10 → 15 → 20 → 30.

I DO · WORKED

Insert value 7 between 4 and 9 in the linked list 4 → 9 → 12.

// Pointer pseudocode: node7 already exists.
node7.next = node4.next; // preserve node9
node4.next = node7;
STEP 1 OF 2

Predict

Create node 7 and set its next link to the existing node 9.

STEP 2 OF 2

Confirm and explain

Point node 4 at node 7. The chain becomes 4 → 7 → 9 → 12.

WE DO · DIFFERENT TASK

Insert 6 after 2 in 2 → 8 → 11 without losing 8.

// Pointer pseudocode: node6 already exists.
node6.next = node2.next; // preserve node8
node2.next = node6;
STEP 1 OF 2

Predict

First link new node 6 to node 8.

STEP 2 OF 2

Confirm and explain

Then link node 2 to node 6, giving 2 → 6 → 8 → 11.

Foundation · 1 OF 3

In linked list 5 → 10 → 15, what follows node 10?

MODEL ANSWER

Node 15.

Core · 2 OF 3

A node with value 12 must be inserted between 7 and 20. State the two link changes.

MODEL ANSWER

Set new12.next to node20, then set node7.next to new12.

Stretch · 3 OF 3

Why does inserting into a linked list avoid shifting array elements but may still take O(n) time?

MODEL ANSWER

Once the insertion node is found, links can be updated in O(1), but finding the position usually needs a traversal that takes O(n).

TERM 1 OF 5

node

A list element containing data and a link.

TERM 2 OF 5

next pointer

Reference or index of the next node.

TERM 3 OF 5

head

Reference to the first list node.

TERM 4 OF 5

null sentinel

Marker such as −1 in an index implementation meaning no next node.

TERM 5 OF 5

traversal

Visit nodes by following successive links.

True or false?

A singly linked list always supports direct O(1) access to its twentieth element.

Model answer

False. Traversal from the head is generally required.
