NEW LEARNING · EXAMPLE FIRST

Predict the effect

using System;
int[] scores = {5,8,3,8};
Console.WriteLine(CountAtLeast(scores,8)); // 2
static int CountAtLeast(int[] values, int t) {
  int count=0;
  foreach(int score in values)
    if(score>=t) count++;
  return count;
}
STEP 1 OF 3

Inputs and output

Inputs are an array and a threshold; the result is the number of qualifying items.

STEP 2 OF 3

Check each element

The counter increases only for values greater than or equal to the threshold.

STEP 3 OF 3

Test a boundary

A value equal to the threshold must count. For 5,8,3,8 at threshold 8, result is 2.

I DO · MODEL

Count values at least 7 in [4,7,9].

Threshold = 7; count starts at 0.
STEP 1 OF 2

Predict

Skip 4 because it is below 7.

STEP 2 OF 2

Explain

Count 7 and 9: the result is 2.

WE DO · DIFFERENT GUIDED PROBLEM

Count values at least 6 in [6,2,6,8].

Threshold = 6; count starts at 0.
STEP 1 OF 2

Predict

The first 6 counts and 2 does not.

STEP 2 OF 2

Explain

The second 6 and 8 count; final result is 3.

Foundation · 1 OF 3

Find CountAtLeast([2,5,7],5).

MODEL ANSWER

2 because 5 and 7 qualify.

Core · 2 OF 3

Change the method so it counts values strictly greater than the threshold.

MODEL ANSWER

Change score>=t to score>t.

Stretch · 3 OF 3

Give normal, boundary and erroneous test cases if the threshold must be non-negative.

MODEL ANSWER

Normal threshold 5 with [3,5,7] gives 2; boundary threshold 0 with [0] gives 1; erroneous threshold −1 must be rejected using an input guard.
