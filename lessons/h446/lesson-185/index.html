ANSWER

Why is a single-item list already sorted?

ANSWER

C# MODEL · INSERTION SORT

Run a complete insertion sort

Open .NET Fiddle →
using System;

public class Program
{
    public static void Main()
    {
        int[] values = { 9, 4, 7, 3 };

        for (int i = 1; i < values.Length; i++)
        {
            int key = values[i];
            int j = i - 1;

            while (j >= 0 && values[j] > key)
            {
                values[j + 1] = values[j];
                j--;
            }

            values[j + 1] = key;
        }

        Console.WriteLine(string.Join(", ", values));
    }
}
Run it: the output should be 3, 4, 7, 9.
