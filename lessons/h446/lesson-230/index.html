QUESTION 1 OF 4 · LAST LESSON · PARADIGMS

Retrieval

How does OOP differ from a procedural program?

MODEL ANSWER

OOP groups state and behaviour into objects; procedural code is organised around procedures/functions.

QUESTION 2 OF 4 · RECENT · SCOPE

Retrieval

What does a local variable mean?

MODEL ANSWER

A variable accessible only within its declaration's scope.

QUESTION 3 OF 4 · OLDER · CLASS STATE

Retrieval

If a field is private-set, how can callers change it safely?

MODEL ANSWER

Through public methods/property logic defined by the class.

QUESTION 4 OF 4 · CHALLENGE · RETURN

Retrieval

Why does `Deposit(balance,5);` not update the caller's int balance if only a return value is produced?

MODEL ANSWER

The return is discarded and a value-type parameter is a copy; the caller must assign the returned result.

NEW LEARNING · CODE FIRST

Compare the structure of the code

// Procedural version with an explicit result:
int Deposit(int balance,int amount)
  => balance+amount;
int updated=Deposit(10,5);
// OOP version updates one object's state:
Account account=new(10);
account.Deposit(5);
class Account {
 public int Balance {get;private set;}
 public Account(int start){Balance=start;}
 public void Deposit(int amount){Balance+=amount;}
}
STEP 1 OF 3

Procedural state

The caller passes an integer balance and explicitly stores the returned value.

STEP 2 OF 3

Object state

Account object A stores Balance internally and Deposit changes that object's state.

STEP 3 OF 3

Separate instances

Account B stays at 20 when Account A changes to 15; the objects have independent state.

I DO · WORKED EXAMPLE

Two accounts start at 8 and 20; only first account deposits 4. Trace both.

Account a = new(8), b = new(20);
a.Deposit(4);
STEP 1 OF 2

Predict

Account a's Balance becomes 12.

STEP 2 OF 2

Model response

Account b remains at 20 because its state is separate.

WE DO · DIFFERENT EXAMPLE

A procedural function returns balance+3, but the caller ignores the return. What happens?

int balance=7;
Deposit(balance,3); // result unused
// What is balance?
STEP 1 OF 2

Predict

Deposit computes and returns 10, but its result is ignored.

STEP 2 OF 2

Model response

The caller's balance remains 7. Assign balance=Deposit(balance,3) to store 10.

Foundation · 3 marks · QUESTION 1 OF 3

Procedural AddFive(x) returns x+5. If caller x=2 discards the result, what is x?

MODEL ANSWER

[3] Function returns 7 [1]; caller does not assign it [1]; x remains 2 [1].

Core · 6 marks · QUESTION 2 OF 3

Two objects have balances A=10, B=30. A.Deposit(7) and B.Deposit(2) run. Find both balances and describe why they differ.

MODEL ANSWER

[6] A=17 [1], B=32 [1]; each is a separate instance [2], each method changes only its own state [2].

Stretch · 6 marks · QUESTION 3 OF 3

Compare one maintenance advantage and one risk of procedural and OOP implementations for a library system.

MODEL ANSWER

[6] Procedures can be individually reused/tested [1] but shared mutable data can create coupling [2]; OOP encapsulates per-book state [1] and validation in methods [1], but excessive class complexity can make a small solution harder to follow [1].

True or false?

Calling a C# function that returns a new balance automatically changes the caller's original int variable.

Model answer

False. The caller must assign the returned value unless code uses a ref parameter or other shared state.
