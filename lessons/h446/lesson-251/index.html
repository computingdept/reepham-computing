Key vocabulary

ALUCUMARMDRCIRPCACC
NEW LEARNING · CODE FIRST

Predict the next state

// A simplified fetch example:
PC = 120    // next instruction address
MAR = PC    // address being accessed
MDR = Memory[MAR] // fetched instruction
CIR = MDR   // current instruction
PC = PC + 1 // next sequential address
STEP 1 OF 3

Understand the CPU areas

The control unit decodes and coordinates operations; the ALU performs arithmetic and logical operations.

STEP 2 OF 3

Separate address from data

MAR holds the address being accessed; MDR holds the instruction or data transferred; PC holds the next instruction's address.

STEP 3 OF 3

Trace the simplified fetch

With PC=120, MAR becomes 120; memory supplies instruction via MDR to CIR; PC advances to the next sequential address. Branching may change PC later.

I DO · MODEL

If PC starts at address 50, trace register roles for the next sequential instruction fetch.

PC=50 → MAR=50
MDR=Memory[50]
CIR=MDR
PC=51
STEP 1 OF 2

Predict first

Copy PC=50 into MAR to identify the memory address being accessed.

STEP 2 OF 2

Explain the answer

Fetch memory content into MDR, copy it to CIR and advance PC to 51.

WE DO · DIFFERENT PROBLEM

If PC initially holds 200 and Memory[200] contains ADD 10, state MAR, CIR and next sequential PC.

MAR=200; CIR=ADD 10; PC=201
STEP 1 OF 2

Predict first

MAR must contain 200 and MDR transports the instruction from memory.

STEP 2 OF 2

Explain the answer

CIR now contains ADD 10; for sequential execution PC has advanced to 201.

Foundation · 5 marks · QUESTION 1 OF 3

State the roles of PC, MAR, MDR, CIR and ACC.

WORKED ANSWER

[5] PC next instruction address [1], MAR accessed address [1], MDR transferred data/instruction [1], CIR current instruction [1], ACC intermediate arithmetic/logical result [1].

Core · 6 marks · QUESTION 2 OF 3

Trace a fetch starting PC=73 where Memory[73] contains LDA 92. State each register's role and the sequential next PC.

WORKED ANSWER

[6] PC initially 73 [1], MAR becomes 73 [1], memory transfers LDA 92 via MDR [1], CIR receives LDA 92 [1], sequential PC becomes 74 [1], CU interprets the instruction [1].

Stretch · 6 marks · QUESTION 3 OF 3

Explain why the CPU uses both MAR and MDR rather than a single undifferentiated register, referring to an instruction fetch and a data load.

WORKED ANSWER

[6] MAR carries memory location address [1]; MDR carries actual contents [1]; fetching uses PC→MAR [1] and memory→MDR→CIR [1]; loading data uses an address in MAR [1] and the retrieved value via MDR towards target register/ACC [1].
