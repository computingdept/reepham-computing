NEW LEARNING · CODE FIRST

Predict the next state

// A simplified fetch example:
PC = 120    // next instruction address
MAR = PC    // address being accessed
MDR = Memory[MAR] // fetched instruction
CIR = MDR   // current instruction
PC = PC + 1 // next sequential address
STEP 1 OF 3

Understand the CPU areas

The control unit decodes and coordinates operations; the ALU performs arithmetic and logical operations.

STEP 2 OF 3

Separate address from data

MAR holds the address being accessed; MDR holds the instruction or data transferred; PC holds the next instruction's address.

STEP 3 OF 3

Trace the simplified fetch

With PC=120, MAR becomes 120; memory supplies instruction via MDR to CIR; PC advances to the next sequential address. Branching may change PC later.

I DO · MODEL

If PC starts at address 50, trace register roles for the next sequential instruction fetch.

PC=50 → MAR=50
MDR=Memory[50]
CIR=MDR
PC=51
STEP 1 OF 2

Predict first

Copy PC=50 into MAR to identify the memory address being accessed.

STEP 2 OF 2

Explain the answer

Fetch memory content into MDR, copy it to CIR and advance PC to 51.

WE DO · DIFFERENT PROBLEM

If PC initially holds 200 and Memory[200] contains ADD 10, state MAR, CIR and next sequential PC.

MAR=200; CIR=ADD 10; PC=201
STEP 1 OF 2

Predict first

MAR must contain 200 and MDR transports the instruction from memory.

STEP 2 OF 2

Explain the answer

CIR now contains ADD 10; for sequential execution PC has advanced to 201.

EXAM QUESTION 1 OF 4 · 3 MARKS · 3 MINUTES

Name THREE other CPU registers involved in the FDE cycle, excluding the accumulator and Program Counter. [3]

OCR H446/01 · June 2022 · Q1(d)(iii) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

Any three of MAR (Memory Address Register), MDR (Memory Data Register), CIR (Current Instruction Register), or Index Register (IR), where included.

Marking: One mark per distinct correctly identified register, up to three. A name and its abbreviation do not count as two.

EXAM QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A CPU uses an accumulator as a working register. Describe TWO specific uses of the accumulator during execution. [2]

OCR H446/01 · June 2022 · Q1(d)(i) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

It can hold operands/results from the ALU, hold data read from memory and provide a value checked for conditional branching.

Marking: One mark per distinct valid role, maximum two.

EXAM QUESTION 3 OF 4 · 2 MARKS · 2 MINUTES

A robotics student sees a CPU register. Define what a processor register is, giving its location and purpose. [2]

OCR H446/01 · November 2021 · Q6(a)(i) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

A small high-speed temporary storage location inside the CPU for specific data, addresses or instructions.

Marking: One mark for temporary CPU-local storage and one for its high-speed or specific processing use.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

During the fetch stage, distinguish the roles of the MAR and MDR. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

MAR holds the address of the memory location being accessed. MDR holds the data or instruction transferred to or from that location.

Marking: One mark for the memory address held by MAR; one for the data/instruction held by MDR.
