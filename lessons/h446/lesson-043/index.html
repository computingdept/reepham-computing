OOP · Polymorphism and Overriding

Animal[] pets = { new Dog(), new Cat() };
foreach (Animal p in pets) Console.WriteLine(p.Sound());

class Animal {
  public virtual string Sound() { return "?"; }
}

class Dog : Animal {
  public override string Sound() { return "Woof"; }
}

class Cat : Animal {
  public override string Sound() { return "Meow"; }
}
THINK

Explain the design decision

One call, p.Sound(), has different results according to the actual object type: Woof then Meow.

CONNECT TO PRIOR KNOWLEDGE

Procedural programming was taught in Lessons 009–012. Now focus on how classes and objects organise related data and behaviour.

One worked example
STEP 1

Read the common interface

The array holds Animal references to Dog and Cat objects.

STEP 2

Trace the first call

Dog's overridden Sound returns Woof.

STEP 3

Trace the second call

Cat's overridden Sound returns Meow.
