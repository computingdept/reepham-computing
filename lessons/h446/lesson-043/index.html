QUESTION 1 OF 4

LAST LESSON · L042 · INHERITANCE

In class Dog : Animal, which is the base class, which is derived, and what can Dog inherit?

ANSWER

Animal is the base class; Dog is derived. Dog can inherit accessible members of Animal.

QUESTION 2 OF 4

EARLIER · L018 · RECORDS

What is the difference between accessing a record field and accessing an array element?

ANSWER

A record uses a named field; an array uses a numbered index.

QUESTION 3 OF 4

EARLIER · L025 · BINARY SEARCH

Why must binary search operate on a sorted collection?

ANSWER

Sorting makes it possible to discard half the remaining items after each comparison.

QUESTION 4 OF 4

CHALLENGE · L042 · INHERITED METHODS

Animal has a public Eat() method. Dog inherits Animal and adds a public Bark() method. Which two methods can a Dog object call, and which is inherited?

ANSWER

It can call Eat() and Bark(). Eat() is inherited from Animal; Bark() is defined in Dog.

class Animal {
  public virtual string Sound() { return "?"; }
}

class Dog : Animal {
  public override string Sound() { return "Woof"; }
}

class Cat : Animal {
  public override string Sound() { return "Meow"; }
}
THINK

Explain the design decision

One call, p.Sound(), has different results according to the actual object type: Woof then Meow.
