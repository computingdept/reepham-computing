CODE FIRST · WORKED REPRESENTATION

Predict what changes

// Undirected graph:
A: B, C
B: A, D
C: A
D: B
STEP 1 OF 3

Identify vertices

A, B, C and D are graph vertices.

STEP 2 OF 3

Follow edges

Edges connect A–B, A–C and B–D. Because this graph is undirected, each connection works both ways.

STEP 3 OF 3

Write adjacency lists

A:B,C; B:A,D; C:A; D:B. Every undirected edge appears in both endpoint lists.

I DO · WORKED

Build adjacency lists for triangle A–B, B–C, A–C.

Edges: AB, BC, AC
Adjacency lists: ?
STEP 1 OF 2

Predict

Every vertex connects to the other two vertices.

STEP 2 OF 2

Confirm and explain

A:B,C; B:A,C; C:A,B. Each undirected edge is listed from both endpoints.

WE DO · DIFFERENT TASK

Build adjacency lists for chain A–B–C–D.

Edges: AB, BC, CD
Adjacency lists: ?
STEP 1 OF 2

Predict

A is adjacent to B; D is adjacent to C.

STEP 2 OF 2

Confirm and explain

Full lists: A:B; B:A,C; C:B,D; D:C.

Foundation · 1 OF 3

Name the vertices and number of edges in A–B, A–C, C–D.

MODEL ANSWER

Vertices A,B,C,D; three edges.

Core · 2 OF 3

Give adjacency lists for an undirected graph with edges AB, BC, CD.

MODEL ANSWER

A:B; B:A,C; C:B,D; D:C.

Stretch · 3 OF 3

Compare adjacency matrix and adjacency list storage on a sparse graph with many vertices.

MODEL ANSWER

An adjacency matrix uses O(V²) space irrespective of edge count; adjacency lists use O(V+E) space and usually save memory for sparse graphs.

TERM 1 OF 5

vertex

A node in a graph.

TERM 2 OF 5

edge

Connection between vertices.

TERM 3 OF 5

adjacency list

Representation listing neighbours of each vertex.

TERM 4 OF 5

adjacency matrix

Two-dimensional matrix marking which vertices are connected.

TERM 5 OF 5

sparse graph

A graph with relatively few edges compared with possible connections.

True or false?

In an undirected graph, A–B is represented in both A's and B's adjacency lists.

Model answer

True. Each undirected connection is recorded from both endpoints.
