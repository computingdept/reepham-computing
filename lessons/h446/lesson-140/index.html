STEP 2 OF 3

Order requests ID 12

Explain the change using correct technical terms.

STEP 3 OF 3

Reject orphan reference

The DBMS rejects the foreign key value 12, unless a matching Customer row is created or the reference is changed. Policies for deleting parent rows may RESTRICT, CASCADE or SET NULL, where permitted and configured.

WE DO · DIFFERENT PROBLEM

A large Book table is queried by ISBN many times per day. Should the ISBN have an index?

STEP 1 OF 3

Frequent ISBN lookup

Identify the relevant information and make a prediction.

STEP 2 OF 3

Indexed search path

Explain the change using correct technical terms.

STEP 3 OF 3

Write and space overhead

An index on ISBN can support quicker exact-match retrieval, especially for large data, but occupies space and requires maintenance after insert/update/delete. A UNIQUE constraint is appropriate if ISBN must be unique in this table.
