Lesson 081 · Merge Sort: Bottom-up Merge Tracing

By the end you can…
  • Merge sort divides the input into smaller runs; merging two already sorted runs repeatedly selects the smallest available front value.
  • Bottom-up merge sort begins with runs of length one and doubles run width on every complete pass; it does not require recursive calls.
  • Worst-case time O(n log n); standard array merging uses O(n) extra space. Include comparisons, not just the final sorted sequence.

// [7,2,9,1] → [2,7,1,9] → [1,2,7,9]
