NEW LEARNING · CODE FIRST

Read the code; predict its effect

using System;
class Program
{
    static int score = 10;
    static void Show()
    {
        int score = 3; // local shadows field
        Console.WriteLine(score);
    }
    static void Main() { Show(); }
}
STEP 1 OF 3

Three control structures

Sequence runs in order; selection chooses a branch; iteration repeats instructions.

STEP 2 OF 3

Where is a variable visible?

A local declaration belongs to its block or method; a class-level field can be accessed by relevant class methods.

STEP 3 OF 3

Shadowing

A local variable with the same name as a field can hide that field inside the method; trace precisely which one is printed.

I DO · MODEL

A class field x is 8. A method declares int x=2 and prints x. What appears?

STEP 1 OF 2

Predict first

Which x is in scope at the print statement?

STEP 2 OF 2

Model solution

The method-local x is 2 and shadows the field. The program prints 2.

WE DO · GUIDED

A class field points is 20. A method runs points += 5 and prints points without declaring a local variable.

STEP 1 OF 2

Predict first

Which variable is modified?

STEP 2 OF 2

Model solution

The class field is modified to 25, then 25 is printed.

EXAM QUESTION 1 OF 3 · 2 MARKS · 2 MINUTES

A student program has a score variable declared inside the markRound() function and a total variable declared at program level. Explain the difference between the scope of a local variable and a global variable. [2]

OCR H446/02 · June 2025 · Q6(b)(i) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

A global variable is in scope throughout the program (subject to language/module rules); a local variable is accessible only within the function/procedure/block in which it was declared.

Marking: One mark for a correctly characterised global scope, one for local scope. Do not confuse scope with the type or lifetime of the stored value.

EXAM QUESTION 2 OF 3 · 2 MARKS · 2 MINUTES

A large school timetable program relies heavily on a global variable named currentClass, which many routines can change. Describe one drawback of using a global variable here, including the consequence of that drawback. [2]

OCR H446/02 · June 2025 · Q6(b)(ii) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

Because many routines can change currentClass, it is harder to trace which modification caused an incorrect timetable (poor maintainability/testing), or a change in one routine unexpectedly affects another (lower reliability/data integrity).

Marking: One mark for a concrete drawback of global state, one for its linked effect on debugging, memory, modularity or correctness.

EXAM QUESTION 3 OF 3 · 2 MARKS · 2 MINUTES

A student writes a function in which an important intermediate value is stored in a local variable. Describe one disadvantage of keeping the value local when other functions also need to use it. [2]

OCR H446/02 · June 2025 · Q6(b)(iii) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

A local variable cannot be read directly outside its routine; the programmer must pass the information as an argument or return value, adding code, coupling/complexity or extra development effort.

Marking: One mark for limited visibility/access of the local variable; one for a consequence such as extra parameter passing or return handling.

True or false?

A local variable always changes a same-named class field.

MODEL ANSWER

False. A local of the same name usually shadows the field, leaving the field unchanged.
