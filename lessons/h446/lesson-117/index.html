What is the difference between linker and loader?

MODEL ANSWER

Linker resolves modules/symbols; loader maps executable into memory to run.

Why must a binary search operate on ordered data?

MODEL ANSWER

It discards half the search space using an ordering comparison.

I DO · TEACHER MODEL

An air-traffic subsystem has carefully fixed specifications and requires formal approvals. Select a development approach.

WORKED REASONING

Model answer

A plan-driven/waterfall approach can support documented phase gates and traceability; however, testing and validation must still occur throughout as appropriate. Safety assurance matters more than simply labelling it waterfall.

WE DO · DIFFERENT PROBLEM

A community app changes weekly after users test prototypes. Which approach is more suitable?

STEP 1 · IDENTIFY

What must we decide?

Identify the inputs, relevant facts and exact output or judgement required.

STEP 2 · APPLY

Work through the method

STEP 3 · EXPLAIN

Shared worked answer

Agile iterations with prioritised backlog, frequent releases and real user feedback. A strictly sequential plan risks discovering changed needs late. Maintain security and test discipline.
