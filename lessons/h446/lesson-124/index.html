I DO · TEACHER MODEL

Trace FUNCTION doublePlusOne(x): result=x*2; RETURN result+1; print(doublePlusOne(4)).

WORKED REASONING

Model answer

Parameter x=4, local result=8, return value 9, printed output 9. The local result does not become a global variable merely because the function runs.

WE DO · DIFFERENT PROBLEM

Trace FUNCTION area(w,h): RETURN w*h; print(area(3,5)). How would a procedure differ?

STEP 1 · IDENTIFY

What must we decide?

Identify the inputs, relevant facts and exact output or judgement required.

STEP 2 · APPLY

Work through the method

Use the middle stage of the visual to follow the process and state each intermediate result.

STEP 3 · EXPLAIN

Shared worked answer

Arguments bind w=3 and h=5; return 15; print shows 15. A procedure is intended primarily to perform an action rather than return a result (conventions vary by language).
