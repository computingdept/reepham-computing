NEW LEARNING · EXAMPLE FIRST

Trace the concept

RAM: volatile active program data.
ROM/firmware: non-volatile boot code.
Virtual storage: remote files via network.
Virtual memory: OS address-space and paging.
These final two are NOT the same concept.
STEP 1 OF 3

RAM versus ROM

RAM supports active execution and is volatile; ROM and firmware storage retain instructions without power.

STEP 2 OF 3

Define virtual storage

A remote or cloud storage service keeps files on network-accessible systems, potentially available on multiple devices.

STEP 3 OF 3

Distinguish virtual memory

OS virtual memory involves memory addressing/paging with secondary storage, taught again in OS memory management.

I DO · MODEL

Why can unsaved editing work disappear after power loss while firmware remains?

Unsaved data lives in RAM.
Firmware resides in non-volatile storage.
STEP 1 OF 2

Predict

Unsaved temporary program state depends on volatile RAM and can disappear without power.

STEP 2 OF 2

Explain

Firmware persists in non-volatile storage, allowing startup instructions to remain available.

WE DO · DIFFERENT PROBLEM

A pupil opens saved coursework from home using a school online drive. State advantages and risks.

Remote file storage accessed over network.
The file may sync to several devices.
STEP 1 OF 2

Predict

Virtual/cloud storage supports access from multiple locations and may offer remote copies.

STEP 2 OF 2

Explain

Network outages, account security and mistakenly synced deletions are relevant risks.
