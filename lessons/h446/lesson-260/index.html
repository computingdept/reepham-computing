NEW LEARNING · EXAMPLE FIRST

Trace the concept

RAM: volatile active program data.
ROM/firmware: non-volatile boot code.
Virtual storage: remote files via network.
Virtual memory: OS address-space and paging.
These final two are NOT the same concept.
STEP 1 OF 3

RAM versus ROM

RAM supports active execution and is volatile; ROM and firmware storage retain instructions without power.

STEP 2 OF 3

Define virtual storage

A remote or cloud storage service keeps files on network-accessible systems, potentially available on multiple devices.

STEP 3 OF 3

Distinguish virtual memory

OS virtual memory involves memory addressing/paging with secondary storage, taught again in OS memory management.

I DO · MODEL

Why can unsaved editing work disappear after power loss while firmware remains?

Unsaved data lives in RAM.
Firmware resides in non-volatile storage.
STEP 1 OF 2

Predict

Unsaved temporary program state depends on volatile RAM and can disappear without power.

STEP 2 OF 2

Explain

Firmware persists in non-volatile storage, allowing startup instructions to remain available.

WE DO · DIFFERENT PROBLEM

A pupil opens saved coursework from home using a school online drive. State advantages and risks.

Remote file storage accessed over network.
The file may sync to several devices.
STEP 1 OF 2

Predict

Virtual/cloud storage supports access from multiple locations and may offer remote copies.

STEP 2 OF 2

Explain

Network outages, account security and mistakenly synced deletions are relevant risks.

EXAM QUESTION 1 OF 4 · 3 MARKS · 3 MINUTES

A design studio upgrades the RAM in computers used for large graphics projects. Explain how this could improve performance. [3]

OCR H446/01 · June 2024 · Q1(g) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

More currently running programs and working data can be held in RAM, reducing reliance on much slower virtual memory/secondary-storage swapping and the risk of thrashing.

Marking: Up to three separate points: more active working data in RAM; less use of disk virtual memory; RAM access faster; less swapping/thrashing.

EXAM QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A portable tracker uses some ROM to retain security configuration and cryptographic keys. Explain why ROM is suitable for storing such important information. [2]

OCR H446/01 · June 2024 · Q2(c)(ii) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

ROM provides non-volatile persistent storage of security material and can prevent ordinary programs from altering essential keys or security settings.

Marking: One mark for storing important security/firmware information; one for the value of preserving it and preventing ordinary alteration. Equivalent accepted ROM applications may be credited when correctly developed.

EXAM QUESTION 3 OF 4 · 2 MARKS · 2 MINUTES

A chain of pharmacies backs up the files from several branches into remote virtual storage. Explain two different reasons this is useful for backups rather than relying only on a drive at each branch. [2]

OCR H446/01 · June 2023 · Q1(c) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

Remote backup copies may survive a fire/flood at a branch; capacity can be expanded and files can be retrieved from other branches; many devices' backup can be centralised.

Marking: One mark for each distinct backup-related benefit. Generic statements such as 'lots of space' without development are insufficient.

EXAM QUESTION 4 OF 4 · 4 MARKS · 4 MINUTES

The cooperative uses RAM and ROM in its office computers. Explain TWO different characteristics of RAM and TWO different characteristics of ROM, including typical uses. [4]

OCR H446/01 · November 2021 · Q1(a)(ii) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

RAM is volatile and holds currently running program code/data; ROM is non-volatile and contains boot firmware or bootstrap instructions.

Marking: One mark each for RAM volatility and current-use storage, ROM nonvolatility and firmware/boot use.
