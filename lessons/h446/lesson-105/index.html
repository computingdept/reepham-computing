Lesson 105 · RAM, ROM and Virtual Storage: Different Roles

By the end you can…
  • RAM holds currently used programs/data and normally loses content without power; ROM or firmware flash retains startup routines.
  • OCR virtual storage means logical storage presented from physically remote or pooled devices, such as a network drive or cloud service.
  • Do not confuse virtual storage with virtual memory. Virtual memory uses secondary storage to extend the apparent addressable memory of processes; virtual storage is remote-file presentation.

NEW LEARNING · VISUAL HARDWARE EXPLANATION

Read the model

RAM: working instructions/data while computer runs;
     normally volatile.
ROM/firmware flash: non-volatile startup code.
VIRTUAL STORAGE: files appear local but are
     stored on remote/network/cloud devices.
NOT THE SAME AS VIRTUAL MEMORY:
     disk used to extend apparent RAM.
STEP 1 OF 3

Understand

RAM holds currently used programs/data and normally loses content without power; ROM or firmware flash retains startup routines.

STEP 2 OF 3

Apply

OCR virtual storage means logical storage presented from physically remote or pooled devices, such as a network drive or cloud service.

STEP 3 OF 3

Evaluate

Do not confuse virtual storage with virtual memory. Virtual memory uses secondary storage to extend the apparent addressable memory of processes; virtual storage is remote-file presentation.

I DO · MODEL

A pupil opens a document from a mounted school network drive. Where is the file physically stored?

WORKED REASONING

Explain the choice

On one or more remote network storage devices, even if Finder/Explorer shows a drive like local storage.

WE DO · DIFFERENT EXAMPLE

A laptop runs out of RAM and the OS moves inactive pages to an SSD. Is this OCR 1.1.3(d) virtual storage?

WORKED REASONING

Explain the choice

No. It is virtual memory under 1.2.1, using secondary storage for memory pages.

CHALLENGE · QUESTION 3 OF 3

Correct a pupil's claim that 'virtual storage is extra RAM created when memory fills up'. [6]

MARK SCHEME / WORKED ANSWER

Virtual storage means remote file store [2], virtual memory uses secondary storage for memory pages [2], they are different concepts in OCR spec [2].
