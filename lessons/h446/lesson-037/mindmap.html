What kind of information can a D-type flip-flop retain?

MODEL ANSWER

QUESTION 3 OF 4 · EARLIER · L012 · PARAMETERS

Retrieval

Why is a parameter passed by reference when a caller needs the updated value?

MODEL ANSWER

The subroutine must modify data whose change remains visible to its caller.

QUESTION 4 OF 4 · CHALLENGE · L026 · K-MAPS

Challenge

Why are neighbouring groups of 1s useful when simplifying a Boolean expression?

MODEL ANSWER

Variables that change within a valid group can be eliminated, leaving a simpler term.

I DO · WATCH THE METHOD

Model a useful micro-branch: local variable

A term is not secure until you can explain its effect in a program.

One strong micro-branch, not a page of copied notes
STEP 1

Definition

‘Local variable’ — a variable that can be accessed within the subroutine or block in which it is declared.

STEP 2

Method / evidence

Sketch Function A containing count, with Function B outside. Label where count can be accessed directly.

STEP 3

Common mistake

Write ‘Local does not mean impossible to use elsewhere: a value can be passed as a parameter.’

STEP 4

Connection

Link ‘scope’ to ‘parameters’, then to ‘modular programming’.
