CODE FIRST · WORKED REPRESENTATION

Predict what changes

int[] scores = { 4, 8, 2 };
scores[1] = scores[0] + scores[2];
// scores is now { 4, 6, 2 }
STEP 1 OF 3

Zero-based indexing

scores[0] is 4 and scores[2] is 2.

STEP 2 OF 3

Read before writing

The right-hand expression is 4 + 2 = 6.

STEP 3 OF 3

Replace the selected value

Assign 6 at index 1; the array now contains 4, 6, 2.

Predict

MODEL ANSWER

Core · 2 OF 3

When would you choose a record rather than a simple array for a pupil's name and mark?

MODEL ANSWER

A record groups related named fields with different types, such as string Name and int Mark; a homogeneous array alone does not describe those two fields clearly.

Stretch · 3 OF 3

Explain a suitable use of a named tuple in C# and one limitation.

MODEL ANSWER

A tuple such as (string name,int score) can return two related values quickly; a named record is usually clearer when the structure is a long-lived domain entity.
