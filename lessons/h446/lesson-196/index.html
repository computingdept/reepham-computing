CODE FIRST · WORKED REPRESENTATION

Predict what changes

int[] scores = { 4, 8, 2 };
scores[1] = scores[0] + scores[2];
// scores is now { 4, 6, 2 }
STEP 1 OF 3

Zero-based indexing

scores[0] is 4 and scores[2] is 2.

STEP 2 OF 3

Read before writing

The right-hand expression is 4 + 2 = 6.

STEP 3 OF 3

Replace the selected value

Assign 6 at index 1; the array now contains 4, 6, 2.

I DO · WORKED

Trace marks = {5,7,3}; marks[2] = marks[0] + marks[1].

int[] marks = {5,7,3};
marks[2] = marks[0] + marks[1];
STEP 1 OF 2

Predict

marks[0] + marks[1] means 5 + 7.

STEP 2 OF 2

Confirm and explain

12 replaces the value at index 2: [5,7,12].

WE DO · DIFFERENT TASK

Trace a = {3,9,5}; a[2] = a[0] * 2.

int[] a = {3,9,5};
a[2] = a[0] * 2;
STEP 1 OF 2

Predict

a[0] is 3, so 3 × 2 = 6.

STEP 2 OF 2

Confirm and explain

Put 6 into index 2: [3,9,6].

EXAM QUESTION 1 OF 4 · 2 MARKS · 2 MINUTES

A programmer has an array and a list. Describe two relevant differences between them in typical programming languages. [2]

OCR H446/01 · June 2023 · Q2(c)(ii) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

An array is usually fixed-size/contiguous and accessed by numeric index; a dynamic list can change length and may provide insertion/removal methods. Both can be indexed in some languages, so indexing alone is not a universal difference.

Marking: Up to two accurate, distinct contrasts, avoiding claims about universal language implementations.

EXAM QUESTION 2 OF 4 · 1 MARK · 1 MINUTE

State one difference between an immutable tuple and a mutable list. [1]

OCR H446/01 · June 2023 · Q2(c)(iii) · RHS exam-style scenario

MODEL ANSWER · 1 MARKS

A tuple's contents/structure cannot be modified after creation; a mutable list can be changed.

Marking: One mark for the immutability difference.

EXAM QUESTION 3 OF 4 · 2 MARKS · 2 MINUTES

A game stores each pending editing job with three attributes: an ID string, a real-valued processing cost and an integer priority code. Explain why a record is a suitable data structure for one such job. [2]

OCR H446/02 · June 2024 · Q7(a) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

A record groups different related fields under one identifier, and can contain mixed data types such as a string, real and integer in the same structure.

Marking: One mark for several attributes stored under one named record, one for mixed types or linked fields. Not simply 'records can store data'.

EXAM QUESTION 4 OF 4 · 1 MARK · 1 MINUTE

A music studio stores fifty audio-level readings in one integer array. Give one benefit of using a single array rather than fifty separately named variables. [1]

OCR H446/02 · June 2022 · Q3(a) · RHS exam-style scenario

MODEL ANSWER · 1 MARKS

All values can be indexed/processed using one identifier and passed to a routine as one collection.

Marking: One mark for shared identifier/index/parameter efficiency.
