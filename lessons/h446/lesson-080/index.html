Lesson 080 · Insertion Sort: Grow the Sorted Prefix

By the end you can…
  • The left portion is kept sorted. Read the next item as key and compare backwards with earlier elements.
  • Shift larger elements one position to the right, then insert key in the vacant position.
  • Worst O(n²), already-sorted best O(n), auxiliary O(1); especially useful on small/nearly sorted arrays.

NEW LEARNING · C# AND ARRAY TRACES

Track the algorithm

static void Insertion(int[] a){
 for(int i=1;i<a.Length;i++){
  int key=a[i],j=i-1;
  while(j>=0 && a[j]>key){
   a[j+1]=a[j];j--;
  }
  a[j+1]=key;
 }
}
