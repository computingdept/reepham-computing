Tracing unfamiliar algorithms

By the end, you can…
  • Trace an array-based algorithm without guessing
  • Track changing variables with a trace table
  • Explain how to identify and correct an error

Today's vocabulary

trace tableaccumulatorcounterconditionaliteration
EXAMPLE FIRST

Read, predict and explain

int[] a = {3, 1, 4, 2};
int total = 0;
for (int i = 0; i < a.Length; i++)
    if (a[i] % 2 == 0) total += a[i];
Console.WriteLine(total);
STEP 1 OF 3

Choose trace columns

Track i, a[i] and total. Start with total=0.

STEP 2 OF 3

Check the condition

Odd values 3 and 1 do not satisfy a[i] MOD 2 = 0; total stays 0.

STEP 3 OF 3

Update then finish

4 and 2 are even, so total becomes 4 then 6; the printed output is 6.

I DO · MODEL

Trace the sum of numbers greater than 3 in [2,5,4].

total=0;
for each value in [2,5,4]:
  if value > 3: total += value
STEP 1 OF 3

Predict and explain

Create columns index, value and total; begin at 0.

STEP 2 OF 3

Check and extend

2 is skipped, then 5 is added.

STEP 3 OF 3

Check and extend

4 is also added. Final total is 9.

WE DO · DIFFERENT GUIDED PROBLEM

Trace how many values are less than 5 in [6,2,4,7].

count=0;
for each value in [6,2,4,7]:
  if value < 5: count++
STEP 1 OF 3

Predict and explain

Start count at zero. Value 6 is not below 5.

STEP 2 OF 3

Check and extend

Values 2 and 4 are below 5, so count becomes 1 then 2.

STEP 3 OF 3

Check and extend

7 is not below 5. Final result: 2.

Foundation · QUESTION 1 OF 3

Trace total=0; for values [2,3,4], add each value. Give total after each.

MODEL ANSWER

2, 5, 9.

Core · QUESTION 2 OF 3

For [4,7,2,6], count values greater than 5. What is returned?

MODEL ANSWER

2: the values 7 and 6 satisfy >5.

Stretch · QUESTION 3 OF 3

An algorithm intends to count even numbers but uses if n%2==1. Identify the error and correct it.

MODEL ANSWER

The test counts odd numbers. Use n%2==0 to count even numbers.

True or false?

When tracing a loop, you can ignore the condition and update the accumulator every iteration.

Answer

False. Update only when the condition is true.
