I DO · TEACHER MODEL

A team distributes an executable without its original C source. Explain the compiler's role.

WORKED REASONING

Model answer

A compiler translates source to target machine/object code; linked executable can run without the source being present. Compilation can report syntax errors and apply optimisation before execution.

Check: link each claim to the scenario and use precise OCR terminology.

WE DO · DIFFERENT PROBLEM

A technician reads LMC 'LDA 20' and wants the CPU's numeric instruction. What translation tool is used?

STEP 1 · IDENTIFY

What must we decide?

Identify the inputs, relevant facts and exact output or judgement required.

STEP 2 · APPLY

Work through the method

Use the middle stage of the visual to follow the process and state each intermediate result.

STEP 3 · EXPLAIN

Shared worked answer

An assembler converts the mnemonic plus operand into its encoded machine instruction. In standard LMC, LDA 20 encodes as 520. This is not an interpreter translating a high-level language.
