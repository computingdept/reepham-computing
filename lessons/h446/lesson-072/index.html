Lesson 072 · Algorithm Design: From Specification to Steps

By the end you can…
  • Read the problem to identify exact input type, required output, boundaries and invalid cases.
  • Write an algorithm with an invariant: after each iteration, count is the number of qualifying values examined so far.
  • Choose meaningful tests around the 40 boundary and compare output against an independently calculated result.

NEW LEARNING · METHOD FIRST

Work through the model

// Requirement: count passing marks (>= 40).
static int CountPasses(int[] marks){
 int count=0;
 foreach(int mark in marks)
  if(mark>=40)count++;
 return count;
}
// [39,40,55,20] → 2.

I DO · MODEL

Design a function counting even numbers in [1,2,6,7].

Count=0; examine each x; if x%2==0 increment; result2.
WORKED METHOD

Explain

Using modulo2==0 identifies even values; the list has 2 and 6.

WE DO · DIFFERENT PROBLEM

Design a function counting temperatures below zero in [−2,5,−1,0].

If x<0 increment count; −2 and −1 qualify → result2.
WORKED METHOD

Explain

Zero does not count as negative, so use <0, not <=0.

WORKED ANSWER
