Symmetric and asymmetric encryption

By the end you can…
  • Symmetric encryption uses the same secret key for encryption and decryption. The difficulty is sharing that key securely.
  • Asymmetric encryption uses a public/private key pair. Public-key encryption for confidentiality uses a recipient's public key to encrypt and their private key to decrypt.
  • Real secure connections typically use a hybrid protocol: authenticated asymmetric cryptography to establish secrets, then efficient symmetric encryption of application data.

NEW LEARNING · WORKED EXAMPLE FIRST

Trace the mechanism

SYMMETRIC: Alice and Bob share K.
Ciphertext = Encrypt(K, plaintext)
Plaintext  = Decrypt(K, ciphertext)
ASYMMETRIC: Bob publishes public key.
Alice encrypts with Bob's public key.
Only Bob's private key decrypts (scheme-dependent).
HTTPS commonly uses asymmetric authentication/key exchange and symmetric session encryption.

I DO · MODEL

Alice and Bob already share the secret key K. Which key does each use to protect and recover a file?

Alice: Encrypt(K, "report")
Bob: Decrypt(K, ciphertext)
STEP 1 OF 2

Predict first

Alice encrypts with the agreed secret K; an observer without K should not recover the plaintext.

STEP 2 OF 2

Show method

Bob uses the same secret K to decrypt, so key secrecy and its secure distribution matter.

WE DO · DIFFERENT QUESTION

Bob posts his public encryption key. Alice wants only Bob to read a message. Which key is used?

Encrypt(BobPublic, message)
Decrypt(BobPrivate, ciphertext)
STEP 1 OF 2

Predict first

Alice encrypts to Bob's public key without needing to learn Bob's private key.

STEP 2 OF 2

Show method

Bob retains the private key and decrypts. The public key must be authenticated to prevent substitution.

FOUNDATION · Q1 OF 3

Describe symmetric and asymmetric key arrangements. [6]

MODEL ANSWER

Symmetric encrypt/decrypt use shared secret [2]; asymmetric uses public/private pair [2], encrypt to recipient's public key [1], private key decrypts [1].

CORE · Q2 OF 3

Explain how a secure website can combine asymmetric and symmetric methods. [6]

MODEL ANSWER

Server identity authenticated via certificate [2]; authenticated key agreement establishes session secret [2]; symmetric session encryption protects bulk traffic efficiently [2].

CHALLENGE · Q3 OF 3

Evaluate symmetric-only encryption for a school communicating with 200 external partners. [6]

MODEL ANSWER

Fast for bulk data [1]; each shared secret needs secure exchange [2]; managing many unique shared keys is difficult [1]; asymmetric authenticated exchange/hybrid design improves distribution [2].
