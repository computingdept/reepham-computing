I DO · TEACHER MODEL

A school wants to limit outgoing web browsing while protecting pupils' login details over public Wi-Fi. Select appropriate controls.

STEP 1 OF 3

Client web request

Identify the facts and make an initial prediction.

STEP 2 OF 3

Proxy and firewall controls

Explain the mechanism or trace the intermediate stage.

STEP 3 OF 3

HTTPS encrypted transfer

A managed web proxy can filter/log permitted requests; a firewall can restrict traffic flows; HTTPS/TLS encrypts the connection so local eavesdroppers cannot read credentials. Policy, MFA and endpoint protection address further threats.

STEP 1 OF 3

STEP 2 OF 3

STEP 3 OF 3

Endpoint controls matter

An allowed connection or email can carry malicious content. Endpoint malware detection, attachment scanning, patching, permissions and user training complement network filtering. A proxy may help inspect or block risky destinations.

FOUNDATION · QUESTION 1 OF 3

State functions of firewall, forward proxy and TLS, one network example each. [6]

MARK SCHEME / WORKED ANSWER

Firewall controls traffic according to rule/state [2]; proxy intermediates requests/cache/filter [2]; TLS protects communication in transit [2].

APPLICATION · QUESTION 2 OF 3

Explain why encrypted traffic is not the same as authenticated trustworthy content. [6]

MARK SCHEME / WORKED ANSWER

Encryption protects data in transit [2]; a malicious website may still use encryption [2]; verify destination, credentials or content separately [2].

CHALLENGE · QUESTION 3 OF 3

Recommend a layered defence for a sixth-form network with remote learners, justifying four different controls. [8]

MARK SCHEME / WORKED ANSWER

Credit four linked controls: firewall, proxy/web filtering, VPN or TLS, MFA, patching/endpoint protection, least privilege or monitoring [2 each].
