NEW LEARNING · EXAMPLE FIRST

Predict the effect

int[] a={3,6,9};
for(int i=0; i<=a.Length; i++)
    Console.WriteLine(a[i]); // BUG
// FIX: i<a.Length
STEP 1 OF 3

Check valid indexes

A three-element array has valid indexes 0, 1 and 2.

STEP 2 OF 3

Follow the condition

When i is 3, i<=a.Length remains true and attempts to read a[3], causing an exception.

STEP 3 OF 3

Fix and retest

Use i<a.Length, which stops before i becomes an invalid index.

I DO · MODEL

Correct a loop summing [2,4] that uses <= length.

for(int i=0;i<=values.Length;i++)
  total+=values[i];
STEP 1 OF 2

Predict

The array's valid indexes are 0 and 1, not 2.

STEP 2 OF 2

Explain

Use i < values.Length and the total is 6.

WE DO · DIFFERENT GUIDED PROBLEM

Binary search uses low=mid when a[mid]<target. Why may it loop forever?

int mid=(low+high)/2;
if(a[mid]<target) low=mid;
STEP 1 OF 2

Predict

With low=3 and high=4, midpoint remains 3 and low=mid fails to shrink the interval.

STEP 2 OF 2

Explain

Use low=mid+1 to exclude the checked midpoint and guarantee progress.

EXAM QUESTION 1 OF 2 · 4 MARKS · 4 MINUTES

For a test, numbers = [4, 2, 4, 4, 2, 7] should produce distinct = [4, 2, 7], counts = [3, 2, 1].

GIVEN INFORMATION
A wildlife centre has written an original algorithm to count occurrences of integers in a list. It uses two parallel output arrays: distinct contains each unique integer and counts stores its frequency. Four numbered lines contain a logical error. Identify each wrong line and give a corrected complete line. [4]

01 function countOccurrences(numbers)
02   distinct = []
03   counts = []
04   size = numbers.length
05   for i = 0 to size
06     target = numbers[i]
07     match = -1
08     for j = 0 to distinct.length - 1
09       if distinct[j] != target then
10         match = j
11       endif
12     next j
13     if match == -1 then
14       distinct.append(target)
15       counts.append(0)
16     else
17       counts[match] = counts[match] - 1
18     endif
19   next i
20   return distinct, counts
21 endfunction

MODEL ANSWER · 4 MARKS

Line 05: for i = 0 to size - 1 Line 09: if distinct[j] == target then Line 15: counts.append(1) Line 17: counts[match] = counts[match] + 1
