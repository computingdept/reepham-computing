Addressing Modes: Immediate, Direct, Indirect and Indexed

STEP 1 OF 3

Immediate versus direct

LOAD #12 uses literal 12; LOAD 12 uses contents of memory[12].

Indirect addressing

STEP 3 OF 3

Indexed addressing

LOAD 20,X uses effective address 20+X; useful for array elements.

I DO · MODEL

With memory[12]=40 and memory[40]=7, compare LOAD #12, LOAD 12 and LOAD @12.

STEP 1 OF 3

#12 gives literal 12

Predict the first step from the prompt.

STEP 2 OF 3

12 reads memory[12]=40

Explain the intermediate result or decision.

STEP 3 OF 3

@12 follows pointer to 7

Using illustrative assembler conventions: immediate gives 12; direct reads 40; indirect follows memory[12]=40 then loads memory[40]=7.

WE DO · DIFFERENT PROBLEM

Array starts at memory address 80. X=3 and memory[83]=19. What does LOAD 80,X load?

STEP 1 OF 3

Base 80, index 3

Predict the first step from the prompt.

STEP 2 OF 3

Effective address 83

Explain the intermediate result or decision.

STEP 3 OF 3

Read memory[83]=19

Effective address = 80+3=83. It loads 19. Indexed addressing avoids writing a new absolute address for each element.

FOUNDATION · QUESTION 1 OF 3

Define immediate and direct addressing with one example each. [6]

MARK SCHEME / WORKED ANSWER

Immediate uses supplied literal [2]; direct accesses memory at given address [2]; valid contrasting examples [2].

APPLICATION · QUESTION 2 OF 3

Memory[15]=29 and memory[29]=6. Give values loaded by direct LOAD 15 and indirect LOAD @15. [6]

MARK SCHEME / WORKED ANSWER

Direct =29 [3]. Indirect follows pointer 29, then loads 6 [3].

CHALLENGE · QUESTION 3 OF 3

Explain indexed addressing for an array at base 50 with index 4 and discuss why this is not simply LMC LDA notation. [8]

MARK SCHEME / WORKED ANSWER

Effective address base + offset =54 [3], retrieves element stored there [2], supports array traversal [1], standard LMC has a restricted instruction set and does not natively specify general indexed addressing [2].

TERM 1/4

immediate

Operand is a literal value.

TERM 2/4

direct

Operand gives the memory location holding a value.

TERM 3/4

indirect

Operand points to a location holding the effective address.

TERM 4/4

indexed

Base address plus index gives effective address.

True or false?

In direct addressing, the operand always means the literal value to be used.

Model answer

False. Direct uses the operand as a memory address; immediate uses a literal.
