Lesson 054 · Hash Tables and Dictionary<TKey,TValue>

By the end you can…
  • A hash function maps keys to hash values that guide placement/lookups. A collision occurs if distinct keys map to the same location/bucket.
  • A .NET Dictionary<TKey,TValue> handles collision management internally; do not equate its actual buckets with simplistic modulo examples.
  • To read a missing key safely, use TryGetValue. Hash-table operations are often expected O(1) but poor collisions can degrade performance.

I DO · MODEL

Apply a toy hash h(k)=k mod 5 to keys 7 and 12. What happens?

h(7)=2
h(12)=2
Both keys map to bucket 2.
WORKING

Explain the trace

Both keys collide in bucket 2; a table must resolve collision by chaining or probing.

WE DO · DIFFERENT PROBLEM

Apply the same toy hash h(k)=k mod 5 to keys 8 and 11. Give buckets.

h(8)=3
h(11)=1
WORKING

Explain the trace

No collision: key 8 maps bucket 3, key11 maps bucket1.
