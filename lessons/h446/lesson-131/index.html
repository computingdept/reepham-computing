I DO · MODEL

Alice wants to send Bob a private message using public-key encryption. Identify both keys used.

STEP 1 OF 3

Bob shares public key

Predict the first step from the prompt.

STEP 2 OF 3

Alice encrypts for Bob

Explain the intermediate result or decision.

STEP 3 OF 3

Bob uses private key

Alice encrypts a suitably sized message or session key using Bob's public key. Bob decrypts using his matching private key. Alice never requires Bob's private key.

WE DO · DIFFERENT PROBLEM

A website publishes a signed update. Which key verifies its authentic signature?

STEP 1 OF 3

Publisher signs privately

Predict the first step from the prompt.

STEP 2 OF 3

Distribute signed file

Explain the intermediate result or decision.

STEP 3 OF 3

Verify with public key

The publisher creates the digital signature with its private key. Users verify it with the public key obtained through a trusted route; this supports authenticity and integrity, not secrecy of the update.
