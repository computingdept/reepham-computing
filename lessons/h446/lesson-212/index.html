ALGORITHM TASK (ORIGINAL PRACTICE)
Trace bubble sort on [6,2,5,1].
Show every complete pass; stop once sorted.
STEP 1 OF 3

Read the task command

A complete pass means all permitted adjacent comparisons for that pass, not just one swap.

STEP 2 OF 3

Trace one pass

[6,2,5,1] becomes [2,5,1,6] after comparing each pair.

STEP 3 OF 3

Finish every pass

Continue to [2,1,5,6], then [1,2,5,6]. A clear trace shows each pass.

I DO · MODEL

Model the first complete ascending bubble-sort pass on [4,1,3].

Compare left to right; swap if the left value is larger.
STEP 1 OF 3

Predict first

Start [4,1,3] and compare 4 with 1: swap.

STEP 2 OF 3

Check the method

Now compare 4 with 3: swap, producing [1,3,4].

STEP 3 OF 3

Check the method

The pass is complete and the array is sorted.

Timed Q1 · 8 marks · QUESTION 1 OF 3

An array contains [8,3,6,1]. Trace ascending insertion sort, giving the array after each outer-loop iteration and explaining how the key is positioned.

MODEL ANSWER

[8] After inserting key 3: [3,8,6,1] [2]; key 6: [3,6,8,1] [2]; key 1: [1,3,6,8] [2]; each key is inserted into the sorted prefix by shifting larger values right [2].

Timed Q2 · 8 marks · QUESTION 2 OF 3

Write a C# function BinarySearch(int[] a,int target) returning the first matching index it encounters, or −1. Include correct bounds and a sorted-input precondition.

MODEL ANSWER

[8] int low=0,high=a.Length-1 [2]; while(low<=high) [1]; mid=low+(high-low)/2 [1]; if(a[mid]==target)return mid [1]; if(a[mid]<target)low=mid+1; else high=mid-1 [2]; return -1 [1]. Input must be sorted.

Timed Q3 · 8 marks · QUESTION 3 OF 3

Explain one advantage and one disadvantage of merge sort over bubble sort, including time complexity, and identify an input scenario for which linear search is more practical than binary search.

MODEL ANSWER

[8] Merge sort O(n log n) worst case [2] versus bubble O(n²) [2]; merge sort typically needs O(n) extra array space [2]; linear search is suitable for a small unsorted collection where sorting before a single search would cost time [2].
