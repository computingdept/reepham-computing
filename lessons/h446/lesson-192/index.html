Key vocabulary for today

CODE / EXAMPLE FIRST

Predict what happens

static void Increase(ref int score)
{
    score = score + 5;
}
int marks = 10;
Increase(ref marks);
// marks becomes 15
STEP 1 OF 3

CALLER

The caller declares marks = 10.

STEP 2 OF 3

ALIAS

ref makes score refer to the caller's marks rather than an independent copy.

STEP 3 OF 3

AFTER

Changing score therefore changes marks, which becomes 15.

I DO · TEACHER MODEL

A function receives a copy of x=7 and adds 4. What is x afterwards?

static void AddFour(int value)
{
    value += 4;
}
int x = 7;
AddFour(x);
STEP 1 OF 2

Predict first

A new parameter value receives a copy of the integer 7.

STEP 2 OF 2

Model the result

value becomes 11 inside AddFour, but x remains 7 after the call.

WE DO · DIFFERENT GUIDED EXAMPLE

A procedure adds 3 to a ref parameter. Trace y=8 through the call.

static void AddThree(ref int n)
{
    n += 3;
}
int y = 8;
AddThree(ref y);
STEP 1 OF 2

Predict first

y starts at 8 and is passed using ref.

STEP 2 OF 2

Model the result

n refers to y, so adding 3 makes y = 11.

Foundation · 1 OF 3

A method takes int number by value and adds 2. Caller x=5. What is x after the call?

MODEL ANSWER

5; only the parameter copy is updated.

Core · 2 OF 3

Write a C# procedure that doubles an integer passed by reference.

MODEL ANSWER

Stretch · 3 OF 3

Explain when returning a result is preferable to changing a ref parameter.

MODEL ANSWER

When only one result is needed, a return makes the data flow explicit and avoids an unexpected side effect on a caller variable.
