QUESTION 4 OF 4 · YEAR 12 CHALLENGE · LESSON 008 · ASCII & UNICODE

Year 12 challenge

ASCII encodes A as decimal 65 and B as 66. A string 'ABBA' uses four 8-bit stored code units in this simplified example. How many bits and bytes, and why is this not proof all Unicode characters fit in one byte?

MODEL ANSWER

4×8=32 bits=4 bytes. Unicode contains many more characters, and UTF encodings may use more than one byte for a character; 8-bit storage here is an assumption.

NEW LEARNING · CODE OR MODEL FIRST

Trace the mechanism

// Automated greenhouse control:
// Temperature sensor → analogue reading
// ADC → digital input for microcontroller
// Compare with threshold
// Motor controller → open vent (output)
// Display → show current temperature
STEP 1 OF 3

Select suitable input

A temperature sensor measures a physical quantity; an analogue-to-digital converter is needed if the controller uses digital samples.

STEP 2 OF 3

Process and control

Software compares the sampled temperature with a target to decide whether to open the vent.

STEP 3 OF 3

Choose appropriate outputs

An actuator makes the physical change; a display can show readings. Design must address accessibility and suitable latency.

I DO · FULL MODEL

Choose input and output for an automatic door that opens when someone approaches.

Proximity sensor → controller decision
→ motor opens door
STEP 1 OF 2

Predict first

A proximity or motion sensor detects someone approaching and passes a signal to the controller.

STEP 2 OF 2

Explain and check

A motor and driver create movement; safety sensing reduces the risk of closing onto a person.

WE DO · DIFFERENT QUESTION

Choose devices for an accessible pedestrian crossing with a push button, lights and audible alert.

Button → controller → lights + audio/tactile signals
STEP 1 OF 2

Predict first

A push button is a clear intentional input and the controller processes it under safe traffic timing rules.

STEP 2 OF 2

Explain and check

Outputs include signal lights plus appropriate audible or tactile cues to improve accessibility.
