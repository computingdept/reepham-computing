QUESTION 4 OF 4 · YEAR 12 CHALLENGE · LESSON 008 · ASCII & UNICODE

Year 12 challenge

ASCII encodes A as decimal 65 and B as 66. A string 'ABBA' uses four 8-bit stored code units in this simplified example. How many bits and bytes, and why is this not proof all Unicode characters fit in one byte?

MODEL ANSWER

4×8=32 bits=4 bytes. Unicode contains many more characters, and UTF encodings may use more than one byte for a character; 8-bit storage here is an assumption.

NEW LEARNING · CODE OR MODEL FIRST

Trace the mechanism

// Automated greenhouse control:
// Temperature sensor → analogue reading
// ADC → digital input for microcontroller
// Compare with threshold
// Motor controller → open vent (output)
// Display → show current temperature
STEP 1 OF 3

Select suitable input

A temperature sensor measures a physical quantity; an analogue-to-digital converter is needed if the controller uses digital samples.

STEP 2 OF 3

Process and control

Software compares the sampled temperature with a target to decide whether to open the vent.

STEP 3 OF 3

Choose appropriate outputs

An actuator makes the physical change; a display can show readings. Design must address accessibility and suitable latency.

I DO · FULL MODEL

Choose input and output for an automatic door that opens when someone approaches.

Proximity sensor → controller decision
→ motor opens door
STEP 1 OF 2

Predict first

A proximity or motion sensor detects someone approaching and passes a signal to the controller.

STEP 2 OF 2

Explain and check

A motor and driver create movement; safety sensing reduces the risk of closing onto a person.

WE DO · DIFFERENT QUESTION

Choose devices for an accessible pedestrian crossing with a push button, lights and audible alert.

Button → controller → lights + audio/tactile signals
STEP 1 OF 2

Predict first

A push button is a clear intentional input and the controller processes it under safe traffic timing rules.

STEP 2 OF 2

Explain and check

Outputs include signal lights plus appropriate audible or tactile cues to improve accessibility.

EXAM QUESTION 1 OF 4 · 4 MARKS · 4 MINUTES

Name one suitable input device and one suitable output device. For each device, explain a specific way the team could use it during development. [4]

GIVEN INFORMATION

A team is building a history-themed computer game for a museum. It must draw graphics, create sounds and test the game on a computer.

OCR H446/01 · June 2025 · Q1(b)(i) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

Possible input: graphics tablet for drawing game characters; keyboard for entering test commands; microphone for recording narration; mouse for editing artwork. Possible output: monitor for inspecting visuals; speakers for listening to audio. Other sensible game-development examples are acceptable.

Marking: Input device 1; contextual input use 1; output device 1; contextual output use 1. The claimed use must fit the named device and game-development setting.

EXAM QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A conservation team clips tiny monitoring devices to migrating birds to track movement and conditions. Name one suitable input sensor and explain one specific measurement it would provide. [2]

OCR H446/01 · June 2024 · Q2(a) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

GPS receiver for position/route; accelerometer for motion or acceleration; temperature sensor for environmental temperature; other appropriate input sensors with context-linked uses.

Marking: One mark for a suitable sensor, one for a valid linked measurement. An unsuitable output device earns no follow-through use mark.

RHS ADDITIONAL PRACTICE · QUESTION 3 OF 4 · 2 MARKS · 2 MINUTES

A museum uses a touch screen to let visitors select an exhibit and read information. Explain why the screen is both an input device and an output device. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

Touch detection sends the visitor's selection into the computer, while the display presents text and images back to the visitor.

Marking: One mark for touch as input; one for displayed information as output.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

A bird-monitoring sensor measures temperature every ten minutes. Identify what type of data it collects and explain why the computer may need an analogue-to-digital converter. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

Temperature is a continuously varying physical measurement. If the sensor produces an analogue signal, an ADC converts it to digital values for processing or storage.

Marking: One mark for continuous analogue measurement; one for converting an analogue signal into digital values when required.
