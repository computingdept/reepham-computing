// Reconstruct only if the goal is reachable.
// This example stores distances as double values.
if (double.IsPositiveInfinity(distance[goal])) {
  Console.WriteLine("No route");
} else {
  var path = new List<string>();
  string? node = goal;
  while (node != null) {
    path.Add(node);
    node = predecessor.GetValueOrDefault(node);
  }
  path.Reverse(); // start → ... → goal
  Console.WriteLine(string.Join(" → ", path));
}

TERM 1 OF 5

predecessor table

For each vertex, stores the prior vertex on its best-known path.

TERM 2 OF 5

relaxation

Replace a distance when a cheaper route is discovered.

TERM 3 OF 5

settled

Shortest distance is final for a vertex under non-negative edge weights.

TERM 4 OF 5

infinity

Marker for an as-yet unreachable vertex.

TERM 5 OF 5

route reconstruction

Follow predecessor links backwards then reverse.

True or false?

A predecessor table should be followed from the destination backwards before reversing.

Model answer

True. The predecessor of each node gives the step immediately before it on the path.
