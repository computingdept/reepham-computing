I DO · WORKED MODEL

A browser sends an HTTP request using TCP/IP over Ethernet. Describe encapsulation from top to bottom.

STEP 1 OF 3

HTTP application data

Identify the relevant information and make a prediction.

STEP 2 OF 3

TCP segment in IP packet

Explain the change using correct technical terms.

STEP 3 OF 3

Ethernet frame

HTTP application bytes become TCP segment payload; the TCP segment goes into an IP packet; the packet is carried in an Ethernet frame. Receivers process headers in reverse to deliver data to the browser/server.

WE DO · DIFFERENT PROBLEM

A packet passes through a router from Ethernet into a Wi-Fi network. Which information changes?

STEP 1 OF 3

Incoming Ethernet frame

Identify the relevant information and make a prediction.

STEP 2 OF 3

Route IP packet

Explain the change using correct technical terms.

STEP 3 OF 3

Outgoing Wi-Fi frame

Router removes the incoming link-layer framing, processes/forwards the IP packet and builds new outgoing link-layer framing. IP hop limit/TTL normally decreases; end-to-end transport data need not change.

CHALLENGE · QUESTION 3 OF 3

Explain what a router changes when forwarding a packet to a different link technology. [8]

MARK SCHEME / WORKED ANSWER

Remove old link frame [2], inspect IP destination/routing [2], reduce TTL/hop limit and update necessary header fields [2], encapsulate with new link frame [2].

TERM 1/4

application layer

Protocols providing services to programs, such as HTTP or DNS.

TERM 2/4

transport layer

End-to-end service such as TCP or UDP.

TERM 3/4

internet layer

IP packet addressing and routing between networks.

TERM 4/4

link layer

Local frame delivery on physical or wireless link.

True or false?

Every router preserves the same link-layer frame all the way to the destination.

Model answer

False. Frames are recreated for each local link/hop.
