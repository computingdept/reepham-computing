SYNOPTIC REFERENCE

Recognise the signature

Bubble → adjacent compare/swap
Insertion → insert next item into sorted section
Merge → split then merge
Quick → pivot then partition

Linear → check each item
Binary → sorted data, halve search area

Dijkstra → lowest known path cost
A* → path cost + heuristic
Key idea: In exam questions, look for the defining operation before you start writing a generic description.

EXAM DIAGNOSIS

Which algorithm is being described?

"Compare neighbouring items and swap them if they are in the wrong order. Repeat passes."
Model the method clearly
STEP 1

Spot the signature

neighbouring / adjacent + swap + passes

Those words point to bubble sort.

STEP 2

Rule out insertion

insertion would grow a sorted section

It does not work as full adjacent passes.

STEP 3

Rule out quick

quick would mention a pivot

No pivot appears.

STEP 4

Answer precisely

Bubble sort

Then demonstrate it if the question asks for working.
