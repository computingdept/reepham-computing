Procedures, functions and parameters

Key vocabulary for today

procedurefunctionparameterargumentreturn
CODE / EXAMPLE FIRST

Predict what happens

static int Double(int value)
{
    return value * 2;
}
Console.WriteLine(Double(6));
STEP 1 OF 3

CALL

The caller supplies argument 6 to Double.

STEP 2 OF 3

PARAMETER

Parameter value receives 6, then value * 2 evaluates to 12.

STEP 3 OF 3

RETURN

The function returns 12. Console.WriteLine displays the result.

I DO · TEACHER MODEL

Trace AddVAT(50), which returns price + price / 5.

static int AddVAT(int price)
{
    return price + price / 5;
}
STEP 1 OF 2

Predict first

The argument 50 becomes local parameter price = 50.

STEP 2 OF 2

Model the result

Integer division 50 / 5 = 10; the returned value is 60.

WE DO · DIFFERENT GUIDED EXAMPLE

What is printed by TriplePlusOne(4)?

static int TriplePlusOne(int n)
{
    return 3 * n + 1;
}
Console.WriteLine(TriplePlusOne(4));
STEP 1 OF 2

Predict first

The argument 4 is assigned to n.

STEP 2 OF 2

Model the result

3 × 4 + 1 = 13, so the method returns 13 and prints 13.

Core · 2 OF 3

Write a C# function IsEven(int n) that returns true when n is even.

MODEL ANSWER

static bool IsEven(int n) { return n % 2 == 0; }

Stretch · 3 OF 3

Explain why static int Show(int x) { Console.WriteLine(x); } is invalid. Correct it.

MODEL ANSWER

The int return type requires an int result. Use static void Show(int x) { Console.WriteLine(x); } or return x and print at the call site.

TERM 1 OF 5

procedure

A subroutine that performs actions and does not return a result.

TERM 2 OF 5

function

A subroutine that returns a value.

TERM 3 OF 5

parameter

A named input in the subroutine declaration.

TERM 4 OF 5

argument

The actual value provided by the caller.

TERM 5 OF 5

return

Finish a function and pass its result to the caller.

True or false?

A C# method with return type void must return an integer.

Model answer

False. A void method does not return a result.
