Database and SQL retrieval challenge

By the end you can…
  • Use a primary key for each Student row and a matching foreign key in Score.
  • INNER JOIN produces one result for each matching StudentID; Cleo has no matching Score and is absent.
  • A WHERE clause can filter matched records; forgetting the join condition can produce unwanted combinations.

NEW LEARNING · EXAMPLE FIRST

Trace the decision

-- Sample Student rows (StudentID,Name): (1,Ada),(2,Ben),(3,Cleo)
-- Sample Score rows (StudentID,Mark): (1,75),(2,82)
SELECT Student.Name, Score.Mark FROM Student
INNER JOIN Score
ON Student.StudentID=Score.StudentID;
-- Expected rows: Ada 75, Ben 82
