What is the difference between WHERE and ORDER BY in a query?

MODEL ANSWER

WHERE filters rows; ORDER BY arranges returned rows.

QUESTION 2 OF 4

MODEL ANSWER

Sum 0, carry 1.

QUESTION 3 OF 4

In Big O notation, what is binary search worst-case complexity?

MODEL ANSWER

O(log n) for sorted random-access data.

When does a linear search stop?

On a match or after examining all items.

I DO · MODELLED

A Book table has BookID=8,Stock=4. Write an UPDATE to set Stock=3 for that row.

STEP 1 OF 3

Identify BookID 8

Find the given data and name the required result.

STEP 2 OF 3

UPDATE Stock = 3

Explain why this intermediate stage is necessary.

STEP 3 OF 3

WHERE BookID = 8

UPDATE Book SET Stock = 3 WHERE BookID = 8; Before running, SELECT the matching row. Without WHERE, the stock column of all books would be changed.

WE DO · DIFFERENT CASE

Add a new Club record and delete only the club with ClubID=12.

STEP 1 OF 3

Insert club 24

Find the given data and name the required result.

STEP 2 OF 3

Confirm club 12 exists

Explain why this intermediate stage is necessary.

STEP 3 OF 3

DELETE WHERE ClubID=12

INSERT INTO Club (ClubID, Name) VALUES (24, 'Robotics'); DELETE FROM Club WHERE ClubID = 12; Foreign-key dependencies may prevent delete until related records are handled by defined policy.

FOUNDATION · QUESTION 1 OF 3

Write SQL inserting StudentID 22 and Name 'Kai' into Student. [4]

MARK SCHEME / WORKED ANSWER

APPLICATION · QUESTION 2 OF 3

A teacher must change a single pupil's YearGroup to 13. Explain a safe SQL statement. [6]

MARK SCHEME / WORKED ANSWER

UPDATE Student SET YearGroup=13 [3] WHERE StudentID=<specific existing ID> [2]; confirm selected row before applying [1].

CHALLENGE · QUESTION 3 OF 3

Explain risks in DELETE FROM Booking; and suggest protections in a relational production database. [8]

MARK SCHEME / WORKED ANSWER

Missing WHERE deletes all rows [2], FK/referential impacts [2], transactions/rollback and backups [2], permission controls and dry-run SELECT [2].

TERM 1/4

INSERT

Adds new rows.

TERM 2/4

UPDATE

Changes values in existing rows.

TERM 3/4

DELETE

Removes matching rows.

TERM 4/4

WHERE

Restricts affected rows; omission can affect every row.

True or false?

UPDATE Book SET Stock=0; changes exactly one Book record.

Model answer

False. With no WHERE it updates every row.
