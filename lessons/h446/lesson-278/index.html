SQL SELECT, JOIN and nested SELECT

By the end you can…
  • SELECT names output columns, FROM identifies input tables and WHERE restricts rows using a Boolean predicate.
  • INNER JOIN combines rows matching a join condition. A nested SELECT can return a set of keys used by an outer IN condition.
  • Both example queries return Ada and Ben, but joining is more flexible when fields from both tables are required.

Vocabulary

NEW LEARNING · CODE FIRST

Work through the process

-- Student(ID,Name): (1,Ada),(2,Ben),(3,Cleo)
-- Score(ID,Mark): (1,75),(2,82),(3,59)
SELECT Student.Name FROM Student
INNER JOIN Score ON Student.ID=Score.ID
WHERE Score.Mark>=70;
-- Ada, Ben.
SELECT Name FROM Student WHERE ID IN
 (SELECT ID FROM Score WHERE Mark>=70);

EXAM QUESTION 1 OF 4 · 4 MARKS · 4 MINUTES

Write SQL that returns ONLY CustomerID and Surname for customers whose Title is exactly "Miss" OR "Mrs". [4]

GIVEN INFORMATION
A vehicle-repair cooperative stores customer and car-cover records in this original flat-file table named Customer:
CustomerID (unique) | Title | Surname | VehicleID
101 | Miss | Ross | UV-21
102 | Mrs | Chen | PV-17
103 | Mr | Adeyemi | CV-42
104 | Dr | Khan | RV-63

The existing key is CustomerID; one row holds only one vehicle. Customers sometimes have more than one vehicle.

OCR H446/01 · November 2021 · Q1(d)(ii) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

SELECT CustomerID, Surname FROM Customer WHERE Title = "Miss" OR Title = "Mrs";

Marking: One mark each for SELECT correct two fields, FROM Customer, WHERE Title='Miss', OR Title='Mrs'. The RHS table is named Customer for this exercise and must display that exact table name.

EXAM QUESTION 2 OF 4 · 5 MARKS · 5 MINUTES

Write a complete SQL query that shows ONLY UserName and FirstName of customers who consented to adverts. Join TblMember to TblPlan by PlanID and qualify the join fields. [5]

GIVEN INFORMATION

A museum's video service stores two connected tables: TblMember(MemberID PK, UserName, FirstName, PlanID FK, Adverts BOOLEAN) TblPlan(PlanID PK, PlanName, MonthlyCost REAL) A member's PlanID references TblPlan.PlanID. Adverts=TRUE indicates marketing consent.

OCR H446/01 · June 2022 · Q2(b) · RHS exam-style scenario

MODEL ANSWER · 5 MARKS

SELECT TblMember.UserName, TblMember.FirstName FROM TblMember JOIN TblPlan ON TblMember.PlanID = TblPlan.PlanID WHERE TblMember.Adverts = TRUE;

Marking: Five points: select the two requested fields; correct FROM; valid two-table JOIN; table-qualified join fields; WHERE Adverts=TRUE. A fully working query is required for full marks.

EXAM QUESTION 3 OF 4 · 5 MARKS · 5 MINUTES

Write an SQL statement using a nested SELECT to return Name for software costing less than EDUDraw. The threshold must come from a subquery, not a fixed number. [5]

GIVEN INFORMATION
A school media club stores software products in TblSoftware(ProductID, Name, Type, Price), where Price is a number in pounds. The table currently contains:
ProductID | Name | Type | Price
EDU01 | EDUCanvas | Image | 129.99
EDU02 | EDUDraw | Image | 119.99
EDU03 | EDUAnimate | Image | 99.99
EDU04 | EDUMovie | Video | 189.99
EDU05 | EDUEffects | Video | 99.99
EDU06 | EDUAudio | Sound | 119.99

OCR H446/01 · June 2025 · Q6(c)(ii) · RHS exam-style scenario

MODEL ANSWER · 5 MARKS

SELECT Name FROM TblSoftware WHERE Price < ( SELECT Price FROM TblSoftware WHERE Name = 'EDUDraw' );

Marking: Five source-aligned criteria: SELECT Name FROM TblSoftware; WHERE Price <; inner SELECT Price; inner FROM TblSoftware; inner WHERE Name = 'EDUDraw'. Equivalent correctly nested syntax accepted.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 4 MARKS · 4 MINUTES

A college stores courses in TblCourse(CourseID, CourseName) and students in TblStudent(StudentID, StudentName, CourseID). Write SQL to display only StudentName and CourseName for students taking Computing. Use a JOIN on CourseID. [4]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 4 MARKS

SELECT TblStudent.StudentName, TblCourse.CourseName
FROM TblStudent
JOIN TblCourse ON TblStudent.CourseID = TblCourse.CourseID
WHERE TblCourse.CourseName = 'Computing';

Marking: One mark for selecting both required fields; one for correct FROM and JOIN tables; one for the correct join condition; one for the correct WHERE condition.
