NEW LEARNING · CODE FIRST

Follow the example

// Cache of square results:
var cache = new Dictionary<int,int>();
int SquareCached(int x) {
  if (cache.TryGetValue(x, out int saved)) return saved;
  int result = x*x;
  cache[x] = result;
  return result;
}
// SquareCached(5): miss then hit on second call.
STEP 1 OF 3

Define the contract

The input is an integer, and the output is its square; overflow is a possible precondition concern.

STEP 2 OF 3

Trace repeated work

First call for 5 calculates and caches 25; second returns the stored result.

STEP 3 OF 3

Evaluate caching

Saves repeated calculation but costs memory. For changing data, cached values can become out of date.

I DO · TEACHER MODEL

A cached ticket price for zone A is £3.40. The same zone is requested twice.

cache['A']=3.40m;
// lookup('A') finds a stored value.
STEP 1 OF 2

Predict first

The key A is already stored, so the lookup uses the cache.

STEP 2 OF 2

Model and check

If pricing changes, the cached price must be updated or expired.

WE DO · DIFFERENT PROBLEM

A cached attendance total is 12 but the live total changes to 15. How should the system respond?

cachedTotal=12; liveTotal=15;
STEP 1 OF 2

Predict first

Using the old cached 12 gives a stale answer instead of the new total 15.

STEP 2 OF 2

Model and check

Update or invalidate the cached value when attendance changes, or apply a suitable expiry policy.
