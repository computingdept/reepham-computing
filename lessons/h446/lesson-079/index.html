Lesson 079 · Bubble Sort: Adjacent Swaps and Passes

By the end you can…
  • Compare adjacent pairs, swapping them when out of ascending order.
  • One completed ascending pass places the largest remaining element at the right end of the unsorted prefix.
  • Straightforward bubble sort is O(n²) worst time and O(1) extra memory; an early-exit flag can give O(n) best time.

NEW LEARNING · C# AND ARRAY TRACES

Track the algorithm

static void Bubble(int[] a){
 for(int end=a.Length-1;end>0;end--)
  for(int i=0;i<end;i++)
   if(a[i]>a[i+1])
    (a[i],a[i+1])=(a[i+1],a[i]);
}
// [5,2,4,1] → [1,2,4,5].
