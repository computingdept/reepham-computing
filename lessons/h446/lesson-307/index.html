EXAM QUESTION 1 OF 4 · 2 MARKS · 2 MINUTES

A theatre uses a Von Neumann computer to store instructions and ticket sales. Explain the stored-program arrangement of instructions, data and communication buses. [2]

OCR H446/01 · June 2022 · Q1(a)(i) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

Program instructions and data are held in shared main memory, usually using the same buses/communication pathway between CPU and memory.

Marking: One mark for shared memory for code and data and one for shared bus/access or stored-program detail.

EXAM QUESTION 2 OF 4 · 4 MARKS · 4 MINUTES

A water-level device reads a signed binary floating-point pattern 1010 1110 with four-bit two's-complement fractional mantissa and four-bit two's-complement exponent. The point is immediately after the sign bit. Calculate its denary value with working. [4]

OCR H446/01 · June 2022 · Q3(b) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

Mantissa 1010 = −0.75; exponent 1110 = −2; −0.75 × 2^(−2) = −0.1875 = −3/16.

Marking: Four source-aligned working points: exponent -2; signed mantissa -0.75 / binary-point movement; signed extension or shift; correct -0.1875.

EXAM QUESTION 3 OF 4 · 4 MARKS · 4 MINUTES

The cooperative uses RAM and ROM in its office computers. Explain TWO different characteristics of RAM and TWO different characteristics of ROM, including typical uses. [4]

OCR H446/01 · November 2021 · Q1(a)(ii) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

RAM is volatile and holds currently running program code/data; ROM is non-volatile and contains boot firmware or bootstrap instructions.

Marking: One mark each for RAM volatility and current-use storage, ROM nonvolatility and firmware/boot use.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 3 MARKS · 3 MINUTES

A computer uses an eight-bit floating-point representation. Explain how allocating more bits to the mantissa and fewer bits to the exponent affects precision and range. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

More mantissa bits allow greater precision, with more distinct representable values at a given scale. Fewer exponent bits reduce the range of possible exponents and therefore the range of magnitudes that can be represented.

Marking: One mark for increased precision; one for decreased range; one for explaining the role of the mantissa or exponent in this trade-off.
