C# QUICK REFERENCE

Three loop patterns

for (int i = 0; i < 5; i++)
{
    // repeat
}

while (condition)
{
    // repeat
}

do
{
    // repeat
}
while (condition);
Choose by purpose: known number of repetitions → for. Unknown number, test first → while. Must run at least once → do...while.
STEP 1 OF 4

Iteration repeats instructions

Iteration means executing a block of instructions repeatedly. The loop needs a rule that determines whether another repetition happens.

Count-controlled: repeat a known number of times. Condition-controlled: repeat while a condition remains true.
1 of 4
STEP 2 OF 4

for = count-controlled

for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}

The header sets the counter, tests whether the loop continues, then changes the counter after each repetition.

This outputs 0, 1, 2, 3, 4 — five repetitions.
2 of 4
STEP 3 OF 4

while = test before repeating

A while loop is useful when you do not know how many attempts will be needed.

while (valid == false)
{
    // ask again
}

If the condition is false before the first test, the loop can execute zero times.

3 of 4
STEP 4 OF 4

do...while = run first, test after

do
{
    Console.Write("Password: ");
    answer = Console.ReadLine();
}
while (answer != "computer");

The body executes before the condition is checked, so it always runs at least once.

OCR do...until answer == "computer" becomes C# do...while (answer != "computer"): the condition is reversed.

ONE COMPLETE WORKED EXAMPLE

Build a times-table program

Ask for a whole number and output its first five multiples.

7 → 7, 14, 21, 28, 35

The number of repetitions is known, so use a for loop.

Worked example
STEP 1 · INPUT

Read the number

Console.Write("Number: ");
int number =
    int.Parse(Console.ReadLine());

This happens once before the repetition begins.

STEP 2 · CONTROL THE LOOP

Count from 1 to 5

for (int i = 1; i <= 5; i++)
{
    // repeated instruction
}

i = 1 starts the counter; i <= 5 keeps the loop running; i++ adds 1 after each repetition.

STEP 3 · USE THE COUNTER

Calculate each multiple

for (int i = 1; i <= 5; i++)
{
    int answer = number * i;
    Console.WriteLine(answer);
}

The same two instructions run five times, but i changes each time.

STEP 4 · TEST

Trace a known input

number = 7

i = 1 → 7
i = 2 → 14
i = 3 → 21
i = 4 → 28
i = 5 → 35
Known number of repetitions → a for loop is the natural choice.
