NEW LEARNING · EXAMPLE FIRST

Study the worked scenario

// C#: largest value in a nonempty array
static int Largest(int[] a) {
  int best = a[0];
  for (int i=1;i<a.Length;i++)
    if (a[i] > best) best = a[i];
  return best;
}
// Largest(new int[] {3,7,2,5}) returns 7.
STEP 1 OF 3

State the precondition

The array must not be empty, or a[0] cannot be read.

STEP 2 OF 3

Trace the maximum

Set best to 3; compare 7, update best to 7, then ignore 2 and 5.

STEP 3 OF 3

Document contract

Input: nonempty int array. Output: greatest element. Does not modify input.

I DO · TEACHER MODEL

Trace Largest([4,2,9]) and write the returned result.

best=4; compare 2; compare 9;
STEP 1 OF 2

Predict first

Start best at first element 4; 2 does not replace it.

STEP 2 OF 2

Model and explain

9 is larger so best becomes 9; return 9.

WE DO · DIFFERENT GUIDED PROBLEM

Trace Largest([8,11,6,10]) and state its precondition.

best=8; process 11, 6, 10;
STEP 1 OF 2

Predict first

11 replaces initial best 8; neither 6 nor 10 exceeds 11.

STEP 2 OF 2

Model and explain

The output is 11; the required precondition is a nonempty array.

WORKED ANSWER

Core · 6 marks · QUESTION 2 OF 3

Write pseudocode to return the minimum of a nonempty array values and explain its precondition.

WORKED ANSWER

[6] Set smallest=values[0] [1]; loop over remaining items [1]; if item<smallest [1] then smallest=item [1]; return smallest [1]; array must be nonempty [1].

Stretch · 6 marks · QUESTION 3 OF 3

Evaluate what happens for Largest([-4,-2,-9]) and explain why initialising best=0 would be incorrect.

WORKED ANSWER

[6] Original best=−4 [1]; update to −2 [1]; ignores −9 [1]; returns −2 [1]; initialising to zero would incorrectly return 0 [1] even though zero is absent [1].

True or false?

Initialising a maximum-tracking variable to 0 is correct for every integer array.

Model answer

False. Arrays containing only negative values would produce an incorrect result.
