OCR pseudocode, files and IDEs

By the end, you can…
  • Read OCR A Level pseudocode for opening, reading and closing a file
  • Trace each readLine call and the end-of-file condition
  • Write OCR pseudocode with openWrite, writeLine and close; distinguish replacing from reading existing contents

Key vocabulary

openReadreadLineendOfFileopenWriteclose
NEW LEARNING · CODE FIRST

Track the changes step by step

// OCR A Level examination pseudocode
myFile = openRead("names.txt")
while NOT myFile.endOfFile()
    print(myFile.readLine())
endwhile
myFile.close()
STEP 1 OF 3

Open the resource

openRead returns a file object for reading; it does not overwrite the file.

STEP 2 OF 3

Read until EOF

endOfFile() is false while another line remains. readLine() retrieves one line and moves the file position.

STEP 3 OF 3

Close the file

After the final line, endOfFile() is true, so the loop stops and the file is closed. For writing use openWrite, writeLine, then close(); unlike reading, opening for writing overwrites any existing file contents.

Trace OCR pseudocode that reads the first two lines of fruits.txt.

f = openRead("fruits.txt")

f.close()
STEP 1 OF 3

Predict first

The first call returns Apple and advances the file position.

STEP 2 OF 3

Model and check

STEP 3 OF 3

Model and check

I DO · FILE WRITING AND REPLACEMENT

Replace the contents of scores.txt with two lines

// OCR A Level examination pseudocode
f = openWrite("scores.txt")
f.writeLine("Ada,82")
f.writeLine("Ben,74")
f.close()
STEP 1 OF 3 · OPEN

Write mode is not read mode

openWrite opens the named text file for writing, replacing any previous contents. Do not use it simply to inspect scores already stored there.

STEP 2 OF 3 · WRITE

Two calls create two lines

After the first call the file contains Ada,82. After the second it also contains Ben,74 on the next line. A text file is not automatically a database table.

STEP 3 OF 3 · CLOSE AND VERIFY

Predict a later read

f.close() releases the file. A separate later openRead("scores.txt") would read Ada,82 then Ben,74 in that order.

WE DO · DIFFERENT GUIDED EXAMPLE

Trace a loop reading all lines of cities.txt. How many readLine calls occur?

f=openRead("cities.txt")
while NOT f.endOfFile()
  print(f.readLine())
endwhile
f.close()
STEP 1 OF 2

Predict first

The loop prints York from the first readLine call.

STEP 2 OF 2

Model and check

Then it prints Bath from the second call. At EOF the loop condition becomes false, so it stops after two reads.

WE DO · A DIFFERENT WRITE

Write two event messages to events.txt, then explain whether an old line survives.

log = openWrite("events.txt")
log.writeLine("START")
log.writeLine("DONE")
log.close()
STEP 1 OF 3 · YOUR TURN

List the final file lines

Predict the order of the two lines stored by the code and name the method that releases the file.

STEP 2 OF 3 · CHECK

Two lines, then close

The file contains START and DONE on separate lines. close() finishes and releases the file.

STEP 3 OF 3 · EXTEND

Overwriting is deliberate

If events.txt previously contained OLD, it is not retained: this openWrite example overwrites rather than appends. To read existing lines use openRead.
