NEW LEARNING · CODE FIRST

Compare the structure of the code

class Book {
  public string Title { get; }
  public bool OnLoan { get; private set; }
  public Book(string title) { Title = title; }
  public bool Borrow() {
    if (OnLoan) return false;
    OnLoan = true; return true;
  }
}
STEP 1 OF 3

Model the entity

A Book has a Title and whether it is currently on loan.

STEP 2 OF 3

Keep state protected

The public Borrow method updates a private-set OnLoan property, so external code cannot change it freely.

STEP 3 OF 3

Test a second call

The first Borrow returns true and changes state; the second call returns false because the book is already on loan.

I DO · WORKED EXAMPLE

Model a Seat object. Reserve() should succeed once, then fail.

class Seat {
 public bool Reserved {get;private set;}
 public bool Reserve() {
   if(Reserved) return false;
   Reserved=true; return true;
 }
}
STEP 1 OF 2

Predict

Initial Reserved is false, so Reserve sets it to true and returns true.

STEP 2 OF 2

Model response

The second call detects Reserved already true; it returns false and leaves state unchanged.

WE DO · DIFFERENT EXAMPLE

A Locker class starts Occupied=false. What happens after Use(), then Use() again?

bool Use() {
 if(Occupied) return false;
 Occupied=true; return true;
}
STEP 1 OF 2

Predict

The first call sets Occupied to true and returns true.

STEP 2 OF 2

Model response

The second call returns false without changing Occupied.
