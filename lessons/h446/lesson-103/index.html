Lesson 103 · Input and Output: Selecting Devices for Tasks

By the end you can…
  • An input device captures data or a user action; an output device communicates information or changes physical conditions.
  • A temperature sensor measures physical conditions; an actuator controls a physical action; a display shows values to the user.
  • Choose devices by required accuracy, accessibility, environment and response time. A touchscreen can perform both input and output functions.

I DO · MODEL

Recommend input and output for automated greenhouse temperature control.

WORKED REASONING

Explain the choice

Input thermistor/temperature sensor; output fan/heater actuator, possibly a display.

WE DO · DIFFERENT EXAMPLE

A library kiosk needs to identify books and display return confirmation. Select suitable devices.

WORKED REASONING

Explain the choice

Input barcode reader or RFID reader; output display and optional printer.

FOUNDATION · QUESTION 1 OF 3

For a room-temperature controller, choose appropriate input and output devices and explain roles. [6]

MARK SCHEME / WORKED ANSWER

Sensor measures temperature [2], CPU compares threshold [2], actuator controls fan/heater [2].

APPLICATION · QUESTION 2 OF 3

Compare barcode reader and RFID for counting library books, linking benefits to context. [6]

MARK SCHEME / WORKED ANSWER

Barcode cheap but line-of-sight [3], RFID can scan tags without direct optical sight but cost/interference [3].

CHALLENGE · QUESTION 3 OF 3

Design accessible touchscreen ticket kiosk: give two input and two output features and justify. [8]

MARK SCHEME / WORKED ANSWER

Touch or keypad as input [2], audio navigation/physical buttons [2], readable display [2], spoken confirmation/printed ticket [2].
