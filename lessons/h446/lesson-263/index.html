LMC branching and debugging

By the end you can…
  • BRP tests whether ACC is non-negative; BRZ tests zero; BRA is unconditional.
  • Load the current counter, output it, subtract one and save the new value.
  • When ACC becomes negative, the BRP loop ends. An update is essential for termination.

QUESTION 1 OF 3

Define BRA, BRZ and BRP and explain their effect on PC. [4]

WORKED ANSWER

BRA unconditional [1]; BRZ if ACC zero [1]; BRP if ACC non-negative [1]; taken branch changes instruction address [1].

QUESTION 3 OF 3

Explain why an unconditional backward branch without a tested exit can run forever, and provide a safe counter-based solution. [6]

WORKED ANSWER

BRA repeats [1]; no progress/exit [1]; initialise count [1]; decrement [1]; store update [1]; test an exit condition [1].
