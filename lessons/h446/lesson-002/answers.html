Two representations

Represent −37 in (a) sign magnitude [2] and (b) two’s complement [2]. Show the positive binary value and the change made for each method.

Completed answer
FINAL ANSWER
Sign magnitude: 10100101 · two’s complement: 11011011
Working and marking guidance

(a) +37 = 00100101 (1); sign magnitude −37 = 10100101 (1).

(b) Invert +37 → 11011010 (1); add 1 → 11011011 (1).

Original question · 2 of 5 QUESTION 2 · INTERPRET · [6]Suggested classroom marks: 6

The same pattern

The pattern is 10010110. Determine its denary value when interpreted as (a) unsigned binary, (b) sign magnitude and (c) two’s complement. Show working. [2 each]

Completed answer
FINAL ANSWER
Unsigned: 150 · sign magnitude: −22 · two’s complement: −106
Working and marking guidance

(a) Unsigned: 128 + 16 + 4 + 2 (1) = 150 (1).

(b) Sign magnitude: sign bit 1 with magnitude 16 + 4 + 2 = 22 (1) → −22 (1).

(c) Two’s complement: −128 + 16 + 4 + 2 (1) = −106 (1).

Signed binary addition

Add 00101101 and 00011011 as two’s-complement integers. Show column working or carries [1], the stored result [1], its denary value [1], and whether signed overflow occurs [1].

Completed answer
FINAL ANSWER
01001000 = 72 · no signed overflow
Working and marking guidance 
   00101101   (+45)
 + 00011011   (+27)
 ----------
   01001000   (+72)

Correct column addition with carries (1); 01001000 (1); 72 (1); no signed overflow (1). The total is within −128…127.

Starting on the right: column totals are 2, 2, 2, 3, 2, 2, 1, 0 when the incoming carries are included.

Subtract using two’s complement

Calculate 18 − 29 using eight-bit two’s complement. Show +29 [1], −29 [1], the binary addition [1], the stored result [1] and its signed denary value [1].

Completed answer
FINAL ANSWER
11110101 = −11
Working and marking guidance

+29 = 00011101 (1). Invert to 11100010, then add 1: −29 = 11100011 (1).

   00010010   (+18)
 + 11100011   (−29)
 ----------
   11110101

Correct addition of +18 and −29 (1); 11110101 (1); −128 + 64 + 32 + 16 + 4 + 1 = −11 (1).

Original question · 5 of 5 QUESTION 5 · EVALUATE · [5]Suggested classroom marks: 5

Explain an overflow

A processor adds 01110000 and 00100000 as eight-bit two’s-complement integers.

  1. State both input values in denary. [1]
  2. Give the stored eight-bit result. [1]
  3. Explain whether signed overflow has occurred. Refer to the mathematical total and the representable range. [2]
  4. State the minimum signed two’s-complement width needed to store the correct result. [1]
Completed answer
FINAL ANSWER
Correct total: 144 (overflow) · stored: −112 · minimum width: 9 bits
Working and marking guidance

(a) 112 and 32 (both for 1).

(b) 10010000 (1).

(c) Correct mathematical total = 144 (1); 144 exceeds the eight-bit signed maximum of +127, so signed overflow occurs (1). The stored pattern decodes to −112; it is not the correct sum.

(d) 9 bits (1), with signed range −256…255.
