Apply AND 00001111 to 10100101. Explain which bits the mask preserves.

ANSWER
00000101. The low four bits are preserved; the high four are cleared.

CHARACTER CODE REFERENCE

Useful ASCII anchors

'A' = 65    'Z' = 90
'a' = 97    'z' = 122
'0' = 48    '9' = 57
space = 32

Standard ASCII uses 7 bits → 128 possible codes.

A character code represents text. The character '7' is not the same value as the integer 7.
STEP 1 OF 4

Characters need agreed codes

A character set defines characters and their assigned numeric codes. An encoding specifies how those codes are represented as bytes.

Sender and receiver must interpret the bytes using the same encoding.
1 of 4
STEP 2 OF 4

Standard ASCII is limited

Seven bits provide 2⁷ = 128 codes for letters, digits, punctuation and control characters.

Eight-bit extensions can provide 256 values, but different extensions may map the extra codes differently.

2 of 4
STEP 3 OF 4

Unicode supports a much larger repertoire

Unicode assigns code points to characters from many writing systems and symbols. Its first 128 code points match ASCII.

Unicode is not simply “16 bits per character”. UTF-8 uses 1–4 bytes; UTF-16 uses one or two 16-bit code units.
3 of 4
STEP 4 OF 4

Use the encoding stated in storage questions

Storage depends on the number of code points and the number of bytes used for each one. Do not assume every Unicode character uses the same width.

'0' in ASCII = 48 = 00110000₂
integer 0     = 0

Worked example
STEP 1 · FIND THE CODES

Start with the character codes

A = 65
B = 66

ASCII assigns a numeric code to each character.

STEP 2 · CONVERT TO BINARY

Write the 7-bit ASCII values

A = 1000001
B = 1000010
STEP 3 · STORE IN BYTES

Add a leading zero

A → 01000001
B → 01000010

AB → 01000001 01000010

The leading zero lets each 7-bit ASCII code sit inside an 8-bit byte; it does not expand the standard ASCII repertoire.

AB = 01000001 01000010
