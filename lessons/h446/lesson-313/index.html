Processors, scheduling and LMC practice

By the end you can…
  • Trace the LMC accumulator and mailbox separately: INP overwrites ACC, while STA copies to storage.
  • Schedule independent CPU jobs with an explicit arrival/time rule and label every Gantt boundary.
  • Distinguish processor speed, memory cache and interrupt/OS services when explaining performance.
