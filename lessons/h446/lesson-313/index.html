EXAM QUESTION 1 OF 4 · 4 MARKS · 4 MINUTES

A school builds a simple processor for an interactive museum exhibit. Describe the fetch stage of its Fetch–Decode–Execute cycle, referring to relevant registers and buses. [4]

OCR H446/01 · June 2024 · Q1(a) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

The PC stores the address of the next instruction. The address is copied to MAR and sent along the address bus; the control unit signals memory read on the control bus; memory returns the instruction across the data bus into MDR, then CIR; the PC advances.

Marking: Up to four distinct accurate steps involving PC, MAR, address bus, control bus, data bus, MDR, CIR and PC increment; avoid giving several marks for one identical step.

EXAM QUESTION 2 OF 4 · 3 MARKS · 3 MINUTES

Describe three features of how this scheduling method manages processes. [3]

GIVEN INFORMATION

A desktop operating system uses a multi-level feedback queue to schedule its active processes.

OCR H446/01 · June 2025 · Q1(d)(ii) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

Processes occupy different priority queues. Different queues may use different time slices or scheduling rules. Processes can change queues according to their behaviour or priority; the scheduler balances responsive and longer-running work.

Marking: One mark for each distinct accurate scheduling feature, maximum three. Avoid granting several marks for repeated descriptions of priority.

EXAM QUESTION 3 OF 4 · 4 MARKS · 4 MINUTES

At a robotics competition, a console accepts two different non-negative scores. Write an LMC program that reads them both and outputs the larger score. Include any DAT storage locations and valid labels. [4]

OCR H446/01 · June 2025 · Q4(b) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

One valid solution: INP STA FIRST INP STA SECOND LDA FIRST SUB SECOND BRP FIRST_WINS LDA SECOND OUT HLT FIRST_WINS LDA FIRST OUT HLT FIRST DAT 0 SECOND DAT 0

Marking: Four independent marks: both inputs and valid storage; subtraction comparing the values; appropriate conditional branch; correct larger-value output for both paths. Accept correct alternate LMC code and approved mnemonics.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 3 MARKS · 3 MINUTES

Three processes arrive at time 0 in the order A, B, C. Their CPU burst times are 5, 2 and 3 time units respectively. Using non-preemptive shortest job first scheduling, state the execution order and the waiting time of each process. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

Execution order: B, C, A. Waiting times: B = 0, C = 2, A = 5 time units.

Marking: One mark for the correct order; one for B and C waiting times; one for A waiting time.
