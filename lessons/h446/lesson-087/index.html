  • Specify output when inputs are empty, and preserve correctness on all-negative arrays.
  • Maintain invariant: best is the largest value among those inspected so far.
  • Compare against alternative sorting-based solution: an O(n) scan avoids O(n log n) sort when only the maximum is needed.

NEW LEARNING · WORKED EXAMPLE FIRST

Explore the model

// Find largest value, return null for empty.
static int? Maximum(int[] a){
 if(a.Length==0)return null;
 int best=a[0];
 foreach(int x in a)
  if(x>best)best=x;
 return best;
}
// [-5,-2,-8] → -2
