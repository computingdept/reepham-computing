I DO · TEACHER MODEL

FCFS: P1 arrives at 0 (burst 4), P2 at 1 (burst 2), P3 at 2 (burst 1). Find waiting times.

WORKED REASONING

Model answer

Timeline P1 0–4, P2 4–6, P3 6–7. Waiting = start − arrival: P1 0, P2 3, P3 4. Average = 7/3 ≈ 2.33 units.

Check: link each claim to the scenario and use precise OCR terminology.

WE DO · DIFFERENT PROBLEM

SJF with all ready at 0: A burst 6, B burst 2, C burst 3. Trace and calculate mean waiting time.

STEP 1 · IDENTIFY

Identify the inputs, relevant facts and exact output or judgement required.

STEP 2 · APPLY

Work through the method

Use the middle stage of the visual to follow the process and state each intermediate result.

STEP 3 · EXPLAIN

Shared worked answer

Order B 0–2, C 2–5, A 5–11. Waits B 0, C 2, A 5; mean 7/3 ≈ 2.33 units. SJF assumes burst-length estimates are available.

FOUNDATION · QUESTION 1 OF 3

Distinguish non-preemptive and preemptive scheduling and give an example of each. [6]

MARK SCHEME / WORKED ANSWER

Non-preemptive runs selected job until completion/block [2]; preemptive may interrupt running job [2]; correct algorithm examples [2].

APPLICATION · QUESTION 2 OF 3

FCFS: A arrives 0/burst 3, B arrives 1/burst 2, C arrives 2/burst 4. Calculate each wait. [6]

MARK SCHEME / WORKED ANSWER

A executes 0–3, wait 0; B 3–5, wait 2; C 5–9, wait 3. Two marks for correct timeline and four for wait calculations.

CHALLENGE · QUESTION 3 OF 3

SRT: A arrives 0/burst 5, B arrives 1/burst 2. Show the timeline and explain preemption. [8]

MARK SCHEME / WORKED ANSWER

A 0–1; B 1–3; A 3–7 [6]. At t1 A has 4 remaining but B needs only 2, so B preempts [2].
