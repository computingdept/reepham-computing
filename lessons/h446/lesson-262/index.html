STEP 1 OF 3

Know LMC's parts

LMC uses numbered mailboxes to hold instructions and data, and an accumulator for working values.

STEP 2 OF 3

Trace instructions in order

First INP enters 4 into ACC, then STA FIRST copies 4 to the data mailbox before another input overwrites ACC.

STEP 3 OF 3

Produce the result

Second INP makes ACC=7; ADD FIRST adds stored 4 to make 11, and OUT prints 11. HLT ends the program.

WE DO · DIFFERENT PROBLEM

Write and trace LMC code to calculate first input 9 minus second input 4.

INP
STA A
INP
STA B
LDA A
SUB B
OUT
HLT
A DAT 0
B DAT 0
STEP 1 OF 2

Predict

Store input 9 as A and input 4 as B, since the accumulator is overwritten by INP.

STEP 2 OF 2

Explain

LDA A restores the first input 9 and SUB B produces 5; OUT prints 5.

Foundation · 4 marks · QUESTION 1 OF 3

Explain what INP, OUT, LDA and STA do in LMC.

WORKED ANSWER

[4] INP takes input to ACC [1]; OUT outputs ACC [1]; LDA loads ACC from mailbox [1]; STA stores ACC to mailbox [1].

Core · 6 marks · QUESTION 2 OF 3

Trace INP; STA X; INP; ADD X; OUT; HLT; X DAT 0 using inputs 6 and 8. State each change and output.

WORKED ANSWER

[6] First INP makes ACC6 [1]; STA X stores X6 [1]; second INP makes ACC8 [1]; ADD X makes ACC14 [2]; OUT prints 14 [1].

Stretch · 6 marks · QUESTION 3 OF 3

Write an OCR LMC program that takes two non-negative numbers, subtracts the second from the first, and outputs the answer. Trace inputs 9 and 2.

WORKED ANSWER

[6] INP; STA A [1]; INP; STA B [1]; LDA A [1]; SUB B [1]; OUT; HLT and A DAT 0; B DAT 0 [1]; output 7 [1]. Assume the inputs and output are representable by the implementation.

True or false?

In LMC, STA X replaces ACC with the stored value of X.

Model answer

False. STA X copies ACC into memory X; LDA X loads the content of X into ACC.
