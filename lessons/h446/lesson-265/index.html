I DO · TEACHER MODEL

Trace an LMC fragment with input 8.

INP
STA X
HLT
X DAT 0
STEP 1

Predict first

INP sets ACC=8; STA X writes 8 to mailbox X; the ACC remains 8. HLT ends the program.

WE DO · DIFFERENT GUIDED PROBLEM

A Running process requests a disk read. Give its next states.

Running → Waiting → Ready → Running
STEP 1

Predict first

The process waits for disk completion, then becomes Ready for selection by the scheduler.
