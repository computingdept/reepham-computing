EXAM QUESTION 1 OF 4 · 4 MARKS · 4 MINUTES

A shared college workstation is used by several pupils, and has printers, files and user accounts. Describe TWO different operating-system functions other than interrupt handling or CPU scheduling. Give a concrete example for each. [4]

OCR H446/01 · June 2024 · Q2(d)(i) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

Memory management allocates/releases RAM or coordinates paging. File management finds, stores or moves files. Device management supports peripherals/drivers. User/security management controls accounts or resource permissions. User interface allows users to interact with the computer.

Marking: Up to two distinct OS functions, each worth a correct role (1) plus a specific example or development (1), four total. Do not credit scheduling or interrupt-handling.

EXAM QUESTION 3 OF 4 · 4 MARKS · 4 MINUTES

At a robotics competition, a console accepts two different non-negative scores. Write an LMC program that reads them both and outputs the larger score. Include any DAT storage locations and valid labels. [4]

OCR H446/01 · June 2025 · Q4(b) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

One valid solution: INP STA FIRST INP STA SECOND LDA FIRST SUB SECOND BRP FIRST_WINS LDA SECOND OUT HLT FIRST_WINS LDA FIRST OUT HLT FIRST DAT 0 SECOND DAT 0

Marking: Four independent marks: both inputs and valid storage; subtraction comparing the values; appropriate conditional branch; correct larger-value output for both paths. Accept correct alternate LMC code and approved mnemonics.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

An LMC program uses INP, STA VALUE and LDA VALUE. Explain the different purposes of STA and LDA in this sequence. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

STA VALUE stores the accumulator's current contents into the memory location VALUE. LDA VALUE later loads the contents of VALUE back into the accumulator.

Marking: One mark for storing from the accumulator using STA; one for loading into the accumulator using LDA.
