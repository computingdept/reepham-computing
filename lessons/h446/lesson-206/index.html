NEW LEARNING · EXAMPLE FIRST

Predict the effect

Problem: print jobs must be processed in arrival order.
Needed: remove the OLDEST job first.
Choose: QUEUE (FIFO), not STACK (LIFO).
STEP 1 OF 3

Identify the operation

The print job that arrived first must leave first.

STEP 2 OF 3

Match the structure

Enqueue adds jobs; dequeue removes the oldest one. This is a queue.

STEP 3 OF 3

Justify and qualify

A stack gives LIFO, which is the wrong order. Other systems may also need priority queues if priority overrides arrival order.

I DO · MODEL

A browser Back button must return to the most recently visited page. Choose a structure.

Visit Home → News → Sport; press Back.
STEP 1 OF 2

Predict

The last visited page is the first one that must be removed.

STEP 2 OF 2

Explain

Use a stack: push visits and pop the most recent page.

WE DO · DIFFERENT GUIDED PROBLEM

A ticketing desk must serve requests in arrival order. Which structure?

Tickets arrive: A → B → C. Serve one ticket.
STEP 1 OF 2

Predict

The first request A must be the first one handled.

STEP 2 OF 2

Explain

Use a queue, because FIFO removes the oldest item.

Foundation · 1 OF 3

Select a structure for processing jobs in arrival order.

MODEL ANSWER

Queue (FIFO).

Core · 2 OF 3

Choose stack or hash table to retrieve customer records by unique ID. Justify.

MODEL ANSWER

Hash table: hashing IDs supports expected fast exact-key retrieval; stacks expose only the latest item.

Stretch · 3 OF 3

Compare a balanced BST and hash table for lookup and sorted output.

MODEL ANSWER

Balanced BST allows ordered traversal and O(log n) search; a hash table has expected O(1) lookup but does not inherently keep keys ordered.

True or false?

A hash table is always O(1) even in the worst case.

Model answer

False. Collisions can make lookup much slower, sometimes O(n).
