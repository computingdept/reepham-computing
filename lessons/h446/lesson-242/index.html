NEW LEARNING · EXAMPLE FIRST

Predict the program's next step

static decimal Price(decimal basket,bool member)
{
  if(member && basket>=50m) return basket*0.9m;
  return basket;
}
// Price(60,true)=54; Price(60,false)=60
STEP 1 OF 3

Locate the decision

A discount needs BOTH an eligible membership and a basket of at least £50.

STEP 2 OF 3

Follow the true branch

For member=true and basket=60, the condition is true and 10% discount produces £54.

STEP 3 OF 3

Follow the false branch

For member=false with basket=60, the AND expression is false, so the full £60 is charged.

I DO · MODEL

A cinema permits admission for age≥15 AND a valid ticket. Trace age=16 with no ticket.

bool permitted = age>=15 && hasTicket;
STEP 1 OF 2

Predict first

The age condition is true, but the ticket condition is false.

STEP 2 OF 2

Model the reasoning

AND requires both true; the result is false, so the deny branch executes.

WE DO · DIFFERENT GUIDED EXAMPLE

A challenge unlocks when score≥80 OR teacherOverride=true. Trace score=72 with override.

bool permitted = score>=80 || teacherOverride;
STEP 1 OF 2

Predict first

The score condition is false because 72<80.

STEP 2 OF 2

Model the reasoning

The override is true, so OR evaluates true and the challenge unlocks.

Core · 6 marks · QUESTION 2 OF 3

Access is allowed if Year13 AND (HasCode OR TeacherApproved). Evaluate Year13=true, HasCode=false, TeacherApproved=true; then Year13=false, HasCode=true, TeacherApproved=true.

MODEL ANSWER

[6] Case 1: bracket false OR true=true [1], true AND true=true [1], allowed [1]. Case 2: bracket true OR true=true [1], false AND true=false [1], denied [1].

Stretch · 6 marks · QUESTION 3 OF 3

A developer changes the discount condition `member && basket>=50` to `member || basket>=50`. Give two wrong outcomes and correct the expression.

MODEL ANSWER

[6] A member spending under £50 incorrectly gets discount [2]; nonmember spending ≥£50 incorrectly gets discount [2]; correct member && basket>=50m [2].

TERM 1 OF 5

condition

Expression evaluated as true or false.

TERM 2 OF 5

branch

Path selected by a decision.

TERM 3 OF 5

AND

True only if both operands are true.

TERM 4 OF 5

OR

True if either or both operands are true.

TERM 5 OF 5

truth table

All Boolean input combinations and outputs.

True or false?

Replacing AND with OR in a two-part eligibility rule can permit extra cases.

Model answer

True. OR is true when either condition holds.
