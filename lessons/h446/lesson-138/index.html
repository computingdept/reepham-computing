I DO · MODELLED

Orders(OrderID,CustomerID,Total) has totals 25,75,120. Write SQL listing orders over 50 with largest first.

STEP 1 OF 3

Filter Total > 50

Find the given data and name the required result.

STEP 2 OF 3

Select OrderID, Total

Explain why this intermediate stage is necessary.

STEP 3 OF 3

Sort DESC 120,75

SELECT OrderID, Total FROM Orders WHERE Total > 50 ORDER BY Total DESC; returns orders with 120 then 75, excluding 25.

WE DO · DIFFERENT CASE

Customer(CustomerID,Name), Orders(OrderID,CustomerID,Total). Show customer names for orders over 100.

STEP 1 OF 3

Join on CustomerID

Find the given data and name the required result.

STEP 2 OF 3

Filter Total > 100

Explain why this intermediate stage is necessary.

STEP 3 OF 3

Project Customer.Name

SELECT Customer.Name FROM Customer INNER JOIN Orders ON Customer.CustomerID = Orders.CustomerID WHERE Orders.Total > 100; Returns a row per matching order; DISTINCT can remove repeated customer names.

FOUNDATION · QUESTION 1 OF 3

Write SQL listing Title and Price from Book where Price<10, sorted ascending by Price. [6]

MARK SCHEME / WORKED ANSWER

SELECT Title,Price [2] FROM Book [1] WHERE Price <10 [2] ORDER BY Price ASC [1].

APPLICATION · QUESTION 2 OF 3

Explain the role of the ON clause in an INNER JOIN between Borrower and Loan. [6]

MARK SCHEME / WORKED ANSWER

Join matches records [2], ON states matching FK/PK relationship [2], avoids Cartesian result/mismatched associations [2].

CHALLENGE · QUESTION 3 OF 3

Write an INNER JOIN query listing Student.Name and Course.Title using Student, Enrolment and Course. [8]

MARK SCHEME / WORKED ANSWER

SELECT columns [2], FROM Student JOIN Enrolment ON Student.StudentID=Enrolment.StudentID [3], JOIN Course ON Enrolment.CourseID=Course.CourseID [3].

True or false?

ORDER BY always removes duplicate result rows.

Model answer

False. Sorting changes order, not duplication; DISTINCT may remove duplicates.
