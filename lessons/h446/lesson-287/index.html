Run-length and dictionary coding

By the end you can…
  • Run-length encoding replaces each maximal run of the same symbol with a value and count; it works best for long consecutive repetitions.
  • Dictionary coding replaces repeated strings with dictionary references; the decoder needs the same dictionary, transmitted or reconstructed according to the scheme.
  • Overhead matters. Alternating characters can make naive RLE larger; long repeated phrases can be valuable for dictionary coding.

EXAM QUESTION 2 OF 4 · 3 MARKS · 3 MINUTES

An employee types new names and dates into a thin-client application. Those text changes travel over the network to a server. Explain why lossless compression is preferable to lossy compression for sending the text. [3]

OCR H446/01 · June 2024 · Q3(c) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

Lossless compression reduces the amount of data transmitted while allowing the exact original text/characters to be reconstructed; lossy compression permanently discards information and could corrupt names or dates.

Marking: Three valid developed points from no irreversible loss, complete reconstruction, preserved text integrity/accuracy, risks of unreadable or incorrect text under lossy. One idea repeated cannot earn several marks.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 3 MARKS · 3 MINUTES

A text file contains the phrase computer science many times. Explain how dictionary coding could compress this file without losing information. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

Store the repeated phrase in a dictionary and replace its occurrences with a shorter reference to that entry. During decompression, replace each reference with the original phrase.

Marking: One mark for a dictionary entry, one for replacement with a shorter reference, one for exact reconstruction.
