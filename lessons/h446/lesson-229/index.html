NEW LEARNING · CODE FIRST

Compare the structure of the code

using System;
using System.Linq;
// Procedural: standalone function
int Double(int x) => x*2;
// Object-oriented: state + method
var account = new Account(10);
account.Deposit(5);
// Functional-style transformation
int[] values = {2,3};
var doubled = values.Select(x => x*2).ToArray();
Console.WriteLine(Double(4)); // 8
class Account {
 public int Balance {get;private set;}
 public Account(int balance){Balance=balance;}
 public void Deposit(int amount){Balance+=amount;}
}
STEP 1 OF 3

Procedural

Instructions and procedures operate on arguments or shared data. A function can be reused independently.

STEP 2 OF 3

Object-oriented

The Account object combines state (Balance) and behaviour (Deposit).

STEP 3 OF 3

Functional style

Values are transformed using expressions/functions, often emphasising avoiding mutation of existing input data.

I DO · WORKED EXAMPLE

Classify a function Square(x) that returns x*x without storing object state.

int Square(int x) => x*x;
Console.WriteLine(Square(3));
STEP 1 OF 2

Predict

It is procedural when used as a standalone function in a procedural programme.

STEP 2 OF 2

Model response

Square(3) returns 9; it does not change object state. C# can use more than one paradigm.

WE DO · DIFFERENT EXAMPLE

Classify a Score object storing Points and updating it using Add(2).

var score=new Score(5);
score.Add(2);
// score.Points is 7
STEP 1 OF 2

Predict

The Score object holds Points alongside a method that changes its state.

STEP 2 OF 2

Model response

This is object-oriented design; after Add(2), its Points becomes 7.

Foundation · 4 marks · QUESTION 1 OF 3

Classify a program using standalone functions with arguments and returns. Give one advantage.

MODEL ANSWER

[4] Procedural [1]; operations organised in subroutines [1]; parameters carry inputs [1]; functions can be reused/tested independently [1].

Core · 6 marks · QUESTION 2 OF 3

Compare procedural and OOP implementations of a bank account with balance and deposit operation.

MODEL ANSWER

[6] Procedural stores balance in a variable/record [1] and supplies it to a procedure/function [1]; OOP stores balance in Account object [1] and updates via method [1]; encapsulation controls changes [1]; either style can be implemented in a multi-paradigm language such as C# [1].

Stretch · 6 marks · QUESTION 3 OF 3

Explain why `values.Select(x=>x*2)` can be considered functional-style programming, and one limitation of labelling C# purely functional.

MODEL ANSWER

[6] Applies a function to each element [2], returns transformed values [1], can avoid mutating original list [1]; C# also supports procedural code and mutable objects [1], so language/paradigm are not identical [1].

TERM 1 OF 5

paradigm

Overall style for organising programs.

TERM 2 OF 5

procedural

Organises a program around sequences of operations and subroutines.

TERM 3 OF 5

object-oriented

Encapsulates state and behaviour into objects.

TERM 4 OF 5

functional

Emphasises functions applied to values and reduced side effects.

TERM 5 OF 5

declarative

Expresses desired results rather than imperative step sequences.
