I DO · TEACHER MODEL

Write OCR-style pseudocode that repeatedly requests an age from 11 to 19 inclusive.

WORKED REASONING

Model answer

age = int(input("Age"))

while age < 11 OR age > 19

age = int(input("Age"))

endwhile

print(age)

Note: this handles numeric range, not a non-numeric input error without extra handling.

APPLICATION · QUESTION 2 OF 3

Explain why 'WHILE age < 11 AND age > 19' fails as range validation. [6]

MARK SCHEME / WORKED ANSWER

Cannot be below 11 and above 19 simultaneously [3]; use OR to detect either invalid condition [3].

True or false?

When rejecting values outside a range, the two invalid inequalities should usually be joined with AND.

Model answer

False. An invalid input is below the minimum OR above the maximum.
