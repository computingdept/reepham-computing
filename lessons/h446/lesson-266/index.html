Paging, segmentation and virtual memory

By the end you can…
  • Pages and frames have equal fixed sizes; the page table maps virtual pages to physical frames.
  • Divide the virtual address by page size for the page number; use remainder as the offset.

NEW LEARNING · CODE FIRST

Follow the trace

Page size = 256 bytes.
Virtual address 770 → page 3, offset 2.
Page table: virtual page 3 → frame 5.
Physical address = frame 5×256 + 2 = 1282.
STEP 1 OF 3

Understand

Pages and frames have equal fixed sizes; the page table maps virtual pages to physical frames.

STEP 2 OF 3

Trace

Divide the virtual address by page size for the page number; use remainder as the offset.

STEP 3 OF 3

Explain

A page fault requires a non-resident page to be loaded. Variable-sized segmentation has different fragmentation characteristics.

I DO · TEACHER MODEL

Translate virtual address 520 with page size 128 and page 4 mapped to frame 9.

page=4; offset=8; physical=9×128+8=1160
STEP 1

Predict first

520 div 128=4 remainder 8; frame 9 base=1152, plus 8 gives 1160.

WE DO · DIFFERENT GUIDED PROBLEM

Virtual address 615 with page size 200, page 3 → frame 7. Calculate physical address.

page=3; offset=15; physical=7×200+15=1415
STEP 1

Predict first

615 div 200=3 remainder 15. Page 3 maps to frame 7, hence physical address 1415.
