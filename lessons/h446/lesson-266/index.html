NEW LEARNING · CODE FIRST

Follow the trace

Page size = 256 bytes.
Virtual address 770 → page 3, offset 2.
Page table: virtual page 3 → frame 5.
Physical address = frame 5×256 + 2 = 1282.
STEP 1 OF 3

Understand

Pages and frames have equal fixed sizes; the page table maps virtual pages to physical frames.

STEP 2 OF 3

Trace

Divide the virtual address by page size for the page number; use remainder as the offset.

STEP 3 OF 3

Explain

A page fault requires a non-resident page to be loaded. Variable-sized segmentation has different fragmentation characteristics.

I DO · TEACHER MODEL

Translate virtual address 520 with page size 128 and page 4 mapped to frame 9.

page=4; offset=8; physical=9×128+8=1160
STEP 1

Predict first

520 div 128=4 remainder 8; frame 9 base=1152, plus 8 gives 1160.

WE DO · DIFFERENT GUIDED PROBLEM

Virtual address 615 with page size 200, page 3 → frame 7. Calculate physical address.

page=3; offset=15; physical=7×200+15=1415
STEP 1

Predict first

615 div 200=3 remainder 15. Page 3 maps to frame 7, hence physical address 1415.

A community library uses one shared computer for cataloguing, web access and public bookings. Discuss how an operating system manages and protects RAM so these applications can coexist. Include allocation, virtual memory, paging or segmentation, and the consequences of poor memory management. Evaluate which challenges matter most to the library. [9]

RHS ADDITIONAL PRACTICE · QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

A process uses paging with a page size of 4 KiB. Explain what a page is and why it can be placed into any available physical frame of the same size. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

A page is a fixed-size block of a process's virtual address space. Because frames are equally sized, the OS can map a page into any free physical frame using a page table.

Marking: One mark for a fixed-size virtual-memory block; one for mapping into equally sized physical frames.

RHS ADDITIONAL PRACTICE · QUESTION 3 OF 4 · 2 MARKS · 2 MINUTES

Explain one difference between paging and segmentation in how a process's memory is divided. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

Paging divides memory into fixed-size pages; segmentation divides a program into logical, usually variable-sized segments such as code or data.

Marking: One mark for fixed-size pages; one for logical, typically variable-sized segments.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

A computer spends most of its time moving pages between RAM and disk rather than running applications. Name this condition and give one likely cause. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

Thrashing. It can occur when the combined active working sets exceed available physical RAM, causing very frequent page faults and swaps.

Marking: One mark for thrashing; one for insufficient RAM/high page-fault activity.
