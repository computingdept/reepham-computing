Lesson 056 · Tree Traversals: Post-order and Breadth-first

By the end you can…
  • Post-order visits both child subtrees before its parent. Traverse left subtree, right subtree, then root.
  • Breadth-first visits by levels, left-to-right with a queue that stores the next vertices.
  • Traversal result depends on the precise tree and stated child order. BFS queue changes must be shown to justify an answer.

I DO · MODEL

Give postorder for tree root5, left2, right7; node2 has left1.

// root 5; left 2 (left 1); right 7
static void PostOrder(Node? node) {
    if (node is null) return;
    PostOrder(node.Left);
    PostOrder(node.Right);
    Console.WriteLine(node.Key);
}
WORKED EXPLANATION

Explain

PostOrder(5) waits for PostOrder(2), which prints 1 then 2. The right call prints 7; only then is 5 printed: 1,2,7,5. null returns without printing. Node supplies Key, Left and Right.

WE DO · DIFFERENT PROBLEM

Give breadth-first order for root9, left4, right12; 4 has right6.

Queue starts [9] → enqueue [4,12] → visit4/enqueue6 → visit12 → visit6.
WORKED EXPLANATION

Explain

Order 9,4,12,6. Visit by depth, using FIFO.

FOUNDATION · QUESTION 1/3

Root8, children3 and10, with 3 children1 and6, 10 right child14. Give postorder. [6]

WORKED ANSWER

CORE · QUESTION 2/3

Give breadth-first order for same tree, and first two queue changes. [6]

WORKED ANSWER

8,3,10,1,6,14 [4]; start [8] [1] and after 8 [3,10] [1].

CHALLENGE · QUESTION 3/3

Explain why postorder is useful for deleting tree structures but BFS for shortest unweighted-edge distance. [6]

WORKED ANSWER

Postorder visits children before parent [2] allowing safe subtree cleanup [1]; BFS explores layers [2] first discovery gives shortest unweighted edge count [1].
