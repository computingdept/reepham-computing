Lesson 055 · Choosing Data Structures for Problems

By the end you can…
  • Choose structures from operations first, not familiar names: indexed access, insertion, deletion, queue discipline or key lookup.
  • Consider runtime and additional memory: arrays/lists support indexed access; linked lists can insert cheaply given a node; dictionaries use extra bucket storage.
  • Justify the suitability for a real task, including constraints and the cost of maintaining the structure.

I DO · MODEL

Choose a structure for a browser's Back action and justify.

History.Push(currentPage)
previous=History.Pop()
WORKING

Explain the trace

Stack (LIFO): the most recently visited earlier page is retrieved first. Browser navigation may use multiple stacks for back/forward.

WE DO · DIFFERENT PROBLEM

Choose a structure for clinic tickets processed in arrival order.

queue.Enqueue(ticket)
next=queue.Dequeue()
WORKING

Explain the trace

Queue FIFO serves earliest arrivals first, subject to real-world priority policies.

CHALLENGE · Q3/3

Evaluate using List<T" versus linked list for a million-item collection, focusing on frequent random index access versus middle insertion with a known node. [6]

WORKED MODEL ANSWER

List random indexing O(1) [2]; LinkedList random index traversal O(n) [1]; List middle insertion O(n) shifts [1]; linked list pointer insertion with known node O(1) [2].
