Von Neumann and Harvard architectures

By the end, you can…
  • Distinguish shared from separate instruction/data storage paths
  • Explain the Von Neumann bottleneck
  • Compare architecture decisions for embedded and general-purpose systems

Key vocabulary

Von NeumannHarvardbottleneckinstruction cachehybrid architecture
NEW LEARNING · CODE OR MODEL FIRST

Trace the mechanism

// Von Neumann (conceptual):
//   CPU <-> shared instructions + data memory/path
// Harvard (conceptual):
//   instruction memory/path and data memory/path separate
// Modern processors may combine aspects of both.
STEP 1 OF 3

Von Neumann organisation

Instructions and data share the same address space and a pathway; access can compete for bandwidth.

STEP 2 OF 3

Harvard organisation

Instruction and data memories/address spaces are separate, allowing independent access paths.

STEP 3 OF 3

Recognise contemporary designs

Many processors have aspects of both, such as a unified main memory and separate instruction/data caches (modified Harvard).

I DO · FULL MODEL

A CPU needs to fetch an instruction while reading its operand. Explain possible contention in a Von Neumann design.

Instruction fetch ─┐
                  ├─ shared memory path
Operand read ──────┘
STEP 1 OF 2

Predict first

The instruction fetch and data read may both need the same memory transfer pathway.

STEP 2 OF 2

Explain and check

The requests may have to be scheduled rather than served simultaneously; this is related to the Von Neumann bottleneck.

WE DO · DIFFERENT QUESTION

A microcontroller uses separate program and data memories. Identify the architecture and a useful consequence.

Program ROM ─instruction path→ CPU
Data RAM    ⇄data path⇄ CPU
STEP 1 OF 2

Predict first

Separate program and data memories indicate Harvard-style organisation.

STEP 2 OF 2

Explain and check

Independent transfer pathways can allow concurrent instruction fetch and data access, subject to the processor design.

Foundation · 4 marks · QUESTION 1 OF 3

State where instructions and data are stored in Von Neumann and Harvard architectures.

WORKED ANSWER

[4] Von Neumann uses a shared instruction/data memory space [2]; Harvard has separate instruction/data memories or address spaces [2].

Core · 6 marks · QUESTION 2 OF 3

A CPU frequently fetches an instruction while reading data. Explain a potential Von Neumann limitation and Harvard advantage.

WORKED ANSWER

[6] Shared transfer pathway [1] used for both instructions and data [1], which can cause contention [1]; Harvard uses independent paths [1], potentially overlapping transfers [1] although overall speed depends on implementation [1].

Stretch · 6 marks · QUESTION 3 OF 3

A modern CPU uses unified main memory but separate L1 instruction and data caches. Explain why it cannot be described as a purely classical Harvard or purely classical Von Neumann design.

WORKED ANSWER

[6] Unified main memory is shared [1], a Von Neumann feature [1]; separate L1 caches [1] offer separate instruction/data access paths [1], a Harvard-like feature [1]; this is a hybrid or modified Harvard organisation [1].

TERM 1 OF 5

Von Neumann

Architecture with shared memory space for instructions and data.

TERM 2 OF 5

Harvard

Architecture with separate program and data storage paths.

TERM 3 OF 5

bottleneck

Limit caused by a shared resource or transfer path.

TERM 4 OF 5

instruction cache

Fast cache storing instructions.

TERM 5 OF 5

hybrid architecture

Combines features of different architectural approaches.
