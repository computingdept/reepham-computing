Database tables, entities and keys

By the end you can…
  • An entity corresponds to a distinguishable object type; a relational table stores rows of its attributes.
  • A primary key uniquely identifies each row; foreign keys express references from related tables.
  • A secondary/index key can accelerate searching without necessarily being unique. One-to-many relationships use a foreign key on the many side.
