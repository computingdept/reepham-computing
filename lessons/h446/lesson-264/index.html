By the end you can…
  • The OS mediates application requests and access to hardware.
  • Resource management schedules processes, allocates memory, controls files and drivers.
  • Permissions and isolation help keep processes and users from accessing unauthorised data.

I DO · TEACHER MODEL

A pupil app requests a protected file. Explain the OS steps.

Open('grades.csv') → check permission → file lookup → read or deny
STEP 1

Predict first

The OS checks authorisation before returning content; a missing permission should prevent the read.

WE DO · DIFFERENT GUIDED PROBLEM

An app prints a document while a printer is busy. Explain the OS's role.

Application → print spool → driver → printer
STEP 1

Predict first

The print job enters a queue and is later sent via a compatible printer driver when the device is available.
