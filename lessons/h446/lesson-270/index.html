BIOS, drivers and virtual machines

By the end you can…
  • BIOS/UEFI firmware initialises key hardware and starts the boot process.
  • Device drivers connect OS abstractions to the instructions and data expected by actual peripherals.
  • A hypervisor provides virtual machines for isolation, testing and consolidation, though CPU/RAM/storage overhead remains.
