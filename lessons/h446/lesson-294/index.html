Search engine indexing and PageRank

By the end you can…
  • A crawler discovers pages by following links and sitemaps; an index records useful information about documents for searching.
  • PageRank models a random web surfer and passes importance through directed links. A link from a high-ranked page can carry more weight than one from a low-ranked page.
  • PageRank uses damping and repeated iterations; raw incoming link counts alone are not the full algorithm. Search engines combine many ranking signals.

NEW LEARNING · EXAMPLE FIRST

Follow the reasoning

Links: A → B; A → C; B → C; C → A.
C has incoming links from A and B.
A has incoming link from C.
Simplified importance: links pass weighted votes.
Actual PageRank iterates a damped probability model.

I DO · MODEL

In graph A→B and A→C, how is A's rank contribution divided (ignoring damping)?

A has 2 outgoing links.
Contribution to B = R(A)/2.
Contribution to C = R(A)/2.
STEP 1 OF 2

Predict first

Outgoing degree of A is two, so its rank is divided across two outgoing edges.

STEP 2 OF 2

Explain

Both B and C receive half of A's contribution before damping and other link contributions.

WE DO · DIFFERENT PROBLEM

A has three outgoing links to B,C,D and rank 0.30. What raw contribution reaches C?

0.30 / 3 = 0.10
Before damping/teleportation.
STEP 1 OF 2

Predict first

The outgoing links split A's contribution evenly in the simplified model.

STEP 2 OF 2

Explain

C receives 0.10; final PageRank needs damping, all incoming contributions and repeated iterations.

FOUNDATION · QUESTION 1 OF 3

Distinguish crawling and indexing. [4]

WORKED ANSWER

Crawling fetches/discovers pages [2]; indexing structures information for efficient query retrieval [2].

CORE · QUESTION 2 OF 3

In directed link graph A→B,C and B→C, identify incoming links of C and A's share given rank 0.4, ignoring damping. [6]

WORKED ANSWER

C receives from A and B [2]; A has two outgoing links [2]; A contributes 0.4/2=0.2 to C [2].

CHALLENGE · QUESTION 3 OF 3

Explain why the number of inbound links alone is not an adequate PageRank calculation. [6]

WORKED ANSWER

Importance weighted by linking pages [2]; outgoing degree splits contributions [1]; damping/teleportation [1]; repeated iterative convergence [1]; other ranking signals used in real search [1].
