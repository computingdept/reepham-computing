Lesson 099 · CISC and RISC: Instruction Set Design

By the end you can…
  • CISC typically offers a larger/more complex instruction repertoire, with instructions able to combine operations; RISC generally uses more regular, often simple operations.
  • RISC load/store designs explicitly move operands between memory and registers and perform ALU work using registers.
  • Avoid outdated absolutes: modern CISC and RISC microarchitectures can both pipeline, use caches and achieve strong performance; trade-offs depend on implementation.

I DO · WORKED MODEL

Model a RISC load-add-store sequence for A5,B8 and result C.

MODEL ANSWER

Follow the reasoning

LOAD R1,A→5; LOAD R2,B→8; ADD R3,R1,R2→13; STORE C,R3→13.

WE DO · DIFFERENT PROBLEM

For A4,B7, trace the same abstract load/store sequence and state result.

MODEL ANSWER

Follow the reasoning

R1=4,R2=7,R3=11, memory[C]=11.
