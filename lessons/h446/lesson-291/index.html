HTML structures and forms

By the end you can…
  • HTML uses nested elements to give structure and semantics: head contains metadata and body contains visible content.
  • Forms collect and submit inputs. The label's for value matches input's id; the input's name is the key submitted to the server.
  • With method GET, query parameters appear in the URL; don't use GET for confidential credentials. Client-side required validation improves usability but is not a substitute for server validation.

NEW LEARNING · WORKED EXAMPLE FIRST

Trace the mechanism

<!doctype html>
<html lang="en">
<head><title>Revision</title></head>
<body>
 <h1>Choose a topic</h1>
 <form action="/search" method="get">
  <label for="topic">Topic</label>
  <input id="topic" name="topic" required>
  <button type="submit">Find</button>
 </form>
</body>
</html>

I DO · MODEL

What is sent by a GET form whose input name is q and value is binary?

<form action='/find' method='get'>
 <input name='q' value='binary'>
</form>
→ /find?q=binary
STEP 1 OF 2

Predict first

The action sets the destination path '/find' and GET encodes form fields into URL query parameters.

STEP 2 OF 2

Show method

The input name 'q' becomes the query key and 'binary' the value.

WE DO · DIFFERENT QUESTION

Correct the accessible label connection in a form where for='email' but input id='user'.

<label for='email'>Email</label>
<input id='email' name='email' type='email'>
STEP 1 OF 2

Predict first

The label for and input id must match exactly.

STEP 2 OF 2

Show method

The email input type provides built-in browser constraints, but the server must validate again.

A school's river-monitoring club is creating its own web page. Fill five blanks in the HTML listing below so it contains a bulleted list, a link, a login label and a form with a password entry and submit control. [5]

OCR H446/01 · June 2023 · Q4(d)(i) · RHS exam-style scenario

MODEL ANSWER · 5 MARKS

Blanks, in order: <ul>; href; Login; password; submit.

Marking: One mark per correct HTML blank, maximum five. In this independent version the secret field intentionally uses input type=password. Case-insensitive element spelling accepted where valid.

EXAM QUESTION 2 OF 4 · 4 MARKS · 4 MINUTES

A school concert website is built using HTML and CSS. Describe how each language contributes to what visitors see, giving two technically distinct roles or features for each. [4]

OCR H446/01 · November 2021 · Q3(a) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

HTML provides semantic page structure/content using tags such as headings and anchors. CSS styles elements using properties and selectors, controls colours/fonts/appearance and can be external or embedded.

Marking: Two marks for meaningful HTML roles and two for CSS roles. Do not give 'formatting' as the only definition of HTML.

EXAM QUESTION 3 OF 4 · 3 MARKS · 3 MINUTES

A swimming pool wants its picture named "pool.png" to act as a hyperlink to the page "reserve.htm". Write complete HTML using an image inside a link. [3]

OCR H446/01 · November 2021 · Q3(b) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

<a href="reserve.htm"><img src="pool.png" alt="Reserve a session"></a>

Marking: One mark for opening/closing anchor tags, one for href target reserve.htm, one for img element/src pool.png. Correct alt text is advisable but not mandatory for the three source marks.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 3 MARKS · 3 MINUTES

Write HTML for a text input named email, with an associated visible label Email address. Use the id email to link the label to the input. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

<label for="email">Email address</label>
<input type="text" id="email" name="email">

Marking: One mark for the label with the requested text and for attribute; one for the text input with name email; one for matching id email. Accept type=email as a valid alternative.
