Karnaugh maps and simplification

By the end, you can…
  • Interpret Gray-code ordering in a three-variable map
  • Group four adjacent 1s correctly
  • Identify which variable remains in a simplified term

Today's vocabulary

Karnaugh mapGray codegroupconstant variablewraparound
EXAMPLE FIRST

Read, predict and explain

Rows: A = 0, 1
Columns: BC = 00, 01, 11, 10
Group all four cells in columns 00 and 01.
B stays 0; A and C both change.
Therefore Q = ¬B.
STEP 1 OF 3

Read the labels

Rows represent A, and columns use Gray order BC: 00, 01, 11, 10.

STEP 2 OF 3

Group neighbouring ones

The four 1s form one 2×2 rectangle. Adjacency across rows is allowed.

STEP 3 OF 3

Keep what is constant

A and C change through the group, but B remains 0. So the simplified result is ¬B.

I DO · MODEL

Four 1s fill the entire A=0 row. Simplify the output.

A=0: 1 1 1 1
A=1: 0 0 0 0
STEP 1 OF 2

Predict and explain

B and C each vary across the row; neither is needed in the expression.

STEP 2 OF 2

Check and extend

A stays 0 in the whole group. The simplified term is ¬A.

WE DO · DIFFERENT GUIDED PROBLEM

Four 1s fill columns BC=11 and BC=10 across both rows. Simplify.

BC columns: 00 01 11 10
A=0:       0  0  1  1
A=1:       0  0  1  1
STEP 1 OF 2

Predict and explain

A changes between rows, and C changes between columns 11 and 10.

STEP 2 OF 2

Check and extend

B remains 1, so the simplified term is B.

Foundation · QUESTION 1 OF 3

Why do we group neighbouring 1s in a Karnaugh map?

MODEL ANSWER

To simplify the Boolean expression by removing variables that change inside a group.

Core · QUESTION 2 OF 3

The whole A=1 row contains four 1s. Which simplified term remains?

MODEL ANSWER

A. Both B and C change within the row, while A remains 1.

Stretch · QUESTION 3 OF 3

Columns BC=00 and BC=10 are joined by wraparound adjacency. Four 1s occupy both these columns. Simplify.

MODEL ANSWER

¬C. A changes between the rows and B changes between 00 and 10; C stays 0.

TERM 1 OF 5

Karnaugh map

Grid for simplifying Boolean functions using adjacent combinations.

TERM 2 OF 5

Gray code

Ordering in which adjacent binary labels differ by one bit.

TERM 3 OF 5

group

A rectangle containing 1, 2, 4, 8, … adjacent 1-cells.

TERM 4 OF 5

constant variable

A variable with the same value in all cells of a group.

TERM 5 OF 5

wraparound

The opposite edges of a Karnaugh map are adjacent.

True or false?

A group of four 1s can remove two changing variables.

Answer

True. The group leaves only variables constant across all four cells.
