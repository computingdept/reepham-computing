Repair a SumTo recursion missing a base case.

static int SumTo(int n){
 if(n==0)return 0;
 return n+SumTo(n-1);
}
STEP 1

Explain the result

The n==0 base case stops recursion and returns zero.

WE DO · DIFFERENT EXAMPLE

Repair a binary search that can repeat the midpoint forever.

if(a[mid]<target)low=mid+1;
else if(a[mid]>target)high=mid-1;
STEP 1

Explain the result

The boundaries exclude a failed midpoint, so the remaining interval shrinks.

EXAM QUESTION 2 OF 4 · 4 MARKS · 4 MINUTES

A wildlife charity must find a given name in an unsorted list. Describe a complete LINEAR SEARCH, including the initial comparison, advancement, termination and returned result. [4]

OCR H446/02 · June 2022 · Q1(a)(ii) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

Compare target with the first item; advance to the next if not equal; repeat until found or end reached; return the index if found or a not-found value otherwise.

Marking: One point each: first comparison, advance, repeat/stop, return position or not found. Order must be logical.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 3 MARKS · 3 MINUTES

An algorithm searches a sorted array of 128 values using binary search. Explain why doubling the size of the array to 256 values adds at most one extra comparison to the worst-case search. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

Each comparison reduces the remaining search interval by approximately half. The maximum number of comparisons grows logarithmically, so doubling the input size adds only one halving step.

Marking: One mark for halving the search interval; one for logarithmic growth; one for linking doubling the array size to one additional step.
