I DO · UNMARKED EXAMPLE

Repair a SumTo recursion missing a base case.

static int SumTo(int n){
 if(n==0)return 0;
 return n+SumTo(n-1);
}
STEP 1

Explain the result

The n==0 base case stops recursion and returns zero.

WE DO · DIFFERENT EXAMPLE

Repair a binary search that can repeat the midpoint forever.

if(a[mid]<target)low=mid+1;
else if(a[mid]>target)high=mid-1;
STEP 1

Explain the result

The boundaries exclude a failed midpoint, so the remaining interval shrinks.
