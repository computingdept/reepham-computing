1.4.2(b)(c) · STACK + QUEUE

Same array idea — different pointer rules

STACK
top → newest item

QUEUE
front → oldest item
rear  → newest item
This lesson uses arrays and integer pointers, so no OO or library Stack/Queue classes are required.
STEP 1 OF 4

Stack array

int[] stack = new int[10];
int top = -1;

-1 means the stack is empty.

1 of 4
STEP 2 OF 4

Push and pop

top++;
stack[top] = value;

value = stack[top];
top--;

Push moves top up; pop reads then moves top down.

2 of 4
STEP 3 OF 4

Queue array

int[] queue = new int[10];
int front = 0;
int rear = -1;

rear tracks the newest item and front tracks the oldest.

3 of 4
STEP 4 OF 4

Enqueue and dequeue

rear++;
queue[rear] = value;

value = queue[front];
front++;

For this introductory linear queue, pointers move forward through the array.

4 of 4
WORKED EXAMPLE

Trace a stack

Push 8, push 7, then process an add operation.

push 8

pop → 7
pop → 8
push 15
Worked example
STEP 1 · PUSH

Store 8

top = 0
stack[0] = 8
STEP 2 · PUSH

Store 7

top = 1
stack[1] = 7
STEP 3 · POP

Remove two values

first = 7
second = 8
top = -1
STEP 4 · PUSH

Store result

top = 0
stack[0] = 15
