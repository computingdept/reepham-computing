INDEPENDENT 1 OF 10

Identify the first logical item

start = 2
data[start] = "Alex"

start identifies the first logical node. Physical slot 0 holds Ben, but the head can be elsewhere.

INDEPENDENT 2 OF 10

Follow the next pointers

2 → 0 → 3 → 1 → -1
Alex → Ben → Cara → Daisy

The -1 value is a null marker, never a valid array index.

INDEPENDENT 3 OF 10

Write the traversal loop

int current = start;
while (current != -1)
{
    Console.WriteLine(data[current]);
    current = next[current];
}

The pointer chooses the next logical node; current++ would follow physical slots instead.

INDEPENDENT 4 OF 10

Count reachable nodes

int count=0, current=start;
while(current!=-1) { count++; current=next[current]; }
Console.WriteLine(count); // 4

The arrays have six slots, but only four are in the original chain.

INDEPENDENT 5 OF 10

Insert after the head

data[4] = "Elliot";
next[4] = next[start]; // preserve Ben at index 0
next[start] = 4;

New indexes: 2→4→0→3→1. Names: Alex→Elliot→Ben→Cara→Daisy. Slot 4 must be unused before insertion.

INDEPENDENT 6 OF 10

Insert a new first node

data[4] = "Zoe";
next[4] = start;
start = 4;

On a fresh starter, indexes become 4→2→0→3→1: Zoe→Alex→Ben→Cara→Daisy. Link to the old head before replacing start.

INDEPENDENT 7 OF 10

Remove the second node

if (start != -1 && next[start] != -1)
    next[start] = next[next[start]];

On a fresh starter, bypass Ben at index0. Remaining indexes 2→3→1: Alex→Cara→Daisy. The data values are not shifted.

INDEPENDENT 8 OF 10

Remove the first node safely

if (start != -1) start = next[start];

On a fresh starter, new start=0 and the order is Ben→Cara→Daisy. For one node, its next is -1, so start becomes -1. An empty list remains empty without an invalid access.

INDEPENDENT 9 OF 10

Search by following links

int current=start;
while(current!=-1 && data[current]!=name)
    current=next[current];
Console.WriteLine(current); // matching index or -1

With a fresh starter: Cara returns 3; an absent name returns -1. Test -1 before accessing data[current]; short-circuit AND prevents invalid indexing.

INDEPENDENT 10 OF 10

Combine, test and explain

Reset before each independent test:
start=-1 → traversal outputs nothing
one reachable node → delete head leaves -1
insert Elliot after Alex → Alex,Elliot,Ben,Cara,Daisy
delete Ben → Alex,Cara,Daisy
no unused slot → reject insertion without changing links

Record the actual results as well as expected results. Reaching an arbitrary predecessor can take O(n); reconnecting a known link is O(1). A removed slot becomes reusable only when the chosen free-slot allocation scheme records it.
