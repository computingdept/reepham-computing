2.2.1(b) · RECURSION

Same problem, smaller input

routine(n)
├── base case → stop
└── recursive case → routine(smaller n)
OCR expects both how recursion is used and how it compares with iteration.
STEP 1 OF 4

Base case stops the chain

if (n == 0)
    return;

The base case prevents another recursive call.

1 of 4
STEP 2 OF 4

Recursive case reduces the problem

Console.WriteLine(n);
CountDown(n - 1);

Each call uses a smaller value so it approaches the base case.

2 of 4
STEP 3 OF 4

Calls use the call stack

CountDown(3)
  CountDown(2)
    CountDown(1)
      CountDown(0) → stop

Each active call has its own stack frame and local state.

3 of 4
STEP 4 OF 4

Trees are naturally recursive

InOrder(node)
  InOrder(node.Left)
  visit node
  InOrder(node.Right)

A subtree has the same structure as the whole tree, so the same routine can process it.

4 of 4
WORKED EXAMPLE

Trace CountDown(3)

Identify the base case, then follow each call.

public static void CountDown(int n)
{
    if (n == 0) return;

    Console.WriteLine(n);
    CountDown(n - 1);
}

Stop at 0

returns immediately
