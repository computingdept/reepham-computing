Router/default gateway

Explain the mechanism or trace the intermediate stage.

STEP 3 OF 3

Remote network

Within the LAN, NICs form frames and the switch forwards using MAC addresses. To reach another IP network, traffic is sent to a router/default gateway that forwards packets. The gateway rewrites the link framing per next hop.

FOUNDATION · QUESTION 1 OF 3

Differentiate switch, router and access point with their forwarding roles. [6]

MARK SCHEME / WORKED ANSWER

Switch forwards LAN frames via MAC [2], router forwards IP packets among networks [2], AP connects wireless clients onto LAN [2].

APPLICATION · QUESTION 2 OF 3

For a PC accessing a website, explain why both MAC and IP addresses are useful. [6]

MARK SCHEME / WORKED ANSWER

IP identifies destination and enables routing [3]; MAC delivers frames on local link/next hop [3].
