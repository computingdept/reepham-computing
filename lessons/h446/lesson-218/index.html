LESSON 218 · DIJKSTRA I

Find the shortest route

By the end you can:

  • Explain when Dijkstra's algorithm is useful
  • Choose the next node and update the best distances
  • Find a shortest route and show working in an exam question

Key words: weighted graph · node · edge · best distance · previous node

NEW LEARNING · THE PROBLEM

Which route costs the least?

Dijkstra's algorithm finds the shortest route through a weighted graph.

Nodes

Places or points in a network.

Edges

Connections between nodes.

Weights

The cost or distance of each connection.

Where is it useful? Road journeys, delivery routes and network connections.
Important: Dijkstra requires all edge weights to be zero or greater.
I DO · EXPLAIN

What is a best distance?

The best distance is the shortest total cost we have found so far from the starting node.

A → B → C

A→B costs 3. B→C costs 2. So the route A→B→C costs 5.

We are comparing whole routes from the start, not individual edge weights.

I DO · MODEL

The four decisions in Dijkstra

  1. Put 0 at the start. Other nodes begin at ∞ (no route found yet).
  2. Choose the unvisited node with the smallest best distance.
  3. Check its neighbours. Update a distance only when the new route is shorter.
  4. Record the previous node so we can rebuild the final route.

Repeat until the destination has been visited.

Use Dijkstra's algorithm to find the shortest route from S to T. Show the order of nodes visited and your distance updates. [6]

On paper: show best distances and previous nodes, then state the route and its total cost.

MARK SCHEME

[6] Start S=0, A=3 and B=8 [1]. Visit A because its total is 3 [1]. Improve B to 5 via A [1]. Set T to 12 via A [1]. Visit B and improve T to 7 [1]. Route S→A→B→T, total cost 7 [1].

EXAM EXTENSION · 3 MARKS

Explain why Dijkstra's algorithm is appropriate for a road network whose distances are all non-negative. [3]

MARK SCHEME

[3] A road network can be represented as a weighted graph [1]. Dijkstra finds a shortest route using the weights [1]. It works correctly when edge weights are non-negative [1].

True or false?

Dijkstra chooses the next unvisited node by its smallest total distance from the start.

Model answer

True. We choose the shortest total distance from the start, not the smallest single edge weight.
