I DO · MODEL

Encode AAAAABBCCC using (count,symbol) pairs; verify the result.

STEP 1 OF 3

AAAAA | BB | CCC

Predict the first step from the prompt.

STEP 2 OF 3

(5,A)(2,B)(3,C)

Explain the intermediate result or decision.

STEP 3 OF 3

Decode original

AAAAA =5A, BB=2B, CCC=3C. Encoded result (5,A)(2,B)(3,C); decoded data restores AAAAABBCCC exactly.

WE DO · DIFFERENT PROBLEM

Encode ABABAB as count-symbol pairs, and explain whether RLE helps.

STEP 1 OF 3

A B A B A B

Predict the first step from the prompt.

STEP 2 OF 3

Six single runs

Explain the intermediate result or decision.

STEP 3 OF 3

Encoded size increases

Six runs of length 1 give (1,A)(1,B) repeated three times. A simple pair encoding uses 12 units for a 6-character input; RLE expands it, ignoring headers.

FOUNDATION · QUESTION 1 OF 3

Apply RLE to AAAABBBCCAAAA using count-symbol pairs. [6]

MARK SCHEME / WORKED ANSWER

(4,A)(3,B)(2,C)(4,A); one mark per correct run/length and two for correct ordered output.

APPLICATION · QUESTION 2 OF 3

Decode (3,X)(1,Y)(2,X) and explain why runs must retain order. [5]

MARK SCHEME / WORKED ANSWER

XXXYXX [3]; order preserves original position, merging separated X runs changes sequence [2].

CHALLENGE · QUESTION 3 OF 3

A bitmap row has 40 alternating pixels. Explain why RLE might increase file size and identify a better-suited pattern. [8]

MARK SCHEME / WORKED ANSWER

40 runs of length one [2], count overhead expands stream [2], long blocks of identical pixels compress well [2], quantified or contextual comparison [2].

True or false?

RLE always reduces the size of any input.

Model answer

False. Frequent symbol changes create many short runs and can increase size.
