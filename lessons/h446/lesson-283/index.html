NEW LEARNING · CONCRETE EXAMPLE FIRST
User enters https://school.example/
DNS resolver supplies an IP address
TCP connection to destination port 443
TLS secures the connection; HTTPS transfers content
STEP 1 OF 3

Start with a hostname

The browser uses DNS (an application-layer protocol) to resolve school.example to an IP address. A cached result may avoid further queries.

STEP 2 OF 3

Understand four layers

Application supports services such as HTTP(S), DNS and SMTP; transport includes TCP and UDP; internet uses IP; link transfers frames on the local connection.

STEP 3 OF 3

Build an HTTPS connection

A browser normally establishes TCP to port 443, negotiates TLS, then exchanges encrypted HTTP requests and responses. DNS lookup happens first if the IP is unknown.

I DO · WORKED EXAMPLE

A user opens https://library.example. Explain what DNS, TCP and HTTPS each do.

STEP 1 OF 3

Name resolution

The resolver returns the IP address for library.example (or uses a cached answer).

STEP 2 OF 3

Transport connection

TCP establishes a connection to the server, typically destination port 443.

STEP 3 OF 3

Application exchange

TLS secures the connection; HTTPS carries the page request and response.

WE DO · DIFFERENT GUIDED TASK

A pupil sends email using SMTP. Place SMTP, TCP and IP into the correct TCP/IP layers.

STEP 1 OF 2

Identify the application

SMTP is an application-layer protocol for transferring outgoing email.

STEP 2 OF 2

Identify the other layers

TCP provides reliable transport for SMTP; IP handles inter-network addressing and routing; link delivers frames on each local link.

EXAM QUESTION 1 OF 4 · 5 MARKS · 5 MINUTES

A school app exchanges PRIVATE online messages using TCP/IP. Describe FIVE application-layer operations involved in sending or receiving encrypted messages. [5]

OCR H446/01 · June 2022 · Q6(b)(i) · RHS exam-style scenario

MODEL ANSWER · 5 MARKS

Choose a service-appropriate secure protocol such as HTTPS for web-based messaging; prepare message/application data; apply encryption via the app security protocol; pass outgoing data to transport; receive data from transport, decrypt as required and present content.

Marking: Up to five distinct appropriate application-layer steps. Do not list HTTP as a secure protocol in this scenario.

EXAM QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

State TWO operations handled at TCP/IP's LINK layer as the messages cross the school's Wi-Fi network. [2]

OCR H446/01 · June 2022 · Q6(b)(ii) · RHS exam-style scenario

MODEL ANSWER · 2 MARKS

Encapsulate data in local frames with MAC addressing and transmit frames over the local wireless link; reverse when receiving.

Marking: One for framing or MAC addresses, one for sending/receiving through link or transferring back to internet layer.

EXAM QUESTION 3 OF 4 · 3 MARKS · 3 MINUTES

The sports centre's network protocols are arranged in layers. Explain three benefits of layering rather than designing a single monolithic protocol. [3]

OCR H446/01 · June 2023 · Q1(d)(iv) · RHS exam-style scenario

MODEL ANSWER · 3 MARKS

Each layer has a defined task; a layer hides implementation details from others; developers can change/test one layer without rewriting the whole system; separate standards aid interoperability and fault isolation.

Marking: One mark per distinct reason for protocol layering, maximum three. Repetition of 'easier' without explaining the specific benefit is not enough.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 3 MARKS · 3 MINUTES

A pupil enters a website's domain name into a browser. Explain how DNS allows the browser to find the web server. [3]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 3 MARKS

A DNS resolver looks up the domain name, querying DNS servers if the result is not cached. DNS returns the associated IP address, which the browser uses to connect to the web server.

Marking: One mark for looking up the domain name using DNS; one for obtaining the associated IP address; one for using the address to contact the server.

TERM 1 OF 5

application layer

Protocols offering services to applications, including DNS and HTTP.

TERM 2 OF 5

transport layer

End-to-end transport protocols such as TCP and UDP.

TERM 3 OF 5

internet layer

Network addressing and forwarding using IP.

TERM 4 OF 5

link layer

Local transfer of frames over media such as Ethernet or Wi-Fi.

TERM 5 OF 5

DNS

Domain Name System; supports name-to-address resolution.
