QUESTION 2 · MODEL ANSWER · 5 MARKS

Complete Reserve: reject non-positive requests or insufficient seats; otherwise subtract and return true. [5]

public bool Reserve(int requested) {
 if (requested <= 0 || requested > remaining) return false;
 remaining -= requested;
 return true;
}

Indicative marking points (one each):

  1. Declares public bool Reserve(int requested).
  2. Rejects requested <= 0.
  3. Rejects requested > remaining.
  4. Subtracts a valid requested value from remaining.
  5. Returns true after a successful reservation.
