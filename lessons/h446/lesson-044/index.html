OCR H446 · 1.4.2

Separate blueprint and instance

Student pupil = new Student();
pupil.Name = "Asha";

class Student {
 public string Name = "";
}
THINK

Class ≠ instance

A class defines the fields and behaviour available to each object. new Student() constructs an instance; a separate new creates another independent object.

Connect to prior knowledge
MODELLED EXAMPLE

One class, two independent objects

using System;

Badge amber = new Badge();
Badge blue = new Badge();
amber.Add(2);
Console.WriteLine(amber.Points + "," + blue.Points);

class Badge {
    public int Points = 0;
    public void Add(int n) { Points += n; }
}
One complete worked example
STEP 1

Identify class, objects and members

Badge is the class (blueprint). amber and blue are references to two objects. Each has its own Points field and can run the Add method.

STEP 2

Trace the state change

new Badge() creates each object with Points = 0. amber.Add(2) changes amber’s field from 0 to 2; blue remains at 0 because it is a different instance.

STEP 3

Predict, then check the output

The output is 2,0. A class definition does not create an object. A method call on one object does not automatically change the fields of another.

GUIDED PRACTICE

Different class, different data

using System;
Counter first = new Counter();
Counter second = new Counter();
first.Increase();
first.Increase();
Console.WriteLine(first.Value + "," + second.Value);

class Counter {
 public int Value = 0;
 public void Increase() { Value++; }
}

What are first.Value and second.Value?

Example 1 of 2
YOUR TURN

Trace both instances

Start with separate fields: first = 0, second = 0. Track which object receives each method call before revealing the result.

MODEL ANSWER

Independent state

first.Value = 2 and second.Value = 0. Both calls act on first; they do not change second.

GUIDED PRACTICE

Change the receiver

Continue from Example 1: second.Increase(); What values are stored now? Explain what second identifies.

Example 2 of 2
YOUR TURN

Predict before checking

Which instance runs Increase()? Which instance field changes?

MODEL ANSWER

Targeted update

first.Value = 2; second.Value = 1. The variable second refers to the second created Counter instance.
