OOP · Design a Class Model

class LibraryBook {
  private bool onLoan = false;
  public string Title { get; }
  public LibraryBook(string title) { Title = title; }
  public bool Borrow() {
    if (onLoan) return false;
    onLoan = true;
    return true;
  }
}
THINK

Explain the design decision

Choose meaningful classes from the scenario, then decide which data each object owns and which methods enforce rules.
