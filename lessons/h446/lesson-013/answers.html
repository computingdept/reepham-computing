1. Display the board with sequence

Each Console.WriteLine() runs in order. You can produce the whole board without a loop.

Console.WriteLine("1 | 2 | 3");
Console.WriteLine("--+---+--");
Console.WriteLine("4 | 5 | 6");
Console.WriteLine("--+---+--");
Console.WriteLine("7 | 8 | 9");

2. Change the middle value

Change the third WriteLine statement to show X rather than 5.

Console.WriteLine("4 | X | 6");

Works, but makes moves difficult to maintain because the board is stored as printed text.

3. Store the nine values in a two-dimensional array

Declare the board as string[,] and change its middle cell using row 1 and column 1.

string[,] board = {
    { "1", "2", "3" },
    { "4", "5", "6" },
    { "7", "8", "9" }
};
board[1,1] = "X";

Indexes start at zero.

4. Output data from the array without loops

The three statements still follow sequence, but they now display the array values. They work after a move changes an array element.

Console.WriteLine(board[0,0] + " | " + board[0,1] + " | " + board[0,2]);
Console.WriteLine(board[1,0] + " | " + board[1,1] + " | " + board[1,2]);
Console.WriteLine(board[2,0] + " | " + board[2,1] + " | " + board[2,2]);

Notice: the only changing part of these statements is the row index. This is why iteration is useful next lesson.
