CODING CHALLENGE 1

Recursive countdown

using System;

public class Program
{
    public static void Main()
    {
        Countdown(5);
    }

    public static void Countdown(int number)
    {
        if (number == 0)
        {
            return;
        }

        Console.WriteLine(number);
        Countdown(number - 1);
    }
}

Why it works: each recursive call reduces number by 1. When it reaches 0, the base case stops further calls.

Countdown(5) → 5 4 3 2 1
CODING CHALLENGE 2

Recursive SumTo

using System;

public class Program
{
    public static void Main()
    {
        Console.WriteLine(SumTo(4));
    }

    public static int SumTo(int number)
    {
        if (number == 1)
        {
            return 1;
        }

        return number + SumTo(number - 1);
    }
}

Why it works: the method keeps solving a smaller problem until number == 1, then the returned values unwind back through the calls.

SumTo(4) → 10SumTo(6) → 21
CODING CHALLENGE 3

Recursive and iterative versions

using System;

public class Program
{
    public static void Main()
    {
        Console.WriteLine(SumTo(6));
        Console.WriteLine(SumToLoop(6));
    }

    public static int SumTo(int number)
    {
        if (number == 1)
        {
            return 1;
        }

        return number + SumTo(number - 1);
    }

    public static int SumToLoop(int number)
    {
        int total = 0;

        for (int i = 1; i <= number; i++)
        {
            total = total + i;
        }

        return total;
    }
}

Comparison: both methods solve the same problem. The recursive version uses repeated method calls; the iterative version uses a loop and accumulator.

SumTo(6) → 21SumToLoop(6) → 21
CODING CHALLENGE 4

Power of two

using System;

public class Program
{
    public static void Main()
    {
        Console.WriteLine(PowerOfTwo(5));
    }

    public static int PowerOfTwo(int exponent)
    {
        if (exponent == 0)
        {
            return 1;
        }

        return 2 * PowerOfTwo(exponent - 1);
    }
}

Trace for exponent 3: 2 × PowerOfTwo(2) → 2 × 2 × PowerOfTwo(1) → 2 × 2 × 2 × PowerOfTwo(0) → 8.

PowerOfTwo(0) → 1PowerOfTwo(3) → 8PowerOfTwo(5) → 32
