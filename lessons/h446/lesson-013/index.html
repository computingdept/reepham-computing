QUESTION 1 OF 4

Last lesson

What is the difference between passing an integer parameter by value and using ref?

ANSWER

By value: the method receives a copy. ref: the method can change the original variable.

QUESTION 2 OF 4

2–3 lessons back

What is the difference between a function and a procedure-style method?

ANSWER

A function returns a value. A procedure-style method uses void and does not return a value.

QUESTION 3 OF 4

Earlier retrieval

Which loop is normally used when the number of repetitions is known in advance?

ANSWER

A for loop.

It is the usual choice for count-controlled iteration.

QUESTION 4 OF 4

Challenge

What will this output: for (int i = 3; i >= 1; i--) Console.WriteLine(i);?

ANSWER

3 · 2 · 1

The counter starts at 3 and decreases by 1 while it remains at least 1.

C# QUICK REFERENCE

A method can call itself

public static int SumTo(int number)
{
    if (number == 1)
    {
        return 1;
    }

    return number + SumTo(number - 1);
}
Two essentials: a base case that stops the recursion, and a recursive call that moves closer to that base case.
STEP 1 OF 4

Recursion = a method calls itself

Each call gets its own parameter values and local variables. The calls build up until the method reaches a stopping condition.

Without a reachable stopping condition, the method keeps calling itself.
1 of 4
STEP 2 OF 4

The base case stops the calls

if (number == 1)
{
    return 1;
}

The base case produces a result without making another recursive call.

Ask: “What is the smallest version of this problem that I already know how to solve?”
2 of 4
STEP 3 OF 4

The recursive case moves toward the base case

return number + SumTo(number - 1);

The method solves a smaller version of the same problem. Here, number decreases by 1 each time.

If the input does not move toward the base case, the recursion will not terminate correctly.
3 of 4
STEP 4 OF 4

Calls build up, then unwind

SumTo(4)
4 + SumTo(3)
    3 + SumTo(2)
        2 + SumTo(1)
            1

then return:
2 + 1 = 3
3 + 3 = 6
4 + 6 = 10

Recursive traces are clearest when you show the calls going down and the returned values coming back up.

Worked example
STEP 1 · FIND THE BASE CASE

Where does recursion stop?

if (number == 1)
{
    return 1;
}

When number reaches 1, there is no further recursive call.

STEP 2 · WRITE EACH CALL

Build the call trace

SumTo(4)
→ 4 + SumTo(3)
→ 4 + 3 + SumTo(2)
→ 4 + 3 + 2 + SumTo(1)

Each call uses a smaller value and therefore moves toward the base case.

STEP 3 · HIT THE BASE CASE

Now the calls can return

SumTo(1) → 1

The deepest call now has a value to return to the previous call.

STEP 4 · UNWIND

Work back outwards

SumTo(2) → 2 + 1 = 3
SumTo(3) → 3 + 3 = 6
SumTo(4) → 4 + 6 = 10
SumTo(4) returns 10.
