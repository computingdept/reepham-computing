BRIDGE TO TIC TAC TOE

Think row, then column

string[,] board =
{
    { "1", "2", "3" },
    { "4", "5", "6" },
    { "7", "8", "9" }
};

board[1,2] = "6";
Rule: first index = row, second index = column.
STEP 1 OF 4

Declare a 2D array

string[,] board = new string[3,3];

[,] means two dimensions. This board has 3 rows and 3 columns.

1 of 4
STEP 2 OF 4

Access one position

board[0,0] = "X";
board[2,1] = "O";

Indexes start at 0. [2,1] means row 2, column 1.

2 of 4
STEP 3 OF 4

Get each dimension

board.GetLength(0)  // rows
board.GetLength(1)  // columns

Dimension 0 is rows; dimension 1 is columns.

3 of 4
STEP 4 OF 4

Traverse with nested loops

for (int row = 0; row < board.GetLength(0); row++)
{
    for (int col = 0; col < board.GetLength(1); col++)
    {
        Console.WriteLine(board[row,col]);
    }
}

The outer loop changes row. The inner loop moves across every column in that row.

Worked example
STEP 1 · OUTER LOOP

Move through rows

for (int row = 0;
     row < board.GetLength(0);
     row++)

row will be 0, 1, then 2.

STEP 2 · INNER LOOP

Move across columns

for (int col = 0;
     col < board.GetLength(1);
     col++)

For each row, col will be 0, 1, then 2.

STEP 3 · ACCESS

Use both indexes

Console.Write(board[row,col] + " ");

The current row and column identify exactly one cell.

STEP 4 · NEW LINE

Finish each row

Console.WriteLine();

Place this after the inner loop so each board row prints on a new line.
