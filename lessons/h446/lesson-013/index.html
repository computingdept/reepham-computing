STEP 1 OF 4

The board is a 2D array

board[row,column]

board[0,0] = "1"
board[1,1] = "5"
board[2,2] = "9"

First index = row. Second index = column.

1 of 4
STEP 2 OF 4

Get each dimension

board.GetLength(0)  // rows
board.GetLength(1)  // columns

This avoids hard-coding the number of rows and columns.

2 of 4
STEP 3 OF 4

Use nested loops

for (int row = 0; row < board.GetLength(0); row++)
{
    for (int col = 0; col < board.GetLength(1); col++)
    {
        // use board[row,col]
    }
}

The inner loop traverses each column in the current row.

WORKED EXAMPLE

Build DrawBoard()

Turn the 2D array into a readable board.

1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
Worked example
STEP 1 · ROWS

Outer loop

for (int row = 0; row < board.GetLength(0); row++)

Move from row 0 to the final row.

STEP 2 · COLUMNS

Inner loop

for (int col = 0; col < board.GetLength(1); col++)

Move across every column in the current row.

STEP 3 · PRINT

Display each square

Console.Write(board[row,col]);

if (col < board.GetLength(1) - 1)
{
    Console.Write(" | ");
}

Add separators between cells, not after the last cell.

STEP 4 · ROW SEPARATOR

Finish the board

Console.WriteLine();

if (row < board.GetLength(0) - 1)
{
    Console.WriteLine("--+---+--");
}

Each row ends on a new line.
