Assembly language and addressing modes

By the end, you can…
  • Explain immediate, direct, indirect and indexed addressing
  • Compute the value fetched from a supplied memory table
  • Distinguish generic ISA syntax from OCR LMC mnemonics

Key vocabulary

immediatedirectindirectindexedeffective address
NEW LEARNING · CODE FIRST

Trace the example

// Educational GENERIC assembly notation — NOT LMC syntax
// Index register X = 2
// M[20]=7, M[21]=20, M[22]=3
MOV R,#5      // immediate: 5
MOV R,[20]    // direct: M[20]=7
MOV R,[[21]]  // indirect: M[M[21]]=7
MOV R,[20+X]  // indexed: M[22]=3
STEP 1 OF 3

Literal versus location

Immediate addressing embeds a literal value; direct addressing points to the memory address holding a value.

STEP 2 OF 3

Follow a pointer for indirect

M[21] contains 20, so an indirect read through address 21 accesses M[20]=7.

STEP 3 OF 3

Calculate indexed address

Base 20 plus index X=2 gives effective address 22 and value 3. These operand formats are generic examples rather than LMC syntax.

I DO · FULL MODEL

M[30]=4, M[31]=30, M[32]=9, X=2. Evaluate #6, [30], [[31]], [30+X].

#6=6
[30]=M[30]=4
[[31]]=M[M[31]]=M[30]=4
[30+X]=M[32]=9
STEP 1 OF 2

Predict

Immediate is literal 6; direct gets 4 from memory address 30.

STEP 2 OF 2

Explain

Indirect follows pointer 30 stored at 31 to value 4; indexed adds offset 2 to base 30 to read 9.

WE DO · DIFFERENT PROBLEM

M[40]=12, M[41]=42, M[42]=5, X=2. Evaluate #8, [40], [[41]], [40+X].

#8=8; [40]=12
[[41]]=M[M[41]]=M[42]=5
[40+X]=M[42]=5
STEP 1 OF 2

Predict

Immediate returns 8; direct reads M[40]=12.

STEP 2 OF 2

Explain

M[41] points to address 42, so indirect reads 5. Indexed base 40+2 reads M[42]=5.

Foundation · 4 marks · QUESTION 1 OF 3

Define immediate, direct, indirect and indexed addressing.

WORKED ANSWER

[4] Immediate literal value in instruction [1]; direct location holds data [1]; indirect location holds another address [1]; indexed effective address is base+index [1].

Core · 6 marks · QUESTION 2 OF 3

Given M[10]=3, M[11]=10, M[12]=9 and X=2, find #4, [10], [[11]] and [10+X], explaining both address calculations.

WORKED ANSWER

[6] Immediate=4 [1]; direct M[10]=3 [1]; indirect first reads M[11]=10 [1], then M[10]=3 [1]; indexed address 10+2=12 [1], contents 9 [1].

Stretch · 6 marks · QUESTION 3 OF 3

An array of 16-bit values begins at byte address 100. Find byte address of array[3] and explain why base+3 would be wrong for byte-addressed memory.

WORKED ANSWER

[6] Array index 3 is fourth element [1]; each 16-bit element occupies 2 bytes [1]; displacement 3×2=6 bytes [2]; effective address 106 [1]; base+3 ignores element size [1].

TERM 1 OF 5

immediate

Operand value encoded as a literal.

TERM 2 OF 5

direct

Memory address of data specified in instruction.

TERM 3 OF 5

indirect

Specified memory holds a further effective address.

TERM 4 OF 5

indexed

Base address modified by index or displacement.

TERM 5 OF 5

effective address

Final memory location used for operand access.

True or false?

Indirect addressing returns the pointer value itself rather than following the pointer.

Model answer

False. Indirect addressing uses the pointer to find the actual operand location.
