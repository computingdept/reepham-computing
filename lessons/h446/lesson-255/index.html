Trace the mechanism

// Educational illustration (not a real ISA):
// CISC-like: ADD_MEM result, A, B
// RISC-like: LOAD R1, [A]
//            LOAD R2, [B]
//            ADD R3, R1, R2
//            STORE [result], R3
// Both compute result = A+B.
STEP 1 OF 3

RISC approach

Typically favours a smaller set of comparatively simple, regular instructions, often using explicit load/store operations.

STEP 2 OF 3

CISC approach

Can offer complex instructions that express several low-level operations in one instruction, potentially improving code density.

STEP 3 OF 3

Avoid oversimplifying

Fewer instructions in assembly do not guarantee fewer clock cycles. Actual performance depends on pipelining, decoding, caching and processor design.

I DO · FULL MODEL

Explain why a load/store architecture needs separate load and add instructions.

LOAD R1,[X]
LOAD R2,[Y]
ADD R3,R1,R2
STEP 1 OF 2

Predict first

Values are brought from memory into registers before the arithmetic instruction.

STEP 2 OF 2

Explain and check

A regular load/store instruction set simplifies certain datapaths but may need more assembly instructions.

WE DO · DIFFERENT QUESTION

Two instruction sets compute and store A+B. One offers a single memory-add; the other requires four steps. Does one automatically run faster?

1 complex instruction vs 4 simpler instructions
Time also depends on cycles/decoding/cache.
STEP 1 OF 2

Predict first

The complex ISA version uses fewer listed instructions but could require more work per instruction.

STEP 2 OF 2

Explain and check

Evaluate clock cycles, decode overhead, code size, memory behaviour and hardware rather than choosing by instruction count alone.

Foundation · 4 marks · QUESTION 1 OF 3

State two characteristics of RISC and two of CISC.

WORKED ANSWER

[4] RISC typically simpler/regular instructions [1] and load/store designs [1]; CISC permits richer complex instructions [1] and often variable instruction lengths or complex addressing [1].

Core · 6 marks · QUESTION 2 OF 3

Compare one CISC-style memory-add instruction against a RISC-style LOAD, LOAD, ADD, STORE sequence for the same task.

WORKED ANSWER

[6] The compound instruction can express more work in one opcode [2]; RISC separates memory access and arithmetic [2]; number of instructions is not the same as measured execution time [2].

Stretch · 6 marks · QUESTION 3 OF 3

Evaluate the claim 'RISC is always faster because its instructions are simpler'. Include code density, decoding and pipelining.

WORKED ANSWER

[6] Simpler regular instructions may support efficient decoding [1] and pipelining [1]; more instructions may increase code size [1] and fetch demand [1]; complex instructions can improve code density [1]; real performance depends on implementation/workload [1].
