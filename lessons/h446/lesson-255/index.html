//            STORE [result], R3
// Both compute result = A+B.
STEP 1 OF 3

RISC approach

Typically favours a smaller set of comparatively simple, regular instructions, often using explicit load/store operations.

STEP 2 OF 3

CISC approach

Can offer complex instructions that express several low-level operations in one instruction, potentially improving code density.

STEP 3 OF 3

Avoid oversimplifying

Fewer instructions in assembly do not guarantee fewer clock cycles. Actual performance depends on pipelining, decoding, caching and processor design.

1 complex instruction vs 4 simpler instructions

Does using fewer instructions always mean faster execution?

EXAM QUESTION 1 OF 4 · 4 MARKS · 4 MINUTES

Compare two different technical characteristics of these approaches. [4]

GIVEN INFORMATION

A robotics company is evaluating a RISC processor against a CISC processor.

OCR H446/01 · June 2025 · Q2(a)(iii) · RHS exam-style scenario

MODEL ANSWER · 4 MARKS

Examples of paired contrasts: RISC has a smaller/simple instruction set versus the larger/complex CISC set; RISC instructions commonly need fewer cycles versus complex CISC instructions that may use more; RISC may be easier to pipeline whereas CISC may be harder; RISC hardware tends to be less complex.

Marking: Award two marks per full, same-feature RISC-versus-CISC comparison; maximum four. Listing unrelated statements without a matched contrast does not earn full comparison credit.

RHS ADDITIONAL PRACTICE · QUESTION 2 OF 4 · 2 MARKS · 2 MINUTES

Explain why a RISC instruction set can make a processor easier to pipeline than a CISC instruction set. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

RISC instructions tend to be simpler and more uniform, making their execution stages more predictable and easier to overlap in a pipeline.

Marking: One mark for relatively simple/uniform instructions; one for explaining the benefit to predictable pipeline stages.

RHS ADDITIONAL PRACTICE · QUESTION 3 OF 4 · 2 MARKS · 2 MINUTES

A CISC processor performs a complex operation with one instruction, while a RISC processor uses several simpler instructions. Give one possible advantage and one possible disadvantage of using CISC in this situation. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

Advantage: fewer machine instructions may be needed for the task, potentially reducing code size. Disadvantage: the complex instruction may take more cycles or require more complex decoding.

Marking: One mark for a plausible instruction-count/code-size benefit; one for a plausible decode or execution-complexity drawback.

RHS ADDITIONAL PRACTICE · QUESTION 4 OF 4 · 2 MARKS · 2 MINUTES

A robotics programmer is told that every RISC instruction completes in exactly one clock cycle. Explain why this claim is an oversimplification. [2]

RHS original follow-on question · linked to this lesson's exam practice

MODEL ANSWER · 2 MARKS

RISC designs favour simple instructions, but actual execution can take multiple cycles due to memory access, pipeline stalls or particular instruction types. A simple instruction set does not guarantee one-cycle completion for every instruction.

Marking: One mark for rejecting the universal one-cycle claim; one for a valid reason such as memory waits or stalls.
