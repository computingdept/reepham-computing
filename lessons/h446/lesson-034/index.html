SECTION A · 1.4.1 DATA TYPES · 15 MARKS

Answer all questions

A1. Convert denary −8 to:
(a) an 8-bit sign-and-magnitude binary number. [1]
(b) an 8-bit two's-complement binary number. [1]

A2. The mask 10101010 is applied to 01010101.
(a) Show the result of an AND operation. [1]
(b) Show the result of an OR operation. [1]

A3. Two floating-point numbers use an 8-bit mantissa followed by a 4-bit exponent, both in two's complement.
Calculate the first number minus the second. Show your working and give your answer in normalised floating-point form using an 8-bit two’s-complement mantissa and a 4-bit two’s-complement exponent.
01001100 0011 − 01001010 0010 [5]

A4. Show denary −119 in 8 bits using:
(a) sign and magnitude. [1]
(b) two's complement. [1]

A5. The floating-point number 00011010 0010 uses an 8-bit mantissa and 4-bit exponent.
(a) State whether it is normalised. [1]
(b) Explain how you know. [1]

A6. Explain how a bit shift can divide the unsigned binary number 00101100 by 4. [2]

SECTION B · 1.4.2 DATA STRUCTURES · 15 MARKS

Answer all questions

B1. An airline stores direct connections/prices between cities. State one suitable data structure. [1]

B2. Describe one difference between an array and a linked list. [2]

B3. Describe what is meant by the term linked list. [3]

B4. A linked list currently represents:
London → Oxford → Birmingham → Manchester → null
It must become:
London → Oxford → Manchester → York → null
Explain how Birmingham is removed and York is added by changing the stored pointers. [4]

B5. Customer records are frequently searched using Customer ID. Explain why a hash table is better suited than a linked list as the number of customers increases. [4]

B6. Give one advantage of storing searchable words in a binary search tree rather than an array. [1]

SECTION C · 1.4.3 BOOLEAN ALGEBRA · 15 MARKS

Answer all questions

C1. A cinema gives a discount if either:
• the customer is under 18 and has a student card, or
• the customer is over 60 and has suitable ID.
Let A = under 18, B = student card, C = over 60, D = ID, Q = discount issued.
Write the Boolean expression for Q. [3]

C2. State the purpose of a D-type flip-flop. [1]

C3. Simplify each expression:
(a) ¬¬A [1]
(b) (¬A ∧ ¬B) [1]
(c) ¬(¬A ∧ ¬B) [1]

C4. A half adder has inputs A and B and outputs Sum and Carry. Draw the half-adder using logic gates. [3]

C5. For a full adder, write the Boolean expression for output S using A, B and Cin. [1]

C6. Simplify the following four-variable Karnaugh map. Show valid groupings and give the final Boolean expression. [4]

CD \ AB00011110
001111
011100
110000
100011
