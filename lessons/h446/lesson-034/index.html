QUESTION 1 OF 4 · LAST LESSON · L033 · LINEAR PROBING

Retrieval

In a seven-bucket hash table, a collision occurs at bucket 6. Which bucket is checked next by linear probing, and why?

MODEL ANSWER

Bucket 0: (6 + 1) MOD 7 = 0, so probing wraps around.

QUESTION 2 OF 4 · RECENT · L032 · C# CONDITIONS

Retrieval

Predict the output of Console.WriteLine((age >= 16) && hasPermission); when age = 17 and hasPermission = false. Explain.

MODEL ANSWER

False. The age test is true but hasPermission is false, so the AND expression is false.

QUESTION 3 OF 4 · OLDER · L022 · BINARY SEARCH TREE

Retrieval

In a binary search tree, a new key is greater than the root but smaller than the root’s right child. Where will it go if that right child has no left child?

MODEL ANSWER

It becomes the left child of the root’s right child.

QUESTION 4 OF 4 · CHALLENGE · L020 · QUEUE DESIGN

Challenge

A print server must process jobs in the order submitted. Choose a suitable data structure and explain why a stack would be unsuitable.

MODEL ANSWER

Use a queue: FIFO serves the earliest job first. A stack uses LIFO and would process the most recently added job first.
