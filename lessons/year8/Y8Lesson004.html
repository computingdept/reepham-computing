The CPU and the cycle

Flashback: instructions and data are processed by the CPU. CPU is an acronym for Central Processing Unit.

The source lesson states that the purpose of the CPU is to fetch instructions from memory, decode them and then execute them.

1 · FetchFetch instructions from memory.
2 · DecodeDecode the instruction.
3 · ExecuteExecute the instruction.
I DoListeningCold Calling

CPU components

CU · Control Unit

Controls the movement of data around your CPU during the fetch–decode–execute cycle.

ALU · Arithmetic Logic Unit

Carries out all the calculations in the CPU.

Cache

Stores currently used data, just like RAM. It is closer to the CPU so instructions can be fetched faster.

Task 2 · A better performing CPU will…

Use the source lesson's key phrases: at the same time, quick access, cycles per second.

More cores

Process instructions at the same time as each other.

Bigger cache

Store more data to be fetched quickly.

Faster clock speed

Complete more fetch–decode–execute cycles every second.

Key terms from the silent-working slide: CPU = Central Processing Unit; ALU = Arithmetic Logic Unit; CU = Control Unit; Cache = small, fast memory inside the CPU; Clock Speed = how many instructions the CPU runs each second.
