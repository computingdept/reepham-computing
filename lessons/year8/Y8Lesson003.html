Random Access Memory

Flashback from the PowerPoint: RAM and ROM are types of memory. The CPU fetches instructions directly from them.

RAM is used to hold

  • The Operating System
  • Open Documents
  • Running Programs

Random Access Memory stores the data and programs that you are currently running.

Volatile

The completed source table states that RAM is volatile and data is wiped when it loses power.

Read Only Memory

ROM stores a start-up program

Read Only Memory stores a program which takes the computer through all the steps to start up the computer.

Non-Volatile
