OCR EXAM REFERENCE LANGUAGE

Check the middle; narrow the range

function binarySearch(dataArray, target, size)
    low = 0
    high = size - 1

    while low <= high
        mid = (low + high) DIV 2

        if dataArray[mid] == target then
            return mid
        elseif dataArray[mid] < target then
            low = mid + 1
        else
            high = mid - 1
        endif
    endwhile

    return -1
endfunction
Precondition: ascending order. Result: an index if found; -1 if absent.
STEP 1 OF 7

Start with the whole array

low = 0
high = size - 1

Eight items have indexes 0–7. The bounds store indexes, not values.

STEP 2 OF 7

Find the middle index

mid = (low + high) DIV 2

Use integer division. With bounds 0 and 7, the middle index is 3.

STEP 3 OF 7

Compare the middle value

dataArray[mid] == target

If it matches, return mid. The returned index identifies where the target was found.

STEP 4 OF 7

Keep the correct half

middle too small: low = mid + 1
middle too large: high = mid - 1

Exclude the middle item: it has already been checked. Ordering makes it safe to discard the other half.

STEP 5 OF 7

Stop when the range is empty

while low <= high

return -1

One remaining item is still checked. If low > high, there are no possible items left.

Example 3 of 3
STEP 1 OF 3

Turn and talk

Why are these replacements incorrect?

high = size
while low < high
low = mid
STEP 2 OF 3

Bounds and final item

high = size can lead to an index outside the array. while low < high skips the final single candidate.

STEP 3 OF 3

Make progress

low = mid can keep the same bounds. For [3, 7], searching for 7 starts with mid = 0 and would keep low = 0 forever. Use mid + 1.
