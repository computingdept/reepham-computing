QUESTION 7 · TEACHER MODEL ANSWER

Sorted data

Ordering lets the algorithm decide which half cannot contain the target. Example: [3, 24, 12, 18, 7, 31, 45, 60], target 24. The first midpoint is index 3, value 18. It sets low = 4 and discards indexes 0–3, including the target at index 1. The search then returns -1 even though 24 is present.

QUESTION 10 · TEACHER MODEL ANSWER

Descending order · stretch

function binarySearchDescending(dataArray, target, size)
    low = 0
    high = size - 1

    while low <= high
        mid = (low + high) DIV 2

        if dataArray[mid] == target then
            return mid
        elseif dataArray[mid] > target then
            low = mid + 1
        else
            high = mid - 1
        endif
    endwhile

    return -1
endfunction
array numbers[8]
numbers = [60, 45, 31, 24, 18, 12, 7, 3]
print(binarySearchDescending(numbers, 24, 8))
print(binarySearchDescending(numbers, 20, 8))

Expected results: 3 and -1. When the middle value is greater than the target, keep the right-hand half. When it is smaller, keep the left-hand half.
