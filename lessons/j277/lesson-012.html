Teacher model

MODEL

Explain what 'fixed length' means for an array.

The array is created with a set number of positions.
Those positions hold multiple values.
Values can change, but the number of positions does not dynamically grow in this model.

GUIDED PRACTICE

Why are arrays useful for search and sort algorithms?

They store a sequence of values.
Algorithms can compare elements by index.
The same algorithm can process each element systematically.
