NEW LEARNING · Read the theory and worked examples before the guided task.

New LearningListening

Computers use two reliable electronic states, represented by 0 and 1. Binary has a place value system in which each column is worth twice the value of the one on its right.

128064032016080402010
An unsigned 8-bit number has 2⁸ = 256 possible patterns. Because counting starts at zero, the range is 0–255.
