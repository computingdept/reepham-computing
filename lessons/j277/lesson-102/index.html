Bubble Sort · starter code

array values[5]
values = [7, 3, 5, 2, 4]

procedure bubbleSort()
    last = 4
    swapped = true

    while swapped == true AND last > 0
        swapped = false
        for i = 0 to last - 1
            if values[i] > values[i + 1] then
                temp = values[i]
                values[i] = values[i + 1]
                values[i + 1] = temp
                swapped = true
            endif
        next i
        last = last - 1
    endwhile
endprocedure

bubbleSort()
for i = 0 to 4
    print(values[i])
next i

STEP 1 OF 5

Compare neighbours

Compare values[i] with values[i + 1]. If the left value is larger, they are in the wrong order.

1 of 5
STEP 2 OF 5

Swap without losing data

Save the left value in temp; copy the right value left; copy temp right.

2 of 5
STEP 3 OF 5

One pass settles the largest remaining value

The largest value in the active range moves to its right-hand end. A pass contains several comparisons.

3 of 5
STEP 4 OF 5

Reduce the active range

Decrease last after each pass. The values beyond last are already in their final positions.

4 of 5
STEP 5 OF 5

Stop early

Reset swapped to false before a pass. If no swaps happen in that complete pass, the array is sorted.
