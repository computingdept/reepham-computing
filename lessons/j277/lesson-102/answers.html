QUESTION 6 · TEACHER MODEL ANSWER

Explain early stopping

The flag records whether any swap occurred in the current pass. Resetting it allows the algorithm to stop after a complete pass with no swaps.
QUESTION 7 · TEACHER MODEL ANSWER

Explain the bound

The comparison accesses i + 1, so i must not exceed last - 1. Each pass settles the largest remaining value at last, so that position can be excluded next time.
QUESTION 8 · TEACHER MODEL ANSWER

Find the error

With [7, 3], values[0] = values[1] produces [3, 3]. Copying values[0] back to values[1] cannot recover 7. The temporary variable preserves 7.
