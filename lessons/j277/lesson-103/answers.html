QUESTION 6 · TEACHER MODEL ANSWER

Explain the saved key

Shifting can overwrite the key's original position. The saved key preserves the value until the gap is ready.
QUESTION 7 · TEACHER MODEL ANSWER

Explain the bounds

j >= 0 keeps the index within the array's left bound. values[j] > key shifts only values larger than the key. Stop when the beginning is reached or the next value belongs before the key.
QUESTION 8 · TEACHER MODEL ANSWER

Find the error

j is the index just before the gap. If every item shifts, j is -1, so j + 1 correctly gives 0. With [3, 7] and key 5, j stops at 0; inserting at 0 would overwrite 3.
QUESTION 9 · TEACHER MODEL ANSWER

Descending order · extension

Change values[j] > key to values[j] < key.
Output: [7, 5, 4, 3, 2]
QUESTION 10 · TEACHER MODEL ANSWER

Count shifts · extension

Sorted: 0 rightward shifts.
Reverse: 1 + 2 + 3 + 4 = 10 rightward shifts.
Every new key in the reverse array must move before the entire sorted section.
