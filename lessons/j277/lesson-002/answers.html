CODE FIRST · WHITEBOARD CODING

Checking binary addition with code

1 · Predict: 00001011 is 11 and 00000110 is 6. Adding these denary values gives 17.

print(11 + 6)

Output: 17. This is 00010001 in eight-bit binary.

2 · Change: Write a single print instruction for 8 + 5.

print(8 + 5)

Output: 13.

3 · Build: Store the result in a variable and then display it.

total = 11 + 6
print(total)

First line: total stores 17. Second line: print(total) displays 17. Then show the carries in the binary addition questions.

QUESTION 2 · BINARY ADDITION

00001011 + 00000110

00001011 + 00000110 = 00010001 (eight-bit result)

11 + 6 = 17. No overflow.

QUESTION 3 · BINARY ADDITION

00110101 + 00010110

00110101 + 00010110 = 01001011 (eight-bit result)

53 + 22 = 75. No overflow.

QUESTION 4 · BINARY ADDITION

01101101 + 00100111

01101101 + 00100111 = 10010100 (eight-bit result)

109 + 39 = 148. No overflow.

QUESTION 5 · BINARY ADDITION

11110000 + 00100000

11110000 + 00100000 = 00010000 (eight-bit result)

240 + 32 = 272, so the full binary result is 1 00010000. The leftmost carry is lost in an eight-bit register: overflow.

QUESTION 6 · LOGICAL SHIFTS · WORKED ANSWER

Shift 00001011 left two places

Start: 00001011 = 8 + 2 + 1 = 11.

Move each bit left two positions and fill zeroes on the right:

00001011
     ↓ left 2
00101100

The result is 00101100 [1], equal to 44 [1] (32 + 8 + 4). This is four times 11 because no set bits were discarded [1].

When an eight-bit logical left shift discards a set bit at the left edge, the eight-bit result no longer equals the full mathematical product. Zeros fill the positions on the right.
