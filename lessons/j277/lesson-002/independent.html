Four binary addition rules
0 + 0 = 0
0 + 1 = 1
No carry is needed.
1 + 1 = 10₂
1 + 1 + 1 = 11₂
Carry 1 into the next column.

Work from right to left, just as with denary addition. For each column, write the right-hand bit and carry any extra 1 left.

I Do · Worked binary addition

Problem: Add 00101101 (45) and 00010111 (23).

00101101
+ 00010111
──────────
01000100

Step 1: rightmost column is 1 + 1 = 10₂. Write 0; carry 1.
Step 2: continue left, including the carry.
Step 3: check: 45 + 23 = 68 = 01000100. No overflow.

Overflow and logical shifts

Overflow: unsigned eight-bit numbers run from 0 to 255. For example, 255 + 1 = 256 requires a ninth bit.

Shift left two: 00010110 → 01011000 (22 → 88).
Shift right one: 00101000 → 00010100 (40 → 20).

A logical shift fills empty positions with zeros. Bits shifted off the end are discarded.
