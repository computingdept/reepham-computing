New Learning · Why hexadecimal?

Binary uses 0 and 1. Hexadecimal uses sixteen possible digits. One hex digit represents exactly four binary bits, so an 8-bit byte can be written using just two hex digits.

VISUAL MODEL · TWO NIBBLES

Split an eight-bit value into two groups of four. Each group becomes one hexadecimal digit.

11118 + 4 + 2 + 1 = 15 → F
11108 + 4 + 2 = 14 → E

11111110₂ = FE₁₆. Remember A=10, B=11, C=12, D=13, E=14, F=15.

REAL-WORLD CONNECTION · RGB COLOURS

An image editor can show green as #00FF00. These are hexadecimal pairs for red, green and blue:

RED00
GREENFF
BLUE00

Hex is easier to read than a long binary pattern. It does not reduce the bits stored.

I Do · Binary → hexadecimal

Convert 11000111 to hexadecimal. Step 1: split into two nibbles. Step 2: work out each nibble using 8–4–2–1. Step 3: replace numbers 10–15 with A–F.

8141201080412111
1100 = 8 + 4 = 12 = C.   0111 = 4 + 2 + 1 = 7.   Answer: C7.
I Do · Convert in both directions

Denary → hex: 62 = 32 + 16 + 8 + 4 + 2 = 00111110 → 0011 | 1110 → 3E.

Hex → denary: A3 = (10 × 16) + 3 = 163. For two hex digits, the left digit counts sixteens.
