MODEL

A bitmap uses a colour depth of 4 bits. How many different colours can be represented?

Use 2^bits.
2⁴ = 16.
So 4 bits can represent 16 colours.

What happens if colour depth increases from 4 bits to 16 bits?

More bits are available for each pixel.
More colours can be represented.
File size increases.
