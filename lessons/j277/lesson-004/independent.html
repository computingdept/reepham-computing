New Learning · How computers store characters

Computers store binary values. A character set connects letters and symbols to numerical codes; the codes can be represented in binary.

VISUAL MODEL · FROM CHARACTER TO CODE TO BITS
A → 65
01000001
B → 66
01000010

These values are examples from ASCII. You should use codes given in questions, not memorise the table.

ASCII vs Unicode: standard ASCII represents a small repertoire. Unicode supports text from many more languages and writing systems. Different Unicode encodings may use different numbers of bytes for characters.

Bits, bytes and storage units
1 nibble = 4 bits    1 byte = 8 bits
1 KB = 1,000 bytes   ·   1 MB = 1,000 KB
For this course use the decimal units given in the question. To convert bits to bytes, divide by 8.
I Do · Follow the worked example

Problem: A text message contains 12 characters, stored using exactly 8 bits each. Calculate the raw data size.

Step 1: 12 characters × 8 bits = 96 bits.

Step 2: 96 ÷ 8 = 12 bytes.

Assumption: every character uses 8 bits in this question. Ignore headers and metadata. Do not assume this applies to all Unicode text.
