Year 10 · Full-Course Synoptic Assessment

45 minutes · 45 marks · OCR J277-style original questions

Name: ________________________________________

Work independently. Show all working, including trace tables. This is an original practice paper, not an official OCR paper.

Q1 · Systems architecture [5 marks]

(a) State the function of the ALU. [1] (b) Describe the role of the program counter during the fetch–decode–execute cycle. [2] (c) Explain one way cache may improve CPU performance. [2]

Q2 · Memory and storage [5 marks]

(a) Give one difference between RAM and ROM. [2] (b) Explain why a portable photographer might choose an SSD rather than a magnetic HDD. [3]

Q3 · Networks and security [6 marks]

(a) State one benefit of a star topology. [1] (b) Explain how a firewall and two-factor authentication each help protect a school network. [4] (c) Name one form of social engineering. [1]

Q4 · Systems software and impacts [5 marks]

(a) Explain how an operating system supports multitasking. [2] (b) Describe one use of utility software. [1] (c) Explain one privacy risk of collecting location data and one way to reduce it. [2]

Q5 · Algorithms and programming [8 marks]

Consider this pseudocode: total = 0 for i = 1 to 4 if i MOD 2 == 0 then total = total + i endif next i print(total) (a) State the output. [1] (b) Complete a trace table showing i and total after each loop iteration. [4] (c) Identify the type of iteration used. [1] (d) Explain why the if statement is selection. [2]

Q6 · Boolean logic [6 marks]

For Q=(A AND B) OR C: (a) Write the intermediate expression X. [1] (b) Complete the Q outputs in order for 000,001,010,011,100,101,110,111. [4] (c) Explain why Q=1 when A=1, B=1, C=0. [1]

Q7 · Translators and IDEs [6 marks]

(a) State one difference between high-level and low-level languages. [2] (b) Compare how a compiler and an interpreter run a program. [2] (c) Describe how a breakpoint and variable watch could help debug a program. [2]

Q8 · Testing and robustness [4 marks]

A program accepts a score from 0 to 100 inclusive. (a) Give one normal, one boundary and one erroneous test value. [3] (b) State one reason for testing erroneous data. [1]
