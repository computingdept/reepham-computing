QUESTION 1 OF 4

Check your thinking

Which two digits are used in binary?

ANSWER

0 and 1.

Binary uses base 2, so each digit is either 0 or 1.

QUESTION 2 OF 4

Check your thinking

What is an algorithm?

ANSWER

A clear sequence of steps for solving a problem.

An algorithm describes the method; it does not have to be written in a particular programming language.

QUESTION 3 OF 4

Check your thinking

What does a loop do in a program?

ANSWER

It repeats instructions.

Iteration lets us repeat instructions instead of writing them many times.

QUESTION 4 OF 4

Check your thinking

CHALLENGE · Why do programmers test their code before saying it is finished?

ANSWER

Testing helps identify errors and check that a program behaves as expected.

A program may run but still give the wrong result; testing helps us find and correct mistakes.

I DO · THE TEACHER MODELS CODE FIRST

What will this code print?

score = 4
score = score + 3
print(score)
Watch the teacher model the four small steps.
1 · PREDICT

Think before running

The variable starts at 4. Adding 3 gives 7.

Prediction: 7
2 · WRITE

Change one thing

Suppose we want the answer to be 9. Change the addition from + 3 to + 5.

score = score + 5
3 · TEST

Run it or trace it

Start at 4. Add 5. The expected output is 9. Check it against your prediction.

Test: 4 + 5 = 9
4 · ITERATE

Learn from the result

If the result is wrong, locate the problem, change one part and test again. Small steps help you understand why it works.

Predict → Write → Test → Iterate. Never just copy a finished answer.

Why Code First?

Give one reason why predicting before running code helps you learn.

MODEL RESPONSE
