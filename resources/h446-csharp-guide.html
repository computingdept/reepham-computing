The standard structure

using System;

public class Program
{
    public static void Main()
    {
        // Main program instructions go here.
        Console.WriteLine("Hello");
    }
}
CodePlace it
using statementsAt the top, before Program
Variables and instructionsInside Main
Functions and proceduresInside Program, but outside Main
This class-and-Main format avoids top-level-statement differences between C# versions and is the standard structure used in these lessons.

1. Variables, input, output and casting

C# declares the data type before the variable name. Console.ReadLine() returns a string; use Parse when a numeric value is required.

using System;

public class Program
{
    public static void Main()
    {
        Console.Write("Enter your name: ");
        string name = Console.ReadLine();

        Console.Write("Enter your age: ");
        int age = int.Parse(Console.ReadLine());

        Console.WriteLine($"Hello {name}. You are {age} years old.");
    }
}
Strings use double quotation marks. Characters use single quotation marks. C# is case-sensitive, and statements normally end with a semicolon.

3. switch selection and for loops

switch / case

using System;

public class Program
{
    public static void Main()
    {
        Console.Write("Enter A, B or C: ");
        string entry = Console.ReadLine();

        switch (entry)
        {
            case "A":
                Console.WriteLine("You selected A");
                break;
            case "B":
                Console.WriteLine("You selected B");
                break;
            case "C":
                Console.WriteLine("You selected C");
                break;
            default:
                Console.WriteLine("Unrecognised selection");
                break;
        }
    }
}

Count-controlled iteration

using System;

public class Program
{
    public static void Main()
    {
        for (int i = 0; i <= 7; i++)
        {
            Console.WriteLine($"Repetition {i}");
        }
    }
}

This loop runs eight times: 0 to 7 inclusive.

4. while loops and the valid Boolean pattern

A while loop tests before it repeats. It is useful when the number of attempts is unknown.

using System;

public class Program
{
    public static void Main()
    {
        bool valid = false;
        int number = 0;

        while (valid == false)
        {
            Console.Write("Enter a number from 1 to 5: ");
            number = int.Parse(Console.ReadLine());

            if (number >= 1 && number <= 5)
            {
                valid = true;
            }
            else
            {
                Console.WriteLine("Invalid - try again.");
            }
        }

        Console.WriteLine($"Accepted: {number}");
    }
}
Valid Boolean pattern: start false. Keep asking while it is false. Set it to true only when the accepted condition is met.

5. do...while loops and strings

OCR's do...until stops when its condition becomes true. C# do...while continues while its condition is true, so the test is reversed.

using System;

public class Program
{
    public static void Main()
    {
        string answer;

        do
        {
            Console.Write("Enter the password: ");
            answer = Console.ReadLine();
        }
        while (answer != "computer");

        Console.Write("Enter a word: ");
        string word = Console.ReadLine();

        Console.WriteLine($"Length: {word.Length}");
        Console.WriteLine($"First: {word[0]}");
        Console.WriteLine($"Last: {word[word.Length - 1]}");

        string text = "Programming";
        Console.WriteLine(text.Substring(3, 4)); // gram
    }
}
Strings are zero indexed. The first character is at index 0; the last is at word.Length - 1.

6. One-dimensional arrays

An array stores a fixed number of values of the same type. OCR and C# arrays are zero indexed.

using System;

public class Program
{
    public static void Main()
    {
        string[] names =
        {
            "Ahmad", "Ben", "Catherine", "Dana", "Elijah"
        };

        for (int i = 0; i < names.Length; i++)
        {
            Console.WriteLine($"Index {i}: {names[i]}");
        }
    }
}
Boundary warning: use i < names.Length, not i <= names.Length.

7. Array algorithms and linear search

using System;

public class Program
{
    public static void Main()
    {
        int[] scores = { 67, 42, 81, 55, 39 };
        int total = 0;
        int passes = 0;
        int highest = scores[0];

        for (int i = 0; i < scores.Length; i++)
        {
            total += scores[i];

            if (scores[i] >= 50)
            {
                passes++;
            }

            if (scores[i] > highest)
            {
                highest = scores[i];
            }
        }

        double average = (double)total / scores.Length;

        Console.WriteLine($"Total: {total}");
        Console.WriteLine($"Average: {average}");
        Console.WriteLine($"Passes: {passes}");
        Console.WriteLine($"Highest: {highest}");
    }
}

Linear search pattern

    {

    }
}

Console.WriteLine(found ? "Found" : "Not found");

8. Two-dimensional arrays

A two-dimensional array stores values in rows and columns. Use nested loops to visit every position.

using System;

public class Program
{
    public static void Main()
    {
        int[,] grid =
        {
            { 1, 2, 3 },
            { 4, 5, 6 }
        };

        int total = 0;

        for (int row = 0; row < grid.GetLength(0); row++)
        {
            for (int column = 0; column < grid.GetLength(1); column++)
            {
                Console.WriteLine(grid[row, column]);
                total += grid[row, column];
            }
        }

        Console.WriteLine($"Total: {total}");
    }
}
ExpressionMeaning
grid.GetLength(0)number of rows
grid.GetLength(1)number of columns
grid[row, column]value at one position

9. Subroutines: functions and procedures

In C#, both OCR functions and procedures are methods. A function returns a value; a procedure uses void and does not return a value.

using System;

public class Program
{
    public static void Main()
    {
        int answer = Triple(7);
        Console.WriteLine(answer);

        Greeting("Hamish");
        Console.WriteLine(IsEven(12));
    }

    public static int Triple(int number)
    {
        return number * 3;
    }

    public static void Greeting(string name)
    {
        Console.WriteLine("Hello " + name);
    }

    public static bool IsEven(int number)
    {
        return number % 2 == 0;
    }
}
Methods are inside the Program class but outside Main. Calls to those methods normally appear inside Main.

10. Passing parameters by value and reference

OCR assumes parameters are passed by value unless it explicitly states byRef.

using System;

public class Program
{
    public static void Main()
    {
        int first = 10;
        ChangeByValue(first);
        Console.WriteLine($"After value: {first}"); // 10

        int second = 10;
        ChangeByReference(ref second);
        Console.WriteLine($"After ref: {second}"); // 100
    }

    public static void ChangeByValue(int number)
    {
        number = 100;
    }

    public static void ChangeByReference(ref int number)
    {
        number = 100;
    }
}
Passing methodMethod receivesOriginal changes?
by valuea copyNo
by reference / refaccess to the originalYes
Write ref in both places: in the method parameter and in the method call.

            }
        }
    }
}
OCR and C# both use // for a single-line comment. Explain purpose rather than simply repeating the instruction.
