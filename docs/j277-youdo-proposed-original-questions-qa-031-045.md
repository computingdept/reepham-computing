## Lesson 031 — Network Attacks

**ID:** `RHS-ORIGINAL-J277-031-Q4-DRAFT` · Q4 · 3 marks

**Question**

> A concert website receives requests from hundreds of compromised computers at the same time. Genuine customers cannot load the booking page.
> 
> Identify the type of attack and explain how it affects the website. [3 marks]

**Proposed answer and marks**

1. Distributed denial-of-service (DDoS) attack [1].
2. Requests come from multiple computers/sources [1].
3. The volume overwhelms service capacity, preventing legitimate access [1].
