### Lesson 103 — Characters and Images

**Specification:** 1.2.4. **Source:** `lessons/j277/autumn2-103.json`.


#### Slot 1: RHS-J277-023 — 3 marks

**OCR source:** OCR J277/01 · June 2022 · Q6(c)

**RHS question text:**

> A photographer uploads an image of a museum collection to a digital archive.
> 
> Identify three pieces of metadata that might be recorded in the image file. [3]

**Verified answer:**

> Any 3 specific metadata fields, such as width, height, bit depth, date, geolocation, format or author.

**Marking rule:** 1 per valid field; avoid vague 'size'/'colour' without defining what is stored.

**Visual/approval:** pending.

#### Slot 2: RHS-J277-067 — 5 marks

**OCR source:** OCR J277/01 · June 2023 · Q3(a)

**RHS question text:**

> A publisher stores letters as binary codes. Complete the five missing terms using the word bank: all, some, repeated, similar, unique, identical, 4, 8, 16, 72, 76, 80.
> 
> (1) A character set stores ___ the characters supported by the system. (2) Each character has a ___ binary value. (3) Uppercase and lowercase versions of the same letter use ___ codes. (4) The ASCII character values in this question use ___ bits. (5) If F is decimal 70, then L is ___. [5]

**Verified answer:**

> all; unique/different; unique/different/similar; 8; 76.

**Marking rule:** Five terms in order, one mark per gap. A word bank is provided in OCR; RHS must include its own bank.

**Visual/approval:** pending.

#### Slot 3: RHS-J277-068 — 1 marks

**OCR source:** OCR J277/01 · June 2023 · Q3(b)(i)

**RHS question text:**

> A wildlife photographer saves bitmap pictures with metadata.
> 
> Explain what metadata means for a digital image. [1]

**Verified answer:**

> Metadata is data describing other data, here a digital image or file.

**Marking rule:** 1 precise definition; simply 'information about the image' may be too vague.

**Visual/approval:** pending.

#### Slot 4: RHS-J277-071 — 2 marks

**OCR source:** OCR J277/01 · June 2023 · Q3(b)(iv)

**RHS question text:**

> A museum increases the colour depth of a stored bitmap to 2 bytes per pixel.
> 
> State two possible effects on the image or its file size. [2]

**Verified answer:**

> Increased possible colours; greater file size/storage; possible quality improvement.

**Marking rule:** Any 2 valid distinct effects; not increased pixel resolution or image dimensions.

**Visual/approval:** pending.
