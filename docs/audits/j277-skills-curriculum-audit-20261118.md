# J277 Skills Curriculum Audit — 18 November 2026

**Status:** Read-only curriculum blueprint. **Scope:** all 164 J277 lesson sources; no changes proposed to existing lesson content, CSS, JS, Skills or paper questions. Matching and teacher sequences below are recommendations for review, not implemented actions.

**Audit source:** [J277 lesson data](https://github.com/computingdept/reepham-computing/tree/main/lessons/j277), [Paper 1 Skills](https://rhsccs.org/exercise/paper1/), [Paper 2 Skills](https://rhsccs.org/exercise/paper2/), and the [prior teaching-progression audit](https://github.com/computingdept/reepham-computing/blob/main/docs/audits/j277-164-lesson-teaching-progression-master-20261023.csv). Lessons 001–003 use legacy HTML and are flagged accordingly. All mappings were assessed from repository source, not projector or browser interaction testing.

**Counts:** 65 strong matches, 48 partial matches, 4 review-only candidates, and 47 lessons without a suitable existing Skill assignment. A 'None' is a valid outcome; do not force Skills into every lesson. The proposed routine is **I Do → teacher-led We Do → Code First (when appropriate) → independent Skills (when suitable) → Call Back → existing paper questions → Exit Ticket**. Existing routine order and assessment exceptions remain protected.

**Match meanings:** Strong = existing tool directly practises the lesson process; Partial = supports only part of the lesson or needs adaptation of the demonstration; Review = link exists but is review-only/not yet classroom-approved; None = no student-ready Skill selected. **Priority** ranks the proposed audit action, not authorisation to modify live lessons. 'Develop later' is only a future idea. Paper 2 **Flowchart Builder**, **Truth Tables**, **Translators & IDEs** and **Synoptic Challenge** are currently marked *planned* in the hub; **Trace Table Lab** routes to a review page and must not be treated as student-ready until checked.
